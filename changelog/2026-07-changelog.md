7월부터 무더운 날씨가 본격적으로 시작되었습니다. 무더위에 건강 관리 유의하길 바라며, 이번 달 **Suprema Docs**에도 반가운 소식이 가득합니다. 온프레미스 서버 없이 클라우드만으로 출입 인증 시스템을 구축할 수 있는 클라우드 매니지드 서비스, 플랫폼 **CLUe**의 이용 가이드를 새롭게 게시했습니다. 이 외에도 CoreStation Setup Manager의 백업/복원 기능, ViOnyx 웹 서버의 RTSP/ONVIF 연동 가이드 등 다양한 문서를 새롭게 추가했습니다. 지금 바로 확인해보세요.

![Suprema Docs 26.07 Changelogs](/img/changelogs/changelogs-202607.png)

{/*truncate*/}

## CLUe 가이드 공개

온프레미스 서버 구축 없이 표준 REST API 연동만으로 출입 인증 시스템을 도입할 수 있는 클라우드 출입 인증 매니지드 서비스, [**CLUe**](../platform/clue/)의 이용 가이드를 새롭게 게시했습니다. 웹 포털과 모바일 앱으로 손쉽게 운영할 수 있습니다.

* [CLUe 웹 포털 가이드](../platform/clue): 관리자 권한 구조, 장치·출입문 설정, 펌웨어 업데이트, 웹훅 설정, 감사 로그 확인 등 CLUe 서비스 운영 전반을 안내합니다.

* [CLUe API](../developer/clue): 사용자 관리와 출입 인증 기능을 직접 연동하려는 개발자를 위한 API 문서입니다.

## Docs

* [쿠키 정책](../cookie) 페이지를 새롭게 게시했습니다. 사이트에서 사용하는 쿠키의 종류와 목적을 안내하며, 최초 방문 시 브라우저 언어 설정에 따라 자동으로 해당 언어 페이지로 안내하는 기능도 함께 추가되었습니다.

* **헤딩 앵커 복사 기능 추가**: 헤딩 앵커의 `#`을 클릭하면 해당 앵커의 해시 ID 값을 포함한 URL 주소를 복사할 수 있습니다.

  ![Copy heading anchor](/img/changelogs/changelog-2607-copy-heading-anchor.png)

* **방향키로 문서 이동**: Suprema Docs 내 문서 페이지에서 키보드 좌, 우 방향키를 누르면 이전 또는 이후 문서로 이동할 수 있습니다.
