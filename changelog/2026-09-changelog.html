2026년 9월

2026년 10월 1일

9월 Suprema Docs에서는 BioStar X 1.0.3 버전과 BioStar Air 2.13 버전에 맞춰 모니터링 일괄 제어, 신분증 스캔, 감사 로그, 구역 및 재실 관리, SSO & SCIM 연동 등 여러 사용 가이드를 추가하고 업데이트했습니다. 또한 BioStation 3, X-Station 2, Device Manager의 릴리스 노트를 공개했습니다.

Docs​

  • 개별 문서 페이지에서 해당 제품의 매뉴얼 PDF를 바로 다운로드할 수 있도록 개선되었습니다.

  • 개별 문서 페이지에서 해당 문서의 최종 업데이트 날짜를 확인할 수 있도록 개선되었습니다.

플랫폼​

BioStar X​

  • 버전 1.0.3: 1.0.3 버전 릴리스 노트 추가

새 문서​

  • 일괄 제어하기: 모니터링에서 여러 출입문, 엘리베이터, 고급 출입 통제를 선택해 한 번에 제어하는 방법 안내

  • 신분증 스캔 설정하기, 신분증 스캔으로 사용자 등록 및 수정하기: 신분증을 스캔해 사용자 정보를 자동으로 입력하는 방법 안내

  • 장기 미출입자 조치하기: 장기 미출입 사용자의 자동 비활성화 기준과 사전 알림 이메일 설정 방법 안내

  • 인증을 통한 출입문 제어 설정하기: 사용자 인증으로 출입문을 수동 개방하거나 해제 상태로 전환하는 방법 안내

  • 감사 로그

    • 출입 통제 감사 로그 조회하기, 감사 설정 관리하기

    • 근태 감사 로그 조회하기, 근태 감사 설정하기

  • BioStar X 서버 제거 및 보안 인증서 복구하기: 서버를 제거하는 방법과 백업한 보안 인증서를 복구하는 방법 안내

문서 업데이트​

  • 사용자 기본 정보 입력하기: 사용자 ID 및 이름 입력 시 특수 문자를 허용하는 규칙 업데이트

  • 모니터링

    • 상태 확인하기: 미리보기 패널에서 알람 확인, 주의가 필요한 항목 모아보기 안내 추가

    • 장치 모니터링하기: 장치 잠금 해제, 인증 실패 잠금 해제, 여러 장치 한 번에 제어하기 안내 추가

  • 장치 관리 기능 사용하기: 장치 설정 내보내기/가져오기 안내 추가

  • 장치 등록하기: 대기 중인 장치 등록 방법 추가

  • 인증 설정하기: 얼굴 인증 설정 옵션 추가

  • 고급 설정하기

    • 마스터 관리자 추가: 마스터 관리자 기능을 CE향 제품에서만 사용할 수 있다는 안내와 글로벌향 제품의 2단계 인증 안내 추가

    • 대기 화면에 동영상 재생: 대기 화면 동영상 재생 기능 안내 추가

  • 운영 권한 관리하기: 운영 권한의 메뉴별 권한을 세분화하여 설정할 수 있는 안내 업데이트

  • 인원 점검(Roll Call): 인원 점검 수행 시 현장에 없는 사람은 제외하는 기능 추가

  • 퀵 액션 사용하기: 헤더에 퀵 액션 버튼을 추가하고 관리하는 안내 추가

  • VMS 연동하기: VMS 인증서 설치 절차와 문제 해결 안내 업데이트

  • 리포트 생성하기: 모든 이벤트 및 경보 이력 조회에서 리포트 저장 기능 안내 추가

  • 시스템 보안 강화하기: 장치와 보안 통신 기능 관련 업데이트

  • BioStar X 라이선스: 여러 라이선스 키를 한 번에 활성화하는 안내 업데이트

  • 라이선스 정책: 변경된 라이선스 정책 업데이트

  • 라이선스 계산기: 라이선스 정책 업데이트에 따른 개선

BioStar X Mobile​

  • 장치 관리하기: 모바일 앱에서 장치 상태를 확인하고 인증 실패 잠금을 해제하는 안내 문서 추가

  • 인원 점검 시작하기 인원 점검 수행 시 현장에 없는 사람은 제외하는 기능 안내 추가

BioStar Air​

  • BioStar Air 릴리스 노트: 2.13.0 버전 릴리스 노트 추가

  • 구역 및 안티패스백

    • 구역 관리, 구역 관리하기: 구역과 안티패스백(APB)의 개념 및 구역 설정 방법 안내

    • APB 위반 확인하기: APB 위반 목록을 확인하고 위반을 해제하는 방법 안내

  • 현장(On Site) 사용자 및 실시간 재실 확인

    • 재실 확인하기: 현장(On Site) 및 외부(Off Site) 사용자를 확인하고 재실 상태를 수동으로 변경하는 방법 안내

    • 비상 호출: 소집 장소별 비상 호출 진행 방법 업데이트

    • 복합 단지 사이트에서 재실 및 소집 장소 설정하기: 여러 건물로 구성된 사이트에서 경계 구역과 소집 장소를 설정하는 방법 안내

  • SSO & SCIM

    • SSO & SCIM 설정하기: 로그인 정책 안내

    • SSO & SCIM 활성화하기: ID 공급자 연동 설정 방법 안내

    • Microsoft Entra ID 연동 설정하기, Okta 연동 설정하기: ID 공급자별 SSO 연결 및 SCIM 프로비저닝 방법 안내

  • 등록 출입문 관리하기: 여러 출입문에 출입 레벨을 일괄 할당하는 방법 추가

장치​

장치 업데이트​

  • XPass Q2: XPQ2-DPB 신규 모델 추가

  • BioEntry W3: 틸팅 브래킷을 사용한 설치 방법 추가

  • BioStation 3

    • 인증: 얼굴 중복 인증 방지 시간 설정 추가

    • 사용자: 사용자 ID와 이름에 입력할 수 있는 특수 문자 안내 업데이트

    • 제품 사양 업데이트

  • FaceStation F2

    • 관리자 메뉴: 장치에서 출입문을 제어하는 방법 추가

    • 사용자: 사용자 ID와 이름에 입력할 수 있는 특수 문자 안내 업데이트

  • BioStation 2a

    • 인증: 인증 결과 표시 옵션 설정 추가

    • 설정: 인증 결과 설정 추가

  • Device Manager: 신규 장치 지원 및 iOS 지원 버전 업데이트

릴리스 노트​

  • BioStation 3 Max: 1.1.0 버전 릴리스 노트 추가

  • BioStation 3: 1.5.1 버전 릴리스 노트 추가

  • FaceStation F2: 2.3.1 버전 릴리스 노트 추가

  • X-Station 2: 1.4.2 버전 릴리스 노트 추가

  • Device Manager: 1.2.4 버전 릴리스 노트 추가

개발자 센터​

  • BioStar Device SDK: 2.9.13 버전 릴리스

  • Suprema G-SDK: 1.9.2 버전 릴리스
