2026년 7월

2026년 8월 3일

7월부터 무더운 날씨가 본격적으로 시작되었습니다. 무더위에 건강 관리 유의하길 바라며, 이번 달 Suprema Docs에도 반가운 소식이 가득합니다. 온프레미스 서버 없이 클라우드만으로 출입 인증 시스템을 구축할 수 있는 클라우드 매니지드 서비스, 플랫폼 CLUe의 이용 가이드를 새롭게 게시했습니다. 이 외에도 CoreStation Setup Manager의 백업/복원 기능, ViOnyx 웹 서버의 RTSP/ONVIF 연동 가이드 등 다양한 문서를 새롭게 추가했습니다. 지금 바로 확인해보세요.

CLUe 가이드 공개​

온프레미스 서버 구축 없이 표준 REST API 연동만으로 출입 인증 시스템을 도입할 수 있는 클라우드 출입 인증 매니지드 서비스, CLUe의 이용 가이드를 새롭게 게시했습니다. 웹 포털과 모바일 앱으로 손쉽게 운영할 수 있습니다.

  • CLUe 웹 포털 가이드: 관리자 권한 구조, 장치·출입문 설정, 펌웨어 업데이트, 웹훅 설정, 감사 로그 확인 등 CLUe 서비스 운영 전반을 안내합니다.

  • CLUe API: 사용자 관리와 출입 인증 기능을 직접 연동하려는 개발자를 위한 API 문서입니다.

플랫폼​

BioStar X​

층 구성하기: 평면도 업로드 시 지원하는 이미지 파일 포맷(PNG, JPEG, JPG) 안내 추가

BioStar Air​

IP 카메라 지원 및 설정하기: 카메라 연동을 위한 비디오 서비스 활성화 단계 추가

장치​

신규 장치​

CLUe 전용 펌웨어를 탑재한 장치 매뉴얼이 추가되었습니다.

  • BioStation 3 CLUe

  • BioLite N2 CLUe

  • X-Station CLUe

  • XPass 2 CLUe 릴리스 노트

장치 업데이트​

  • CoreStation Setup Manager: 장치 설정 백업 및 복원, SCB Key 기능 안내 추가

  • ViOnyx 웹 서버: RTSP/ONVIF 연동하기 문서 신규 추가

  • ViOnyx

    • 안전주의 문구 추가

    • 나사 사양 추가

    • 제품 사양 업데이트

  • XPass Q2

    • 전원, 네트워크 관련 문구 업데이트

    • 제품 사양 업데이트

릴리스 노트​

  • BioStation 2a: 1.2.2 버전 릴리스 노트 추가

  • BioStation 3 Max: 1.0.0, 1.0.1 버전 릴리스 노트 추가

  • CoreStation 40: 1.7.3 버전 릴리스 노트 추가

  • CoreStation 20: 1.0.5 버전 릴리스 노트 추가

Docs​

  • 쿠키 정책 페이지를 새롭게 게시했습니다. 사이트에서 사용하는 쿠키의 종류와 목적을 안내하며, 최초 방문 시 브라우저 언어 설정에 따라 자동으로 해당 언어 페이지로 안내하는 기능도 함께 추가되었습니다.

  • 헤딩 앵커 복사 기능 추가: 헤딩 앵커의 #을 클릭하면 해당 앵커의 해시 ID 값을 포함한 URL 주소를 복사할 수 있습니다.

  • 방향키로 문서 이동: Suprema Docs 내 문서 페이지에서 키보드 좌, 우 방향키를 누르면 이전 또는 이후 문서로 이동할 수 있습니다.
