14 Subjects of CoreStation FAQ

1. CoreStation Network Reset and Factory Default​

How to reset CoreStation network?

Push init button on CoreStation more than 3 seconds.

Información

For more details, please refer to the link below.

Network and Factory Default W2, P2, CoreStation

How to do factory default setting of CoreStation?

  1. Factory default setting by BioStar 2

    • Connect CoreStation with BioStar 2

    • Go to Server and set Secure Communication with Device as USE and click Apply

    • Wait until CoreStation connects to Server

    • Push init button on CoreStation 4 times straight

  2. Factory default setting by CoreStation SETUP Manager

    • Connect CoreStation with PC

    • Access web browser at https://169.254.0.1:3001

    • Log in CoreStation SETUP Manager

    • Click Factory Default button on configuration page

    Información

    For more details, please refer to the link below.

2. CoreStation Network Setting​

How to set CoreStation IP?

  1. Connect CoreStation with PC in 1:1 and access web browser at https://169.254.0.1:3001 and log in CoreStation SETUP Manager. You can configure CoreStation IP.

  2. Connect CoreStation with BioStar 2 and configure CoreStation IP in Device setting.

3. The number of door controlled by CoreStation​

How many doors does a CoreStation support?

CoreStation has built-in 4 relays which are to control 4 doors. By adding slave device via RS485, it can control up to 52 doors and via Wiegand, control up to 132 doors.

How many RS485 (OSDP) devices can be connected to CoreStation?

64ch. Each port supports up to 31 slave devices with daisy chain.

How many Wiegand devices can be connected to CoreStation?

132ch. CoreStation has 4 Wiegand ports and 64ea DM-20 which has 2 Wiegand ports can connect to CoreStation by RS485.

How many doors can DM-20 support?

DM-20 has 4 relays which support 4 doors with RS485 devices.

4. How to use 3rd party reader with CoreStation​

Can we use 3rd party card reader with CoreStation?

Yes, All standard card readers that support Wiegand output can work with CoreStation.

Can we use 3rd party keypad reader with CoreStation?

No, CoreStation doesn't support the single key output from Wiegand signal so it cannot use with 3rd party keypad reader.

Can we use 3rd party fingerprint reader with CoreStation?

Yes, 3rd party fingerprint reader can connect with CoreStation by Wiegand. CoreStation has a matcher that supports Suprema template. You can either use Suprema fingerprint slave reader BER2 or Suprema intelligent fingerprint reader by RS485 (OSDP) connection.

5. How to use XPD2 or BER2 with 3rd party controller​

Can we use XPD2 with 3rd party controller?

Yes, XPD2 can connect with 3rd party controller by Wiegand or RS485. You can easily configure XPD2 setting via Suprema Device Manager Application via mobile phone.

Can we use BER2 with 3rd party controller?

Yes, If the 3rd party controller can store fingerprint template, BER2 can be used with the ACU.

6. How to replace a 3rd party controller and Wiegand reader with CoreStation, XPD2 and/or BER2​

Can we connect Wiegand cable with RS485 cable of XPD2 and BER2?

Yes, Check Wiegand cable at the site is shielded twisted 2 pair cable. If it is, you can connect Wiegand 3 core cable with RS485 cable (TRX+,TRX-,GND) of XPD2 and/or BER2.

How many can XPD2 and BER2 connect with CoreStation when being cabled by RS485 and Wiegand cable together?

Max.10ea.

7. Suprema platform compatibility with CoreStation​

Which Suprema device can be used with CoreStation?

  1. Slave RFID reader: XPD2

  2. Slave Biometric reader: BER2

  3. All intelligent biometric readers

  4. All peripherals

Does XPD2 support Airfob Pass?

Yes, XPD2 supports Airfob Pass (Suprema Mobile Access)

8. Maximum Biometric Devices with CoreStation​

How many fingerprint reader can connect with CoreStation?

64ch. Performance would be different depending on the number of users at the site. CoreStation matching speed is 400,000/1sec for Genuine Matching which is 1:N matching where the user's fingerprint template is in the device.

How many face authentication reader can connect with CoreStation?

5ch. Face reader can connect to each RS-485 port of CoreStation one by one.

10. Power​

What is the specification of Power AUX IN of CoreStation?

12V DC, 3A

What is the power output of CoreStation?

12V, up to 1.5A. Slave device or Wiegand device or lock etc. can be powered within 1.5A. In case of exceeding 1.5A, you need separate power supply.

11. Installation​

How to connect slave device with CoreStation by RS485?

Use an AWG24 twisted pair with a maximum length of 1.2km for RS485 cable which has 120 ohm impedance. It is mandatory to wire in parallel format.

12. Configuration​

Can we use PIN Only Mode with XPass D2 Keypad reader?

Yes, You can create virtual card number in User Configuration in BioStar 2 and enable XPD2 authentication mode to Input card ID from keypad available.

Can we configure supervised input?

Yes, CoreStation input No.0~7. can be used for normal TTL input or supervised input.

Can we use fire alarm panel with CorStation?

Yes, you can connect CoreStation input with fire alarm panel. BioStar 2 Standard license is required.

13. Offline function​

When the host computer to go offline, can CoreStation work?

Yes, It works in local zone mode. CoreStation has capacity of storing 5,000,000 logs. When the network is back, it will upload all the logs to the host. However, it is not supported in global zone mode.

When slave device is cut from CoreStation, can the slave work?

No, it's not supported.

Can we connect CoreStation to another CoreStation by RS485 for back-up?

No, it's not supported.

14. Replacement function​

When CoreStation is failed and should be replaced, do we have to reconfigure settings?

Yes, Currently, you should reconfigure all the settings. but we are working on developing f/w to restore configuration of the CoreStation.
