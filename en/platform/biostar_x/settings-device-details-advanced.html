Configure Advanced Settings

Learn about the settings available in the Advanced section. Learn how to set up the master administrator, administrator permissions, T&A events, screen/sound, triggers and actions, image logs, Wiegand, and security tamper, and what each option means. Apply settings that fit your environment to manage the device efficiently.

Info

  • The available network options may differ depending on the device type.

  • If you made changes, click Apply. Unsaved changes are not applied to the device.

Add a master administrator CE products​

The Master Admin feature strengthens administrator permissions on the device to improve security and prevent unauthorized access and setting changes. With this feature, you must register a master administrator on a new device, and only the registered master administrator can access the administrator menu and change settings.

In Advanced → Administrator, select and enroll two credential types in the Master Admin menu.

The credentials you can enroll in Master Admin are as follows.

Credential typeMaximum enrollmentsConditions
CardUp to 4Supports only CSN and Wiegand types, and you cannot enroll duplicates within the same type.
FaceUp to 2Available only on devices equipped with the same algorithm.
FingerprintUp to 2-
PIN1Enter at least eight digits.

  • To change an enrolled credential, click to the right of the credential.

  • To delete an enrolled credential, click to the right of the credential.

Caution

This feature is available only on CE products among Suprema products that support a user interface through an LCD screen. For more information about supported devices and firmware versions, see Master Admin Setup Guide.

Enrollment conditions

  • You must enroll at least two types of credentials.

  • The same conditions apply to all firmware-upgraded devices that support master administrators.

  • All credentials supported by the device can be used as authentication means.

Info

  • This feature is available only on Suprema products that support a user interface through an LCD screen.

  • On existing devices with upgraded firmware, the Master Admin menu does not appear in BioStar X device settings.

  • Some devices without the Master Admin setting (for example, after a firmware upgrade) can strengthen administrator permissions with the Two-step Authentication option. Depending on the device, the Two-step Authentication option may not appear.

  • Master administrator credentials are stored separately on the device and managed independently of regular users' PINs. Changing or deleting a user PIN does not affect master administrator credentials.

Two-step authentication settings​

After upgrading firmware on a global device that does not support Master Admin, use the Two-step Authentication option to strengthen administrator permissions and improve device security.

If you set the Two-step Authentication option to Use, administrators must use two or more credential types when they authenticate on the device. For example, if a card and a PIN are both enrolled, an administrator must scan the card and enter the PIN to authenticate successfully.

Info

  • If any administrator has fewer than two types of credentials enrolled, activation fails and an error message appears. Enroll two or more types of credentials for all administrators and try again.

  • Depending on the device, Two-step Authentication may not appear on the screen even though the previously enabled setting is still active. You cannot disable it in BioStar X, so contact Suprema Global Technical Support Team.

Caution

If an administrator is not set on the device, the following pop-up message will appear. In Advanced → Administrator, add administrators for all permissions.

Warning

If you turn on Two-step Authentication and then delete credentials so that every administrator has fewer than two credential types, you cannot access the administrator menu on the device when it cannot connect to BioStar X. Therefore, you need to be particularly careful when deleting administrator credentials.

Add an administrator​

The Administrator group lets you manage device administrators by permission level.

To add an administrator by permission level, click + Add. When the user list appears, select the user to add. In the user list, you can also click to search for a user.

For the permissions of each level, see below.

LevelManage user informationDevice Settings
All✔️✔️
User✔️❌
Configuration❌✔️
Info

  • Add and manage up to 1,000 administrators. The number of administrators you can add may vary depending on the device firmware version.

  • To search for a registered user, click in Name / ID.

  • Device Settings lets you change settings for the screen and sound, network, and RS-485.

  • To delete an administrator, click to the right of the administrator.

  • Administrators set on each device do not affect BioStar X permissions.

  • If a device administrator has a PIN shorter than eight digits on a master administrator-supported device (CE products), re-enroll the user's PIN with at least eight digits. For more information about enrolling PINs, see Enroll a PIN.

  • To change the PIN of a user with Configuration permissions to four digits, first remove the user from administrator roles on all devices.

Caution

If the user being set as a device administrator has fewer than two types of credentials enrolled, an error message appears. Enroll two or more types of credentials for all device administrators and try again.

Handle administrator registration for deleted users​

If the device administrators include a user already deleted from BioStar X, the following pop-up appears when you click Apply at the bottom of the screen to save the device settings.

  • Yes: Removes the deleted user from the administrator list and saves the settings.

  • No: Cancels saving.

Attendance management​

In the T&A group, change the names of the device's attendance events or set the attendance mode.

  • T&A Mode: Set how attendance events are recorded.

    • Not Use: Attendance events are not recorded.

    • By User: The user can select an attendance event when authenticating.

    • By Schedule: Attendance events automatically change based on the schedule you set. Select a schedule to apply to attendance events.

    • Last Choice: Users can continue using the last attendance event they used.

    • Fixed: Only the selected attendance event can be used. Select the fixed attendance event to use.

  • T&A Required: Set this to require the user to record an attendance event when authenticating.

    This option is available when the T&A Mode option is set to By User.

  • T&A Event: Edit attendance event names or add schedules used when the T&A Mode option is set to By Schedule.

    • T&A Event Key: Shows a list of keys you can use to log attendance.

    • Label: Change the attendance event name based on T&A Event Key.

    • Schedule: Set the schedule for automatic changes when the T&A Mode option is set to By Schedule.

Info

  • Devices without an LCD screen can use Fixed or By Schedule mode and record a fixed attendance event or a schedule-based one. Supported devices are XPass Q2, XPass 2, XPass D2, BioEntry P2, and BioEntry W2.

  • For more information about setting up a new schedule, see Set Up Schedules.

  • If Multi Face Authentication is set to Use on the device, this device cannot be used for time and attendance management. For more information about Multi Face Authentication, see Set Up Authentication.

Screen and sound settings​

Change the device screen and sound settings. Available options may vary depending on the device.

XPass 2, XPass D2, BioEntry P2, BioEntry W2

  • Sound: Turn sound on or off.

  • LED/Buzzer: Select and set the events that activate the LED or buzzer.

  • Keypad Backlight: Turn the keypad backlight on or off. When you turn on this option, the light behind the keypad turns on. Keys are easy to identify in dark environments.

The Keypad Backlight option is available on XPass D2 hardware V02M and firmware v1.7.1 or later.

FaceLite, BioLite N2, BioStation L2, BioStation 2

  • Language: Set the language that appears on the device screen. To send language resource files to the device, click Update Resource.

  • Device Volume: Set the default volume level for sounds on the device.

  • Menu Timeout: Set how long it takes to switch from the menu screen to the idle screen.

  • Theme: Change the style of the device home screen.

  • Backlight Timeout: Set how long it takes for the screen backlight to turn off automatically.

  • Message Timeout: Set how long it takes for messages to disappear automatically.

  • Voice Instruction: Use voice guidance instead of notification tones.

  • Background: Set what appears in the background of the device home screen.

    • Logo: Shows an image registered by the user on the device home screen. To register an image, click Add.

    • Notice: Shows text entered by the administrator on the home screen.

    • Slide Show: Shows up to 10 images registered by the user as a slideshow on the home screen. To register an image, click Add.

    • To apply the changes to the device immediately, click Update.

    • If you change the background type, clicking Update does not apply it to the device. Click Apply at the bottom of the screen.

    • The BioStation 2 model supports the Notice and Slide Show options.

  • Sound: Set the sound effects played when the device starts, authentication succeeds, or authentication fails. Select a *.wav file that is 500 KB or smaller. Click Browse.

    To apply the changes to the device immediately, click Update.

BioStation 3 Max, BioStation 3, X-Station 2, FaceStation F2, FaceStation 2, BioStation A2

  • Language: Set the language that appears on the device screen. To send language resource files to the device, click Update Resource.

  • Device Volume: Set the default volume level for sounds on the device.

  • Intercom Speaker Volume: Set the volume of the sound played on the device when you use the Intercom feature.

  • Intercom Microphone Volume: Set the volume level for audio input to the device when you use the Intercom feature.

  • Menu Timeout: Set how long it takes to switch from the menu screen to the idle screen.

  • Backlight Timeout: Set how long it takes for the screen backlight to turn off automatically.

  • Message Timeout: Set how long it takes for messages to disappear automatically.

  • Server Private Message: Set whether to use a private message that appears on the screen when the user authenticates.

    If Multi Face Authentication is set to Use on the device, this option is not available. For more information about Multi Face Authentication, see Set Up Authentication.

  • Voice Instruction: Use voice guidance instead of notification tones.

  • Home Screen: Set what to show in the background of the device home screen.

    • Normal: Shows the default image on the home screen.

    • Logo: Shows an image registered by the user on the device home screen. To register an image, click Add.

    • Notice: Shows text entered by the administrator on the home screen.

    • To apply the changes to the device immediately, click Update.

    • If you change the background type, clicking Update does not apply it to the device. Click Apply at the bottom of the screen.

    • If you set the home screen to Logo and Slide Show, you can show up to 10 images as a slideshow on the home screen. To register an image, click Add.

  • Sound: Set the sound effects played when the device starts, authentication succeeds, or authentication fails. Select a *.wav file that is 500 KB or smaller. Click Browse.

    To apply the changes to the device immediately, click Update.

  • Default Idle Screen: Select the idle screen that appears when the device is not in use.

    • Screen Saver: Shows the screen saver as the idle screen.

    • Home Screen: Shows the option selected under Home Screen.

    • This option is supported on the BioStation 3 Max, BioStation 3, X-Station 2, FaceStation F2, and FaceStation 2 models.

    • For more information about the Play Video option, see #playVideo.

LED/Buzzer: Select and set the events that activate the LED or buzzer.

Play a video on the idle screen​

The feature to play videos on the idle screen is supported on BioStation 3 Max firmware v1.1.0 or later. Prepare the video before sending it to the device.

Add a video and transfer it to the device​

Set the device to play content on the idle screen.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. In the device list, click BioStation 3 Max.

  4. Go to the Advanced → Display/Sound section.

  5. In Idle Screen → Play Video, set the option to Use.

  6. Click Add Video.

  7. Select the video saved locally.

  8. After the video uploads, set Video Schedule and Video Volume.

  9. To transfer the uploaded video to the device, click Update to Device.

  10. The update progress pop-up appears. Do not close the page until the upload completes.

  11. When the upload complete message appears, click Ok.

  12. To save the changes, click Apply at the bottom of the screen.

Info

  • Videos play according to the schedule set in Video Schedule, only when Play Video is set to Use and at least one video is registered. For schedules that do not meet these conditions, the screen selected in Default Idle Screen appears.

  • The maximum supported video file size is 200 MB, and the file format is MP4 (H.264).

  • Video file names can be up to 48 characters long. The file name cannot include characters such as a period (.), apostrophe ('), or backtick (`).

  • You can add up to three videos. When three videos are added, the Add Video button is disabled.

  • If the device is connected as a slave (via RS-485), you cannot add, delete, or transfer videos.

    • If the master device supports video playback, the slave screen shows the list of videos added to the master device as read-only. The list is read-only, and you can add, delete, transfer, or reorder videos only on the master device.

    • If the master device does not support video playback, the slave screen shows only Default Idle Screen.

Tip

Use Batch Edit to add and transfer videos to multiple devices at once. For more information about the Batch Edit feature, see Use Device Management Features.

Change video playback order​

Click and drag the area to the right of a video thumbnail to change the playback order. To save changes after reordering, click Apply at the bottom of the screen.

Delete videos​

To delete an uploaded video, click for the video in Idle Screen → Play Video. Then click Update to Device. To save the changes, click Apply at the bottom of the screen.

Video transfer failure​

If sending a video to the device fails, a pop-up shows the name of the video that failed.

The main reasons for transfer failure are as follows.

  • When an error occurs while processing the device response

  • When an error occurs for reasons other than those above

Tip

If only some devices fail during batch video transfer with Batch Edit, click Copy Failure Details in the results pop-up to copy the failed-device list and reasons to the clipboard.

Trigger and action settings​

In the Trigger & Action group, set triggers and actions for each situation. For example, set all alarms to sound when authentication fails, or disable the device when the RS-485 connection is lost.

You can register triggers and actions by selecting an event, or set custom triggers and actions. Click Add on the right side of the Trigger & Action group.

Trigger​

Select a predefined event or add a custom condition.

  • Event: Select a predefined event.

  • Input: Set custom conditions by selecting each entry under the option.

  • Input(Event Name Change): Set custom conditions by selecting each entry under the option. Set it to detect input only, without a separate action for the input.

Info

  • When Trigger is set to Event, you can select only one event from the event list.

  • When you select Input or Input(Event Name Change) to set custom conditions, if the schedule you need is not available, click + Add Schedule. For more information about schedule settings, see Set Up Schedules.

  • When you select Input(Event Name Change) to set custom conditions, if the event name you need is not available, click Add Event Name. When this event occurs, the event name you set appears in the event log and real-time log.

  • The event name can be up to 64 characters long.

Action​

Select a predefined action or add a custom action.

Info

  • When you select Output to set custom actions, if the signal setting you need is not available, click + Add Signal to set one.

  • If you set Trigger to Input(Event Name Change), you can set Action to Port None.

Image log settings​

In the Image Log group, set the image log events and schedules that the device uses.

  1. Set the Image Log option to Use.

  2. In Configuration, click + Add to set events and schedules.

Info

  • This feature is supported on BioStation 3 Max, BioStation 3, X-Station 2, FaceStation F2, FaceStation 2, and BioStation A2.

  • For more information about default image log settings, see Set Up Image Logs.

Wiegand settings​

In the Wiegand group, set I/O details for Wiegand devices.

  • Input/Output: Select the I/O mode.

  • Pulse Width(μs): Set the pulse width of the Wiegand signal.

  • Wiegand Input Format: Change the Wiegand format assigned to the device.

  • Pulse Interval(μs): Set the pulse interval of the Wiegand signal.

  • Output Mode: Set the Wiegand signal output mode.

    • Normal: Scans cards using the Wiegand format that is set. Set an error code, and select the value to send when card authentication using Wiegand fails.

    • Bypass: Sends the CSN regardless of Wiegand authentication. Set this when you use the device without door control features.

  • Output info: Select the information output from the device during authentication.

Info

For more information about Wiegand format settings, see Set Up Wiegand Card Formats.

Security tamper settings​

If a tamper event occurs on the device, you can set the device to delete all user information, logs, and security keys stored on the device. To turn on the Secure Tamper feature, set it to On.

Analog intercom settings​

Set whether to use an analog intercom. To use the intercom connected to the device, click Use in the Interphone group.

Info

This feature is supported only on the BioStation 2 model.

Camera settings​

Set the camera frequency. If you set the frequency incorrectly in an environment with fluorescent lights, images may flicker. In the Camera group, set the frequency for your region.

Info

  • This feature is supported by the FaceStation F2 and BioStation A2 models with firmware v2.1.4 or later.

  • Camera frequencies vary by geographic location. The USA typically uses 60 Hz, while most other regions use 50 Hz. For the camera frequency in your area, contact your dealer.
