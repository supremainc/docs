(Draft) Version 1.0.3 (Build No. 1.0.3.130)

Release|2026-09-21

New Features and Improvements​

  1. Supported new device
    • XPass Q2: XPQ2-DPB
    • XPass 2 (V2): XP2-GDPB-V2, XP2-GKDPB-V2, XP2-MAPB-V2, XP2-MDPB-V2, XP2-MAPB-H-V2
  1. Added real-time status monitoring and direct control of doors and elevators in the Monitoring preview
  1. Added face authentication features
    • Added support for Multi Face Authentication (device license required)
    • Added support for tailgating prevention (Anti-Tailgating)
    • Added support for Duplicate Authentication Prevention
  1. Added Include On-Site Users Only mode to Roll Call
  1. Added Scan ID feature to automatically fill in user information using an ID
  1. Added Export/Import Device Configuration feature
  1. Supported EV2 Secure Messaging authentication and issuance for DESFire EV2 and EV3 cards.
  1. Added the ability to select and batch control multiple devices in Monitoring
    • Run Unlock Device, Release Lockout, Stop Action, Reconnect, and Reboot on multiple devices at once
  1. Added support for Select All and group selection in the Monitoring event filter
  1. Added the ability to select and batch control multiple doors, elevators, and zones in Monitoring
  1. Added a feature to manage users with long-term inactivity
    • View users with long-term inactivity based on Last Access
    • Set a policy to automatically deactivate users based on conditions
    • Send a pre-notification email to designated recipients before auto deactivation
  1. Separated firmware builds for CE and Global (Non-CE) products.

    CE and Global (Non-CE) products can be identified via the label sticker on the back of the product. The Master Admin feature is enabled only on products with a label bearing the CE mark.

  1. Added Auth Fail Lockout feature, which locks the device after repeated PIN authentication failures.
  1. Expanded allowed characters for User ID and User Name
    • Added support for periods (.) in User ID
    • Added support for periods (.) and apostrophes (') in User Name
  1. Added the Audit Trail feature to T&A
  1. Added a filter to the Monitoring status tree that shows only items requiring attention
  1. Added the ability to configure account permissions at the submenu level
  1. Added the Idle Screen Video Playback feature
    • Supported models: BioStation 3 Max
  1. Supported an option to select QR authentication using the device camera upon Camera QR license activation on XS2-QDPB and XS2-QAPB models.
  1. Added the ability to display frequently used Quick Actions directly in the header
  1. Added the Door Control through Authentication feature, which unlocks or normalizes a door through user authentication
  1. Added the ability to display and unlock locked devices in the Monitoring status tree
  1. Improved license policy and added bulk activation
    • Feature add-on licenses can now be activated on the Essential tier
    • Separated Advanced Access Control into individual licenses
    • Added the ability to activate multiple license keys at once
  1. Added the report save feature to All Events and Alert History in the Data menu
  1. Improved the Access Control Audit Trail feature
    • Expanded logging to capture previously missing actions
    • Recorded before-and-after values when settings or information change
    • Added logging of user information access
  1. Improved the Device menu tree to remember the expanded/collapsed state per account
  1. Added element-specific icons and improved the expand/collapse method in the Monitoring status tree
  1. Improved Monitoring to display the event log across the full screen when there are no maps or cameras to show
  1. Improved the Settings menu with a group tree structure
  1. Improved the VMS certificate installation process
  1. Improved the T&A screen UI design
  1. Improved the Monitoring map status tree to move to the corresponding map when double-clicking a facility
  1. Improved the device hardware version to display the same value as the product label (requires supported firmware)
  1. Changed Secure Communication with Device to be enabled by default
  1. Improved group mapping for users belonging to multiple groups in Entra ID.
  1. Improved Send Face Mobile Enrollment Link to indicate in the Audit Trail that the change was made via this feature.
  1. Improved the display timing and behavior of the notification popup for an existing BioStar X folder when upgrading from BioStar 2 to BioStar X.
  1. Improved the behavior where unnecessary error popups appeared due to response delays during Sync Device.
  1. Improved the group selection UI when creating custom levels.
  1. Security vulnerability improvements
    • Upgraded communication channels to TLS 1.3
    • Updated AngularJS and jQuery versions
    • Improved Reverse Tabnabbing vulnerability
    • Enhanced session cookie security
    • Updated Log4j library version
    • Updated Java Runtime Environment (JRE) version
    • Improved SQL Injection vulnerability
    • Improved a redirect URL security vulnerability during Entra ID login
    • Updated the commons-text library version
    • Updated the OpenSSL library version
    • Updated security vulnerability-related libraries
    • Updated the Log4j library version
    • Improved security vulnerabilities in Entra ID integrated login authentication.
  1. Improved login to transmit passwords in encrypted form.
  1. Enhanced security by requiring the current password when changing your own password.
  1. Time & Attendance security vulnerability improvements
    • Improved an SSL certificate-related security vulnerability
    • Updated Node.js and library versions
  1. Improved Visual Face user synchronization performance.
  1. Improved Custom Report query performance when retrieving data over a wide date range.
  1. Performance and query improvements in large-scale environments
    • Improved face authentication performance in environments with many users and face data
    • Improved bulk edit speed for 1,000 or more users
    • Fixed query failures when Device, Access Level, or Credential numbers are large
  1. Improved event query performance for custom accounts using specific device groups.
  1. Improved Door Status query performance in Multi Communication Server environments.
  1. Improved the query performance of the Status tab in the Access Group screen in large-scale environments.
  1. Improved device list query performance when adding a credential.
  1. Improved the long synchronization time when saving Door settings.
  1. Improved slow server startup in environments with many registered licenses.
  1. Improved slow user retrieval in environments with many Access Groups.
  1. Improved slow loading of the Elevator detail screen in environments with many devices.
  1. Improved synchronization in Multi Communication Server environments
    • Improved so that each server processes only its own devices for firmware synchronization
    • Improved User Group query performance in environments with many users
  1. Improved delays in saving settings when the Dashboard has many components.
  1. Improved operator permission check performance and Zone permission handling
    • Improved operator permission check performance in environments with many targets
    • Improved Zone permissions being applied incorrectly in some cases
  1. Improved device list tree loading speed in environments with many devices.
  1. Improved device synchronization speed in environments with many devices.
  1. Improved device synchronization by sending updates only for modified users when Access Group members are changed.
  1. Improved overall device synchronization performance and resolved device disconnection issues by sending only device-relevant information during sync.
  1. Added removal of unused files during upgrade.
