Use Device Management Features

Learn how to use other device features in BioStar X. Learn how to reconnect or synchronize devices, batch edit information, delete devices, and export or import settings, and how to delete secure communication certificates when you delete devices.

Manage a single device​

Use the following steps to manage a single device.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. In the All Devices list, right-click the device. Alternatively, click the checkbox for the device in the device list.

  4. Select a feature from the pop-up menu or from the top of the device list.

For the available features, see below. Available features may vary depending on the device.

  • Reconnect: Reconnects the selected device. This feature is available only when you select one device. In general, the device automatically comes back online after the network connection is restored. Use this feature when the device does not reconnect automatically after the network is restored.

    Info

    This feature is not supported by devices connected with the Device ▶ Server Connection option. For more information about registering devices, see Register Device.

  • Sync Device: Synchronizes all user information on the registered device with BioStar X. Synchronization is based on the BioStar X database, and user information registered only on the device is deleted. To upload user information to BioStar X, use the Manage Users in Device feature.

  • Delete Data & Sync Device: Deletes all settings and user information stored on the device and resends them. This feature is also available when you select a device in the device list and click .

  • Manage Users in Device: Uploads user information registered on the device to BioStar X or deletes it from the device. For more information, see Manage Users Registered on a Device.

  • Firmware Upgrade: Easily upgrades the device firmware. For more information, see Upgrade Firmware.

  • Reboot: Restarts the selected device. Use this feature when the device is not working properly.

  • Delete Device: Deletes the selected device from the list. Devices set as doors or zones cannot be deleted. For more information, see #deleteDevice.

Info

  • For more information about the Add Wiegand Device feature, see Register a Wiegand Device.

  • For more information about the Search Slave Device feature, see Register a Slave Device.

Manage multiple devices​

Use the following steps to manage one or more devices.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. Click the checkboxes for the devices in the device list. Select one or more devices.

  4. Select a feature at the top of the device list.

For the available features, see below. Available features may vary depending on the device.

  • Sync Device: Synchronizes all user information on the registered device with BioStar X. Synchronization is based on the BioStar X database, and user information registered only on the device is deleted.

  • Batch Edit: Batch edits information for the selected devices. When you click the button, the Device Batch Edit window appears.

    Info

    • Depending on the selected device type, the details that appear in the Device Batch Edit window may vary.

    • If you select a master device and slave devices at the same time and click Batch Edit, you can change only some options in Authentication and Display/Sound.

    • Auth Mode can be batch edited only when you select devices with the same model name.

  • Firmware Upgrade: Easily upgrades the device firmware. For more information, see Upgrade Firmware.

  • Delete Device: Deletes the selected device from the list. Devices set as doors or zones cannot be deleted. For more information, see #deleteDevice.

Delete a device​

Use Delete Device to delete devices from the list. The options that appear during deletion depend on whether Secure communication with device is enabled.

When secure communication is disabled​

When Secure communication with device is set to Not Use, delete the selected device without additional options.

When secure communication is enabled​

If Secure communication with device is set to Use, the Delete Device dialog shows the Also delete the secure communication certificate option.

  • If Also delete the secure communication certificate is cleared (default), only the device is deleted and the certificate is kept.

  • If Also delete the secure communication certificate is selected, the secure communication certificate stored on the device is also deleted. Use this option to connect the deleted device to another BioStar X server.

Caution

The certificate on a device disconnected from BioStar X cannot be deleted, so you cannot delete the device while Also delete the secure communication certificate is selected. To delete the device, clear the option or reconnect the device, then try again.

Info

  • If Secure communication with device is enabled, deleting the device without selecting Also delete the secure communication certificate leaves the certificate on the device. If you then set Secure communication with device to Not Use and register the device in BioStar X again, the device does not connect because the certificate remains on it. If you use the default certificate, change the Secure communication with device option back to Use.

  • If all selected devices are slave devices or do not support secure communication, delete the devices without the Also delete the secure communication certificate option.

  • The Also delete the secure communication certificate option appears only when Secure communication with device is enabled. For more information, see Enhance System Security.

Export/import device settings​

Export the settings from one device to a file, then import and apply them to another device of the same model. Instead of entering the same settings on multiple devices, create a settings file from a configured device and apply it to the other devices.

Info

  • Same model means that the detailed model name and part number match (for example, XXX in XPD2-XXX).

  • The export/import device settings feature is available to administrators with full permissions for device settings. For more information about administrator permission settings, see Manage Operation Permissions.

Export device settings​

To download the settings for a single device as a file, follow these steps.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. In the device list, select the checkbox for the device to export settings from. Only one device can be selected.

  4. Click → Export Device Configuration at the top of the device list.

  5. When the download window appears, save the settings file locally.

Caution

You cannot export settings for the following devices.

  • Devices that are disconnected from BioStar X or have timed out

  • Virtual devices

  • Devices without RS-485 communication mode (for example, Wiegand devices, I/O modules, Door Interface, Door modules, Secure modules, and OSDP Antenna/Reader)

Info

  • This feature is unavailable unless you select exactly one device.

  • The file name is set automatically in this order: model name, device ID, RS-485 communication mode (Master/Default/Slave), and export date. The date follows the date format set in Settings → System → Preferences.

    For example, a device with the model name BS3-DB, device ID 538001234, serial communication mode Master, and export date June 23, 2026 is saved as BS3-DB_538001234_Master_20260623.json.

Settings excluded from export ​

The following settings are not included in the export file because they must be unique per device, are stored only on the device, or contain sensitive information such as authentication information.

  • Device-specific settings: Name, Group, wired and wireless network settings, server connection settings, OSDP identifier, Trigger & Action

  • Settings stored only on the device that cannot be moved to another device: language resources, home screen, and sound options in Display/Sound, the SCB key for serial communication, and video settings added to BioStation 3 Max

  • Authentication information and sensitive information: usernames and passwords for Intercom and RTSP, Master Admin settings, Two-step Authentication options

Import device settings​

To apply the exported settings file to one or more devices of the same model, follow these steps.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. In the device list, select the checkbox for the device to apply the settings to. You can select one or more devices.

  4. Click → Import Device Configuration at the top of the device list.

  5. When the Open window appears in the web browser, select the settings file saved locally.

  6. When the Import device settings result message appears, review the message and click Ok.

Caution

The system accepts settings files created on other sites or servers as valid files without verifying the source or showing a warning. Make sure the file to import comes from a trusted source.

Info

This feature is unavailable unless you select at least one device.

When you run the import, the system checks the following in order before applying the settings. If any check does not meet the conditions, the system does not apply the settings and shows the reason.

  • Whether all selected devices have the same model name (including the part number)

  • Whether the RS-485 communication mode matches across the selected devices and the file

  • Whether the model name saved in the file (including the part number) matches the model names of the selected devices (including the part number)

  • Whether any of the selected devices is a virtual device

If the checks pass, the system applies all settings except Settings excluded from export to all selected devices.

Info

  • If you import a file exported from a device that does not support a feature into a device that supports it, the feature is applied as turned off, and any options already turned on in the target device are turned off. Conversely, if you import a file exported from a device that supports a feature into a device that does not support it, the feature is not applied and only the remaining settings are applied. In both cases, the system does not mark the import as failed or include it in the failure list.

  • Settings that require a device license do not apply to devices that do not have the license applied. Conversely, if you import a file exported from an unlicensed device into a licensed device, the setting is applied as turned off, and any options already turned on in the target device are turned off. In both cases, the system does not mark the import as failed or include it in the failure list.

  • If the system successfully applies the settings to all devices, a success message appears. If the system fails to apply the settings to some or all devices, a message appears with the number of failed devices and lets you download the failure list as a CSV file. This file contains the ID, name, and failure reason for each failed device (the device is disconnected, or an access group is set so full access cannot be turned on).

    For example, if an import run at 15:45:30 on 6/23/2026 fails, the file name is Device_Template_Import_Error_20260623T154530.csv.

  • CoreStation devices are also included.

  • To view the export and import history for device settings, click Settings → Audit Trail → AC Audit Log.

Delete event logs from a device​

This feature deletes event logs stored on the device.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. Click the checkboxes for the devices in the device list. Select one or more devices.

  4. Click → Delete All Event Logs in Device at the top of the device list.

  5. When a warning message appears, review it and click Continue.

When the device event log deletion is complete, a pop-up message appears. Shows the number of target devices, successful devices, and failed devices.

Caution

Event logs deleted from a device cannot be recovered and cannot be resent from the server to the device. Make sure the device event logs are stored on the server before you proceed with deletion. Also, if the selected devices include slave devices, virtual devices, or Wiegand devices, those devices do not store logs and are excluded from log deletion.

Info

  • Only users with the Administrator Role permission can use this feature.

  • To view the device event log deletion history, click Settings → Audit Trail → AC Audit Log.

Additional features​

Additional features are available, such as printing the device list or changing column settings.

Print the device list​

Save the device list as a PDF or SVG file, and then print it.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. Click at the top of the device list.

  4. Click Print in the pop-up menu.

  5. When the Print Option window appears, select a format under File Format and set the other options.

  6. Click Print.

You can print the PDF or SVG file that opens in the browser.

Device list column settings​

You can change which columns appear in the device list. Select the columns to show, or change their order.

  1. On the Launcher page, click Settings.

  2. Click Device → Device in the left sidebar.

  3. Click at the top of the device list.

  4. Click Column Setting in the pop-up menu.

  5. When the Column Setting window appears, select or clear columns to show.

  6. To change the column order, drag the columns.

  7. To save the settings, click Apply.

Info

To restore the default column settings, click Default Column.
