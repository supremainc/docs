출입 통제 감사 로그 조회하기

Not translated
This page is currently being translated. We will complete the translation as soon as possible.

AC Audit Log 기능은 사용자, 장치, 출입문 등 출입 통제와 관련된 모든 생성 및 수정, 삭제, 조회, 내보내기, 가져오기, 운영 활동을 기록합니다. 각 기록은 언제, 누가, 무엇을, 어떻게 변경했는지 함께 보여주므로 보안 감사와 문제 해결에 활용할 수 있습니다.

  • 보안 감사: 비인가 접속 시도나 권한 남용을 탐지하세요.

  • 문제 해결: 시스템 오류 발생 시점과 설정 변경 이력을 추적하세요.

  • 규정 준수: 개인정보 조회 이력을 포함한 접근 기록을 보관하고 감사 보고서를 작성하세요.

출입 통제 감사 로그 확인​

  1. Launcher 페이지에서 Settings을 클릭하세요.

  2. 화면 왼쪽 사이드바에서 Audit Trail → AC Audit Log를 클릭하세요.

  3. 감사 로그 목록이 화면에 표시됩니다.

Info

보관 기간 등 감사 로그 정책을 변경하려면 감사 설정 관리하기를 참고하세요.

테이블 구성​

감사 로그 목록 테이블은 10개 컬럼으로 구성되며, 현재 검색 조건에 해당하는 기록을 Datetime 기준 최신순으로 표시합니다.

컬럼설명
Datetime이벤트가 발생한 날짜와 시간입니다.
User이벤트를 수행한 사용자입니다. id(이름) 형식으로 표시됩니다.
Account Level이벤트를 수행한 사용자의 관리자 등급입니다.
Category이벤트 대상의 도메인 분류입니다(예: 사용자, 장치, 출입문).
Action수행된 동작 종류입니다. Create, Update, Delete, Read, Export, Import, Operation 중 하나로 분류됩니다.
Sub Action로그인 방식, 알람 해제처럼 세부 동작 이름이 있는 경우에만 표시됩니다.
Target동작이 적용된 대상입니다. 타입: id(이름) 형식으로 표시됩니다.
Modified Fields변경되거나 조회된 필드 이름입니다.
Details동작별 상세 정보입니다. (예: 변경 값, 사유, 조회 조건 등)
IP사용자가 접속한 IP 주소입니다. 시스템이 자동으로 발급한 기록은 127.0.0.1로 표시됩니다.
Info

  • Target과 Modified Fields 값이 2건 이상이면 첫 항목만 표시되고, 나머지는 오른쪽에 잔여 건수 배지(예: +208)로 압축됩니다. 잔여 건수가 1,000건 이상이면 +999로 표기하며, 정확한 총 건수는 상세 팝업 제목에서 확인할 수 있습니다. 배지를 클릭하면 해당 셀의 상세 팝업이 열립니다.

  • 셀 값이 길면 한 줄로 말줄임 처리됩니다. 마우스를 오버하면 전체 값이 툴팁으로 표시되며, 툴팁을 벗어나는 길이는 ...으로 줄여 표기됩니다.

상세 정보 확인​

값이 있는 Target, Modified Fields, Details 열은 밑줄로 표시되며 클릭할 수 있습니다. 해당 열의 값을 클릭하면 동작에 맞는 상세 팝업이 열리고, 팝업을 닫으려면 OK 버튼 또는 버튼을 클릭하세요.

팝업 상단의 Search Keyword 입력 필드에 검색어를 입력하면 일치하는 항목만 강조되거나 필터링됩니다. 대상 팝업은 검색 시 그룹과 그룹별 건수도 함께 갱신되지만, 제목의 전체 건수는 검색과 관계없이 그대로 유지됩니다.

필터로 원하는 기록 찾기​

Filter 섹션에서 제공하는 필터를 조합해 원하는 기록을 좁혀서 찾으세요. 한 필터 안에서 여러 값을 선택하면 OR로, 서로 다른 필터를 함께 적용하면 AND로 결합됩니다.

필터동작 방식
Datetime시작·종료 날짜와 시각을 지정합니다. 조회 기간에는 길이 제한이 없습니다.
User검색어를 입력하고 Enter 키를 눌러 일치하는 사용자를 찾으세요. 처음 열면 목록이 비어 있습니다.
Account Level검색어를 입력하고 Enter 키를 눌러 일치하는 관리자 등급을 찾으세요.
Category검색 가능한 체크박스 목록에서 하나 이상의 분류를 선택하세요.
Target검색어를 입력하고 Enter 키를 눌러 일치하는 대상을 찾으세요.
Action체크박스 목록에서 하나 이상의 동작을 선택하세요.
Sub Action검색 가능한 목록에서 세부 작업을 선택하세요. 자세한 내용은 #audit-trail-sub-actions을 참고하세요.
IP검색어를 입력하고 Enter 키를 눌러 일치하는 IP를 찾으세요.

  • 적용된 필터가 없으면 현재 날짜로부터 30일 전까지의 기록을 기본 표시합니다.

  • 각 필터 팝업에서 원하는 값을 선택한 뒤 Add Condition 버튼을 클릭하면 즉시 검색에 반영됩니다. Cancel을 클릭하면 선택을 취소하고 팝업을 닫습니다.

  • 적용된 필터는 첫 항목과 추가 건수로 요약되어 표시됩니다. 버튼을 클릭하면 해당 필터만 해제됩니다. 값을 선택하지 않은 필터는 None으로 표시됩니다.

Info

User, Account Level, Target, IP 필터는 검색어를 입력해야 결과가 나타납니다. 부분 일치를 지원하므로 이름이나 아이디의 일부만 입력해도 됩니다. 삭제된 대상은 Deleted 표기로 함께 검색됩니다.

조회 기간 지정​

Datetime를 클릭하면 Date Range 팝업이 열립니다.

  1. Start datetime과 End datetime의 날짜와 시각을 각각 지정하세요. Today를 클릭하면 오늘 날짜로 바로 이동합니다.

  2. 조회 기간을 적용하려면 OK 버튼을 클릭하세요.

세부 작업 목록​

Sub Action 컬럼과 Sub Action 필터에 나타나는 세부 동작 이름을 주제별로 정리했습니다. 각 항목을 클릭하여 세부 내용을 확인하세요.

로그인 및 인증

  • Login (ID+Password), Login (ID+Password+Fingerprint), Login (Entra ID), Logout

  • 로그인 실패: Login Failed (ID+Password), Login Failed (Fingerprint), Login Failed (IP not allowed), Exceeded maximum login attempts

  • 세션·토큰: Session ID Provided, Service Token Issued, Login failure for service token issuance (ID+Password), Login attempts exceeded for service token issuance

시스템 백업
  • Quick Action, Backup Started, Backup Finished, Backup Cancelled, Auto Backup Started, Auto Backup Finished, Auto Backup Cancelled
사용자 관리

  • Change Password, Delete personal & credential data when issuing an AoC(Card and Mobile), Device Display Message

  • 얼굴 데이터: Face Import, Face Migration

  • 장치 연동: Transfer To Device, Delete From Device

  • 장기 미출입 사용자: Delete Long-term Idle Users, Search Long-term Idle Users, CSV Export Long-term Idle Users

  • 데이터 가져오기·내보내기: CSV Import, CSV Export, Data File Import, Data File Export

  • 이메일: Sending Email Succeeded, Sending Email Failed

  • 리포트 내보내기: PDF Export

카드 및 방문자

  • Block, Unblock

  • Check In, Check Out, Delete personal data

장치 관리

  • 연결 및 동기화: Connect, Disconnect, Sync Device, Time Sync with Server, Move Device

  • 설정: Config Export, Config Import, Set Network, Update Resource, Reset Config, Change Device ID, Set Fingerprint Template Format, Set Fire Alarm Signal

  • OSDP: Set OSDP Security Key, Replace OSDP Device, OSDP Bulk Edit

  • 잠금 및 활성화: Lock, Unlock, Activate, Inactivate, Device Locked, Device Unlocked

  • 유지 보수: Firmware Upgrade, Reboot, Factory Default, Upload Log, Delete All Event Logs in Device, Discover Wiegand Device

  • 카드 및 인증: Scan Card, Erase Card, Write Card, Release Auth Fail Lockout, Apply Auth Fail Lockout

  • 영상: Upload Video, Delete Video, Cancel Upload Video

  • 사이트 키 및 라이선스: Set Site Key, Delete Site Key, Send License File, Disable License, Manage Users

출입 통제 운영(출입문/엘리베이터/구역)

  • 출입문/엘리베이터: Lock, Unlock, Lock, Unlock, Clear Timed APB

  • 구역: Count Modified, Arm, Disarm, Update Tracking, Roll Call Started, Roll Call Ended

  • Event Log Imported
시스템 설정 및 라이선스

  • Register Enrollment Device, Unregister Enrollment Device, Reload Log Config, Sync Now

  • Activate License, Manual License Activation

  • Event Priorities
Info

다음과 같이 여러 화면에서 공통으로 쓰이는 이름은 대상에 따라 서로 다른 세부 작업으로 기록되므로 목록에서 개별적으로 다루지 않았습니다.

Upload, Delete, Print, Use, Not Use, Open, Release, Clear Alarm, Clear APB

정확한 대상은 같은 행의 Category와 Target 컬럼에서 확인하세요.

필터 저장​

자주 사용하는 검색 조건은 Saved Filters에 저장해 두고 다시 불러올 수 있습니다.

  1. 원하는 조건으로 필터를 설정하세요.

  2. Filter 섹션의 Save Filter 버튼을 클릭하세요.

  3. 화면 왼쪽 필터 목록에 New Filter 항목이 추가됩니다.

  • 필터 이름을 바꾸려면 버튼을 클릭하고 새 이름을 입력한 뒤 Enter 키를 누르세요.

  • 필터를 삭제하려면 버튼을 클릭하세요.

Info

저장할 수 있는 필터는 최대 20개입니다. 저장한 필터는 브라우저에 보관되므로 다른 PC나 브라우저에서는 표시되지 않습니다.

페이지 탐색​

페이지를 이동하거나 한 페이지에 표시할 목록 개수를 설정할 수 있습니다.

  • : 처음 페이지로 이동합니다.

  • : 이전 페이지로 이동합니다.

  • : 다음 페이지로 이동합니다.

  • : 마지막 페이지로 이동합니다.

  • : 한 페이지에 표시할 목록 개수를 선택합니다.

열 설정​

감사 로그 테이블의 컬럼 위치를 바꾸거나 숨길 수 있습니다. Filter 섹션 오른쪽의 → Column Setting을 클릭하세요.

  • [ Column List ]에서 숨기려는 항목의 체크박스 선택을 해제하세요.

  • 열 순서를 바꾸려면 원하는 항목을 드래그하세요.

  • 열 설정을 초기화하려면 Default Column 버튼을 클릭하세요.

설정을 저장하려면 Apply 버튼을 클릭하세요.

CSV로 내보내기​

감사 로그를 CSV 파일로 내보내 외부 분석 도구에서 활용하세요.

  1. Filter 섹션에서 필요한 경우 필터를 설정하세요.

  2. 섹션 오른쪽의 → CSV Export를 클릭하세요.

  3. CSV Export 창이 나타나면 Reason(선택 사항)을 입력하고 Download 버튼을 클릭하세요.

내보낸 CSV 파일은 레코드당 한 줄로 10개 컬럼을 모두 포함하며, 모든 값은 인용 부호로 감싸 표기됩니다. 대상이 여러 개인 값은 버티컬 바(|)로 구분되고(예: User: 7(Kim)|User: 8(Lee)), Details 값은 말줄임 없이 전체 대상과 전체 필드를 포함합니다.

Tip

필터를 설정했다면 필터링된 결과만 CSV 파일로 내보내집니다.

BioStar 2 기록 확인​

이전 버전(BioStar 2)에서 남긴 기록도 같은 테이블에서 함께 조회할 수 있습니다. BioStar 2 기록은 다음과 같이 표시됩니다.

  • User와 Target은 이름(id) 형식(공백 변형 포함)으로 원형 그대로 보존됩니다.

  • Modified Fields는 항상 하이픈(-)로 표시됩니다.

  • 제공되는 필터로 BioStar 2 기록도 동일하게 검색할 수 있으며, User와 Target은 이름과 아이디 양쪽으로 매칭됩니다.

Info

레거시 기록에는 지원하지 않는 검색 조건이 포함될 수 있습니다. 저장된 필터를 불러올 때 일부 조건이 제외되면 안내 메시지가 표시됩니다.
