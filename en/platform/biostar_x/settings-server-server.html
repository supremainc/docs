Configure Advanced Server Settings

You can change settings for the BioStar X server basics, user and device management, server matching, system log levels, and face image storage.

  1. On the Launcher page, click Settings.

  2. Click System → Server in the left sidebar.

  3. Set the options you need in each section.

    • General: Sets the IP address, port number, session timeout, event log upload method, and log retention period.

    • User/Device Management: Changes user and device management settings.

    • System Log Level Settings: Changes system log level settings.

    • Expert Settings: Sets whether to store both the face image and template, or store only the template without the face image.

  4. To save the settings, click Apply in the lower-right corner of the screen.

Basic information settings​

In the General section, check or set basic information for BioStar X.

  • BioStar X IP Address: Shows the server IP address.

  • Log Upload: Select an event log upload method. If real-time communication with the server is difficult, set this to Manual.

  • System log storage duration: The log retention period can be set from 1 to 120 days.

  • Session Timeout: Set the session timeout. If you are inactive for the set time after you log in to BioStar X, you are automatically logged out.

Info

If you set the Log Upload option to Automatic, the device automatically uploads its stored event logs when it reconnects to the server.

User and device management​

In the User/Device Management section, set synchronization and authentication methods between users and devices.

Automatic User Synchronization​

Select how to synchronize user information between the server and devices in the Automatic User Synchronization option. Synchronization includes users' access levels and access groups, so changes to them on the BioStar X server automatically apply to the related devices.

  • All Devices: User information is automatically synchronized between the server and devices.

  • All Devices(Including user update from device): User information on the server is synchronized with all devices registered on the server. However, user information modified on a device is not synchronized to the server, and only user information added on a device is synchronized to the server.

  • Specific Devices(Only devices belonging to the access group): Only devices in an access group with changes are automatically synchronized with the server.

Info

  • If you select the Specific Devices(Only devices belonging to the access group) option, users stored on a device that are not in an access group cannot be managed on the server. To use this option, click Settings → Device → Device, select each device, and click Delete Data & Sync Device to run synchronization. For more information about the Delete Data & Sync Device feature, see Use Device Management Features.

  • Even if you select the Specific Devices(Only devices belonging to the access group) option, access groups designated for special purposes are synchronized regardless of the device access group, as follows.

    • Dual authentication access group set for devices and elevators

    • Bypass group in the anti-passback settings

    • Bypass group in the scheduled lock settings

    • Unlock authentication access group in the scheduled unlock settings

    • Intrusion alarm group in the intrusion alarm settings

  • Even if you select the Specific Devices(Only devices belonging to the access group) option, users designated as device administrators are synchronized regardless of the access group.

Fingerprint Template Format​

In the Fingerprint Template Format option, select the fingerprint template format. Select from the following options.

  • SUPREMA: Suprema fingerprint template format. Used when enrolling fingerprints on Suprema devices.

  • ISO: ISO international fingerprint template format.

  • ANSI378: Fingerprint template format defined by the American National Standards Institute (ANSI).

Info

If user fingerprint templates remain on the device, you cannot change to a different format.

In the User ID Type option, select Number or Alphanumeric as the user ID type. Check the list of devices registered on the BioStar X server, and select compatible settings.

Enrollment Device​

The Enrollment Device option lets you add devices you use often to enroll fingerprints, faces, or cards.

  1. To add a device, click + Add.

  2. When the Enrollment Device window appears, select the checkbox for the device to add in the list.

  3. To add the selected device, click Add.

  4. To save the added device settings, click Apply in the lower-right corner of the screen.

Info

  • If there are too many registered devices to find in the list, enter a keyword in the search field to search for a device. Enter a device ID, device name, device group, or IP address.

  • For more information about enrolling fingerprints or face, card credentials, see the followings:

    • Enroll Fingerprint
    • Enroll Face
    • Enroll Access Card
    • Enroll Mobile Access Cards

Custom User Field​

The Custom User Field option lets you add fields for entering additional user information. The added fields appear on the user information screen.

  1. To add a custom user field, click + Add.

  2. Enter a name for the custom user field, and select a type.

    • Number Input Box: Enter a value from 0 to 4294967295. Letters are not allowed.

    • Text Input Box: Allows entry of up to 32 characters, including numbers and letters.

    • Combo Box: Add up to 20 entries of up to 32 characters, separated by semicolons (;). (for example, Option1;Option2;Option3)

    • File Upload: Adds a field for file uploads.

      • The maximum file size is 1 MB.

      • The file name can be from 1 to 120 characters long.

      • File name requirements: Use alphanumeric characters, underscores (_), and hyphens (-), and use a period (.) to separate the extension.

      • There are no restrictions on file extensions, and uploaded files are encrypted and stored in the database.

  3. To save the added custom user field, click Apply in the lower-right corner of the screen.

Info

  • To change the order of custom user fields, change the number in the Order column. The field position changes.

  • After modifying the custom user fields, click Apply in the lower-right corner of the screen.

  • To delete a custom user field, click . Deleted fields cannot be recovered.

  • For more information about registering and editing user information, see Users.

  • User information with custom user fields can be printed on a card. For more information, see Print Cards.

Other settings​

  • AC event log storage duration: Set the retention period for access control event logs.

    Info

    The access control event log retention setting applies only to server logs. This setting does not apply to device event logs. If you need to delete device event logs, delete them individually in the Settings → Device → Device menu.

  • Hide Face Credential Preview Image: To protect users' personal information, hide the preview image when you enroll face credentials. When this option is enabled, the preview screen does not appear when you enroll face credentials for a user.

Set up server matching​

In the Server Matching section, you can set up the server matching feature, which authenticates user information in BioStar X instead of on the device.

  • Use Server Matching: Turn server matching on or off.

  • Max. Simultaneous Server Matching Count: Set the maximum number of server matching tasks that can run at the same time.

    This option may vary depending on the CPU performance of the server PC where BioStar X is installed.

  • Fingerprint

    • Fast Mode: Adjust the fingerprint matching speed.

    • Security Level: Set the server matching security level for fingerprints. A higher security level increases the false rejection rate (FRR).

  • IR Face
    • Security Level: Set the server matching security level for IR face. A higher security level increases the false rejection rate (FRR).
Info

The Server Matching feature is available as an add-on option with an Essential license or higher. For more information about the licensing policy, see License Policy.

Set system log level​

In the System Log Level Settings section, you can set the level of system logs stored in the database.

System logs are managed by predefined categories, and log levels are divided into Trace, Debug, Info, Warning, and Error. A higher level includes all lower-level logs. For example, if you select Trace, the system saves all Debug, Info, Warning, and Error logs as well.

Store face images​

When you enroll a face as a credential, you can set whether to store both the actual image and the template, or only the template.

Before you begin

Before enabling the Display expert settings option, save any changes you made in the Server menu first. Click Apply in the lower-right corner of the screen.

  1. In the Expert Settings section, set the Display expert settings option to Use.

  2. Click Expert Settings.

  3. When the Expert Settings screen appears, set the Store Face Image option.

    • Use: Default. Stores both the actual image and the template of the face credential.

    • Not Use: Stores only the template and does not store the actual image of the face credential. Read the warning pop-up that appears when you select this option carefully before setting it.

  4. To save the settings, click Apply.

Caution

Precautions when turning off the Store Face Image option

  • If you turn off this feature, all stored face images are deleted, and only templates are stored for faces enrolled later.

  • You cannot turn off this feature if the enrolled face images do not have both types of templates. For more information about the Face Migration feature, see Face Migration.

  • After you disable this feature, you cannot import a data file from Data File Import if it includes invalid face image templates. To resolve the issue, temporarily enable this feature and then import the data file.
