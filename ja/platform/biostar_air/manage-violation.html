APB 위반 확인하기

Not translated
This page is currently being translated. We will complete the translation as soon as possible.

ゾーン管理 → 違反 메뉴에서는 구역에 설정한 안티패스백(APB) 규칙을 어긴 사용자를 확인하고, 필요할 때 위반 상태를 해제할 수 있습니다. 구역과 APB 모드를 아직 설정하지 않았다면 먼저 구역 관리하기를 참고하세요.

위반이 발생하는 경우​

APB 위반은 사용자가 구역에 설정된 APB 모드에 따라 순서에 어긋난 출입을 시도할 때 기록됩니다.

  • Hard 모드로 설정된 구역에서는 APB 위반 시 출입이 차단되고, APB 위반으로 기록됩니다.

  • Soft 모드로 설정된 구역에서는 APB 위반 시 출입은 허용되지만, APB 위반으로 기록됩니다.

  • APB 예외 그룹에 속한 사용자는 APB 규칙이 적용되지 않으므로 위반 목록에 나타나지 않습니다.

위반 목록 살펴보기​

  • Web
  • Mobile

Web

화면 왼쪽 사이드바에서 ゾーン管理 → 違反를 클릭하세요.

Mobile

  1. 모바일 기기에서 BioStar Air 앱을 실행하고 로그인하세요.

  2. 화면 하단의 管理를 탭하세요.

  3. 違反 카드를 탭하세요.

목록에서는 현재 활성 상태인 APB 위반 사용자를 확인할 수 있습니다. 활성 APB 위반이 없으면 목록 대신 빈 상태 화면이 표시됩니다.

  • ユーザー: APB 위반이 기록된 사용자입니다.

  • APB違反: APB 위반이 발생한 모드(Hard/Soft)입니다.

  • ゾーン: APB 위반이 발생한 구역입니다.

  • ドア: APB 위반이 발생한 출입문입니다.

  • アクション: 개별 APB 위반을 해제할 수 있습니다.

情報

해제된 APB 위반과 과거 APB 위반 이력은 モニタリング → イベントログ에서 계속 확인할 수 있습니다.

위반 목록 관리 기능​

목록 상단 및 하단에서 제공하는 관리 기능으로 다음 작업을 수행할 수 있습니다.

  • 違反を解除: 목록에서 선택한 사용자의 APB 위반을 해제할 수 있습니다. 자세한 내용은 #clearingViolations를 참고하세요.

  • リフレッシュ: 목록을 즉시 새로고침해 최신 상태로 갱신합니다. 목록 하단의 自動更新에서 자동 새로고침 간격(無効/５秒/１分)을 선택하면 설정한 주기마다 목록을 자동 갱신합니다.

  • ユーザー名を検索…: 사용자 이름으로 검색할 수 있습니다.

위반 목록 필터링​

  • Web
  • Mobile

Web

목록 상단 헤더의 APB違反, ゾーン, ドア 열에 있는 버튼을 클릭하면 해당 조건으로 목록을 필터링할 수 있습니다.

情報

필터링을 해제하려면 リセット 버튼을 클릭하세요.

Mobile

  1. 위반 목록 오른쪽 상단의 フィルター를 탭하세요.

  2. APB違反, ゾーン, ドア에서 원하는 조건을 선택하세요.

  3. 선택한 조건으로 목록을 필터링하려면 保存 버튼을 탭하세요.

情報

필터링을 해제하려면 リセット 버튼을 탭하세요.

위반 해제​

APB 위반을 해제하면 사용자의 활성 APB 위반 상태가 초기화되어, 다시 구역에 정상 출입할 수 있습니다.

情報

  • 違反を解除는 사용자의 활성 APB 위반 상태만 초기화합니다. APB 위반이 발생한 원본 이벤트는 삭제되지 않으며 이벤트 로그에 그대로 남습니다.

  • 구역이 비활성화되어도 이미 발생한 APB 위반은 그대로 유지되며, 위반 목록에서 해제할 수 있습니다.

  • APB 예외 그룹에 속한 사용자는 이 목록에 표시되지 않지만, 구역의 내부 인원 수에는 계속 포함됩니다.

개별 사용자의 위반 해제​

  • Web
  • Mobile

Web

  1. 목록에서 APB 위반을 해제할 사용자의 アクション 열에서 違反を解除 버튼을 클릭하세요.

  2. 확인 메시지가 나타나면 違反を解除 버튼을 클릭하세요.

Mobile

  1. 목록에서 APB 위반을 해제할 사용자의 버튼을 탭하세요.

  2. 확인 메시지가 나타나면 違反を解除 버튼을 탭하세요.

여러 사용자의 위반 해제​

  • Web
  • Mobile

Web

  1. 목록에서 APB 위반을 해제할 사용자의 체크박스를 클릭하세요. 한 명 이상의 사용자를 선택할 수 있습니다.

  2. 목록 상단의 違反を解除 버튼을 클릭하세요.

  3. 확인 메시지가 나타나면 違反を解除 버튼을 클릭하세요.

Mobile

  1. 목록에서 APB 위반을 해제할 사용자를 길게 누르세요.

  2. 위반을 해제할 사용자를 선택하세요. 한 명 이상의 사용자를 선택할 수 있습니다.

  3. 화면 하단의 違反を解除 버튼을 탭하세요.

  4. 확인 메시지가 나타나면 違反を解除 버튼을 탭하세요.
