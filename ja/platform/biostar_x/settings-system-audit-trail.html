監査トレイルを管理する​

Audit Trail 機能は、システムで発生するすべてのアクティビティを記録して追跡します。 ユーザーのログイン／ログアウト、設定変更、システム管理作業などのすべてのアクティビティが記録され、セキュリティ監査やシステム監視に活用できます。

  • セキュリティ監査：不正アクセスの試みや権限乱用を検出できます。

  • トラブルシューティング：システムエラーが発生した時点や設定変更履歴を追跡できます。

  • コンプライアンス：アクセス記録の保存や監査レポートの作成ができます。

監査履歴を使用する​

  1. LauncherページでSettingsをクリックします。

  2. 画面左のサイドバーで System → Audit Trail をクリックします。

  3. 監査トレイルの一覧が画面に表示されます。

主要な追跡項目の詳細については#audit-trail-itemsをご参照ください。

追跡される操作タイプ​

Filter セクションで Action オプションをクリックして、監査トレイルを次の動作タイプで分類します。

  • Add：新しい項目の作成​

  • Update：既存項目の変更​

  • Delete：項目の削除​

  • Action：システム機能の実行（ログイン、デバイス制御など）​

権限レベル別の分類​

管理者レベルに応じて監査履歴を分類できます。 Filter セクションで Account Level オプションをクリックして、次の権限レベルでフィルタリングします。

  • Administrator(1)：すべてのシステム機能へのアクセス​

  • User Operator(2)：ユーザー管理機能​

  • Monitoring Operator(3)：モニタリング機能​

  • Video Operator(253)：ビデオ関連機能​

  • TA Operator(254)：勤怠管理機能​

情報

  • Video Operator(253) の権限は アドバンス（Advanced）ライセンス以上で追加オプションとして利用できます。

  • TA Operator(254) の権限は追加オプションで利用できます。

ライセンスポリシーの詳細については、ライセンス ポリシーを参照してください。

期間設定の照会​​

照会する期間を設定し、特定期間の監査トレイル履歴を確認します。

事前定義された期間で照会​​

画面左のフィルターリストで Last 1 Month または Last 3 Months を選択します。

ユーザー定義期間で照会​​

詳細な期間設定が必要な場合は、Filter セクションの Datetime オプションで開始日と終了日を設定します。

フィルター設定​​

監査トレイル一覧を効率的に閲覧できるよう、さまざまな条件でフィルターします。

Filter セクションで次のオプションを設定できます。 フィルターオプションは監査履歴一覧の列項目と一致します。 ただし、Modification 列はフィルタリングできません。

  • Datetime：イベントが発生した日時​

  • USER：イベントを実行したユーザーID​

  • Account Level：ユーザーの権限レベル​

  • IP：ユーザーが接続したIPアドレス​

  • Category：変更された項目のメニューカテゴリ​

  • Target：変更された対象​

  • Action：実行された操作​

  • Modification：イベント発生時の詳細内容​

フィルターの保存​

フィルターを設定し、Filter セクションの Save Filter ボタンをクリックすると、画面左のフィルターリストに設定したフィルターを保存できます。

  • フィルター名を変更するには ボタンをクリックします。 フィルター名を入力し、Enter キーを押すとフィルター名が変更されます。

  • フィルターを削除するには ボタンをクリックします。 フィルターリストからそのフィルターが削除されます。

ページナビゲーション​​

ページを移動したり、1ページに表示する一覧の件数を設定できます。

  • ：最初のページへ移動します。

  • ：前のページへ移動します。

  • ：移動したいページ番号を入力し、Enter キーを押すとそのページへ移動します。

  • ：次のページへ移動します。

  • ：最後のページへ移動します。

  • ：1ページに表示するリスト数を選択できます。

CSV へのエクスポート​

監査トレイルの一覧をCSVファイルにエクスポートし、外部分析ツールで活用します。

  1. Filter セクションで必要に応じてフィルターを設定します。

  2. セクション右側の → CSV Export をクリックします。

  3. CSV エクスポートウィンドウが表示されたら、Export Reason（任意）を入力し、Download ボタンをクリックします。

ヒント

フィルタリングを設定した場合、フィルタリングされた結果だけがCSVファイルにエクスポートされます。

列設定​

監査履歴リストの列の位置を変更したり、非表示にしたりできます。 Filter セクションの一番右で → Column Setting をクリックします。

  • 列リストで非表示にしたい項目のチェックボックスの選択を解除します。

  • 列の順序を変更するには、目的の項目をドラッグして位置を変更できます。

  • 列設定を初期化するには、Default Column をクリックします。

設定を保存するには、Apply をクリックします。

主要監査項目​

監査履歴で記録されるすべてのアクティビティをカテゴリ別に整理しました。 各項目をクリックして詳細を確認します。

システムアクセス

  • ログイン：Login (ID+Password)

  • 多要素認証ログイン：Login (ID+Password+Fingerprint)

  • ログアウト：Logout

  • ログイン失敗理由：Login Failed (Fingerprint)、Login Failed (ID+Password)、Login Failed (IP not allowed)

  • ログイン失敗回数超過：Exceeded maximum login attempts

ユーザー情報

  • 基本情報：Name、User ID、Login ID、Email、Phone

  • 認証情報：Password、PIN、Fingerprint Template、IR Face、Cards

  • 権限およびグループ：Account Level、Access Groups、User Group、Private Auth Modes

  • ユーザー状態：Status、Start Datetime、Expiry Datetime

  • データ管理：CSV Import、CSV Export、Data File Import、Data File Export

  • デバイス連携：Transfer To Device、Delete From Device

  • その他：Photo、Custom Fields、1:1 Security Level、Print

  • 管理：CSV Export Long-term Idle Users、Delete Long-term Idle Users、Face Migration、Face Import

  • メール機能：Sending Email Succeeded、Sending Email Failed

アクセス制御

  • ドア設定：Name、Description、Door Group

  • ドアデバイス：Entry Device、Exit Device、Relay、Door Sensor、Exit Button

  • ドア制御：Door Open Duration、Door Open Once、Door Open Timeout、Dual Authentication、Use Automatic Door

  • ドア動作：Lock、Unlock、Release、Open、Clear Alarm、Clear APB、Clear APB、Clear Timed APB

  • アクセスグループ：Name、Description、Access Levels、User Groups、Users

  • アクセスレベル：Name、Description、Access Level

  • エレベーター設定：Name、Description、Elevator Group、Floors、Open Time

  • エレベーターデバイス：Controller、Reader、Module、Tamper

  • エレベーター制御：Dual Authentication、Trigger & Action

  • エレベーター動作：Lock、Unlock、Release、Open、Clear Alarm、Clear APB

  • フロアレベル：Name、Description、ID、Floor Level

デバイス管理

  • デバイス基本設定：Name、Device Group、Time Zone

  • 認証設定：Authentication、Fingerprint、IR Face、Card

  • インターフェース設定：Display、Image Log、Image Log

  • 通信設定：TCP/IP、Device to Server Connection、RS485、WLan、Wiegand、Wiegand IO、USB、VOIP

  • 機能設定：System、TNA、Trigger & Action、Camera Frequency

  • ユーザー管理：Manage Users

  • デバイス制御：Connect、Disconnect、Sync Device、Delete Data & Sync Device、Discover Wiegand Device

  • システム管理：Factory Default、Reboot、Firmware Upgrade、Time Sync with Server、Send License File

  • デバイス状態：Locked、Clear Alarm、Delete

高度アクセス制御

  • 高度アクセス制御の基本設定：Name、Description、Advanced AC Type、Active/Inactive、Mode

  • アンチパスバック：APB、Clear APB、Clear APB

  • 火災警報：Fire Alarm

  • スケジュール制御：Scheduled Lock、Scheduled UnLock

  • 在室人数管理：Count +1、Count -1、Count Modified

  • 高度アクセス制御の操作：Lock、Unlock、Release、Open、Clear Alarm

システム設定

  • サーバー設定：BioStar X IP Address、BioStar X Port、Web Server Protocol、Session Timeout

  • セキュリティ設定：Secure communication with device、Password Level、Server Matching

  • 同期設定：Log Upload、Automatic User Synchronization

  • デバイス設定：Enrollment Device、Fingerprint Template Format、Mobile Card Enrollment、Use User Photo

  • ライセンス：License

  • 基本設定：Language、Date Format、Time Format、Time Zone

  • スケジュール設定：Name、Description、ID、Schedule、Holiday、Start Date、Type、Cycle

  • 休日設定：Name、Description、Holiday

  • 警報設定：On、Off

  • イメージログ設定：Preset、Delete Option

  • モバイルクレデンシャル：Use、Not Use

  • 監査記録: CSV Export、Automatic Report Schedule 追加、修正、削除

高度セキュリティ設定

  • スマートカード - DESFire：DESFire App ID、DESFire File ID、DESFire Encryption Type、DESFire Primary Key、DESFire Secondary Key

  • スマートカード - iClass：iClass Primary Key、iClass Secondary Key、iClass Start Block Index
