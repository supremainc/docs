# BS2_UnlockDoor

Configures the priority of when the door gets unlocked. The unlock priority must be higher than the lock to unlock the door.

## Declaration

```cpp
#include "BS_API.h"

int BS2_UnlockDoor(void* context, uint32_t deviceId, uint8_t flag, uint32_t* doorIds, uint32_t doorIdCount);
```

## Parameter

- \[In\] `context` : Context

- \[In\] `deviceId` : Device ID

- \[In\] `flag` : Priority of the unlock status to add

- \[In\] `doorIds` : List of door IDs

- \[In\] `doorIdCount` : Number of door IDs

## Return Value

If successfully done, `BS_SDK_SUCCESS` will be returned.

If there is an error, the corresponding error code will be returned.
