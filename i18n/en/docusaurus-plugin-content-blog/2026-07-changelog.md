Summer heat has arrived in full force this July. We hope you stay healthy through the hot weather, and this month brings plenty of good news for **Suprema Docs**. We've newly published a user guide for the cloud-managed platform **CLUe**, which lets you build an access control system entirely in the cloud, without an on-premises server. ## CLUe Guide Released

We've newly published a user guide for [**CLUe**](../platform/clue/), a cloud-managed access authentication service that lets you deploy an access control system through standard REST API integration alone, without building an on-premises server. Manage it easily through the web portal or mobile app.

* [CLUe Web Portal Guide](../platform/clue): Covers the full range of CLUe service operations, including administrator permission structure, device and door settings, firmware updates, webhook configuration, and audit log review.

* [CLUe API](../developer/clue): API documentation for developers who want to directly integrate user management and access authentication features.
