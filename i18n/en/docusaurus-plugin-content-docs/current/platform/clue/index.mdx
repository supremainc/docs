Suprema CLUe is an open cloud integration platform that lets you build an access authentication system with only the cloud, without an on-premises server. Because the device connects directly to the cloud, you can easily implement server-to-server integration through the standard REST API. Pair it with Suprema's biometric access control devices to enhance security, and manage it easily through a mobile app and web portal while getting technical support. It suits a wide range of businesses that need member management, such as fitness centers, shared offices, and multi-branch offices, and it directly supports all features needed for access control, so customers can focus on their core business.

## Key features of CLUe

* **Simple development**: Use API integration between web services instead of an SDK, so you can quickly connect access authentication features without building a separate development environment.

* **Simple installation**: It works as a Plug & Play solution that does not require a separate server, so you can use it right away without a complex installation process.

* **Efficient maintenance**: It supports continuous upgrades and responds quickly to issues through constant system monitoring.

* **Various authentication methods**: It supports various authentication methods, including QR codes, Facial Authentication, RFID, and Fingerprint.

* **Custom development**: It supports custom development to match each customer's service environment.

* **Data security**: It has earned CSA STAR Level 2 certification and manages data securely in compliance with ISO27001 and ISO27701 standards.
