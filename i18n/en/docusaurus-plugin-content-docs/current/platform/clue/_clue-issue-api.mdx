## Generate an API key

1. Log in to the [CLUe web portal](https://clue.moon.supremainc.com).

2. Select the place group for API integration. 

3. Click <IcAirMore title='more' /> → <Cmd sid='settings_2' product='clue' /> in the upper right of the screen.

   <ProdImg src='/img/clue/clue-place-group-settings.png' />

4. Click <Cmd sid='admin' product='clue' /> in the left sidebar.

   <ProdImg src='/img/clue/clue-place-group-settings-admin.png' />

5. In the <Cmd sid='manage_api_keys' product='clue' /> section, click <Cmd sid='add_new_api_key' product='clue' />.

6. Select the desired validity period.

   <ProdImg src='/img/clue/clue-place-group-settings-admin-new-api.png' />

   :::note

   If you select <Cmd sid='custom' product='clue' />, you can set the validity period for up to 365,000 days.

   :::

7. To issue a new API key, click the <Cmd sid='add_2' product='clue' /> button.

8. When the new API key is created, click the <Cmd sid='copy' product='clue' /> button and use it as a Bearer token when calling the CLUe API.

   <ProdImg src='/img/clue/clue-place-group-settings-admin-api-copy.png' />

:::caution

The API key grants access to the CLUe API, so keep it secure and do not expose it externally. Suprema is not responsible for problems caused by misuse.

:::
