The <Cmd sid='safety_menu' product='air' /> → <Cmd sid='presence_submenu' product='air' /> menu shows users currently on site in real time. The presence status is calculated based on authentication logs from the entry and exit devices set in <Cmd sid='apb.zoneList.perimetterZone' product='air' className='bold' />. If <Cmd sid='apb.zoneList.perimetterZone' product='air' className='normal' /> is not set yet, see <DocLink docId='platform/biostar_air/manage-zone' /> first.

## How presence status is determined {/* #howPresenceIsDetermined */}

When users authenticate at an entry device in the perimeter zone, their status changes to <Cmd sid='presence_on_site' product='air' />. When they authenticate at an exit device, it changes to <Cmd sid='presence_off_site' product='air' />.

* For sites without an exit device in the perimeter zone, always set <Cmd sid='apb.zoneForm.offsite.label' product='air' />. If users are inactive for the set time, their status automatically changes to <Cmd sid='presence_off_site' product='air' />.

* For how to set entry and exit devices for the perimeter zone and the <Cmd sid='apb.zoneForm.offsite.label' product='air' /> setting, see <DocLink docId='platform/biostar_air/manage-zone#addingZone' />.

* Presence status is calculated based on the same rules used in the menus below.

  * <Cmd sid='dashboard_menu' product='air' />

  * <Cmd sid='safety_menu' product='air' /> → <Cmd sid='presence_submenu' product='air' />

  * <Cmd sid='safety_menu' product='air' /> → <Cmd sid='roll_call_submenu' product='air' />

By default, the presence list shows only users with the <Cmd sid='presence_on_site' product='air' /> status.

* <Cmd sid='presence_entered_through_column' product='air' />: The entry device and time when the user authenticated to enter the site.

## Manually change presence status {/* #manualOverride */}

When actual conditions differ from the presence status recorded in the system, an administrator can change the status.

* Presence accuracy varies depending on the site’s entry and exit device setup. Sites with clearly defined entry and exit devices provide more reliable presence information.

* If a device goes offline or event delivery is delayed, the presence status may update after synchronization completes.

* Presence status differs from access permissions. Users shown as <Cmd sid='presence_on_site' product='air' /> cannot necessarily access every door.

* Users with expired, inactive, or suspended accounts cannot change presence status until the account is active.

:::info

Manual changes only update the status recorded in the system. They do not physically verify a user’s location. Check the change history in <Cmd sid='monitoring_menu' product='air' /> → <Cmd sid='audit_logs_submenu' product='air' />.

:::

   <Image src='/img/air/bsair-safety-presence-action.png' />
