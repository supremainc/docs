title: Set Up SSO & SCIM
description: This guide shows how to set up SSO and SCIM with Microsoft Entra ID or Okta. Strengthen BioStar Air administrator sign-in and automate account creation and deletion.
---

Many organizations already manage internal system access with Microsoft Entra ID or Okta, regardless of company size. BioStar Air integrates with these ID providers to centrally manage admin accounts and credential users from a single source.

SSO (Single Sign-On) applies your organization’s existing ID policies to BioStar Air admin logins, enhancing security. SCIM (System for Cross-domain Identity Management) automatically creates and deletes user accounts, reducing security risks from accounts left active without access. This reduces repetitive work to create, edit, and delete users, user groups, and admin accounts.

In the left sidebar, click <Cmd sid='settings_menu' product='air' /> → <Cmd sid='site_submenu' product='air' />. On the <Cmd>SSO & SCIM</Cmd> tab, select the sign-in policy and identity provider, and configure them. For basic settings, see <DocLink docId='platform/biostar_air/site-sso-scim-basic-settings' />.

If <Cmd sid='sso_scim.additional_features.sso.microsoft_entra_id' product='air' className='bold' /> or <Cmd sid='sso_scim.additional_features.sso.okta' product='air' className='bold' /> is the identity provider, use the documents below. Set up SSO and SCIM provisioning.
