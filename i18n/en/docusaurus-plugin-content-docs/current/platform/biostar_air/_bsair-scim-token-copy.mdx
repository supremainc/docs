### BioStar Air: Copy SCIM token {/* #copyToken */}

1. Click <Cmd sid='settings_menu' product='air' /> → <Cmd sid='site_submenu' product='air' /> in the left sidebar of BioStar Air.

2. Click the <Cmd>SSO & SCIM</Cmd> tab.

3. In the <Cmd sid='sso_scim.additional_features.scim.title' product='air' /> section, copy the <Cmd sid='sso_scim.additional_features.scim.endpoint_url' product='air' /> value.

   <Image src='/img/air/bsair-settings-site-idp-okta-copy-endpoint-url.png' />

4. Click <Cmd sid='sso_scim.additional_features.scim.generate_token' product='air' />.

5. In the Token Generation Complete dialog box, copy the token.

:::info

* Copy the generated token immediately. Copy the token only when you generate it. After you close the dialog box, you cannot copy the token again.

* If you lose the token, click <Cmd sid='sso_scim.additional_features.scim.rotate_token' product='air' /> to generate a new token. Enter the new token in the identity provider again.

* In the next step, enter the SCIM endpoint URL and token copied in this step.

:::
