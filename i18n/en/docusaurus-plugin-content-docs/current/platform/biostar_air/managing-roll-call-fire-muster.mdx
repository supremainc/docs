With BioStar Air's Roll Call feature, organizations can track which users have safely evacuated during an emergency. Set muster zones and run a roll call in the BioStar Air mobile app. Administrators can quickly identify on-site users based on presence information and confirm safety.

:::note

**Accurate muster lists based on Presence**

* Roll call does not assume all users are on site. Using Presence logic, include only users confirmed to be on site at the time of the emergency as roll call targets.

* Assign user groups to certain muster zones and designate dedicated administrators. Safety managers can focus on assigned users.

* The Suprema Pass app guides mobile credential users on site to the correct muster zone and warns off-site users not to enter the facility during an emergency.

:::

:::info

* Ensure that muster zones are correctly assigned to user groups to avoid confusion.

* Regularly test the roll call feature to ensure smooth operation during a real emergency.

* Use access events to verify attendance for safety compliance.

:::

## Before you start {/* #beforeStart */}

* Roll call accuracy depends on presence detection. If <Cmd sid='apb.zoneList.perimetterZone' product='air' /> is not set correctly, the roll call list may differ from the actual on-site headcount.

* Mobile notifications require the Suprema Pass app. Users who use only RF cards or biometric credentials cannot receive mobile roll call notifications.

* On-site users not assigned to a muster zone may not receive muster point guidance.

* If the <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' /> setting is incorrect, the expected roll call screen may not appear for administrators.

* If a device goes offline or event delivery is delayed, it can affect presence information and roll call accuracy.

* Inactive users do not receive roll call notifications.

:::info

Users and administrators who use earlier versions of the Suprema Pass or BioStar Air app can continue using the legacy roll call method. Update to the latest version to use the new features.

:::

## Set muster zones {/* #settingMusterPoints */}

A muster zone is a designated location where users authenticate their credentials to indicate they are safe during an emergency.

1. Click <Cmd sid='safety_menu' product='air' /> → <Cmd sid='roll_call_submenu' product='air' /> on the left sidebar.

2. Click <Cmd sid="add_muster_point_btn" product="air" /> at the top right of the screen.

   <Image src='/img/air/bsair-adv-rollcall.png' />

3. Enter the muster point name and description (optional) when the <Cmd sid='add_muster_point_title' product='air' /> panel appears.

   <Image src='/img/air/bsair-adv-rollcall-add.png' />

4. In the <Cmd sid="add_muster_point_devices_title" product="air" /> section, add the device group or device to assign to the muster zone. Select the checkbox for the device group or device, and click <Cmd sid="add_btn" product="air" />.

   <Image src='/img/air/bsair-adv-rollcall-add-device-group.png' />

5. In the <Cmd sid="add_muster_point_user_groups_title" product="air" /> section, select the user groups that must report when they arrive at the muster zone.

   <Image src='/img/air/bsair-adv-rollcall-add-user-group.png' />

   * Select the checkbox for the group, and click <Cmd sid='add_btn' product='air' />.

   * <Cmd sid='fm.musterForm.allUsers.name' product='air' />: Includes all currently active users in this muster zone instead of selecting specific user groups. Running a roll call does not assume all users are on site. It targets only users confirmed on site based on presence detection. Enabling this option disables individual user group selection. Disable this option first to select only certain groups.

6. In the <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' /> section, select the checkbox for the administrator who will run Roll Call at the muster location, then click <Cmd sid='add_btn' product='air' />.

   <Image src='/img/air/bsair-adv-rollcall-add-assign-admin.png' />

   :::note

   * If you select <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' />, only the selected administrators can start the Roll Call. During an ongoing Roll Call, they can view and manage only users in their assigned muster zones.

   * If you do not assign <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' />, users with the <Cmd sid='master_role' product='air' />, <Cmd sid='admin_role' product='air' />, or <Cmd sid='operator_role' product='air' /> role can start Roll Call.

   * An administrator cannot be assigned as the designated administrator for multiple muster zones at the same time.

   :::

7. Click <Cmd sid="save_btn" product="air" /> to save the muster zone settings.

:::note

**Best practices for muster zones**

* Make the muster zone name and description clear and easy to understand. For example, use names like 'East Parking Lot' or 'Main Building Lobby'.

* When adding multiple devices to a muster zone, select a device group instead of individual devices. Device groups let you manage multiple devices at once. For more information on device group management, refer to <DocLink docId='platform/biostar_air/manage-device-group' />.

* In a large campus with multiple buildings, assign **only relevant users** to a specific muster zone.

* Wired access control devices support both mobile and card authentication, whereas Airfob Tag and Airfob Patch support only mobile credentials.

:::

## Start roll call {/* #startingRollcallonMobile */}

### Start on mobile

Start a roll call and check attendance in the BioStar Air mobile app.

<Image src='/img/air/bsair-mobile-adv-rollcall.png' className='none' />

1. Open the BioStar Air app on your mobile device and log in.

2. Tap <Cmd en="All Menu">All Menu</Cmd> → <Cmd sid="roll_call_submenu" product="air" /> at the bottom of the screen.

3. Tap <Cmd en='Start Roll Call'>Start Roll Call</Cmd>.

4. Select the muster zone to start Roll Call, then tap <Cmd en='Continue'>Continue</Cmd>.

   To run Roll Call in all muster zones, select <Cmd en='Site-wide'>Site-wide</Cmd>, then tap <Cmd en='Continue'>Continue</Cmd>.

5. Select a muster zone in the ongoing Roll Call list.

6. A list of all users who must gather at the muster location appears.

:::note

**Differences by administrator role**

* <Cmd sid='master_role' product='air' />, <Cmd sid='admin_role' product='air' />, and <Cmd sid='operator_role' product='air' /> users can view the Roll Call list. This applies when they are not assigned as <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' /> for the muster zone. They start new Roll Calls in the order listed above.

* <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' /> receives a notification when Roll Call starts in the assigned muster zone. Tap the notification to go directly to the progress screen for the assigned muster zone.

:::

:::note

**End scope by role**

* The site master can end Roll Calls individually one by one, select multiple calls to end at once, or end all ongoing Roll Calls at the site at once.

* <Cmd sid='admin_role' product='air' className='normal' /> or <Cmd sid='operator_role' product='air' className='normal' /> selected in <Cmd sid='fm.musterForm.assignedAdmins.title' product='air' /> can end only Roll Calls for the zones they manage.

:::

:::info

Manually mark users in the <Cmd sid='presence_off_site' product='air' /> status as safe. For example, mark users working from home that day as safe in advance.

:::

## View roll call history {/* #viewingRollCallHistory */}

View the history of previous roll calls.

1. Click <Cmd sid='safety_menu' product='air' /> → <Cmd sid='roll_call_submenu' product='air' /> on the left sidebar.

2. Click the <Cmd sid="roll_call_history_tab" product="air" /> tab.

   <Image src='/img/air/bsair-adv-rollcall-history.png' />

3. Click a completed roll call entry to view its details.

<Image src='/img/air/bsair-adv-rollcall-history-details.png' />

* View the list of all access events recorded during the roll call.

* Check whether each user was marked safe or unconfirmed.

* Check the start and end times of the roll call.
