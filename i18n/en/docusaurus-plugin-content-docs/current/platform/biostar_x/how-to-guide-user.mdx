Learn about the various features available on the <Cmd sid='shell.header.user' /> page, one of **BioStar X**'s core features. This page shows how to manage users efficiently with features such as user group management, user management, user template management, and viewing users by access permission, and how to strengthen security with permissions. Use these features to get more out of **BioStar X**.

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />, or select <Cmd sid='shell.header.user' /> from the shortcut list in the upper-left corner of the screen.
