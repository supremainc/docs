In the <Cmd sid='shell.header.data' /> menu, you can search user information registered in **BioStar X** or events that match selected criteria, and generate reports at set intervals. If needed, you can automatically generate a report at set intervals, and export the generated report as CSV or PDF files or print it.

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.data' />, or select <Cmd sid='shell.header.data' /> from the shortcut list in the upper-left corner of the screen.
