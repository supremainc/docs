Learn how to upgrade BioStar 2 to **BioStar X** step by step. Check the system requirements and precautions before you start the upgrade.

## Before you start {/* #start-before */}

Check the following before upgrading from BioStar 2 to **BioStar X**.

:::info[Important]

### Minimum requirements

* Before you proceed with the upgrade, see <DocLink docId='platform/biostar_x/system-requirements' /> and confirm that your server meets the requirements.

* If you are in an environment of BioStar 2 v2.9.11 or later, you can upgrade to **BioStar X**.

  * If you are using BioStar 2 v2.6.4 or earlier, upgrade sequentially to v2.9.11 first. For instructions on upgrading BioStar 2 step by step, see the **BioStar 2 Admin Guide**. 

  * You cannot upgrade from BioStar 2 v2.9.10 or earlier.

* If the following devices are connected to BioStar 2, upgrading to **BioStar X** is not supported. 

  * XPass S2, XPass, BioEntry W, BioEntry Plus, BioLite Net

---

### License

* Contact your dealer and prepare at least one BioStar X license before upgrading to **BioStar X**.

* A different licensing policy applies when upgrading to **BioStar X** compared to BioStar 2.

* If you upgrade while an Advanced grade or higher BioStar 2 AC license is activated, the service features and settings below are deleted.

  * Graphic Map

  * Cloud

* To use the BioStar 2 T&A service in **BioStar X**, purchase the **BioStar X T&A** license separately.

:::

:::warning 

### Verify certificate {/* #checkCert */}

When you upgrade from BioStar 2 to BioStar X, the `biostar_cert.crt` files in `nginx\conf` and `nginx\cert` may differ. If you upgrade in this state, the following problems occur.

* Some audit logs are not recorded.

* Creating user groups, adding Wiegand, and refreshing the tree fail.

To match the certificate files before upgrading to BioStar X, follow these steps.

1. Stop the BioStar 2 service.

2. Overwrite the `biostar_cert.crt` and `biostar_cert.key` files in `nginx\cert` with the files from `nginx\conf`.

3. Restart the BioStar 2 service.

:::

## Upgrade installation instructions {/* #upgrade-install */}

1. Go to the [Suprema Download Center](https://download.supremainc.com/), log in, and download the installation package (*BioStar X Setup.X.Y.Z.BB.exe*).

2. Run the downloaded installation file.

3. Select the language to use, and then click <Cmd code='biostar2.install.ok' className='bold'/>.

   <Image src='/img/biostarx-install-select-language.png' />

4. Agree to the licensing policy for transitioning from BioStar 2 to **BioStar X**. Select the checkbox, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-2-to-x-agree.png' />

5. To continue the installation, select <Cmd code='biostar2.install.agree' className='bold'/>, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-agree.png' />

6. When upgrading from BioStar 2, the installer connects to your existing database to continue the installation. Click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-upgrade-select-install-type.png' />

7. Enter the root account password of the existing database and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-input-db-pw.png' />

8. Set the path to store the encryption key and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-set-encrypt-path.png' />

9. Read the information about the management and responsibility of personal information stored in the database, and click <Cmd code='biostar2.install.next' className='bold'/> to continue the installation.

   <Image src='/img/biostarx-install-read-covenant.png' />

10. When a message about the port number appears, click <Cmd code='biostar2.install.ok' className='bold' />.

    <Image src='/img/biostarx-install-set-port-confirm.png' />

11. Set the port for **BioStar X** communication and click <Cmd code='biostar2.install.next' className='bold'/>.

    <Image src='/img/biostarx-upgrade-set-port.png' />

12. Select the components of **BioStar X** and click <Cmd code='biostar2.install.next' className='bold'/>. Selecting **USB Device Agent** installs the USB Agent and drivers required to use BioMini, BioMini Plus 2, BioMini Slim 2, and DUALi DE-620.

    <Image src='/img/biostarx-install-additional.png' />

13. When you finish preparing for installation, click <Cmd code='biostar2.install.btnInstall' className='bold'/>.

    <Image src='/img/biostarx-upgrade-complete.png' />

14. Select whether to install additional programs and click **Finish**.

    <Image src='/img/biostarx-install-additional-fin.png' />

15. Follow the instructions on the installation screen to complete the **USB Device Agent** installation.
