Learn how to create a schedule template based on the <Cmd sid='tab.shift' product='2' className='normal' /> you set up.

## <Cmd sid='scheduleTemplate.addScheduleTemplate' product='2' className='bold' />

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click <Cmd sid='tab.shift' product='2' /> → <Cmd sid='tab.scheduleTemplate' product='2' /> in the left sidebar.

3. Click <Cmd sid='scheduleTemplate.addScheduleTemplate' product='2' />.

   <Image src='/img/biostarx-tna-shift-schedule.png' />

4. When the <Cmd sid='scheduleTemplate.addScheduleTemplate' product='2' /> screen appears, set each field.

:::info

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

* To add a work schedule next, click <Cmd sid='payCode.applyAndAddShift' product='2' />.

* To save the settings and then add another <Cmd sid='tab.scheduleTemplate' product='2' />, click <Cmd sid='ta.apply_add_another' product='2' />.

:::

## Schedule options

<Image src='/img/biostarx-tna-shift-schedule-adding.png' />

* <Cmd sid='form.name' product='2' />: Enter the name of the <Cmd sid='tab.scheduleTemplate' product='2' className='normal' />.

* <Cmd sid='form.description' product='2' />: Enter a description for the <Cmd sid='tab.scheduleTemplate' product='2' className='normal' />.

* <Cmd sid='form.type' product='2' />: Select <Cmd sid='scheduleTemplate.type.weekly' product='2' /> or <Cmd sid='scheduleTemplate.type.daily' product='2' /> for the <Cmd sid='tab.scheduleTemplate' product='2' className='normal' />.

  When you select <Cmd sid='scheduleTemplate.type.daily' product='2' />, you can set the repeat period (<Cmd sid='scheduleTemplate.cycle' product='2' />).

  <Image src='/img/biostarx-tna-shift-schedule-adding-daily.png' />

* <Cmd sid='scheduleTemplate.weekendSetting' product='2' />: Set the days to designate as weekends.

* <Cmd sid='scheduleTemplate.shift' product='2' />: Shows the list of configured <Cmd sid='tab.shift' product='2' className='normal' />.

* Weekly/daily schedule: Drag and drop the <Cmd sid='tab.shift' product='2' className='normal' /> you set up. 

  <Image src='/img/biostarx-tna-shift-schedule-adding-drag-shift.png' />

  :::info

  * To apply to Monday through Sunday, click <Cmd sid='scheduleTemplate.copyAll' product='2' />.

  * To remove the applied <Cmd sid='tab.shift' product='2' className='normal' />, click <IcTrash2 />.

  * If you apply a <Cmd sid='tab.shift' product='2' className='normal' /> with <Cmd sid='shift.dayStartTimeExcessTime' product='2' /> set, you cannot set the previous-day excess time to more than 24 hours before the day start time of the previous day's shift.

  :::
