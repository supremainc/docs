**BioStar X**'s <Cmd sid='settings.deviceConnectionManager.settingMenuTitle' product='2' /> is a feature designed to efficiently manage a large number of devices in companies or large buildings. Previously, one server could connect up to 1,000 devices, but now you can install **communication** servers on multiple computers to manage up to 3,000 network devices.

:::info

* This feature is available when the **Device Manager** license is activated. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* For more information about the Multi Communications Server specifications and installation, see the followings:

  * <DocLink docId='platform/biostar_x/system-requirements#communication-server' />

  * <DocLink docId='platform/biostar_x/install-communication-server' />

:::

## Key features

* **Server expansion**: Install communication servers on additional computers besides the main computer to connect more devices.

* **Multiple server operation**: Use up to three servers together to support a total of 3,000 devices.

* **Convenient device management**: When adding new devices, you can choose which server to connect to, and you can also move existing devices to another server.

* **Support for large environments**: Reliably operate a large number of devices in large business sites or buildings.

The Multi Communications Server is a dedicated service that separates only the device connection feature from the BioStar X integrated server. It focuses on reliable communication with devices to improve overall system performance.

## Move devices to another server

You can move devices registered to the main server or another Multi Communications Server to a different Multi Communications Server. This feature helps you move devices between servers while maintaining the devices' connection status.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.deviceConnectionManager' /> in the left sidebar.

3. In the <Cmd sid='settings.deviceConnectionManager.followerSelectLabel' product='2' /> field on the left, select the server where the device to move is registered.

   <Image src='/img/biostarx-setting-device-connection-manager-01.png' />

4. In the <Cmd sid='settings.deviceConnectionManager.selectedSelectLabel' product='2' /> field on the right, select the destination server to move the devices to.

   <Image src='/img/biostarx-setting-device-connection-manager-02.png' />

5. Select the devices to move in the device list. You can select multiple devices.

   <Image src='/img/biostarx-setting-device-connection-manager-03.png' />

   :::note

   To search for a device, enter a keyword in the input field at the top. You can search by device name or serial number.

   :::

6. To move the devices to the destination server, click <Cmd sid='settings.deviceConnectionManager.moveButtonTitle' product='2' />.

   <Image src='/img/biostarx-setting-device-connection-manager-04.png' />

7. In the message window, check the total number of devices to move, the number of devices connected via TCP/IP, the destination server name, and the IP address.

8. Click <Cmd sid='button.yes' product='2' />.

After the move, the message window shows the total number of devices moved, TCP/IP-connected devices, and the destination server name and IP address. 

If any devices fail to move, the message window shows the number of devices that failed to move and the number of TCP/IP-connected devices. To view a list of devices that failed to move and the reasons for failure in a CSV file, click <Cmd sid='button.download' product='2' />.

:::info

* If there are no connected extension servers, <Cmd sid='settings.deviceConnectionManager.selectedSelectLabel' product='2' /> does not appear in the right pane.

* When you select a server, the list shows all registered devices on that server, including devices connected via Wiegand and RS-485.

* When you select a device or device group, the subordinate devices connected to the device and the devices included in the group are also moved.

* Devices not connected via TCP/IP cannot be moved.

:::
