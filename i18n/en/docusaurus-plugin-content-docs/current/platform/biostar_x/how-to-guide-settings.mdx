Learn about the various features you can set on the <Cmd sid='shell.header.setting' /> page in **BioStar X**. You can add devices and explore various options to customize your environment, such as permissions, language, date and time, and access card management. 

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />, or select <Cmd sid='shell.header.setting' /> from the shortcut list in the upper-left corner of the screen.

:::info

The features you can set may differ depending on your permissions. Some features are available only to users with administrator privileges. For more information about the menus accessible at each user permission level, see <DocLink docId='platform/biostar_x/set-permission#operatorLevel' />.

:::
