This document explains how to install the **BioStar X** **Multi Communications Server**. 

The Multi Communications Server handles communication with access control devices. It helps to manage many devices reliably by installing separately from the main server. A single Multi Communications Server can connect up to 1,000 devices. Add multiple Multi Communications Servers as needed.

:::info

Up to 1,000 devices can connect via Ethernet (TCP/IP).

:::

## Before you start {/* #start-before */}

Before installing the Multi Communications Server, check the following.

* The Multi Communications Server cannot be installed on the same server as the **BioStar X** server.

* The Multi Communications Server can only be installed on a 64-bit operating system. For more information on minimum system requirements, see <DocLink docId='platform/biostar_x/system-requirements#communication-server' />.

* A Multi Communications Server license is required to install and connect the server. For more information on licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

### Pre-installation checks {/* #check-before-install */}

Before installing the Multi Communications Server, run **BioStar X Service Manager** to check the information required during installation.

1. Click <Start/> → **BioStar X** → **BioStar X Service Manager** on Windows.

2. The <Cmd>BioStar X Service Manager</Cmd> window appears.

3. Click <Cmd>SERVICE SETTINGS</Cmd>.

Below is the information required to install the Multi Communications Server. Review and prepare each item.

<Image src='/img/biostarx-cumm-server-matching.png' />

<div className='table-fixed'>

| BioStar X Service Manager | Information required for Multi Communications Server installation |
| --- | --- |
| <Cmd>BioStar X Core Service</Cmd> → <Cmd>RPC Port</Cmd> | **BioStar X Server gRPC Port for Communication** |
| <Cmd>BioStar X Coordinator Service</Cmd> → <Cmd>Client Port</Cmd> | **BioStar X Coordinator Service Port for Communication** |
| <Cmd>BioStar X Cache Service</Cmd> → <Cmd>Client Port</Cmd> | **BioStar X Cache Service Client for Communication** |

</div>

:::info

For more information on <Cmd>SERVICE SETTINGS</Cmd>, see <DocLink docId='platform/biostar_x/service-settings' />.

:::

## Installation guide {/* #install-guide */}

Follow the steps below to install the Multi Communications Server.

1. Access the [Suprema Download Center](https://download.supremainc.com/), log in, and download the installation package (*BioStar X Communications Server.X.Y.X.BB.exe*).

2. Run the downloaded installation file.

3. Select the language to use and select the <Cmd code='biostar2.install.ok' className='bold'/> button.

   <Image src='/img/biostarx-install-select-language.png' />

4. To continue the installation, select <Cmd code='biostar2.install.agree' className='bold'/> and click the <Cmd code='biostar2.install.next' className='bold'/> button.

   <Image src='/img/biostarx-install-comm-server-license-agree.png' />

5. Set the installation path for the Multi Communications Server and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-set-path.png' />

6. Review the permissions and responsibilities regarding personal information and click <Cmd code='biostar2.install.next' className='bold'/> to continue the installation.

   <Image src='/img/biostarx-install-comm-server-private-policy.png' />

7. Select the components of the Multi Communications Server and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-select-component.png' />

8. Enter the IP address and port number of the **BioStar X** server, and input details for connection to the **BioStar X** server. Complete your settings and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-settings.png' />

   :::note

   For more information on each input field, see <DocLink inner='#check-before-install' />.

   :::

9. Enter the **BioStar X** administrator ID and password, then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-login.png' />

10. Set the port for communication and click <Cmd code='biostar2.install.next' className='bold'/>.

    <Image src='/img/biostarx-install-comm-server-port-settings.png' />

11. When all preparations for installation are complete, click the <Cmd code='biostar2.install.btnInstall' className='bold'/> button. Proceed with the installation.

    <Image src='/img/biostarx-install-comm-server-install-step.png' />

12. Check the installation completion message and click <Cmd code='biostar2.install.complete' className='bold'/>.

    <Image src='/img/biostarx-install-comm-server-complete.png' />

Complete the installation of the Multi Communications Server. Once the installation is complete, verify the connection between the Multi Communications Server and the **BioStar X** main server.

## Post-installation checks {/* #check-after-install */}

After installing the Multi Communications Server, connect it to the main server in **BioStar X Service Manager**.

1. Click <Start/> → **BioStar X** → **BioStar X Service Manager** on Windows. 

2. The <Cmd>BioStar X Service Manager</Cmd> window appears.

3. In the left sidebar, click the <Cmd>COMMUNICATIONS</Cmd> menu.

   <Image src='/img/common/biostarx-sm-cluster-main-01.png' alone />

4. Click <Cmd>Add Communication Server</Cmd> in the upper right corner of the screen.

5. When the <Cmd>Add Communication Server</Cmd> window appears, select the checkbox that matches the installed Multi Communications Server IP address. In the <Cmd>Database</Cmd> column, select the database to use.

   <Image src='/img/common/biostarx-sm-cluster-main-03.png' alone />

6. Click the <Cmd>Add</Cmd> button.

In the Multi Communications Server list, check that <Cmd>Server Status</Cmd> shows <Cmd>Connected</Cmd>.

<Image src='/img/common/biostarx-sm-cluster-main-04.png' alone />

:::info

* The <Cmd>COMMUNICATIONS</Cmd> menu can be used when the multi-communication server license is activated. For more information on licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* To delete the Multi Communications Server, check the box of the server to be deleted in the list and click <Cmd>Delete Communication Server</Cmd> in the upper right corner of the screen.

* When adding a Multi Communications Server, add a secondary database to reduce the load on the main server. For more information on adding a secondary database, see <DocLink docId='platform/biostar_x/add-sub-db' />.

:::
