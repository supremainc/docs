Learn how to install the **BioStar X** **Multi Communications Server**. 

The Multi Communications Server handles communication with access control devices. Installing it separately from the main server helps you manage large numbers of devices reliably. A single Multi Communications Server can connect up to 1,000 devices. Add multiple Multi Communications Servers as needed.

:::info

Up to 1,000 devices can connect via Ethernet (TCP/IP).

:::

## Before you start {/* #start-before */}

Before installing the Multi Communications Server, check the following.

* The Multi Communications Server cannot be installed on the same server as the **BioStar X** server.

* The Multi Communications Server can only be installed on a 64-bit operating system. For more information about minimum system requirements, see <DocLink docId='platform/biostar_x/system-requirements#communication-server' />.

* A Multi Communications Server license is required to install and connect the Multi Communications Server. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

### Checks before installation {/* #check-before-install */}

Before installing the Multi Communications Server, run **BioStar X Service Manager** to check the information required during installation.

1. In Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**.

2. The <Cmd>BioStar X Service Manager</Cmd> window opens.

3. Click <Cmd>SERVICE SETTINGS</Cmd>.

Below is the information you need to enter when installing the Multi Communications Server. Review and prepare each requirement.

<Image src='/img/biostarx-cumm-server-matching.png' />

<div className='table-fixed'>

| BioStar X Service Manager | Information to enter when installing the Multi Communications Server |
| --- | --- |
| <Cmd>BioStar X Core Service</Cmd> → <Cmd>RPC Port</Cmd> | **BioStar X Server gRPC Port for Communication** |
| <Cmd>BioStar X Coordinator Service</Cmd> → <Cmd>Client Port</Cmd> | **BioStar X Coordinator Service Port for Communication** |
| <Cmd>BioStar X Cache Service</Cmd> → <Cmd>Client Port</Cmd> | **BioStar X Cache Service Client for Communication** |

</div>

:::info

For more information about <Cmd>SERVICE SETTINGS</Cmd>, see <DocLink docId='platform/biostar_x/service-settings' />.

:::

## Installation guide {/* #install-guide */}

To install the Multi Communications Server, follow these steps.

1. Go to the [Suprema Download Center](https://download.supremainc.com/), log in, and download the installation package (*BioStar X Communications Server.X.Y.Z.BB.exe*).

2. Run the downloaded installation file.

3. Select the language to use, and then click <Cmd code='biostar2.install.ok' className='bold'/>.

   <Image src='/img/biostarx-install-select-language.png' />

4. To continue the installation, select <Cmd code='biostar2.install.agree' className='bold'/>, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-license-agree.png' />

5. Set the installation path for the Multi Communications Server, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-set-path.png' />

6. To continue the installation, review the permissions and responsibilities regarding personal information and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-private-policy.png' />

7. Select the components for the Multi Communications Server, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-select-component.png' />

8. Enter the IP address and port number of the **BioStar X** server, and enter the values in each field to connect to the **BioStar X** server. Complete the setup and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-settings.png' />

   :::note

   For more information about each input field, see <DocLink inner='#check-before-install' />.

   :::

9. Enter the **BioStar X** administrator ID and password, then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-install-comm-server-login.png' />

10. Set the port for communication and click <Cmd code='biostar2.install.next' className='bold'/>.

    <Image src='/img/biostarx-install-comm-server-port-settings.png' />

11. When you finish preparing for installation, click <Cmd code='biostar2.install.btnInstall' className='bold'/>. The installation starts.

    <Image src='/img/biostarx-install-comm-server-install-step.png' />

12. Check the installation completion message and click <Cmd code='biostar2.install.complete' className='bold'/>.

    <Image src='/img/biostarx-install-comm-server-complete.png' />

The Multi Communications Server installation is complete. Once the installation is complete, verify that the Multi Communications Server is connected to the **BioStar X** main server.

## Checks after installation {/* #check-after-install */}

After installing the Multi Communications Server, connect it to the main server in **BioStar X Service Manager**.

1. In Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**. 

2. The <Cmd>BioStar X Service Manager</Cmd> window opens.

3. Click the <Cmd>COMMUNICATIONS</Cmd> menu in the left sidebar.

   <Image src='/img/common/biostarx-sm-cluster-main-01.png' alone />

4. Click <Cmd>Add Communication Server</Cmd> in the upper-right corner of the screen.

5. When the <Cmd>Add Communication Server</Cmd> window appears, select the checkbox for the entry that matches the IP address of the installed Multi Communications Server, and select a database in the <Cmd>Database</Cmd> column.

   <Image src='/img/common/biostarx-sm-cluster-main-03.png' alone />

6. Click <Cmd>Add</Cmd>.

In the Multi Communications Server list, check that the <Cmd>Server Status</Cmd> column for the added Multi Communications Server shows <Cmd>Connected</Cmd>.

<Image src='/img/common/biostarx-sm-cluster-main-04.png' alone />

:::info

* The <Cmd>COMMUNICATIONS</Cmd> menu is available when the Multi Communications Server license is activated. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* To delete a Multi Communications Server, select the checkbox for the server in the list, and then click <Cmd>Delete Communication Server</Cmd> in the upper-right corner of the screen.

* When you add a Multi Communications Server, you can add a secondary database to reduce the main server load. For more information about adding a secondary database, see <DocLink docId='platform/biostar_x/add-sub-db' />.

:::
