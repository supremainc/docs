title: Manage Audit Trail
description: You can track not only user access information but also all information changed in the system.
---

The <Cmd sid='setting.menu.auditTrail.root' /> feature records and tracks all activities occurring in the system. All activities such as user login/logout, setting changes, and system administration tasks are recorded and can be utilized for security audits and system monitoring.

The <Cmd sid='setting.menu.auditTrail.root' /> group on the left sidebar includes the following three menus.

* <Cmd sid='setting.menu.auditTrail.acAuditLog' />: Records access control activities, including creating, updating, deleting, viewing, exporting, importing, and administrative actions for users, devices, and doors.

* <Cmd sid='setting.menu.system.auditTrailRetention' />: Sets the audit log retention period and whether to record view history.

:::info

For more information on <Cmd sid='setting.menu.auditTrail.taAuditLog' />, see <DocLink docId='platform/biostar_x/tna-audit-trail' />.

:::
