id: settings-system-audit-trail
title: Manage Audit Trail
description: You can track not only user access information but also all changes made in the system.
---

The <Cmd sid='setting.menu.auditTrail.root' /> feature records and tracks all activities that occur in the system. All activities, such as user login/logout, setting changes, and system administration tasks, are recorded, and you can use them for security audits and system monitoring.

The <Cmd sid='setting.menu.auditTrail.root' /> group in the left sidebar includes the following menus.

* <Cmd sid='setting.menu.auditTrail.acAuditLog' />: Records all create, update, delete, view, export, import, and operational activities related to access control, such as users, devices, and doors.

* <Cmd sid='setting.menu.system.auditTrailRetention' />: Sets the audit log retention period and whether to record audit log views.

:::info

For more information about <Cmd sid='setting.menu.auditTrail.taAuditLog' />, see <DocLink docId='platform/biostar_x/tna-audit-trail' />. The <Cmd sid='setting.menu.auditTrail.taAuditLog' /> menu is available only when the Time & Attendance (T&A) license is active.

:::
