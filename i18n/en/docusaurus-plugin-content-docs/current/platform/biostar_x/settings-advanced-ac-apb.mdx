Anti-passback provides more advanced features than door- or device-based anti-passback. Set up anti-passback to require users to use designated doors and devices when they enter and exit. This prevents unauthorized re-entry and enhances security.

:::info

<Glossary termid='apb' />

:::

## Register anti-passback {/* #addAPBZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.antiPassback' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the anti-passback feature to add.

   <Image src='/img/biostarx-settings-adv-ac-add-apb.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the anti-passback feature details. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='common.alarm' product='2' /> section, set the actions to run when an anti-passback violation occurs.

8. In the <Cmd sid='zone.apb.bypass' product='2' /> section, select the access groups that can bypass anti-passback. Users in this group can bypass anti-passback.

9. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='common.alarm' product='2' /> section is available only after you set both <Cmd sid='zone.entryDevices' product='2' /> and <Cmd sid='zone.exitDevices' product='2' />.

:::

## Setting options {/* #setting */}

Anti-passback settings are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Set the scope.

  * <Cmd sid='zone.globalZone.local' product='2' />: Select to use devices connected to the entry device via RS-485.

  * <Cmd sid='zone.globalZone.global' product='2' />: Select to use all devices registered in **BioStar X**.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.apbType' product='2' />: Select the anti-passback type.

  * <Cmd sid='door.apbType.hard' product='2' />: Creates an anti-passback event and blocks access.

  * <Cmd sid='door.apbType.soft' product='2' />: Creates an anti-passback event and allows access.

* <Cmd sid='door.resetTime' product='2' />: Set the wait time before access is allowed again for a user who violated the anti-passback rule. After an alarm occurs and the set time elapses, the system automatically allows access for that user.

  * Set a value from **1** to **10080** minutes (7 days).

  * If set to **0** minutes, the alarm does not clear automatically, and access is blocked until the administrator clears it manually.

* <Cmd sid='zone.apbUseDoorSensor' product='2' />: Set the scope to apply anti-passback rules.

  * <Cmd sid='common.on' product='2' />: Anti-passback rules apply based on the actual operation of the door with the configured entry and exit devices.

  * <Cmd sid='common.off' product='2' />: Rules apply based on user authentication regardless of door operation.

  * <Cmd sid='zone.apbUseEachDoorSensorSetting' product='2' />: When door-based APB is used for this door, anti-passback rules apply based on the sensor usage option setting.

* <Cmd sid='zone.entryDevices' product='2' />: Select the devices to use for entry. Select from the list of registered devices.

* <Cmd sid='zone.exitDevices' product='2' />: Select the devices to use for exit. Select from the list of registered devices.

* <Cmd sid='zone.apbFailAction' product='2' />: Set the door action when communication between **BioStar X** and a device set up with anti-passback is interrupted. This feature is available when the <Cmd sid='zone.globalZone' product='2' /> option is set to <Cmd sid='zone.globalZone.global' product='2' />.

  * <Cmd sid='zone.apbFailAction.noAction' product='2' />: The door unlocks when the user is authenticated normally.

  * <Cmd sid='zone.apbFailAction.recordLog' product='2' />: An anti-passback violation alarm occurs and the door unlocks.

  * <Cmd sid='zone.apbFailAction.doorLocked' product='2' />: An anti-passback violation alarm occurs and the door does not unlock.
