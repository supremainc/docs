Integrate **BioStar X** with cardPresso to print cards with the design of your choice. cardPresso is professional software for designing and printing cards. cardPresso lets you create various card templates and lay out user information on cards.

## Before you start

To use the card printer feature of **BioStar X**, install cardPresso and connect it to **BioStar X**. A cardPresso XXL edition license is required to use the web printing server feature in cardPresso.

:::info

* For more information about the license types of the cardPresso program, see [the following link](https://www.cardpresso.com/cardpresso-software/editions/).

* The web printing server feature is supported only on Windows operating systems.

:::

### Install and set up cardPresso {/* #installing-configuring-cardPresso */}

To install cardPresso and set up the web printing server, follow the steps below. 

:::note

Depending on the installed version, the menu path or screen may differ.

:::

1. Download the latest version of cardPresso that matches the operating system of the PC used as the web printing server from [cardPresso Download](https://www.cardpresso.com/downloads-cp). 

2. Install the program and activate the license issued by cardPresso.

3. Run cardPresso, and then create a card template.

   <Image src='/img/common/cardpresso-new-card-template.png' alone caption />

4. Save the card template you created to a location of your choice on the server where **BioStar X** is installed. (for example, *C:\template\example.card*)

5. Right-click on the desktop of the PC where cardPresso is installed, then click **New** → **Shortcut** from the pop-up menu. {/* New → Shortcut */}

6. Enter the following in the **Item Location** field, then click **Next**.

   ```
   "C:\Program Files (x86)\cardPresso\cardPresso.exe" /PRINTSERVER
   ```

   <Image src='/img/cardpresso-print-server-short-cut.png' width={400} />

   :::note

   The path where cardPresso is installed may differ depending on the installation environment. After you confirm where cardPresso is installed, update the path above accordingly.

   :::

7. Enter a name for the shortcut, then click **Finish**.

8. Double-click the cardPresso web printing server shortcut on the desktop to run it.

9. When the cardPresso web printing server window appears, click **Settings**.

   <Image src='/img/biostarx-settings-card-printer-installation2.png' />

   * **Address**: Enter the IP address of the PC that runs the web printing server.

   * **Port**: The port number that cardPresso uses to receive print requests.

   * **Allowed user groups**: Select the user group that has permission to access the web printing server.

10. When the settings are complete, click **Save**.

11. Click <Image src='/img/common/ico-card-printer-play.png' ico alone /> in the lower-right corner of the screen to start the service. If set correctly, the icon changes to <Image src='/img/common/ico-card-printer-stop.png' ico alone /> and the **listen OK** message appears.

    <Image src='/img/biostarx-settings-card-printer-installation3.png' />

    :::note

    Don't close the window until card printing is complete.

    :::

## Connect cardPresso to BioStar X

To connect cardPresso to **BioStar X**, set it up as shown below.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid="setting.menu.cardPrinter.root" /> in the left sidebar.

3. Set <Cmd sid="common.cardPrinter.cardpressoSetting" product='2' /> to <Cmd sid="common.use" product='2' />, and then enter each field.

   <Image src='/img/biostarx-settings-card-printer.png' className='none' />

   * <Cmd sid="common.cardPrinter.id" product='2' />: Enter the cardPresso login ID. (default: ADMIN)

   * <Cmd sid="common.cardPrinter.password" product='2' />: Enter the cardPresso login password. (default: admin)

   * <Cmd sid="common.cardPrinter.ipAddress" product='2' />: Enter the IP address of the PC that runs the web printing server.

   * <Cmd sid="common.cardPrinter.ipAddressPort" product='2' />: Shows the port number that cardPresso uses to receive print operations.

   * <Cmd sid="common.cardPrinter.printerName" product='2' />: Enter the printer name to use as the card printer. You can find it in Windows **Control Panel** → **Devices and Printers**.

   * <Cmd sid="common.cardPrinter.cardTemplate" product='2' />: Click <Cmd sid="button.plusAdd" product='2' /> to add a <Cmd sid="common.cardPrinter.cardTemplate" product='2' />. In the <Cmd sid="setting.server.card_template.configure.th.name" product='2' /> field, enter the full path that includes the card template file name and extension.

     * The card template file name supports letters, numbers, and special characters.

     * Up to 20 card templates are supported.

     * Example path: C:\template\example.card

   * <Cmd sid="common.cardPrinter.printTestLabel" product='2' />: Test prints the card template.

4. After you complete the setup, click <Cmd sid="button.apply" product='2' />.

## Test print the card template

You can test print a card template with Administrator information.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid="setting.menu.cardPrinter.root" /> in the left sidebar.

3. Select the card template you want to print, then click <Cmd sid="common.cardPrinter.testPrint" product='2' />.

   <Image src='/img/biostarx-settings-card-printer1.png' className='none' />

4. A card template with Administrator information is printed.

## Print card templates per user {/* #printing-card-template-per-user */}

You can print cards using card templates with per-user information.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <Cmd sid='team.user.dialog.newUser' /> in the upper-right corner of the screen. The <Cmd sid='team.user.dialog.newUser' /> window appears.

3. Fill out the form and click <Cmd sid="button.printCard" product='2' />.

   * User information can include English letters, numbers, and special characters.

   <Image src='/img/biostarx-settings-card-printer-user.png' />

4. Select the card template you want to print and click <Cmd sid="common.cardPrinter.print" product='2' />.

   <Image src='/img/biostarx-settings-card-printer-user1.png' className='none' />

5. When the pop-up window asking whether to print the card appears, click <Cmd sid="common.cardPrinter.ok" product='2' />.

   <Image src='/img/biostarx-settings-card-printer-user2.png' className='none' />

A new user is created, and a card is printed using a card template that includes user information.

## Add custom user fields {/* #adding-custom-user-fields */}

You can print a card using a card template with added custom user fields.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.server.server' /> in the left sidebar.

3. In the <Cmd sid='setting.server.userDeviceManagement' product='2' /> section, click <Cmd sid="button.plusAdd" product='2' /> in <Cmd sid="setting.server.custom_field.title" product='2' />, enter <Cmd sid="setting.server.custom_field.configure.th.name" product='2' />, and select <Cmd sid="setting.server.custom_field.configure.th.type" product='2' />. The card template attribute **ID** is determined by the order of the <Cmd sid="setting.server.custom_field.title" product='2' /> entries you add.

   <Image src='/img/biostarx-settings-card-printer-custom-user.png' />

   In BioStar X attribute ID order, **Order 1** is the same as **CUSTOM1**. For more information about BioStar X attribute IDs, see <DocLink inner='#card-template-attribute-ids' />.

4. Once you complete the settings, click <Cmd sid="button.apply" product='2' /> at the very bottom of the screen.

5. In cardPresso, click **File** → **Open Template** to open the card template file. Add a new attribute, and enter the **ID** as the **XML item ID name** that matches the BioStar X attribute ID order.

   <Image src='/img/biostarx-settings-card-printer-template.png' />

6. When setup is complete, click **File** → **Save**.

7. Return to **BioStar X** and select the user to apply the card template to on the <Cmd sid='shell.header.user' /> page.

8. The custom user field entries you added appear. Fill in accordance with the form and click <Cmd sid="button.printCard" product='2' />.

   <Image src='/img/biostarx-settings-card-printer-custom-user1.png' />

9. Select the card template you want to print and click <Cmd sid="common.cardPrinter.print" product='2' />.

   <Image src='/img/biostarx-settings-card-printer-user1.png' className='none' />

10. When the pop-up window asking whether to print the card appears, click <Cmd sid="common.cardPrinter.ok" product='2' />.

    <Image src='/img/biostarx-settings-card-printer-user2.png' className='none' />

User information is saved, and a card is printed using a card template with added custom user fields.
