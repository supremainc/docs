Use the <Cmd sid='shell.header.visitor' /> feature to create a visit request page on the visit request PC and manage visitor access on the visitor management PC.

:::info

* The <Cmd sid='shell.header.visitor' /> feature is available as an additional option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* For more information about setting up the visitor feature after you activate it with a license, see <DocLink docId='platform/biostar_x/settings-visitor' />.

:::

Applying the visitor license activates the <Cmd sid='shell.header.setting' /> → <Cmd sid="common.visitor" product='2' /> menu, and adds a link to the management page of <Cmd sid='shell.header.visitor' /> in the shortcuts list in the upper-left corner of the screen.

:::

## Set up the visit request page

You can use the visit request page after you set up the visitor settings. For more information about setting up the visit request page, see <DocLink docId='platform/biostar_x/settings-visitor' />. 

You can access the visit request page from a dedicated visit request PC, and visitors can submit access requests. For more information about visit requests, see <DocLink docId='platform/biostar_x/visitor-register' />.

## Manage visitor access

You can review visit request history and manage visitor access. For more information about managing visitor access, see <DocLink docId='platform/biostar_x/visitor-register-manage' />.
