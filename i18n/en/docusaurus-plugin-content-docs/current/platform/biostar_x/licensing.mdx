**BioStar X** is the next generation access control software developed as a successor to **BioStar 2**. Supports various deployment environments of today and the future through an enhanced system architecture, expanded features, and a more flexible licensing model.

**BioStar X** offers a total of five scalable license levels ranging from **Starter** to **Elite**, allowing you to choose according to various environments from small businesses to large corporate settings. Designed in a modular structure, it can add a variety of optional features such as video integration, mobile access, and multi-server support.

## Base License {/* #base-license */}

**The base license** is an essential component for activating and operating the system. This license serves as a foundation for applying additional features or upgrades.

<div className='table--licensing overflow-x'>

| &nbsp; | Device Manager | Starter | Essential | Advanced | Enterprise | Elite |
| --- | :-: | :-: | :-: | :-: | :-: | :-: |
| **Maximum Number of Doors** | 0 | 5 | 32 | 128 | 500 | 2000 |
| **Maximum Users** | 200 | 100 | 1,000 | 50,000 | 100,000 | 500,000 |
| **Maximum Operators** | 1 | 1 | 10 | 20 | 40 | 100 |
| **Maximum Connected IP Devices** | 1,000 | 1,000 | 1,000 | 1,000 | 1,000 | 1,000 |
| **Maps** | ❌ | ❌ | ✔️ | ✔️ | ✔️ | ✔️ |
| **Video** | ❌ | ❌ | Add on | Add on | Add on | Add on |
| [**Advanced Access Control**](#advanced-access-control)<br/>*(Anti-passback, Fire Alarm, Intrusion Alarm, Muster, Occupancy Limit, Elevator, Interlock)* | ❌ | ❌ | Add on | Add on | ✔️ | ✔️ |
| [**Capacity Upgrade**](#capacity-upgrade)<br/>*(Doors/Users/Operators)* | Users, Operators only | ❌ | Add on | Add on | Add on | Add on |

</div>

:::note

* The **Device Manager** license is required for customers using third-party software or third-party systems who wish to efficiently manage Suprema devices through **BioStar X**.

* **Maximum Operators** refers to the number of users who are granted access permissions to the system.

* If the maximum number of connected IP devices exceeds 1,000, it is recommended to use the **Multi Communications** server.

:::

## Capacity Upgrade {/* #capacity-upgrade */}

License upgrades are available for holders of **Essential**, **Advanced**, **Enterprise**, and **Elite** licenses. License holders of the **Device Manager** can only purchase User and Operator Upgrades.

| &nbsp; | Number |
| :-: | :-: |
| Doors | 32 |
| Users | 5,000 |
| Operators | 10 |

## Feature add-ons {/* #features-add-ons */}

The following options are available for individual purchase and can be added to **Essential**, **Advanced**, **Enterprise**, and **Elite** license tiers.

<div className='cols3--20-20-60 overflow-x'>

| Feature | License Type | Remarks |
| --- | --- | --- |
| **Multi Communications Server Init** | Base License | Includes 1 Multi Communications Server. Supports up to 1,000 IP devices. |
| **Multi Communications Server Add-on** | Additional Server | Required to add 1 additional Multi Communications Server. Extends IP device capacity by 1,000 per add-on. |
| **GIS Map** | System | You can use the GIS map to set up areas, facilities, and floors. |
| **Video** | Camera | Required when integrating third-party VMS. Supports up to 1,000 integrated cameras per system. |
| **Server Matching** | ID, Card, Fingerprint, IR face | Server matching method compares the ID, card, fingerprint, and IR face stored on the device to the credentials stored in the server database. |
| **Visitor** | System | Administrators and operators can track or control visitor access. |
| **Directory Integration** | System | Supports integration with directory services for centralized user management. |
| **Roll Call** | System | - |

</div>

:::note

Not all cameras connected to the VMS need to be integrated with BioStar X. For example, even if the VMS supports 32 cameras, users only need to purchase a license for the specific camera that they want to integrate with **BioStar X**, and there is no need to purchase a license for all cameras.

:::

## Advanced Access Control {/* #advanced-access-control */}

**Advanced access control** consists of the following 7 individual features, and you can select and purchase only the features you need. **Essential** and **Advanced** license tiers offer these as add-on options, while **Enterprise** and **Elite** license tiers include all 7 features by default.

<div className='table-fixed overflow-x'>

| Feature | License Type | Remarks |
| --- | :-: | --- |
| **APB**(Anti-passback) | System | - |
| **Fire Alarm** | System | - |
| **Intrusion Alarm** | System | - |
| **Muster** | System | - |
| **Occupancy Limit** | System | - |
| **Elevator** | System | - |
| **Interlock** | System | - |

</div>

:::note

* Scheduled Lock(Scheduled Lock) and Scheduled Unlock(Scheduled Unlock) are basic access control features that do not require a license and are always available separately from the 7 features above.

* Customers who previously purchased the Advanced Access Control package can continue to use it. From new purchases onward, the 7 features can be selected and purchased individually.

:::
