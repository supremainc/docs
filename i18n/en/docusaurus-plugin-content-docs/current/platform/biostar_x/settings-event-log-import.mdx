Import device logs to the **BioStar X** server to review events. This feature is available when the <Cmd sid='setting.server.logUploadType' product='2' /> option is set to <Cmd sid='common.manual' product='2' /> in <Cmd sid='setting.server' product='2' /> settings.

:::info

For more information about the <Cmd sid='setting.server.logUploadType' product='2' /> option, see <DocLink docId='platform/biostar_x/settings-server-server#basic-setting' />.

:::

## Import manually

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.event.root' /> → <Cmd sid='setting.menu.event.eventLogImport' /> in the left sidebar.

3. In <Cmd sid='setting.eventLogImport.UpdateLog.label' />, select the period to import logs.

   <Image src='/img/biostarx-settings-event-log-from-device.png' />

   * <Cmd sid='setting.eventLogImport.UpdateLog.dropdown.SinceLast' product='2' />: Imports logs since the date of the last log saved to the **BioStar X** server.

   * <Cmd sid='setting.eventLogImport.UpdateLog.dropdown.All' product='2' />: Imports all logs from the device.

   * <Cmd sid='setting.eventLogImport.UpdateLog.dropdown.UserDefined' product='2' />: Select to set the start and end dates for importing logs.

4. Click <Cmd sid='button.updateLog' product='2' /> to import the logs.

## Import from external storage

Import event logs stored on an external storage device (USB) into **BioStar X**.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.event.root' /> → <Cmd sid='setting.menu.event.eventLogImport' /> in the left sidebar.

3. Click <Cmd sid='button.browse' product='2' /> under <Cmd sid='menu.dataImport' product='2' />.

   <Image src='/img/biostarx-settings-event-log-import-data.png' />

4. Select the data file (*.tgz*) saved locally.

If the data file is imported successfully, a message appears on the screen.

:::info

* Data exported from devices running an older firmware version cannot be imported into **BioStar X**. Always use the latest firmware version.

* Only data files exported from the following models can be imported: BioStation 3 Max, BioStation 3, X-Station 2, FaceStation F2, FaceLite, FaceStation 2, BioStation A2, and BioStation 2.

* If the imported event logs are not from doors, elevators, or zones set in the **BioStar X** system, some information may appear blank.

:::
