description: Activate your BioStar X license to use additional features.

If you purchased a BioStar X license, you can register the license key and use more features.

Click <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.menu.license.biostarXLicense' />.

How you can activate <Cmd sid='setting.menu.license.biostarXLicense' /> varies depending on your network environment. Follow the provided instructions to check the network status and activate the license.

:::info

* Some features, such as adding users, doors, and devices, are limited when the license is not registered.

* For more information about the <Cmd sid='setting.menu.license.root' /> menu, see <DocLink docId='platform/biostar_x/settings-license' />.

* For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* To check license error codes, see [the following link](https://reprisesoftware.com/docs/isv/appendix/appendix-b-rlm-status-values.html).

:::
