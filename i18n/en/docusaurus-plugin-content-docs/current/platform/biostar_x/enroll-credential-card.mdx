Guide users on how to enroll access cards. Explain the enrollment methods for CSN cards, Wiegand cards, and smart cards, as well as the card reading/formatting features. Refer to the manual of the device for the types of cards supported by the device.

:::note

**Card enrollment using a USB agent**

<div className='table-fixed'>

| Card type | CSN | Wiegand | Smart card |
| --- | :-: | :-: | :-: |
| EM | ❌ | ❌ | ❌ |
| MIFARE | ✅ | ❌ | ✅ |
| DESFire | ✅ | ❌ | ✅ |
| FeliCa | ✅ | ❌ | ❌ |
| HID Prox | ❌ | ❌ | ❌ |
| HID iCLASS | ❌ | ❌ | ❌ |

</div>

:::

## CSN card {/* #csncard */}

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd>CSN</Cmd> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-csn.png' />

3. Select your desired card enrollment method from the <Cmd sid='common.registrationOption' product='2' /> field.

   * <Cmd sid='common.registerByCardReader' product='2' />: Select the device from the <Cmd sid='common.device' product='2' /> list to scan the card and click <Cmd sid='common.readCard' product='2' />.

   * <Cmd sid='common.assignCard' product='2' />: Select the card you want to assign to the user from the list. You can search through the input field.

   * <Cmd sid='common.enterManually' product='2' />: Enter the card number manually or click <Cmd sid='common.useUserId' product='2' />.

4. Click <Cmd sid='button.enroll' product='2' />.

## Wiegand card {/* #wiegandcard */}

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd>Wiegand</Cmd> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-wiegand.png' />

3. Select the desired format from the <Cmd sid='user.cardEnrol.cardFormat' product='2' /> field.

4. Select your desired card enrollment method from the <Cmd sid='common.registrationOption' product='2' /> field.

   * <Cmd sid='common.registerByCardReader' product='2' />: Select the device from the <Cmd sid='common.device' product='2' /> list to scan the card and click <Cmd sid='common.readCard' product='2' />.

   * <Cmd sid='common.assignCard' product='2' />: Select the card you want to assign to the user from the list. You can search through the input field.

   * <Cmd sid='common.enterManually' product='2' />: Enter the facility code and card ID manually.

5. Click <Cmd sid='button.enroll' product='2' />.

:::info

If the desired card data format isn't available in the <Cmd sid='user.cardEnrol.cardFormat' product='2' /> options, see <DocLink docId='platform/biostar_x/settings-credential-wiegand-format' />.

:::

## Smart card {/* #smardcard */}

Enroll an access-on card, secure credential card, or custom smart card.

:::info

* To issue a smart card, the correct card type must be set. For more information about card formats, see <DocLink docId='platform/biostar_x/settings-credential-smart-format' />.

* The user information stored on the smart card uses information stored in **BioStar X**. Failure to store updated user information may result in incorrect information being stored on the smart card. Additionally, if the updated user information is not synchronized with the device, the device may fail to perform authentication.

* To use a face template, select <Cmd sid='setting.cardFormat.useFace' product='2' /> in the <Cmd sid='setting.cardFormat.layout' product='2' /> section when you add a new smart card from the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.cardFormat' /> menu. For more information, see <DocLink docId='platform/biostar_x/settings-credential-smart-format#layout' />.

* See <DocLink docId='platform/biostar_x/settings-device-details-auth#deviceCardsupremaSmartCard' /> to set up the smart card layout on the device.

* See <DocLink inner='#readformatcard' /> to format the smart card and rewrite its data.

:::

### <Cmd sid='user.accessOnCard' product='2' className='normal' /> {/* #accessOnCard */}

Select <Cmd sid='user.accessOnCard' product='2' /> to store user information on the card. This includes card ID, PIN, access group, period, fingerprint template, face template, and personal authentication mode.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd sid='common.smartCard' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

3. Select the device for card enrollment from the <Cmd sid='common.device' product='2' /> field.

4. Once selected, the card layout format set in the <Cmd sid='user.cardLayoutFormatName' product='2' /> field will be displayed.

5. Select <Cmd sid='user.accessOnCard' product='2' /> from the <Cmd sid='user.cardMode' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-smartcard.png' />

6. Select a fingerprint template if available. If no template is available, skip this step.

7. Click <Cmd sid='button.writeCard' product='2' />.

:::info

<Cmd sid='user.accessOnCard' product='2' className='normal' /> cannot set the card ID manually.

:::

### <Cmd sid='user.secureCredentialCard' product='2' className='normal' /> {/* #secureCredentialCard */}

Select <Cmd sid='user.secureCredentialCard' product='2' /> to store user information on the card. This includes card ID, PIN, fingerprint template, and face template.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd sid='common.smartCard' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

3. Select the device for card enrollment from the <Cmd sid='common.device' product='2' /> field.

4. Once selected, the card layout format set in the <Cmd sid='user.cardLayoutFormatName' product='2' /> field will be displayed.

5. Select <Cmd sid='user.secureCredentialCard' product='2' /> from the <Cmd sid='user.cardMode' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-smartcard-secure.png' />

6. Directly enter <Cmd sid='common.cardId' product='2' />.

7. Select a fingerprint or face template if available. If no template is available, skip this step.

8. Click <Cmd sid='button.writeCard' product='2' />.

## Read/format card {/* #readformatcard */}

You can format smart cards and rewrite information.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd sid='common.readCard' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-readcard.png' />

3. Select the device capable of reading smart cards from the <Cmd sid='common.device' product='2' /> field.

4. Select the <Cmd sid='user.cardModeLong' product='2' />.

5. Click <Cmd sid='common.readCard' product='2' />.

6. Verify the card information and click <Cmd sid='button.formatCard' product='2' />.

:::info

* The device list in the <Cmd sid='common.device' product='2' /> field is shown only when the smart card layout has been configured. For more information about this setting, see <DocLink docId='platform/biostar_x/settings-device-details-auth' />.

* Custom smart cards cannot be formatted.

:::
