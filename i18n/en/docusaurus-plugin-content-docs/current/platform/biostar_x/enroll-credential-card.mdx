Learn how to enroll access cards for a user. Learn how to enroll CSN cards, Wiegand cards, and smart cards, and how to read and format cards. For supported card types, see the device manual.

:::note

**Card enrollment using a USB agent**

<div className='table-fixed'>

| Card type | CSN | Wiegand | Smart card |
| --- | :-: | :-: | :-: |
| EM | ❌ | ❌ | ❌ |
| MIFARE | ✅ | ❌ | ✅ |
| DESFire | ✅ | ❌ | ✅ |
| FeliCa | ✅ | ❌ | ❌ |
| HID Prox | ❌ | ❌ | ❌ |
| HID iCLASS | ❌ | ❌ | ❌ |

</div>

## CSN card {/* #csncard */}

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd>CSN</Cmd> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-csn.png' />

3. Select a card enrollment method from the <Cmd sid='common.registrationOption' product='2' /> options.

   * <Cmd sid='common.registerByCardReader' product='2' />: Select the device from the <Cmd sid='common.device' product='2' /> list to scan the card and click <Cmd sid='common.readCard' product='2' />.

   * <Cmd sid='common.assignCard' product='2' />: Select the card to assign to the user from the list. Alternatively, search using the input field.

   * <Cmd sid='common.enterManually' product='2' />: Enter the card number manually or click <Cmd sid='common.useUserId' product='2' />.

4. Click <Cmd sid='button.enroll' product='2' />.

## Wiegand card {/* #wiegandcard */}

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd>Wiegand</Cmd> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-wiegand.png' />

3. Select a format from the <Cmd sid='user.cardEnrol.cardFormat' product='2' /> options.

4. Select a card enrollment method from the <Cmd sid='common.registrationOption' product='2' /> options.

   * <Cmd sid='common.registerByCardReader' product='2' />: Select the device from the <Cmd sid='common.device' product='2' /> list to scan the card and click <Cmd sid='common.readCard' product='2' />.

   * <Cmd sid='common.assignCard' product='2' />: Select the card to assign to the user from the list. Alternatively, search using the input field.

   * <Cmd sid='common.enterManually' product='2' />: Enter the facility code and card ID manually.

5. Click <Cmd sid='button.enroll' product='2' />.

:::info

If the card data format you need is not available in the <Cmd sid='user.cardEnrol.cardFormat' product='2' /> option, see <DocLink docId='platform/biostar_x/settings-credential-wiegand-format' />.

:::

## Smart card {/* #smardcard */}

You can enroll an Access-on-Card, Secure Credential Card, or custom smart card.

:::info

* To issue a smart card, you must set the correct card format. For more information about card formats, see <DocLink docId='platform/biostar_x/settings-credential-smart-format' />.

* The user information stored on the smart card uses the information stored in **BioStar X**. If you do not save the updated user information, incorrect user information may be stored on the smart card. Also, if you do not synchronize the updated user information with the device, the device may fail to authenticate.

* To use a face template, select <Cmd sid='setting.cardFormat.useFace' product='2' /> in the <Cmd sid='setting.cardFormat.layout' product='2' /> section when you add a new smart card from the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.cardFormat' /> menu. For more information about card layout, see <DocLink docId='platform/biostar_x/settings-credential-smart-format#layout' />.

* To set up the smart card layout on the device, see <DocLink docId='platform/biostar_x/settings-device-details-auth#deviceCardsupremaSmartCard' />.

* To format a smart card and rewrite its data, see <DocLink inner='#readformatcard' />.

:::

### <Cmd sid='user.accessOnCard' product='2' className='normal' /> {/* #accessOnCard */}

To store user information on the card, including card ID, PIN, access group, period, fingerprint template, face template, and personal authentication mode, select <Cmd sid='user.accessOnCard' product='2' />.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd sid='common.smartCard' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

3. Select the device to enroll the card from the <Cmd sid='common.device' product='2' /> options.

4. When you select a device, the card layout format set in the <Cmd sid='user.cardLayoutFormatName' product='2' /> option appears.

5. Select <Cmd sid='user.accessOnCard' product='2' /> from the <Cmd sid='user.cardMode' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-card-smartcard.png' />

6. If a fingerprint template is available, select it; otherwise, skip this step.

7. Click <Cmd sid='button.writeCard' product='2' />.

:::info

You cannot set the card ID manually for <Cmd sid='user.accessOnCard' product='2' className='normal' />.

:::

## Read/format a card {/* #readformatcard */}

This feature formats smart cards and rewrites information.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addCard' product='2' />.

2. When the <Cmd sid='user.header.card' product='2' /> window appears, select <Cmd sid='common.readCard' product='2' /> in the <Cmd sid='user.cardType' product='2' /> option.

   <Image src='/img/biostarx-new-user-credential-card-readcard.png' />

3. Select a device that can read smart cards in the <Cmd sid='common.device' product='2' /> option.

4. Select <Cmd sid='user.cardModeLong' product='2' />.

5. Click <Cmd sid='common.readCard' product='2' />.

6. Verify the card information and click <Cmd sid='button.formatCard' product='2' />.

:::info

* The device list in the <Cmd sid='common.device' product='2' /> field is shown only when the smart card layout has been configured. For more information about this setting, see <DocLink docId='platform/biostar_x/settings-device-details-auth' />.

* Custom smart cards cannot be formatted.

:::
