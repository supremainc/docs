title: Manage All Visitors
description: View all visitors with visit request, check-in, or check-out status for the set period. You can also add visitors from the list.

  - Visitor Management
---

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.visitor' />.

2. Click the <Cmd sid='common.total' product='2' /> tab at the top of the screen.

   <Image src='/img/biostarx-visitor-register-all-lists.png' />

:::info

* In the All Visitors list, approve visit requests or add visitors. For more information, see <DocLink docId='platform/biostar_x/visitor-register' />.

* In the All Visitors list, manage visitors with check-in or check-out status. For more information, see the following documents.

  * <DocLink docId='platform/biostar_x/visitor-register-checkin-manage' />

  * <DocLink docId='platform/biostar_x/visitor-register-checkout-manage' />

:::
