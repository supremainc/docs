On the dashboard, each user can add widgets by selecting the information to display and freely set up and arrange the widgets.

:::info

* Each user can set up their own <Cmd sid='shell.header.dashboard' />.

* The information available in <Cmd sid='shell.header.dashboard' /> may vary depending on <Cmd sid='user.bioStarOperator' product='2' />.

:::
