Delete visitor information after the personal data retention period expires.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.visitor' />.

2. Click the <Cmd sid='visitor.expired.personalData' product='2' /> tab at the top of the screen.

3. When the list of visitors whose personal data retention period has expired appears, select the checkbox for the visitor to delete. You can select one or more visitors.

   <Image src='/img/biostarx-visitor-expire-personal-data-lists.png' />

4. Click <Cmd sid='visitor.button.deletePersonalData' product='2' /> in the top right of the visitor list.

5. When the confirmation message appears, click <Cmd sid='button.yes' product='2' />.

:::info

* Only users with <Cmd sid='setting.account.administrator' product='2' className='bold' /> permission can view the list of visitors with expired personal data. For more information about user permissions, see <DocLink docId='platform/biostar_x/add-user' />.

* For more information about setting the personal data retention period, see <DocLink docId='platform/biostar_x/settings-visitor#settings-visitor-terms' />.

:::
