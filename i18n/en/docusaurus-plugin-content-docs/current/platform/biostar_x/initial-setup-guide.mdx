Learn how to set up **BioStar X** for normal operation after initial installation, step by step. Follow each step in order to build an efficient access control environment.

<Steps>
<Step>

## Register devices

Register devices to connect to **BioStar X**. Set up separate authentication modes by device, or assign an administrator to each device.

You can set actions for various events that occur on the device (for example, authentication failures, duress fingerprint authentication, and anti-passback violations).

* <DocLink docId='platform/biostar_x/settings-manage-device-group' />

* <DocLink docId='platform/biostar_x/settings-adding-devices' />

* <DocLink docId='platform/biostar_x/settings-adding-wiegand' />

* <DocLink docId='platform/biostar_x/settings-adding-slave-device' />

* <DocLink docId='platform/biostar_x/settings-device-details' />

:::info

You need a **Device Manager** or higher license to register devices. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

</Step>
<Step>

## Register and configure doors

Register door information where devices are installed. You can set relay, anti-passback, dual authentication, alarms, and more.

* <DocLink docId='platform/biostar_x/settings-manage-door-group' />

* <DocLink docId='platform/biostar_x/settings-door-add' />

</Step>
<Step>

## Configure access levels

Create access levels by combining door and schedule information, and register multiple doors and schedules to a single access level.

<DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' />

</Step>
<Step>

## Configure access groups

Create access groups by combining access levels (doors, schedules) and user information, and register multiple access levels and users to a single access group.

<DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />

</Step>
<Step>

## Register users

Register user information, and enroll credentials for access control. Register user information directly on the device or in **BioStar X**. In addition, you can get user information registered on the device into **BioStar X**, or send user information registered in **BioStar X** to the device.

* <DocLink docId='platform/biostar_x/user-group-manage' />

* <DocLink docId='platform/biostar_x/user-manage' />

* <DocLink docId='platform/biostar_x/add-user' />

* <DocLink docId='platform/biostar_x/enroll-credential' />

</Step>
<Step>

## Configure advanced access control

Anti-passback and fire alarms are supported, and you can set fire alarms as local or global.

* <DocLink docId='platform/biostar_x/settings-advanced-ac' />

* <DocLink docId='platform/biostar_x/monitoring-map' />

:::

</Step>
