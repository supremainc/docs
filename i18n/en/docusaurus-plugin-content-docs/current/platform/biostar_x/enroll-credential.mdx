Learn how to enroll a user's credentials. You can enroll the user's fingerprints, facial data, card information, and PINs as credentials. Credentials can be added or changed when you register a new user or edit a user.

On the <Cmd sid='shell.header.launcher' /> → <Cmd sid='shell.header.user' /> page, you can enroll, add, or change credentials in the following two ways.

import EnterUserPage from '../../common/_enter-user-page.mdx';

<EnterUserPage />

In the <Cmd sid='team.user.credential.title' /> section, you can set the following. See the description for each option, and set the appropriate user permissions.

<Image src='/img/biostarx-new-user-credential.png' />

Enroll credentials, and then set the appropriate security level in the <Cmd sid='user.fingerSecurityLevel' product='2' /> field. A higher security level may lead to a lower authentication rate or a higher false rejection rate (FRR).
