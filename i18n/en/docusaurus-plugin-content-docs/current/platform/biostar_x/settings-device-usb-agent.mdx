Supports USB fingerprint enrollment devices, card enrollment devices, and ID scanners when you access **BioStar X** from a client PC. To do this, install the USB Device Agent. Learn how to install and set up the USB Device Agent.

## Supported Devices

The following devices can be used after installing the USB Device Agent.

* USB fingerprint scanners: BioMini, BioMini Plus 2, BioMini Slim 2

* USB card reader: DUALi DE-620

* DESKO ID scanner

:::info

DESKO ID scanners are supported in BioStar X version 1.0.3 or later.

:::

## Install the USB Device Agent {/* #install-usb-agent */}

To use USB fingerprint enrollment devices, card enrollment devices, and ID scanners when accessing **BioStar X** from a client PC, install the USB Device Agent.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' /> in the left sidebar.

3. Click <Cmd sid='button.download' product='2' /> in the <Cmd sid='settings.usgAgent.lable' product='2' /> section.

   <Image src='/img/biostarx-setting-device-usb-agent-download.png' />

4. Run the downloaded file and follow the on-screen instructions to complete the installation.

:::info

If **User Account Control** is enabled in Windows, the USB Agent cannot start automatically. Turn off User Account Control, or run it directly with administrator privileges.

:::

## Set the byte order for the USB card device {/* #usb-card-device-byte-order */}

You can set the byte order for the USB card device.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' /> in the left sidebar.

3. In the <Cmd sid='settings.usbAgent.byteOrder.title' product='2' /> section, set the <Cmd sid='settings.usbAgent.byteOrder' product='2' /> option.

   <Image src='/img/biostarx-setting-device-usb-byte-order.png' />

   * <Cmd>MSB</Cmd>: Processes card data from the most significant byte to the least significant byte and stores the card serial number (CSN) sequentially from left to right.

   * <Cmd>LSB</Cmd>: Processes card data from the least significant byte to the most significant byte and stores the card serial number (CSN).

4. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='settings.usbAgent.byteOrder' product='2' /> option applies only to CSN cards.

:::

## Set the USB Agent port

Set the port that the USB Agent uses.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' /> in the left sidebar.

3. In the <Cmd sid='settings.usbAgent.port.title' product='2' /> section, enter the port number in the <Cmd sid='settings.usbAgent.port' product='2' /> input field.

   <Image src='/img/biostarx-setting-device-usb-agent-port.png' />

4. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The USB Agent runs on each client PC, and the port number setting lets the server communicate through that port.

:::
