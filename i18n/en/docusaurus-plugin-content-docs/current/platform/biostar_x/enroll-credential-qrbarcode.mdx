Learn how to enroll a QR code or barcode as a user credential. You can enroll QR codes generated in **BioStar X** and externally issued QR codes or barcodes.

:::info

* For devices that support QR/Barcode authentication with a scanner, see the list below.

  * X-Station 2 (XS2-QDPB, XS2-QAPB)

* For devices that support QR/Barcode authentication with a camera, see the list below.

  * BioStation 3 Max firmware v1.0.0 or later

  * XPass Q2 firmware v1.0.0 or later

  * BioStation 3 firmware v1.1.0 or later

  * X-Station 2 (XS2-ODPB, XS2-OAPB, XS2-DPB, XS2-APB) firmware v1.2.0 or later

  * X-Station 2 (XS2-QDPB, XS2-QAPB) firmware v1.4.1 or later

* A separate device license is required to use QR/Barcode authentication with a camera. For more information, see <DocLink docId='platform/biostar_x/settings-license-device-license' />.

:::

## BioStar X QR {/* #biostarxqr */}

You can issue a QR code that includes an encrypted PIN to a user to grant access.

:::note

**Before you start**

* Set email information, including SMTP settings, before using **BioStar QR**. For more information, see <DocLink docId='platform/biostar_x/settings-email-setting' />.

* To issue **BioStar QR**, you must enter an email address in the user information. For more information, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

:::

1. Click <Cmd sid='button.addQr' product='2' /> in the <Cmd sid='common.credential' product='2' /> section.

2. When the <Cmd sid='user.header.qr' product='2' /> window appears, select <Cmd sid='team.user.biostarQr' /> from the <Cmd sid='user.qrType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-biostarqr.png' />

3. Select the <Cmd sid='zone.intrusion.inputType' product='2' /> option.

   * <Cmd sid='user.random.cardid' product='2' />: Automatically generates a card ID.

   * <Cmd sid='user.manual.input' product='2' />: Enter the card ID manually.

4. Click <Cmd sid='button.enroll' product='2' />.

Afterward, when the user authenticates for access, the system issues a QR code and sends it to the email address registered in the user information. The user can scan the QR code in the email on the device to gain access.

:::info

To prevent duplicate card IDs, set <Cmd sid='zone.intrusion.inputType' product='2' /> to <Cmd sid='user.random.cardid' product='2' />.

:::

## QR/Barcode {/* #qrbarcode */}

You can enroll QR codes or barcodes issued by other external providers for the user.

1. Click <Cmd sid='button.addQr' product='2' /> in the <Cmd sid='common.credential' product='2' /> section.

2. When the <Cmd sid='user.header.qr' product='2' /> window appears, select <Cmd sid='team.user.credential.qrBarcode.title' /> from the <Cmd sid='user.qrType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-qrbarcode.png' />

3. Select <Cmd sid='common.enterManually' product='2' /> from the <Cmd sid='common.registrationOption' product='2' /> options.

4. In the <Cmd sid='user.cardId' product='2' /> field, enter the previously issued QR/barcode ID.

5. Click <Cmd sid='button.enroll' product='2' />.

:::info

The <Cmd sid='user.cardId' product='2' /> field accepts up to 32 characters, including letters, numbers, and special characters.

:::
