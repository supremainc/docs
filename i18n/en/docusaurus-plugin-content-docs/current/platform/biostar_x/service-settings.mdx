In the <Cmd>Service Settings</Cmd> menu of <Cmd>BioStar X Service Manager</Cmd>, you can set up and manage the system's core services. Each service is set independently, and you can check network ports and version information.

<Cmd>Service Settings</Cmd> consists of the following major services.

* <Cmd>BioStar X Core Web Service</Cmd>: Web interface service

* <Cmd>BioStar X Core Service</Cmd>: Core system features and API communication service

* <Cmd>Unified Gateway Service</Cmd>: Reverse proxy-based unified gateway service

* <Cmd>BioStar X Coordinator Service</Cmd>: Manages distributed system settings and synchronizes services

* <Cmd>BioStar X Server (Main)</Cmd>: Main server service

* <Cmd>BioStar X Cache Service</Cmd>: Data caching and improved system performance

## When to change settings {/* #when-to-change */}

You may need to change service settings in the following situations.

* **Resolving port conflicts**: When another application uses the same port and a conflict occurs

* **Compliance with security policies**: When only specific port ranges are allowed under your organization's network security policy

* **Firewall settings**: When you need to change to ports that your corporate firewall allows

* **Server environment changes**: When the server IP address changes or network settings change

* **Performance optimization**: When you need to separate ports for traffic distribution or load balancing

## Change settings {/* #how-to-change */}

1. Click <Cmd>SERVICE SETTINGS</Cmd> in <Cmd>BioStar X Service Manager</Cmd>.

2. Go to the section for the service you are changing.

3. Edit the required port number or address.

4. To apply changes, click <Cmd>Apply</Cmd> in the upper-right corner of the screen.

:::note

* After you change service settings, restart the related service to apply the changes.

* Some services may not support changing the port.

:::

:::caution

When changing port numbers, make sure there are no conflicts with other services or applications.

:::

## Service components {/* #service-composition */}

### BioStar X Core Web Service {/* #biostar-x-core-web-service */}

This service handles the web-based user interface.

<Image src='/img/common/biostarx-sm-cws.png' alone />

* <Cmd>HTTPS Port</Cmd>: Web interface access port (default: 5002)

* <Cmd>WebServerThrift Port</Cmd>: Web server communication port for the Thrift protocol (default: 9310)

### BioStar X Core Service {/* #biostar-x-core-service */}

This is the main service that handles the system's core features and external API communication.

<Image src='/img/common/biostarx-sm-core-s.png' alone />

* <Cmd>WebSocket Port</Cmd>: WebSocket port for real-time bidirectional communication (default: 9002)

* <Cmd>API Port</Cmd>: REST API communication port (default: 9010)

* <Cmd>WebServerFastCgi Port</Cmd>: Web server communication port for the FastCGI protocol (default: 9000)

* <Cmd>Rpc Port</Cmd>: Remote Procedure Call (RPC) communication port (default: 51218)

### Unified Gateway Service {/* #unified-gateway-service */}

It efficiently processes requests to the **BioStar X** server through a reverse proxy, mitigates security vulnerabilities in iframes, and minimizes SSL certificate errors.

<Image src='/img/common/biostarx-sm-ugs.png' alone />

* <Cmd>HTTPS Port</Cmd>: Unified Gateway HTTPS communication port (default: 443)

### BioStar X Coordinator Service {/* #biostar-x-coordinator-service */}

This service manages settings for the distributed system, monitors service status, and synchronizes services.

<Image src='/img/common/biostarx-sm-coordinator-s.png' alone />

* <Cmd>Client Port</Cmd>: Communication port for client connections (default: 21810)

:::info

* After you change the <Cmd>Client Port</Cmd> value, find **BioStar X Coordinator Service** in **Windows Services**(*services.msc*) and restart the service manually.

* After restarting **BioStar X Coordinator Service**, go to **BioStar X Service Manager** → **SERVICES** and restart all services. 

  Click <Cmd>Stop All</Cmd> in the upper-right corner of the screen. After all services stop and the <Cmd>Start All</Cmd> button is enabled, click the button.

:::

### BioStar X Server (Main) {/* #biostar-x-server-(main) */}

This is the core service that acts as the system's main server.

<Image src='/img/common/biostarx-sm-server.png' alone />

* <Cmd>Server Address</Cmd>: IP address for the main server

* <Cmd>Server Port</Cmd>: General server communication port (default: 51212)

* <Cmd>SSL Server Port</Cmd>: SSL-encrypted communication port (default: 51213)

* <Cmd>gRPC Server Port</Cmd>: High-performance communication port for the gRPC protocol (default: 51219)

### BioStar X Cache Service {/* #biostar-x-cache-service */}

This service improves the system's data processing speed and performance by storing frequently used data in memory.

<Image src='/img/common/biostarx-sm-cache-s.png' alone />

* <Cmd>Client Port</Cmd>: Cache service client connection port (default: 10800)

* <Cmd>Communication Port</Cmd>: Internal communication port between cache nodes (default: 47500)

* <Cmd>Discovery Port</Cmd>: Port for automatic discovery of distributed cache nodes (default: 47100)
