You can set a schedule to automatically generate the <Cmd sid='reportApp.customReport' product='2' /> you created with the DYNAMIC period.

## Add an auto-generation schedule

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.data' />, or select <Cmd sid='shell.header.data' /> from the shortcut list in the upper-left corner of the screen.

2. Click <Cmd sid='reportApp.mainMenu.schedule' product='2' />.

3. Click <Cmd sid='reportApp.addSchedule' product='2' /> in the upper-right corner of the screen.

   <Image src='/img/biostarx-data-auto-schedule-main.png' />

4. When the <Cmd sid='data.schedule.newSchedulePageTitle' /> screen appears, set each field.

### Information settings

Set the basic information for the auto-generation schedule.

<Image src='/img/biostarx-data-information.png' className='none' />

* <Cmd sid='reportApp.scheduleName' product='2' / >: Enter the schedule name.

### Report and schedule settings

Set an auto-generation schedule for each report.

<Image src='/img/biostarx-data-report-schedule.png' className='none' />

* <Cmd sid='reportApp.report' product='2' / >: Select the custom report to generate automatically. Only custom reports set to the DYNAMIC period appear.

* <Cmd sid='reportApp.frequency' product='2' / >: Set how often to generate reports automatically.

* <Cmd sid='reportApp.generateTime' product='2' / >: Set the time to generate reports automatically.

:::info

For more information about creating custom reports, see <DocLink docId='platform/biostar_x/data-generate-reports#custom-report' />.

:::

### Report format settings

Set the format for each report.

<Image src='/img/biostarx-data-report-format.png' className='none' />

* <Cmd sid='reportApp.outputType' product='2' />: Set how to generate reports automatically.

* <Cmd sid='reportApp.reportTitle' product='2' />: To show the report name as the title on every page, select <Cmd sid='reportApp.showTitle' product='2' />.

* <Cmd sid='reportApp.header' product='2' />: If <Cmd sid='reportApp.showHeader' product='2' /> is selected, the header appears when the report is generated. To show the header on every page, select <Cmd sid='reportApp.onEveryPage' product='2' />.

    :::info

    The generated header can vary by report.

    :::

* <Cmd sid='reportApp.footer' product='2' />: Set whether to show page numbers.

* <Cmd sid='reportApp.fileFormat' product='2' />: Set the file format for exporting reports.

3. To save the settings, click <Cmd sid="reportApp.apply" product='2' />.

:::info

When you complete all settings, set the path to save the report. For more information, see <DocLink docId='platform/biostar_x/data-settings' />.

:::

## Delete an auto-generation schedule

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.data' />, or select <Cmd sid='shell.header.data' /> from the shortcut list in the upper-left corner of the screen.

2. Click <Cmd sid='reportApp.mainMenu.schedule' product='2' />.

3. Select the checkbox for the schedule to delete in the automatic schedule list.

   <Image src='/img/biostarx-data-auto-schedule-remove-item.png' />

4. Click <Cmd sid='common.button.delete' /> in the upper-right corner of the screen.
