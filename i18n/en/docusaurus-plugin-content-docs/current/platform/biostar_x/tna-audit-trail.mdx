The <Cmd sid='setting.menu.auditTrail.taAuditLog' /> feature records all activities related to Time & Attendance, such as shifts, schedules, and reports. Each record shows when the change happened, who made it, what changed, and how, to support security audits and troubleshooting.

:::info

To use the <Cmd sid='setting.menu.auditTrail.taAuditLog' /> menu, the Time & Attendance (T&A) license must be active, and the operations administrator must have permission for this menu. The <Cmd sid='setting.account.taOperator' product='2' /> account created by default during Time & Attendance plugin installation does not have this permission, so you must add and set up a custom permission.

:::

## Add Time & Attendance audit permission {/* #addTnaAuditLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> in the left sidebar.

3. Click <Cmd sid='setting.account.addCustomOperator' product='2' />.

   <Image src='/img/biostarx-settings-account-add-custom-permission.png' />

4. Enter a permission name and description for viewing Time & Attendance audit logs.

   <Image src='/img/biostarx-settings-account-add-custom-permission-details.png' />

5. In <Cmd sid='settings.account.menu.setting' product='2' />, set permissions for <Cmd sid='common.taAuditLog' product='2' /> and <Cmd sid='common.retentionSettings' product='2' /> under the <Cmd sid='common.auditTrail' product='2' /> menu.

   <Image src='/img/biostarx-settings-custom-account-level.png' />

6. In <Cmd sid='settings.account.addUser' product='2' />, click <Cmd sid='button.plusAdd' product='2' /> and select a user group or a user.

7. To save the custom permission, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen. 

## View Time & Attendance audit logs

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.taAuditLog' /> in the left sidebar.

3. The Time & Attendance audit log list appears on the screen.

<Image src='/img/biostarx-settings-tna-audit-trail.png' />

:::info

* To change audit log policies such as the retention period, see <DocLink docId='platform/biostar_x/tna-audit-trail-settings' />.

* After upgrading to version 1.0.3, new audit logs are stored encrypted regardless of the <Cmd sid='setting.sever.secure.comm.encrypt.db' product='2' /> option under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.system.security' />.

* If some audit logs are not recorded after upgrading from BioStar 2 to **BioStar X**, see <DocLink docId='platform/biostar_x/migration-x#checkCert' />.

:::

## Table layout

The audit log list table has 10 columns and shows the records that match the current search criteria, newest first by <Cmd sid='audit.column.datetime' />.

| Column | Description |
| --- | --- |
| <Cmd sid='audit.column.datetime' /> | The date and time the event occurred. |
| <Cmd sid='audit.column.user' /> | The user who performed the event. Shown in the **id(name)** format. |
| <Cmd sid='audit.column.accountLevel' /> | The administrator level of the user who performed the event. Blank for actions the system runs automatically. |
| <Cmd sid='audit.column.action' /> | The type of action that was run. Classified as <Cmd sid='action.create' />, <Cmd sid='action.update' />, <Cmd sid='action.delete' />, <Cmd sid='action.read' />, <Cmd sid='action.export' />, or <Cmd sid='action.operation' />. |
| <Cmd sid='audit.column.category' /> | Domain category of the event target. (<Cmd sid='category.shift' />, <Cmd sid='category.schedule' />, <Cmd sid='category.report' />, <Cmd sid='category.ta_audit_log' />, <Cmd sid='category.setting' />, <Cmd sid='category.system' />) |
| <Cmd sid='audit.column.target' /> | The target the action applies to. Shown in the **type: id(name)** format. |
| <Cmd sid='audit.column.subAction' /> | Detailed action name that appears only for <Cmd sid='action.operation' />, <Cmd sid='action.read' />, and <Cmd sid='action.export' /> actions. |
| <Cmd sid='audit.column.modifiedFields' /> | The name of the field that changed or was viewed. Always blank for <Cmd sid='action.operation' /> actions. |
| <Cmd sid='audit.column.details' /> | Detailed information for each action. (Changed values, query conditions, field snapshots, and more) |
| <Cmd sid='audit.column.ip' /> | The IP address the user connected from. Records that the system generates automatically appear as **127.0.0.1**. |

:::info

* Records where <Cmd sid='audit.column.action' /> is <Cmd sid='action.update' /> always point to a single target. Time & Attendance does not support batch editing that changes multiple targets at once, so targets do not appear grouped.

* Names shown in <Cmd sid='audit.column.user' />, <Cmd sid='audit.column.target' />, and <Cmd sid='audit.detail.changeDetails' /> keep the value from when the record occurred. If the name changes later or the target is deleted, the name shown in past records stays the same.

* If the <Cmd sid='audit.column.target' /> or <Cmd sid='audit.column.modifiedFields' /> column has two or more values, only the first appears, and the rest are collapsed into a count badge on the right (for example, **+208**). If the remaining count is 1,000 or more, the badge shows **+999**. Check the exact total count in the detail pop-up title. Click the badge to open the detail pop-up for that cell.

  <Image src='/img/biostarx-settings-system-audit-trail-list-badge.png' />

* Long cell values truncate to one line with an ellipsis. When you hover over the cell, the full value appears in a tooltip, and text longer than the tooltip is shortened to `...`.

  <Image src='/img/biostarx-settings-system-audit-trail-list-tooltip.png' />

:::

## View details

Cells with values in <Cmd sid='audit.column.target' />, <Cmd sid='audit.column.modifiedFields' />, or <Cmd sid='audit.column.details' /> appear underlined and are clickable. Click a cell to open a details pop-up for the row's action, and close it by clicking <Cmd sid='audit.filter.ok' /> or <IcClose />.

<Image src='/img/biostarx-settings-tna-audit-trail-detail-popup.png' />

Enter a keyword in the <Cmd sid='audit.detail.searchPlaceholder' /> field at the top of the pop-up to highlight or filter matching entries. When searching, the target pop-up updates groups and counts per group. The title total count stays the same.

## Find records with filters

Combine the filters in the <Cmd sid='audit.filter.title' /> section to narrow down records. Selecting multiple values in one filter combines them with `OR`, and applying multiple filters together combines them with `AND`.

<Image src='/img/biostarx-settings-tna-audit-trail-filtered.png' />

| Filter | How it works |
| --- | --- |
| <Cmd sid='audit.filter.datetime' /> | Set the start and end dates and times. No length limit applies to the search period. |
| <Cmd sid='audit.filter.user' /> | Enter a search term and press <Kbd>Enter</Kbd> to find matching users. The list is empty when you first open it. |
| <Cmd sid='audit.filter.accountLevel' /> | Enter a search term and press <Kbd>Enter</Kbd> to find matching administrator levels. |
| <Cmd sid='audit.filter.category' /> | Select one or more categories from the searchable checkbox list. |
| <Cmd sid='audit.filter.target' /> | Enter a search term and press <Kbd>Enter</Kbd> to find matching targets. |
| <Cmd sid='audit.filter.action' /> | Select one or more actions from the checkbox list. |
| <Cmd sid='audit.filter.subAction' /> | Select a detailed action from the searchable list. |
| <Cmd sid='audit.filter.ip' /> | Enter a search term and press <Kbd>Enter</Kbd> to find matching IP addresses. |

* If no filters are applied, records from the last 30 days appear by default.

* Select a value in each filter pop-up, then click <Cmd sid='audit.filter.addCondition' /> to apply it to the search immediately. Click <Cmd sid='audit.filter.cancel' /> to cancel the selection and close the pop-up.

  <Image src='/img/biostarx-settings-system-audit-trail-set-filter-popup.png' />

* Applied filters appear summarized as the first entry and the number of additional entries. Click <IcClose title='Disable' /> to clear only that filter. Filters with no selected value appear as <Cmd sid='audit.filter.none' />.

  <Image src='/img/biostarx-settings-system-audit-trail-seted-filters.png' />

:::info

Enter a search term to see results for the <Cmd sid='audit.filter.user' />, <Cmd sid='audit.filter.accountLevel' />, <Cmd sid='audit.filter.target' />, and <Cmd sid='audit.filter.ip' /> filters. The search supports partial matches, so you can enter part of a name or ID. The search includes deleted targets, marked as <Cmd sid='audit.detail.target.deleted' />.

:::

### Set the date range

Click <Cmd sid='audit.filter.datetime' /> to open the <Cmd sid='audit.filter.dateRangeTitle' /> pop-up.

<Image src='/img/biostarx-settings-tna-audit-trail-set-period.png' />

1. Set the date and time for <Cmd sid='audit.filter.startDatetime' /> and <Cmd sid='audit.filter.endDatetime' /> separately. Click <Cmd sid='audit.filter.today' /> to jump to today's date.

2. To apply the date range, click <Cmd sid='audit.filter.ok' />.

## Save a filter

You can save frequently used search conditions in <Cmd sid='audit.filter.savedFilters' /> and load them again later.

1. Set the filter conditions.

2. Click <Cmd sid='audit.filter.save' /> in the <Cmd sid='audit.filter.title' /> section.

3. The system adds the <Cmd sid='audit.filter.newFilterName' /> entry to the filter list in the left pane.

<Image src='/img/biostarx-settings-tna-audit-trail-add-filter.png' />

* To rename the filter, click <IcAuditEdit title='Edit' />, enter a new name, then press <Kbd>Enter</Kbd>.

* To delete the filter, click <IcAuditDelete title='Delete' />.

:::info

Up to 20 filters can be saved. The browser stores saved filters, so they do not appear on other PCs or browsers.

:::

## Additional records from cascading deletion {/* #tna-audit-trail-cascade */}

Editing or deleting a work schedule may also delete temporary schedules and absences for users who use it. Then, the system logs an additional record for each deleted temporary schedule and absence, separate from the work schedule change or deletion record.

* If cascading deletion deletes nothing, the system creates no additional records.

* <Cmd sid='audit.column.target' /> includes the one work schedule that caused the deletion and only the users whose entries were actually deleted. It does not include all users in the schedule.

* <Cmd sid='audit.column.details' /> shows the number of deletions, and when a work schedule is deleted, it also shows the affected period.

## Export to CSV

Export audit logs to a CSV file for use with external analysis tools.

1. In the <Cmd sid='audit.filter.title' /> section, set filters if needed.

2. Click <IcMoreW /> → <Cmd sid='audit.filter.menuCsvExport' /> on the right side of the section.

3. When the <Cmd sid='audit.csvExport.title' /> window appears, enter <Cmd sid='audit.csvExport.reasonLabel' /> (optional), and click <Cmd sid='common.apply' />.

   <Image src='/img/biostarx-settings-system-audit-trail-export-csv.png' />

The exported CSV file includes all 10 columns, one line per record, and adds quotation marks only to cells that contain commas. Cells with multiple values, such as <Cmd sid='audit.column.target' /> and <Cmd sid='audit.column.modifiedFields' />, use a vertical bar (`|`) as a separator (for example, **Schedule: 7(Team Schedule)| User: 12(Robert)**). In records where <Cmd sid='audit.column.action' /> is <Cmd sid='action.update' />, <Cmd sid='audit.column.details' /> includes all fields without ellipses.

:::caution

The CSV file includes values as-is, including values a spreadsheet program may interpret as formulas. Do not open the downloaded CSV file directly in a spreadsheet program. If needed, open it with the text import feature.

:::

:::tip

If you set filters, only the filtered results are exported to the CSV file.

:::
