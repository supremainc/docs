This is useful when you do not add overtime time codes to <Cmd sid='tab.shift' product='2' className='normal' />. Overtime set in <Cmd sid='tab.shift' product='2' className='normal' /> has start and end times, but <Cmd sid='rule.rule' product='2' className='normal' /> calculates total time beyond regular work hours. <Cmd sid='rule.rule' product='2' className='normal' /> is useful for managing total overtime hours daily, weekly, or monthly. When you set <Cmd sid='rule.rule' product='2' className='normal' />, it applies instead of the overtime time codes added to <Cmd sid='tab.shift' product='2' className='normal' />.

## <Cmd sid='rule.addRule' product='2' className='bold' />

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click <Cmd sid='tab.shift' product='2' /> → <Cmd sid='rule.rule' product='2' /> in the left sidebar.

3. Click <Cmd sid='rule.addRule' product='2' />.

   <Image src='/img/biostarx-tna-shift-overtime.png' />

4. When the <Cmd sid='rule.addRule' product='2' /> screen appears, set each field.

:::info

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

* To add a work schedule next, click <Cmd sid='payCode.applyAndAddShift' product='2' />.

* To add another <Cmd sid='rule.rule' product='2' /> after you save the settings, click <Cmd sid='ta.apply_add_another' product='2' />.

:::

## Schedule options

Set <Cmd sid='rule.rule' product='2' className='normal' />. You can set overtime rules to apply daily, weekly, or monthly.

<Image src='/img/biostarx-tna-shift-overtime-adding.png' />

* <Cmd sid='form.name' product='2' />: Enter the name of <Cmd sid='rule.rule' product='2' className='normal' />.

* <Cmd sid='form.description' product='2' />: Enter a description for <Cmd sid='rule.rule' product='2' className='normal' />.

* <Cmd sid='rule.overtime' product='2' />: Select the overtime rules to apply after regular work hours daily, weekly, or monthly. A different overtime rule can apply after a set amount of time. You can also set a maximum overtime limit to restrict how much overtime an employee can work.

  :::tip

  With the following settings, when regular work hours are from 8:00 a.m. to 5:00 p.m., the **Overtime(1.5)** time code applies from 5:00 p.m. to 11:00 p.m. The **Overtime(2)** time code applies from 11:00 p.m. to 2:00 a.m. In addition, the maximum daily overtime is limited to 9 hours, so the system uses only records up to 2:00 a.m. to calculate daily pay.

  <Image src='/img/biostarx-tna-shift-overtime-example.png' />

  :::

  :::info

  Total work hours do not include breaks or meal times.

  :::

* <Cmd sid='rule.weekendOvertime' product='2' /> / <Cmd sid='rule.holidayOvertime' product='2' />: Set the rules to apply on weekends or holidays.

  * <Cmd sid='payCode.payCode' product='2' />: Select the <Cmd sid='tab.payCode' product='2' className='normal' /> to apply.

  * <Cmd sid='shift.dayStartTime' product='2' />: Set the work start time.

  * <Cmd sid='rule.firstInLastOut' product='2' />: Records the first time a user authenticates as the clock-in time and the last time a user authenticates as the clock-out time.
