Learn how to view and manage users by access group. Use <Cmd sid='team.tree.accessExplorer' /> to view registered users by access group and explore the access permission hierarchy in the tree structure.

:::info

To check the doors or floors in an access group in <Cmd sid='team.tree.accessExplorer' />, you must set up the access control feature first. For more information, see <DocLink docId='platform/biostar_x/settings-access-control' />.

:::

## View users by access group {/* #view-user-by-access */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the tree structure menu, click <Cmd sid='team.tree.accessExplorer' />.

   <Image src='/img/biostarx-user-access-explorer.png' />

3. In <Cmd sid='team.user.tree.accessExplorerRootName' />, click an access group.

Users in the selected access group appear in the user list.

:::info

To expand or collapse access levels or floor levels under an access group, click <IcAdd /> or <IcMinus />.

:::

## Learn about the tree structure {/* #learn-tree-view */}

The tree structure menu has the following structure.

<Treeview />

* An **access group** is a top-level group that includes access levels, floor levels, user groups, and users. You manage access permissions through an **access group**. For more information about creating access groups, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />.

* An **access level** sets when users can access and grants permission to access doors during that time. For more information about creating access levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' />.

* Use a **floor level** to manage the floors users can access by elevator. For more information about creating floor levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-floor-level' />.

* A **schedule** is a feature that sets access and holiday schedules to run access control and Time & Attendance efficiently. For more information about registering schedules, see <DocLink docId='platform/biostar_x/settings-schedule' />.

* You can register **elevators** and manage the floors users can access by elevator. For more information about registering an elevator, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

:::info

The elevator registration feature is available as an additional option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::
