This guide shows how to query and manage users based on access groups. Use <Cmd sid='team.tree.accessExplorer' /> to check registered users by access group and explore the access permission hierarchy through the tree structure.

:::info

To check access doors or floors belonging to an access group in <Cmd sid='team.tree.accessExplorer' />, you must first set up the access control feature. For more information, see <DocLink docId='platform/biostar_x/settings-access-control' />.

:::

## Check users by access group {/* #view-user-by-access */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click the <Cmd sid='team.tree.accessExplorer' /> tab in the tree structure menu.

   <Image src='/img/biostarx-user-access-explorer.png' />

3. Click the desired access permission group in <Cmd sid='team.user.tree.accessExplorerRootName' />.

You can view users belonging to the selected access permission group in the user list.

:::info

To expand or collapse access levels or floor levels under the access group, click <IcAdd /> or <IcMinus />.

:::

## Learn about the tree structure {/* #learn-tree-view */}

The tree structure menu is composed of the following structure.

<Treeview />

* **Access group** is the upper layer that includes access levels, floor levels, user groups, and users. You can manage access permissions through the **access group**. See <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' /> For more information about creating access groups.

* **Access level** sets the times when users can enter and grants permission to access doors during this time. See <DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' /> For more information about creating access levels.

* You can manage the floors users can access via elevators through the **floor level**. See <DocLink docId='platform/biostar_x/settings-access-control-manage-floor-level' /> For more information about creating floor levels.

* **Schedule** is a feature that efficiently operates access control and attendance management by setting access and holiday schedules. See <DocLink docId='platform/biostar_x/settings-schedule' /> For more information about registering schedules.

* You can register elevators and manage the floors accessible via the elevators. For more information about registering an elevator, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

:::info

The elevator registration feature is available as an additional option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::
