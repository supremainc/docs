Set the format for reading card data. Card data is processed using the Wiegand format you set.

## Set up Wiegand card formats

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.cardFormat' /> in the left sidebar.

3. Click <Cmd sid='common.wiegand' product='2' /> in the card format list on the left side of the screen.

   <Image src='/img/biostarx-settings-credentail-card-wiegand-list.png' />

4. Click <IcEdit /> for the unnamed item in the Wiegand format list.

5. When the <Cmd sid='setting.cardFormat.addNewWiegand' product='2' /> screen appears, set each field. For more information, see <DocLink inner='#setting' />.

6. To add the Wiegand format you set, click <Cmd sid='button.apply' product='2' />.

:::info

* The system supports up to 15 Wiegand formats.

* Predefined formats cannot be edited or deleted.

:::

## Setting options {/* #setting */}

When you add or edit a Wiegand card format, set the bit layout based on the fields below.

<Image src='/img/biostarx-settings-credential-wiegand-format.png' />

* <Cmd sid='common.name' product='2' />: Enter the Wiegand format name.

* <Cmd sid='common.description' product='2' />: Enter a brief description of the Wiegand format.

* <Cmd sid='setting.cardFormat.totalBits' product='2' />: Enter the total number of bits.

* <Cmd sid='setting.cardFormat.fcField' product='2' />: Set whether to use the facility code. To use the facility code, select the checkbox, and enter <Cmd sid='setting.cardFormat.startBit' product='2' /> and <Cmd sid='setting.cardFormat.endBit' product='2' />.

* <Cmd sid='setting.cardFormat.idField' product='2' />: Enter the <Cmd sid='setting.cardFormat.startBit' product='2' /> and <Cmd sid='setting.cardFormat.endBit' product='2' /> for the identifier to use. To add an ID field, click <Cmd sid='button.plusAdd' product='2' />.

* <Cmd sid='setting.cardFormat.parityBits' product='2' />: Click <Cmd sid='button.plusAdd' product='2' />, and enter the number of parity bits. Enter the position, start bit, and end bit of the parity bits to use.

:::info

To add parity bits, you must enter <Cmd sid='setting.cardFormat.totalBits' product='2' />.

:::
