Learn about the user interface of the <Cmd sid='shell.header.dashboard' /> page.

<Image src='/img/biostarx-dashboard.png' className='none' caption />

<Calloutlists>

1. **Widget display area**: The area where user-added widgets appear.

   * The size of each widget is adjustable within its size limits.

   * Widgets can be placed only in empty areas, and they cannot overlap each other.

2. **Refresh**: Refreshes the dashboard page to update the data in the modified widgets.

   In <Cmd sid='reportApp.dashboardSettings' product='2' />, set the refresh interval in <Cmd sid='reportApp.autoRefreshInterval' product='2' />.

3. <Cmd sid='reportApp.dashboardSettings' product='2' />: Adds new widgets or sets the data and appearance of existing widgets.

</Calloutlists>
