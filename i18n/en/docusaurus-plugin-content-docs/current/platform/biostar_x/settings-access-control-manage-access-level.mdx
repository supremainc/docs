Access levels enable users to set times for entry and grant permission to access doors during those times. Access levels are a key element for configuring access groups.

## Before you start {/* #beforeStart */}

* Initialize doors before enrolling access levels. For more information about registering doors, see <DocLink docId='platform/biostar_x/settings-door-add' />.

* You can predefine time to apply to access levels through schedule settings. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

## Register access level {/* #addAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addAccessLevel' product='2' />.

   <Image src='/img/biostarx-settings-access-level.png' />

4. Enter <Cmd sid='common.name' product='2' /> and <Cmd sid='common.description' product='2' /> in the <Cmd sid='accessGroup.addNewAccessLevel' product='2' /> screen.

   <Image src='/img/biostarx-settings-add-access-level.png' />

5. Select the door to apply the access level in the <Cmd sid='common.door' product='2' /> field.

6. Select the schedule to apply the access level in the <Cmd sid='common.schedule' product='2' /> field.

7. Click <Cmd sid='button.apply' product='2' /> at the bottom of the screen to register the access level.

:::info

* Up to 128 access levels can be registered per access group.

* Click <IcSearch /> in the <Cmd sid='common.door' product='2' /> and <Cmd sid='common.schedule' product='2' /> fields to search for the desired doors and schedules.

* Click <IcTrash2 /> to delete items added in the <Cmd sid='common.door' product='2' /> and <Cmd sid='common.schedule' product='2' /> fields.

* If the desired door is not available, you need to register a new door. For more information about registering doors, see <DocLink docId='platform/biostar_x/settings-door-add' />.

* If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::

## Edit access level {/* #editAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click the <Cmd sid='access_control.tab.access_level' product='2' /> tab.

   <Image src='/img/biostarx-settings-access-level-tab.png' />

4. Click the access level you wish to modify from the access level list.

5. Edit the fields as needed.

6. After you finish editing, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## Delete access level {/* #deleteAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click the <Cmd sid='access_control.tab.access_level' product='2' /> tab.

4. Check the checkbox of the access level you wish to delete from the access level list.

5. Click <Cmd sid='button.deleteAccessLevel' product='2' /> in the upper-right corner of the screen.

<Image src='/img/biostarx-settings-delete-access-level.png' />
