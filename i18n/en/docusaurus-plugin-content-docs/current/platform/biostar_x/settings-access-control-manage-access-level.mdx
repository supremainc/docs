An access level sets the times when a user can access a door, and grants permission to access the door during those times. Access levels are a key element for setting up access groups.

## Before you start {/* #beforeStart */}

* Set up doors before you register access levels. For more information about registering doors, see <DocLink docId='platform/biostar_x/settings-door-add' />.

* Schedule settings let you predefine times to apply to access levels. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

## Register an access level {/* #addAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addAccessLevel' product='2' />.

   <Image src='/img/biostarx-settings-access-level.png' />

4. In the <Cmd sid='accessGroup.addNewAccessLevel' product='2' /> screen, enter <Cmd sid='common.name' product='2' /> and <Cmd sid='common.description' product='2' />.

   <Image src='/img/biostarx-settings-add-access-level.png' />

5. In the <Cmd sid='common.door' product='2' /> field, select the door to apply to the access level.

6. In the <Cmd sid='common.schedule' product='2' /> field, select the schedule to apply to the access level.

7. To register the access level, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* An access group can have up to 128 access levels.

* In the <Cmd sid='common.door' product='2' /> and <Cmd sid='common.schedule' product='2' /> fields, click <IcSearch /> to search for doors and schedules.

* To delete entries you added in the <Cmd sid='common.door' product='2' /> and <Cmd sid='common.schedule' product='2' /> fields, click <IcTrash2 />.

* If the door you need is not available, register a new door. For more information about registering doors, see <DocLink docId='platform/biostar_x/settings-door-add' />.

* If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::

## Edit an access level {/* #editAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='access_control.tab.access_level' product='2' />.

   <Image src='/img/biostarx-settings-access-level-tab.png' />

4. In the access level list, click the access level to edit.

5. Edit the fields as needed.

6. After you finish editing, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## Delete an access level {/* #deleteAccessLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='access_control.tab.access_level' product='2' />.

4. In the access level list, select the checkbox for the access level to delete.

5. Click <Cmd sid='button.deleteAccessLevel' product='2' /> in the upper-right corner of the screen.

<Image src='/img/biostarx-settings-delete-access-level.png' />
