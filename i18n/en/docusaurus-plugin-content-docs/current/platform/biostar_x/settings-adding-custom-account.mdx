Learn how to add a permission level. Custom permissions are a user-customizable feature that lets you set additional permissions beyond the default operator permissions.

## Add a custom permission

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> in the left sidebar.

3. Click <Cmd sid='setting.account.addCustomOperator' product='2' />.

   <Image src='/img/biostarx-settings-account-add-custom-permission.png' />

4. Enter a name and description for the new permission.

   <Image src='/img/biostarx-settings-account-add-custom-permission-details.png' />

5. Enter or select the remaining fields.

6. To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* The available <Cmd sid='settings.account.menu.setting' product='2' /> options may vary depending on the active license type.

* For more information about <Cmd sid='settings.account.menu.detailSetting' product='2' />, see <DocLink inner='#detailSetting' />.

* For more information about <Cmd sid='settings.account.menu.setting' product='2' />, see <DocLink inner='#menuSetting' />.

* For more information about <Cmd sid='settings.account.addUser' product='2' />, see <DocLink inner='#addUser' />.

:::

### <Cmd sid='settings.account.menu.detailSetting' product='2' className='normal' /> {/* #detailSetting */}

Set detailed permissions for entries. Select the groups to grant edit and view permissions for each menu. Set detailed entry permissions for <Cmd sid='common.permission.module.userGroup' product='2' />, <Cmd sid='common.permission.module.deviceGroup' product='2' />, <Cmd sid='common.permission.module.doorGroup' product='2' />, and <Cmd sid='common.permission.module.accessGroup' product='2' /> based on the groups already created in each menu.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-item.png' />

:::info

* If the group is not available, go to that menu and add a new group. For more information about adding groups, see the followings:

  * <DocLink docId='platform/biostar_x/user-group-manage' />

  * <DocLink docId='platform/biostar_x/settings-manage-device-group' />

  * <DocLink docId='platform/biostar_x/settings-manage-door-group' />

  * <DocLink docId='platform/biostar_x/settings-manage-elevators-group' />

  * <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />

* The <Cmd sid='setting.account.item.map' product='2' /> permission is available with an **Essential** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* The <Cmd sid='common.permission.module.elevatorGroup' product='2' />, <Cmd sid='setting.account.item.advAC' product='2' />, <Cmd sid='common.permission.module.cameraGroup' product='2' /> permissions are available as an add-on option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

### <Cmd sid='settings.account.menu.setting' product='2' className='normal' /> {/* #menuSetting */}

Select <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' /> for each menu. Assign different permissions to each menu. Select the <Cmd sid='settings.account.menu.permission' product='2' /> checkbox for the menu, and then select <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' />.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-menus.png' />

* <Cmd sid='settings.account.menu.readOnly' product='2' />: Grants permission to enter the menu and view the settings only.

* <Cmd sid='settings.account.menu.fullAccess' product='2' />: Grants permission to add, edit, and delete entries in the menu.

:::info

* In the <Cmd sid='shell.header.arena' /> menu, <Cmd sid='settings.account.menu.fullAccess' product='2' className='bold' /> lets you add tabs or control state tree entries.

* In the <Cmd sid='shell.header.data' /> menu, <Cmd sid='settings.account.menu.fullAccess' product='2' className='bold' /> allows you to save reports, add automatic report schedules, and access settings.

* In the <Cmd sid='shell.header.dashboard' /> menu, you can create new dashboards and widgets with only the <Cmd sid='settings.account.menu.readOnly' product='2' className='bold' /> permission.

* Menus not listed in <Cmd sid='settings.account.menu.item' product='2' /> are accessible regardless of permissions.

:::

:::tip

When you click the permission for a parent menu, permissions for all submenus are enabled.

<Image src='/img/biostarx-settings-account-add-custom-permission-example.png' />

:::

### Plugin

If you add a plugin, you can set plugin permissions. Users without plugin permissions cannot access the plugin, and the plugin does not appear on the home screen or launcher.

<Image src='/img/biostarx-settings-account-add-custom-permission-plugin.png' />

:::info

* A plugin license is required to use plugin features. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* For the <Cmd sid='common.permission.module.time_attendance' product='2' /> plugin only, you can apply <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' />.

:::

### <Cmd sid='settings.account.addUser' product='2' className='normal' /> {/* #addUser */}

Add or review user information to grant permissions. To add a user, click <Cmd sid='button.plusAdd' product='2' />. In the user list, select the user to grant permissions to.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-users.png' />

:::info

When you click <IcTrash2 /> for a user in the user list, the user is excluded from the permission.

:::
