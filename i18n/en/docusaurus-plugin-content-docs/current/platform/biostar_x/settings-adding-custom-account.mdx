This guide describes how to add the desired permission level. Custom permissions are user-customizable features that allow for additional permissions beyond the default operational permissions.

## Add custom permissions

1. Click <Cmd sid='shell.header.setting' /> on the <Cmd sid='shell.header.launcher' /> page.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> on the left sidebar.

3. Click <Cmd sid='setting.account.addCustomOperator' product='2' />.

   <Image src='/img/biostarx-settings-account-add-custom-permission.png' />

4. Enter a name and description for the newly created permission.

   <Image src='/img/biostarx-settings-account-add-custom-permission-details.png' />

5. Fill in or select each of the remaining items.

6. Click <Cmd sid='button.apply' product='2' /> at the bottom of the screen to save the settings.

:::info

* The types of <Cmd sid='settings.account.menu.setting' product='2' /> settings you can configure may vary depending on the activated license type.

* For more information on <Cmd sid='settings.account.menu.detailSetting' product='2' />, see <DocLink inner='#detailSetting' />.

* For more information on <Cmd sid='settings.account.menu.setting' product='2' />, see <DocLink inner='#menuSetting' />.

* For more information on <Cmd sid='settings.account.addUser' product='2' />, see <DocLink inner='#addUser' />.

:::

### <Cmd sid='settings.account.menu.detailSetting' product='2' className='normal' /> {/* #detailSetting */}

Set detailed permissions for items. You can select groups to grant edit and view permissions for each menu. You can set item permissions for <Cmd sid='common.permission.module.userGroup' product='2' />, <Cmd sid='common.permission.module.deviceGroup' product='2' />, <Cmd sid='common.permission.module.doorGroup' product='2' />, <Cmd sid='common.permission.module.accessGroup' product='2' /> based on the information of already created groups in each menu.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-item.png' />

:::info

* If your desired group is not available, go to the appropriate menu to add a new group. For more information about adding groups, refer to the followings:

  * <DocLink docId='platform/biostar_x/user-group-manage' />

  * <DocLink docId='platform/biostar_x/settings-manage-device-group' />

  * <DocLink docId='platform/biostar_x/settings-manage-door-group' />

  * <DocLink docId='platform/biostar_x/settings-manage-elevators-group' />

  * <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />

* The permissions for <Cmd sid='common.permission.module.elevatorGroup' product='2' />, <Cmd sid='setting.account.item.advAC' product='2' />, <Cmd sid='setting.account.item.map' product='2' /> are available with an **Essential** license or higher. For more information on the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* The <Cmd sid='common.permission.module.cameraGroup' product='2' /> permission is available as an add-on option with an **Essential** license or higher. For more information on licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

### <Cmd sid='settings.account.menu.setting' product='2' className='normal' /> {/* #menuSetting */}

Select <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' /> for each menu. Assign different permissions to each menu. Click the <Cmd sid='settings.account.menu.permission' product='2' /> checkbox, then select <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' />.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-menus.png' />

* <Cmd sid='settings.account.menu.readOnly' product='2' />: Grants permission to enter the menu and only view the settings.

* <Cmd sid='settings.account.menu.fullAccess' product='2' />: Grants permission to add, edit, or delete entries in the menu.

:::info

* In the <Cmd sid='shell.header.arena' /> menu, <Cmd sid='settings.account.menu.fullAccess' product='2' className='bold' /> allows adding tabs or controlling state tree entries.

* In the <Cmd sid='shell.header.data' /> menu, <Cmd sid='settings.account.menu.fullAccess' product='2' className='bold' /> allows saving reports, adding automatic report schedules, and accessing settings.

* In the <Cmd sid='shell.header.dashboard' /> menu, <Cmd sid='settings.account.menu.readOnly' product='2' className='bold' /> permission allows creating new dashboards and widgets.

* Menus not listed in <Cmd sid='settings.account.menu.item' product='2' /> are accessible regardless of permissions.

:::

:::tip

Click a parent menu permission to enable permissions for all submenus.

<Image src='/img/biostarx-settings-account-add-custom-permission-example.png' />

:::

### Plugin

After adding a plugin, configure plugin permissions. Users without plugin permissions cannot access the plugin, and the plugin does not appear on the home screen or launcher.

<Image src='/img/biostarx-settings-account-add-custom-permission-plugin.png' />

:::info

* A plugin license is required to use plugin features. For more information on licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* Apply <Cmd sid='settings.account.menu.readOnly' product='2' /> or <Cmd sid='settings.account.menu.fullAccess' product='2' /> only to the <Cmd sid='common.permission.module.time_attendance' product='2' /> plugin.

:::

### <Cmd sid='settings.account.addUser' product='2' className='normal' /> {/* #addUser */}

You can add or verify user information for granting permissions. Click <Cmd sid='button.plusAdd' product='2' /> to add a user. Select the user to grant permissions from the user list.

<Image src='/img/biostarx-settings-account-add-custom-permission-details-users.png' />

:::info

Clicking <IcTrash2 /> next to a user in the user list will exclude that user from permissions.

:::
