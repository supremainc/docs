You can use user information from a previous version or another server by exporting or importing it.

## Export or import CSV {/* #csvexportimport */}

You can save selected user information as a CSV file, or import a saved CSV file. You can easily transfer user information using a CSV file.

:::info

* If you have custom user field data that you did not add to **BioStar X**, you cannot import the CSV file correctly. For more information about adding custom user fields, see <DocLink docId='platform/biostar_x/settings-server-server#custom-field' />.

* If user information is entered in a language other than English or Korean, save the CSV file as UTF-8.

:::

### Export CSV {/* #csvexport */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Select the checkbox next to the users to save as a CSV file in the user list. You can select one or more users.

3. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.export.title' /> → <Cmd sid='team.menu.export.csv' />.

   <Image src='/img/biostarx-user-export-csv.png' />

4. When the <Cmd sid='team.menu.export.csv' /> <Cmd sid='team.menu.export.title' /> window appears, enter <Cmd sid='team.menu.export.exportReason' /> (optional) and click <Cmd sid='common.button.download' />.

   <Image src='/img/biostarx-user-export-csv-popup.png' />

5. Save the CSV file to a location on your computer.

:::info

<Cmd sid='team.menu.export.exportReason' /> is optional. Export reasons are recorded in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

### Import CSV {/* #csvimport */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.csv' />.

3. Select the CSV file saved locally.

4. Set <Cmd sid='user.list.csvImport.importStartRow' /> in the <Cmd sid='team.menu.export.csv' /> <Cmd sid='team.menu.import.title' /> window and click <Cmd sid='common.button.next' />.

   <Image src='/img/biostarx-user-import-01.png' />

5. The user data fields in the CSV file are automatically mapped to the user data fields in **BioStar X**. To remap fields with the same name, click <Cmd sid='user.list.csvImport.reMapping' product='2' />.

   <Image src='/img/biostarx-user-import-02.png' width='50%' />

6. Choose whether to keep the data of users whose IDs already exist in **BioStar X** or overwrite it with the CSV data, and then click <Cmd sid='common.apply' />.

   <Image src='/img/biostarx-user-import-03.png' />

If an error occurs while importing the CSV file information, you can recheck and upload only the CSV data that caused the error.

:::info

* CSV import lets you issue mobile access cards. When using the regular site, one credit is deducted from the Airfob Portal for each mobile access card when the import completes. To avoid issuing mobile access cards, remove the mapping.

* If the CSV file contains the **same** data as a mobile access card issued to a user registered in **BioStar X**, you can keep or overwrite the data, and the existing mobile access card is retained.

* If the CSV file contains **different** data from a mobile access card issued to a user registered in **BioStar X**, keeping the data retains the existing mobile access card, and overwriting it issues a new mobile access card to that user.

* When you issue mobile access cards through CSV import on a dynamic site, make sure you enter values for the `mobile_start_datetime` and `mobile_expiry_datetime` fields.

* **BioStar X** QR cannot be issued through CSV import.

* CSV import lets you enroll a user's face. For more information, see <DocLink docId='platform/biostar_x/batch-import-face#import-csv' />.

* CSV import lets you enroll a user's PIN. For more information, see <DocLink docId='platform/biostar_x/enroll-credential-pin' />.

* If you add columns that do not match the saved CSV file, **BioStar X** cannot import it.

* If a username starts with `&@~`, importing that CSV entry fails.

* Set the validity period (expiration date and time) up to 2037-12-31 23:59:59. Import fails for entries with values after this date.

* Avoid opening the exported CSV file directly in spreadsheet programs such as Excel. If a username starts with the `=` character, the program may treat it as a formula and show a different value than the actual value.

:::

## Export or import data files {/* #exportimportdatafile */}

You can store user information on external storage (USB) and import it into **BioStar X** or a device. Up to 500,000 user records can be transferred from the server to a device or from one device to another.

:::info

* Data exported from devices running outdated firmware cannot be imported into **BioStar X**. Always use the latest firmware version.

* Data cannot be imported when different fingerprint template formats are used. For example, data exported from devices using the Suprema fingerprint template format cannot be imported into devices using the ISO fingerprint template format.

* When importing user data, if fingerprint and face credentials already exist on the **BioStar X** server, the existing data is overwritten.

* Data cannot be imported from devices running outdated firmware. Upgrade the device firmware to a compatible version. 

  <details>
  <summary>View compatible devices and firmware versions</summary>

  * BioStation 2 Firmware v1.9.0 or later

  * BioStation A2 Firmware v1.8.0 or later

  * FaceStation 2 firmware v1.4.0 or later

  * FaceStation F2 firmware v2.2.0 or later

  * X-Station 2 firmware v1.0.0 or later

  * BioStation 3 Firmware v1.3.1 or later

  * BioStation 2a firmware v1.0.0 or later

  </details>

:::

### Export data {/* #exportdata */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, select the checkbox for the users to export. You can select one or more users.

3. Click <IcMoreW /> in the upper-right corner of the screen, then select <Cmd sid='team.menu.export.title' /> → <Cmd sid='team.menu.export.dataFile' />.

   <Image src='/img/biostarx-user-export-data.png' />

4. In the <Cmd sid='team.menu.dialog.exprotDataFile.title' /> window, select the device to apply the data file to.

   <Image src='/img/biostarx-user-export-data-select-device.png' />

5. Enter <Cmd sid='team.menu.export.exportReason' /> (optional) and click <Cmd sid='common.apply' />.

6. Save the data file to a local path.

:::info

* Data file export saves the following user information as a file: profile photo, ID, name, validity period, access group, PIN, private authentication mode, credentials (face, fingerprint, card, mobile card, face, QR/Barcode), and 1:1 security level.

* If you do not select the correct device to apply the data file to, the device cannot recognize the data file.

* <Cmd sid='team.menu.export.exportReason' /> is optional. Export reasons are recorded in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

:::caution

To import a file exported from **BioStar X** to a device, rename the file as follows so the device can recognize it. The file name format is scheduled to be adjusted through a future device firmware update so the device recognizes it automatically.

*<b>BioStarX</b>_YYYYMMDD_HHMMSS.tgz* → *<b>BioStar2</b>_YYYYMMDD_HHMMSS.tgz*

:::

### Import data {/* #importdata */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <IcMoreW /> in the upper-right corner of the screen, then select <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.dataFile' />.

   <Image src='/img/biostarx-user-import-data.png' />

3. Select the data file (*.tgz*) saved locally.

If the data file is imported successfully, a message appears on the screen.
