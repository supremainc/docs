To connect **BioStar X** over HTTPS, you must register the IP address of the server where **BioStar X** is installed to install a certificate.

## When certificate installation is required

If you access **BioStar X** without an HTTPS certificate installed, a security warning like the following appears in your web browser.

<Image src='/img/biostarx-settings-server-not-secure.png' />

These warnings appear because the browser cannot verify the identity of the server. When you install the certificate, the browser trusts the **BioStar X** server, so you can use a secure HTTPS connection without security warnings.

## Install a certificate

Install the certificate before you use **BioStar X** to ensure proper network connectivity.

1. Go to the **BioStar X** login page.

2. Click <Cmd sid='auth.httpsDownload' /> at the bottom of the screen.

   <Image src='/img/biostarx-settings-server-login-down-https-cert.png' />

3. Save the *cert-register.zip* file locally.

4. Extract the downloaded file, and then run the *cert-register.exe* file. The **Enroll Certificate** program opens.

5. Select **BioStar X** for **Target System**, enter the IP address of the PC where **BioStar X** is installed in **Server Address**, and click **Enrollment**.

   <Image src='/img/common/biostarx-settings-server-enrollment-certification.png' className='none' alone />

   :::note

   The default port number for **BioStar X** is 443. If you changed the port number, enter the new port number in **Port**.

   :::

6. Read the security warning message, and then click **Yes**.

Restart the web browser, enter the registered IP address, and go to the **BioStar X** page. When you click the icon to the left of the address bar, the message **This connection is secure** appears.

<Image src='/img/biostarx-settings-server-secure.png' />

:::info

The IP address you enter in **Enroll Certificate** must match the IP address set in **BioStar X**. Check it under <Cmd sid='setting.server.biostarIPAdress' product='2' /> in the menu path <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.server.server' />.

:::

## Install a certificate in server settings

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid="setting.menu.server.https" /> in the left sidebar.

3. Click <Cmd sid="button.certDownload" product='2' />.

   <Image src='/img/biostarx-settings-server-https.png' className='none' />

4. Save the *cert-register.zip* file locally.

5. Extract the downloaded file, and then run the **cert-register.exe** file. The **Enroll Certificate** program opens.

6. Select **BioStar X** for **Target System**, enter the IP address of the PC where **BioStar X** is installed in **Server Address**, and click **Enrollment**.

   <Image src='/img/common/biostarx-settings-server-enrollment-certification.png' className='none' alone />

   :::note

   The default port number for **BioStar X** is 443. If you changed the port number, enter the new port number in **Port**.

   :::

7. Read the security warning message, and then click **Yes**.

Restart the web browser, enter the registered IP address, and go to the **BioStar X** page. When you click the icon to the left of the address bar, the message **This connection is secure** appears.

<Image src='/img/biostarx-settings-server-secure.png' />

## Install the VMS server certificate {/* #vms-certification */}

If any of the following situations occur, resolve the issue by installing the certificate from the VMS server on the client PC.

* When you access **Video Management System** (VMS) through a browser and a 'Not secure' warning appears

* When real-time video plays on the <Cmd sid='shell.header.arena' /> page but recorded video does not play

* When installing the VMS server and **BioStar X** on the same server

:::info

* For more information about installing the certificate on the VMS server, see <DocLink docId='platform/biostar_x/settings-video-integration#install-vms-certification' />.

* The feature that integrates with the VMS server requires a separately purchased add-on option. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

### Install the certificate on the client PC {/* #install-client-certification */}

1. On a client PC with **BioStar X** installed, download the HTTPS certificate installer (*cert-register.zip*) from the login screen or <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid="setting.menu.server.https" />.

2. Extract the downloaded file, and then run the **cert-register.exe** file. The **Enroll Certificate** program opens.

3. Select **VMS** for **Target System** and enter the following information.

   <Image src='/img/common/biostarx-settings-server-enrollment-vms-certification.png' alone />

   * **Server Address**: IP address of the VMS server

   * **Port**: Port number of the VMS server

4. Click **Enrollment**.

5. Read the security warning message, and then click **Yes**.

Restart the web browser, and then check whether the recorded video from the VMS server plays normally on the <Cmd sid='shell.header.arena' /> page.
