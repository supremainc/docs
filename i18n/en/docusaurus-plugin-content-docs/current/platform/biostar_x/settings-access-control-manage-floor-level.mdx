Learn how to set floor levels using the configured elevator and floor information. Floor levels are a key element that you can apply to access groups. Setting floor levels lets you manage which floors users can access by elevator.

:::info

Floor level features are available through add-on options with the **Essential** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

## Before you start {/* #beforeStart */}

* You must set up the elevator before you register floor levels. For more information about registering an elevator, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

* Schedule settings let you define in advance when to apply floor levels. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

## Register a floor level {/* #addFloorLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='ac.al.main.addFloorlevel.button' product='2' />.

   <Image src='/img/biostarx-settings-access-floor-level.png' />

4. In the <Cmd sid='ac.al.addFloorlevel.top' product='2' /> screen, enter <Cmd sid='common.name' product='2' /> and <Cmd sid='common.description' product='2' />.

   <Image src='/img/biostarx-settings-add-access-floor-level.png' />

5. In the <Cmd sid='ac.al.list.column.elevator' product='2' /> field, select the elevator to apply to the floor level.

6. In the <Cmd sid='ac.al.list.column.floorName' product='2' /> field, select the floor to apply to the floor level.

7. In the <Cmd sid='common.schedule' product='2' /> field, select the schedule to apply to the floor level.

8. To register a floor level, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* If the access level you need is not available, register a new access level. For more information about registering access levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' />.

* If the elevator you need is not available, register a new elevator. For more information about registering an elevator, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

* If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

* To delete an added entry, click <IcTrash2 />.

* To search for an entry, click <IcSearch />.

:::

## Edit a floor level {/* #editFloorLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='ag.floorLevel.title' product='2' />.

   <Image src='/img/biostarx-settings-access-floor-level-tab.png' />

4. In the floor level list, click the floor level to edit.

5. Edit the fields as needed.

6. After you finish editing, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## Delete a floor level {/* #deleteFloorLevel */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='ag.floorLevel.title' product='2' />.

4. In the floor level list, select the checkbox for the floor level to delete.

5. Click <Cmd sid='ac.al.main.deleteFloorlevel.button' product='2' /> in the upper-right corner of the screen.

<Image src='/img/biostarx-settings-access-delete-floor-level.png' />
