In the <Cmd sid='arena.eventTable.title' /> section at the bottom of the monitoring page, view and manage events as they occur in real time. Manage events efficiently with features such as event status, alarm event handling, filtering, and color coding. In particular, monitor events related to doors, devices, and users in real time, and quickly take any necessary action.

<Image src='/img/biostarx-monitoring-event-list.png' />

## View the event list {/* #event-list */}

In the <Cmd sid='arena.eventTable.title' /> section, view events as they occur in real time. Each event includes the following information:

<Image src='/img/biostarx-monitoring-event-list-details.png' />

* <Cmd sid='arena.eventTable.date' />: The date and time the event occurred.

* <Cmd sid='arena.eventTable.door' />: The door where the event occurred.

* <Cmd sid='arena.eventTable.device' />: The device where the event occurred.

* <Cmd sid='arena.eventTable.user' />: The user who triggered the event.

* <Cmd sid='arena.eventTable.event' />: Detailed information about the event.

* <Cmd sid='arena.eventTable.status' />: The event status. Active events appear as <Cmd sid='arena.preview.event.active' />. Alarm events show an <Cmd sid='common.acknowledge' /> button. To resolve the event, click <Cmd sid='common.acknowledge' />.

  <Image src='/img/biostarx-monitoring-event-list-alarm-active.png' />

* <Cmd sid='arena.eventTable.view' />: If the event includes video from a camera connected to the door, a video icon (<IcVidLog />) appears. To view the video, click the icon.

:::info

* When you click an event, its details appear on the right side of the screen. The details include the event time, area, door, device, user group, user, port, and event information. 

* If the event includes video or images from a camera connected to the door, you can also view the video and image logs.

:::

## Event colors {/* #event-color */}

Events in the event list are color-coded by type.

<Image src='/img/biostarx-monitoring-event-list-types.png' />

* **No color**: A normal event.

* <span style={{fontWeight: 'bold', color: '#ffa200'}}>Orange</span>: A caution event. This event needs attention, such as when a user tries to enter an area without access permission or when a door is left open.

* <span style={{fontWeight: 'bold', color: '#ff0000'}}>Red</span>: An [alarm](../../reference/glossary#alarm) event. This warning event occurred in the system and requires action.

* <span style={{fontWeight: 'bold', color: '#6dae00'}}>Green</span>: A resolved alarm event.

{/* Differences between Alarm Events and Warning Events */}

## View alarm events {/* #alarm-event */}

View only alarm events in the <Cmd sid='arena.eventTable.title' /> section list. Click <IcAlarm /> <Cmd sid='arena.eventTable.toolbar.alarmEvents' /> in the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section. Only alarm events appear in the event list. Alarm events appear in red.

<Image src='/img/biostarx-monitoring-event-list-view-only-alarm.png' />

:::info

To view all events, including alarm events, click <IcAlarm /> <Cmd sid='arena.eventTable.toolbar.allEvents' /> in the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section.

:::

## Real-time events {/* #real-time-event */}

View events as they occur in real time in the event list of the <Cmd sid='arena.eventTable.title' /> section. To pause real-time events, click <IcPause /> <Cmd sid='arena.eventTable.toolbar.pause' /> in the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section. To resume real-time events, click <IcPlay/> <Cmd sid='arena.eventTable.toolbar.play' />.

<Image src='/img/biostarx-monitoring-event-list-pause.png' />

## Filter events {/* #filter-event */}

### Apply filters {/* #apply-filter */}

Filter the event list by the conditions you need. This helps you quickly find events that match those conditions.

1. In the <Cmd sid='arena.eventTable.title' /> section list, click <IcFilter /> on a column header.

   <Image src='/img/biostarx-monitoring-event-list-filter-01.png' />

2. When the filter window appears, click the options you need in the list on the left.

   <Image src='/img/biostarx-monitoring-event-list-filter-02.png' />

   * When you select a parent option, all of its child options are selected.

   * To deselect an option, click <IcClose title='Remove' />. To deselect all options, click <Cmd sid='common.removeAll' />.

3. After you complete all settings, click <Cmd sid='common.apply' />.

The event list shows only the events that match the conditions you set.

:::info

* To find options quickly, use the search field in the filter window.

* You can set multiple conditions for each column header. When you set more than one condition, the conditions are combined with `AND`.

* The options available for filtering can vary by column header.

* When you set filter conditions, the <IcFilter2 title='Filter' /> icon in the column header changes color.

:::

### Remove filters {/* #removefilter */}

Remove the filter conditions you applied.

1. In the <Cmd sid='arena.eventTable.title' /> section list, click <IcFilter2 title='Filter' /> on the column header with the filter applied.

2. When the filter window appears, in the list on the right, click <IcClose title='Remove' /> next to the option to remove. To remove all filters, click <Cmd sid='common.removeAll' />.

   <Image src='/img/biostarx-monitoring-event-list-filter-02.png' />

3. After you select all conditions to remove, click <Cmd sid='common.apply' />.

:::info

* To find options quickly, use the search field in the filter window.

* When the filter conditions are removed, the icon in the column header returns to its original color.

:::

## Clear the event list {/* #cleareventlist */}

Clear events from the <Cmd sid='arena.eventTable.title' /> section list. Click <IcMoreB/> in the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section, and then select <Cmd sid='arena.eventTable.clearEvents' /> in the pop-up menu. When many unnecessary events accumulate in the event list, use <Cmd sid='arena.eventTable.clearEvents' /> to clean up the list.

<Image src='/img/biostarx-monitoring-event-list-remove.png' />

## Acknowledge alarms and record actions {/* #acknowledge-alarm-and-record-action */}

When an alarm event such as a door forced open occurs, an alarm message window appears. The alarm message window shows the details of the alarm event. You can acknowledge the alarm event and record the actions taken.

<Image src='/img/biostarx-monitoring-event-alert-message.png' />

:::info

The <Cmd sid='common.ignoreAll' /> button appears only when two or more alarm events occur.

:::

### Record actions for an alarm event {/* #recordactionforalarmevent */}

In the message field, enter the actions taken for the alarm event. You can enter up to 500 characters. After you enter the actions, click <Cmd sid='common.acknowledge' />. The acknowledgment and actions for the alarm event are recorded. The alarm message window closes.

<Image src='/img/biostarx-monitoring-event-alert-acknowledge-input-detail.png' />

### Defer acknowledgment of an alarm event {/* #deferalarmeventacknowledgment */}

To defer acknowledgment of the alarm event, click <Cmd sid='common.ignore' />. You can still record the actions taken. The alarm message window closes. Deferred alarm events appear as <Cmd sid='arena.preview.event.active' /> in the event list, and the <Cmd sid='common.acknowledge' /> button is available.

<Image src='/img/biostarx-monitoring-event-list-alarm-active.png' />

### Acknowledge alarm events in the event list

To acknowledge an alarm event and record the actions taken, click <Cmd sid='common.acknowledge' /> in the <Cmd sid='arena.eventTable.status' /> column of the event list. After you complete the entry, click <Cmd sid='common.acknowledge' />.

<Image src='/img/biostarx-monitoring-event-alert-acknowledge.png' />

## View unacknowledged alarm events

View all unacknowledged alarm events at once and record actions for them. This is useful when the same alarm event occurs multiple times.

1. Click <IcViewAlert /> in the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section.

   <Image src='/img/biostarx-monitoring-event-list-view-alerts-01.png' />

2. When the <Cmd sid='arena.activeAlarm.activeAlarmEvents' /> window appears, in the list on the left, select the alarm events to record actions for. To select all events, select the checkbox at the far left of the column header.

   <Image src='/img/biostarx-monitoring-event-list-view-alerts-02.png' />

3. In the <Cmd sid='arena.activeAlarm.memo' /> field, enter the actions taken for the alarm event.

4. Click <Cmd sid='common.acknowledge' />.

The actions for the selected events are recorded. The alarm event pop-up closes.

:::info

The <Cmd sid='common.acknowledge' /> button is enabled only when you select at least one event in the alarm event list.

:::

## Set up event list columns

Add, reorder, or hide the columns that appear in the event list.

1. In the upper-right corner of the <Cmd sid='arena.eventTable.title' /> section, click <IcMoreB /> → <Cmd sid='arena.eventTable.columnLayout' />.

   <Image src='/img/biostarx-monitoring-event-list-column-layout.png' />

2. When the <Cmd sid='arena.eventTable.columnLayout' /> window appears, select or clear the checkbox of each column to show or hide it. To change the column order, drag and drop the columns.

   <Image src='/img/biostarx-monitoring-event-list-column-layout-popup.png' />

3. After you change all column settings, click <Cmd sid='common.apply' />.

:::info

To restore the default column settings, click <Cmd sid='columnSetting.button.defaultColumn' product='2' />.

:::
