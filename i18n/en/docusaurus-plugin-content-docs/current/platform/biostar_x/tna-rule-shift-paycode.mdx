Learn how to set up <Cmd sid='tab.payCode' product='2' className='normal' /> used for working time calculations. You can set time codes for regular work, overtime, and absence. Each <Cmd sid='tab.payCode' product='2' className='normal' /> can use a different hourly weight.

## <Cmd sid='payCode.addPayCode' product='2' className='bold' />

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click <Cmd sid='tab.shift' product='2' /> → <Cmd sid='tab.payCode' product='2' /> in the left sidebar.

3. Click <Cmd sid='payCode.addPayCode' product='2' />.

   <Image src='/img/biostarx-tna-shift-paycode.png' />

4. When the <Cmd sid='payCode.addPayCode' product='2' /> screen appears, set each field.

:::info

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

* To add a <Cmd sid='tab.shift' product='2' className='normal' /> next, click <Cmd sid='payCode.applyAndAddShift' product='2' />.

* To add another <Cmd sid='tab.payCode' product='2' /> after you save the settings, click <Cmd sid='ta.apply_add_another' product='2' />.

:::

## Schedule options

<Image src='/img/biostarx-tna-shift-paycode-adding.png' />

* <Cmd sid='form.name' product='2' />: Enter the name of the <Cmd sid='tab.payCode' product='2' className='normal' />.

* <Cmd sid='form.description' product='2' />: Enter a description for the <Cmd sid='tab.payCode' product='2' className='normal' />.

* <Cmd sid='form.type' product='2' />: Select the type of <Cmd sid='tab.payCode' product='2' className='normal' />.

  * <Cmd sid='payCode.countAsAttendance' product='2' />: Sets the <Cmd sid='tab.payCode' product='2' className='normal' /> used for regular work.

  * <Cmd sid='payCode.accumulateTowardOvertime' product='2' />: Sets the <Cmd sid='tab.payCode' product='2' className='normal' /> used for overtime.

  * <Cmd sid='payCode.trackOnLeaveManagement' product='2' />: Sets the <Cmd sid='tab.payCode' product='2' className='normal' /> used for outings, offsite work, business trips, and leave.

* <Cmd sid='payCode.timeRate' product='2' />: Set the hourly weight for the <Cmd sid='tab.payCode' product='2' className='normal' />. **1** is the base weight, and if you set it to **2**, working time is calculated at 2 times the hourly rate when the configured <Cmd sid='tab.payCode' product='2' className='normal' /> applies.

* <Cmd sid='payCode.color' product='2' />: Set the color to distinguish the <Cmd sid='tab.payCode' product='2' className='normal' />.
