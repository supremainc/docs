Firmware on devices connected to **BioStar X** can be upgraded easily without additional connections or actions. Keeping the device firmware up to date resolves security vulnerabilities and lets you use new features.

## Before you start {/* #before-start */}

Before you upgrade the device firmware, prepare the new firmware file. Save the downloaded firmware file to the path below and extract it. Create the *firmware* folder if it does not exist.

> *C:\Program Files\BioStar X\firmware*

:::info

Search for the device model name in the [Suprema Download Center](https://download.supremainc.com) and download the latest firmware file.

:::

## Firmware upgrade {/* #upgrade-firmware */}

:::caution

* Before you upgrade the firmware, check the device's power supply and network status. In particular, make sure power is not interrupted during the upgrade.

* Depending on the device type and mode, it may take up to 1 hour or longer. Also, the device cannot be used during the upgrade.

* Do not turn off the device during the firmware upgrade. When the upgrade is complete, the device restarts automatically.

:::

### Upgrade firmware for a single device

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. Click the device to upgrade in the device list.

4. Click <Cmd sid='button.firmwareUpgrade' product='2' /> in the <Cmd sid='device.info.information' product='2' /> section of the device details screen.

   <Image src='/img/biostarx-setting-device-info-upgrade-firmware.png' />

5. When the <Cmd sid='device.firmwareUpgrade' product='2' /> window appears, click the firmware version.

   <Image src='/img/biostarx-setting-device-upgrade-firmware-popup.png' />

6. When the warning message window appears, click <Cmd sid='button.continue' product='2' />.

The firmware upgrade starts on the device.

### Upgrade firmware for multiple devices

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. Select the checkbox on the far left of each device to upgrade in the device list. You can select multiple devices.

4. Click <Cmd sid='button.firmwareUpgrade' product='2' /> in the upper-right corner of the device list.

   <Image src='/img/biostarx-setting-device-upgrade-firmware.png' />

5. When the <Cmd sid='device.firmwareUpgrade' product='2' /> window appears, click the firmware version.

   <Image src='/img/biostarx-setting-device-upgrade-firmware-popup.png' />

6. When the warning message window appears, click <Cmd sid='button.continue' product='2' />.

The firmware upgrade starts on the selected devices.

:::info

* The <Cmd sid='button.firmwareUpgrade' product='2' /> button is enabled only after you select a device in the device list.

* Devices with the same RS-485 mode can be upgraded simultaneously. For example, you can upgrade multiple master devices at once, and multiple slave devices at once.

* Master devices or slave devices without a master can be upgraded simultaneously.

* Multiple slave devices connected to the same master device cannot be upgraded simultaneously.

:::
