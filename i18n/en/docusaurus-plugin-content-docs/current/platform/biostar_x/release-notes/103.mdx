## New Features and Improvements

---

{/* <Jira bss='BX-6414' /> [BDP-1638] XPass Q2 PoE 모델(XPQ2-DPB) 지원 */}
{/* <Jira bss='BX-6511' /> [BDP-1642] XPass 2 HW Revision 신규 모델 BioStar X 디바이스 지원 */}
1. Supported new device

{/* <Jira bss='BX-5560' /> [BDP-1424] Monitoring Door Tab Preview 상태 표시 및 제어 */}

3. Added face authentication features
    - Added support for **Multi Face Authentication** (device license required)
    - Added support for tailgating prevention (**Anti-Tailgating**)
    - Added support for **Duplicate Authentication Prevention**

{/* <Jira bss='BX-5634' /> [BDP-1489] Roll Call 수행 시 현장에 없는 사람은 제외하기 */}
4. Added **Include On-Site Users Only** mode to **Roll Call**

{/* <Jira bss='BX-5637' /> [BDP-971] Passport Scanner */}
5. Added **Scan ID** feature to automatically fill in user information using an ID

{/* <Jira bss='BX-5649' /> [BDP-994] Device Template */}
6. Added **Export/Import Device Configuration** feature

{/* <Jira bss='BX-5702' /> [BDP-1343] Desfire EV2 Secure Messaging supported by Readers and Software */}
7. Supported EV2 Secure Messaging authentication for DESFire EV2 and EV3 cards.

{/* <Jira bss='BX-5828' /> [BDP-1485] Batch Stop Action for Devices */}
8. Added the ability to select and batch control multiple devices in **Monitoring**
    - Run Unlock Device, Release Lockout, Stop Action, Reconnect, and Reboot on multiple devices at once

{/* <Jira bss='BX-5829' /> [BDP-1468] Add 'Select All' to all partial selection popup menu */}
9. Added support for Select All and group selection in the **Monitoring** event filter

{/* <Jira bss='BX-5834' /> [BDP-1464] Batch Control of Doors and Elevators */}
10. Added the ability to select and batch control multiple doors, elevators, and advanced access control in **Monitoring**

{/* <Jira bss='BX-5845' /> [BDP-1483] 장기 미출입자에 대한 후속 조치 기능 */}
11. Added a feature to manage users with long-term inactivity
    - View users with long-term inactivity based on Last Access
    - Set a policy to automatically deactivate users based on conditions
    - Send a pre-notification email to designated recipients before auto deactivation

{/* <Jira bss='BX-5850' /> [BDP-1509] Master Admin 기능을 제공하지 않는 스탠다드향 동작 추가 */}
12. Separated firmware builds for **CE** and **Global (Non-CE)** products.
    :::note
    **CE** and **Global (Non-CE)** products can be identified via the label sticker on the back of the product. The **Master Admin** feature <Cmd>is enabled only on products with a label bearing the CE mark</Cmd>.
    :::

{/* <Jira bss='BX-5854' /> [BDP-1480] Auth Fail Lockout 지원 */}
13. Added **Auth Fail Lockout** feature, which locks the device after repeated PIN authentication failures.

{/* <Jira bss='BX-5859' /> [BDP-1488] BioStar X의 사용자 정보 입력 필드에 특수 문자 입력할 수 있도록 지원 */}

    - Added support for periods (.) in User ID
    - Added support for periods (.) and apostrophes (') in User Name
