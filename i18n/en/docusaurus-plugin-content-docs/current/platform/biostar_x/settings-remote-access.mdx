Remote Access is a feature that lets you securely connect to an internal network from an external network through the ngrok service. This feature lets you remotely access the **BioStar X** server without firewall settings or port forwarding.

:::info

* The Remote Access feature is available as an add-on option. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />. The Remote Access license is an annual subscription.

* When you purchase a Remote Access license, Suprema issues the license, creates a bot account and endpoint on the ngrok Suprema site, and provides the license document to you.

:::

:::caution

* The Remote Access feature is provided through ngrok's tunneling service, a third-party service. Before using this feature, please review [Remote Access Feature Agreement](../../legal/eula#remote-access-agreement).

* BioStar X only supports the connection by calling the ngrok API, and internet connection security, safety, and continuity depend entirely on the ngrok service. Therefore, Suprema assumes no responsibility for any security incidents, data loss, or system breaches that may occur while using this feature.

:::

## When should you use it?

Use the Remote Access feature in the following situations.

* When you need to access the **BioStar X** server on your internal network from an external network

* When a firewall or NAT environment makes direct access difficult

* When you need to set up remote access easily without complex network settings

* When you need to temporarily grant external access

## Set up Remote Access

<Steps>
<Step>

### Activate the Remote Access license

1. Log in with a **BioStar X** administrator account.

2. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

3. Click <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.menu.license.biostarXLicense' /> in the left sidebar.

4. Enter the Remote Access license key and administrator name provided by Suprema, and then click <Cmd sid='setting.server.license.button.activate' product='2' />.

:::info

For more information about license registration, see <DocLink docId='platform/biostar_x/settings-license-biostar-x-license' />.

:::

</Step>
<Step>

### Activate Remote Access

1. Log in with a **BioStar X** administrator account.

2. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

3. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.remoteAccess.root' /> in the left sidebar.

4. In the <Cmd sid='setting.remoteAccess.section.title' /> section, change the <Cmd sid='setting.menu.remoteAccess.root' /> option to <Cmd sid='common.use' />.

<Image src='/img/biostarx-settings-remote-access.png' />

</Step>
<Step>

### Enter ngrok setup information

Enter the ngrok setting information provided by Suprema.

* <Cmd sid='setting.remoteAccess.field.tunnelToken' />: Enter the **Authtoken**.

* <Cmd sid='setting.remoteAccess.field.hostURL' />: Enter the endpoint URL. The URL is in the format `https://subdomain.bsx.ngrok.app`.

:::info

The subdomain (`subdomain`) must follow the rules below. Subdomains that do not comply with the rules cannot be used.

* Only English letters (A-Z, a-z), numbers (0-9), and hyphens (`-`) are allowed.

* Special characters and spaces are not allowed.

:::

1. After entering all the information, click <Cmd sid='button.apply' product='2' />. 

2. When the <Cmd sid='setting.remoteAccess.dialog.label.agreement' /> window appears, review the contents.

   <Image src='/img/biostarx-settings-remote-access-agree.png' />

3. Select the checkbox to agree to the terms, then click <Cmd sid='setting.remoteAccess.button.agree' />.

</Step>

</Steps>

## Access the endpoint URL

After you complete the setup, verify that you can access the **BioStar X** server from an external network using the endpoint URL entered in <Cmd sid='setting.remoteAccess.field.hostURL' />.

:::info

* After connecting to the endpoint URL, you can check access logs in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

  > For example: [Remote Access] 192.168.1.100

* If you cannot access the endpoint URL from an external network, contact the sales office or distributor that issued the license.

:::
