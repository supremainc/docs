A wireless door lock lets you control access with a CoreStation without wiring to the door. A wireless door lock communicates wirelessly with the OSDP antenna connected to a CoreStation.

Learn how to use a wireless door lock, from activating a device license to registering an OSDP antenna and wireless door lock, setting authentication modes, and managing status.

## Before you start

You can add a wireless door lock to a CoreStation registered in **BioStar X**. For more information about registering CoreStation, see <DocLink docId='platform/biostar_x/settings-adding-devices' />.

### Supported versions and devices

* **CoreStation v1.7.1** or later, **BioStar X v1.0.0** or later

* OSDP antenna: U&Z CX8936 (OSDP v2.2 or later)

* Wireless door lock: U&Z CX217x (Handle), CX212x (Knob)

* Card: CSN card, MIFARE or DESFire type

### Connection limits

An OSDP antenna must be connected to the CoreStation to connect a wireless door lock.

* Up to two OSDP antennas per CoreStation

* Up to six wireless door locks per OSDP antenna (up to 12 wireless door locks per CoreStation)

### Prerequisites

* Wireless door lock device license (contact your BioStar X reseller)

* SERVICEKEY card (provided by the wireless door lock reseller)

:::info

You can obtain device licenses for up to 12 devices, based on the number of wireless door locks you connect. The total cannot exceed 12 devices, even if you activate multiple device licenses.

:::

## Register a wireless door lock device

<Steps>
<Step>

### Activate a device license

Registering and using a wireless door lock requires a separate device license.

Use **BioStar X** to activate **wireless door lock** device licenses on a CoreStation.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.server.license.device' product='2' /> in the left sidebar.

3. Click <Cmd sid='user.list.csvImport.browse' product='2' />.

   <Image src='/img/biostarx-settings-license-device-license.png' className='none' />

4. Select the wireless door lock device license file you received.

5. Check <Cmd sid='setting.server.license.device.list' product='2' />. To activate the device license, click <Cmd sid='setting.server.license.button.activate' product='2' />.

:::info

* If license activation fails, check the error message and try again.

* The device license file is an encrypted file and cannot be modified arbitrarily.

* Device licenses are issued based on the device serial number (S/N). If you change the device serial number (S/N) in an unauthorized way, Suprema does not provide warranty service for the license.

* For more information about device licenses, see <DocLink docId='platform/biostar_x/licensing#deviceLicense' />.

:::

</Step>
<Step>

### Register an OSDP antenna

To add a wireless door lock to CoreStation, register the OSDP antenna first.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. Right-click the CoreStation device in the <Cmd sid='menu.device.allDeviceGroups' product='2' /> list.

4. Click <Cmd sid='device.menu.addOsdpDevice' product='2' /> from the pop-up menu.

   <Image src='/img/biostarx-setting-device-list-add-osdp.png' />

5. When the <Cmd sid='device.menu.selectOsdpDeviceType' product='2' /> window appears, select <Cmd sid='device.info.osdpModule' product='2' /> and click <Cmd sid='button.ok' product='2' />.

   <Image src='/img/biostarx-setting-device-select-osdp-antenna.png' />

6. When the port list appears, select a port with <Cmd sid='device.info.portStatus' product='2' /> set to <Cmd sid='device.info.portStatusAvailable' product='2' /> to add the OSDP antenna.

   <Image src='/img/biostarx-setting-device-add-osdp-module.png' />

7. Set <Cmd sid='device.info.information' product='2' /> and <Cmd sid='device.info.osdpNetworkRS485' product='2' />, and click <Cmd sid='button.apply' product='2' />.

   <Image src='/img/biostarx-setting-device-add-osdp-device.png' />

   :::note

   <Cmd sid='device.info.osdpOsdpID' product='2' /> defaults to 0. Enter the <Cmd sid='device.info.osdpOsdpID' product='2' /> set on the OSDP antenna.

   :::

</Step>
<Step>

### Register a wireless door lock

Register the wireless door lock with the OSDP antenna.

1. Right-click the added OSDP antenna.

2. Click <Cmd sid='device.menu.autoAddWirelessDoorLock' product='2' /> from the pop-up menu.

   <Image src='/img/biostarx-setting-device-osdp-popup.png' />

3. Tag the provided SERVICEKEY card on the wireless door lock.

The device list shows the connected wireless door lock under the OSDP antenna. When the connection succeeds, the wireless door lock's blue LED turns on.

<Image src='/img/biostarx-setting-device-osdp-conneted-wireless-door-lock.png' />

:::info

* The SERVICEKEY card is a dedicated card that you tag to enter service mode and pair the wireless door lock with the OSDP antenna. The SERVICEKEY card is available from the wireless door lock reseller.

* The connected wireless door lock can be set as an entry or exit device for a door. For more information about registering doors, see <DocLink docId='platform/biostar_x/settings-door-add' />.

:::

</Step>
<Step>

### Set authentication mode {/* #setAuthmode */}

Set the authentication mode for access through the wireless door lock. The wireless door lock uses only CSN cards for authentication.

1. Click the wireless door lock in the device list.

2. In the <Cmd sid='device.info.authentication' product='2' /> section, under <Cmd sid='device.info.authenticationMode' product='2' />, click <Cmd sid='button.plusAdd' product='2' />.

3. When the <Cmd sid='device.addNewAuthMode' product='2' /> window appears, drag <Cmd sid='user.authMode.card' product='2' /> to an empty area.

   <Image src='/img/biostarx-setting-device-wl-door-lock-auth-mode.png' />

4. Select a schedule in the <Cmd sid='schedule.schedule' product='2' /> field.

5. To add the authentication mode, click <Cmd sid='button.ok' product='2' />.

6. To save the settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

* When authentication with a CSN card succeeds, the wireless door lock turns on the green LED. If authentication fails, the wireless door lock turns on the red LED.

* If the schedule you need is not in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> in the <Cmd sid='schedule.schedule' product='2' /> field to add a schedule.

* For more information about adding schedules, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::

</Step>
</Steps>

## Change wireless door lock settings

After you register the wireless door lock, you can change the device name, status, and authentication settings.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. Click the wireless door lock in the device list.

   <Image src='/img/biostarx-setting-device-wl-door-lock-details.png' />

   * <Cmd sid='device.info.osdpName' product='2' />: Enter a device name. If you leave it blank, the system assigns it automatically.

   * <Cmd sid='device.info.osdpStatus' product='2' />: Set the device status. If you set it to <Cmd sid='common.inactive' product='2' />, CoreStation does not communicate with the wireless door lock. Use this when inspecting the wireless door lock or replacing the battery. For more information about changing the status in the device list, see <DocLink inner='#changeStatus' />.

   * <Cmd sid='device.info.authenticationMode' product='2' />: The wireless door lock can use only a CSN card as an authentication mode. For more information, see <DocLink inner='#setAuthmode' />.

   * <Cmd sid='device.info.usersHaveFullAccess' product='2' />: Grants full access to users registered on the connected CoreStation without setting an access group.

4. To save the settings, click <Cmd sid='button.apply' product='2' />.

## Change wireless door lock status {/* #changeStatus */}

In the device list, activate or deactivate the wireless door lock.

1. Right-click the wireless door lock under <Cmd sid='menu.device.allDeviceGroups' product='2' />.

2. Click <Cmd sid='device.menu.activeWirelessDoorLock' product='2' /> or <Cmd sid='device.menu.deActiveWirelessDoorLock' product='2' /> in the pop-up menu.

<Image src='/img/biostarx-setting-device-status-wl-door-lock.png' />

## Delete a wireless door lock

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. In the device list, select the checkbox on the far left of the wireless door lock to delete.

4. Click <Cmd sid='button.deleteDevice' product='2' /> in the upper-right corner of the device list.

   <Image src='/img/biostarx-setting-device-list-remove-wl-door-lock.png' />

5. When the deletion confirmation message appears, click <Cmd sid='button.delete' product='2' />.

:::tip

<Columns>
<Column className='width--30'>

<Image src='/img/biostarx-setting-device-remove-wl-door-lock.png' />

</Column>
<Column className='padding--l20'>

* Alternatively, delete a wireless door lock from the <Cmd sid='menu.device.allDeviceGroups' product='2' /> list to the left of the device list. To delete a wireless door lock, right-click the wireless door lock, and click <Cmd sid='device.menu.deleteWirelessDoorLock' product='2' />.

</Column>
</Columns>

:::

:::info

Deleting a wireless door lock does not remove the device licenses activated on the CoreStation. You can connect as many other wireless door locks as you deleted.

:::

## Check wireless door lock status in Monitoring

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.arena' />.

2. Click <Cmd sid='common.gnb.device' product='2' /> tab in the left sidebar.

3. Click the wireless door lock in the device list.

A panel that shows detailed information and recent events for the wireless door lock appears on the right side of the screen.

<Image src='/img/biostarx-monitoring-device-wl-door-lock.png' />
