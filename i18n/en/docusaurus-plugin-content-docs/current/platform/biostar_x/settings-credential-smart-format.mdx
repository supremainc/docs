Set the layout for smart cards such as MIFARE, iCLASS, DESFire, and iCLASS Seos.

## Add a smart card {/* #addSmartformat */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.cardFormat' /> in the left sidebar.

3. Click <Cmd sid='common.smartCard' product='2' /> in the card format list on the left side of the screen.

   <Image src='/img/biostarx-settings-credentail-card-smart.png' />

4. Click <Cmd sid='button.func.addSmartCard' product='2' className='upper' /> in the upper-left corner of the screen.

5. When the <Cmd sid='setting.cardFormat.addNewSmartCard' product='2' /> screen appears, set each field. For more information, see <DocLink inner='#smartCardType' />.

   <Image src='/img/biostarx-settings-credentail-smart-format-add.png' />

6. When you finish all settings, click <Cmd sid='button.apply' product='2' />.

## Smart card types {/* #smartCardType */}

In the <Cmd sid='setting.cardFormat.smartCardType' product='2' /> option, select a smart card type.

* <Cmd sid='common.supremaSmartCard' product='2' />

  <Image src='/img/biostarx-settings-credentail-smart-format-type.png' />

* <Cmd sid='common.customSmartCard' product='2' />

  <Image src='/img/biostarx-settings-credentail-custom-smart-format-type.png' />

:::info

* Custom smart cards support only MIFARE, DESFire, and FeliCa. 

* FeliCa is only supported on BioStation 3 firmware v1.3.0 or later.

:::

## Setting options {/* #setting */}

In the <Cmd sid='common.information' product='2' /> section, set the card layout.

<Image src='/img/biostarx-settings-credentail-smart-format-info.png' />

:::info

* <Cmd sid='setting.cardFormat.primaryKey' product='2' /> and <Cmd sid='setting.cardFormat.secondaryKey' product='2' /> support only hexadecimal values. Enter the key value to use in the field in the right pane, and click <Cmd sid='setting.cardFormat.convertToHex' product='2' />. Use the converted value as the site key.

* <Cmd sid='setting.cardFormat.convertToHex' product='2' /> is available only when the <Cmd sid='setting.cardFormat.smartCardType' product='2' /> option is <Cmd sid='common.supremaSmartCard' product='2' />.

:::

### Set basic information

* <Cmd sid='common.name' product='2' />: Enter the smart card name.

* <Cmd sid='setting.cardFormat.secondaryKey' product='2' />: Set whether to use a secondary site key. Set to <Cmd sid='common.active' product='2' /> to set a secondary site key. When you set a secondary site key, the system authenticates using it if the card's primary site key does not match.

  <Image src='/img/biostarx-settings-credential-cart-secondary-key.png' />

### Smart card settings

Set the smart card structure.

#### Suprema smart card

<Cmd sid='setting.cardFormat.primaryKey' product='2' /> and <Cmd sid='setting.cardFormat.secondaryKey' product='2' /> support only hexadecimal values. Enter the key value for each input field, and click <Cmd sid='setting.cardFormat.convertToHex' product='2' />. Use the converted value as the site key.

##### Layout {/* #layout */}

Edit the layout in which user information, face data, and fingerprint data are written.

* <Cmd sid='setting.cardFormat.numberOfTemplate' product='2' />: Set the number of fingerprint templates to include in the layout.

* <Cmd sid='setting.cardFormat.templateSize' product='2' />: Set the number of bytes used by each fingerprint template.

* <Cmd sid='setting.cardFormat.useFace' product='2' />: Select whether to use a face template.

* <Cmd sid='setting.cardFormat.faceTemplateSize' product='2' />: Set the number of bytes used by the face template.

:::info

<Cmd sid='setting.cardFormat.useFace' product='2' /> is available on the BioStation 3 Max, BioEntry W3, BioStation 3, and FaceStation F2 models.

:::

#### Custom smart card

Custom smart cards support only MIFARE, DESFire, and FeliCa.

:::info

FeliCa is only supported on BioStation 3 firmware v1.3.0 or later.

:::
