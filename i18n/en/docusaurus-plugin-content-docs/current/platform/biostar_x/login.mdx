If you have completed installing **BioStar X** using the installation package, access it in a web browser to check that it works properly. **BioStar X** provides a web-based service, so you can access it anytime and anywhere.

## Log in from a web browser {/* #log-in-from-a-web-browser */}

1. In Windows, click <Start/> → **BioStar X** → **BioStar X**. 

2. **BioStar X** opens in a web browser.

   <Image src='/img/common/biostarx-login-web-browser-ip-address.png' alone />

   :::note

   * Check the access address of **BioStar X** in the web browser's address bar.

   * If you installed **BioStar X** on another PC, enter that PC's IP address. For example, `https://192.168.0.1`

   * Do not use 'localhost' as the **BioStar X** access address.

   * **BioStar X** processes all requests through the Unified Gateway. Therefore, web access and API calls go through the Unified Gateway port (default 443).

   :::

3. When the login screen appears, log in with an administrator account.

   <Image src='/img/biostarx-login.png' />

   :::note

   * The administrator ID is **admin**. 

   * If you see a **Not Secure** warning in the web browser address bar, install the HTTPS certificate. For more information about installing a certificate, see <DocLink docId='platform/biostar_x/settings-server-https' />.

   :::

After you log in, the <Cmd sid='shell.header.launcher' /> screen appears.

<Image src='/img/biostarx-launcher.png' />

:::info

* We recommend Chrome 100 or later.

* To check the external IP address of the PC where **BioStar X** is installed, visit [this link](https://whatismyipaddress.com/).

* **BioStar X** uses **port 443** by default. If a program is using port **443**, close it and try connecting again. If you cannot close the program, run the **BioStar X Service Manager** and change the port number. For more information, see <DocLink docId='platform/biostar_x/change-port' />.

:::
