Set authentication methods flexibly for each user. You can use the default authentication method set on the device or assign a private authentication mode for each user. The extended authentication mode combines facial authentication and fingerprint authentication to increase security. 

## Device default

Setting the <Cmd sid='common.authMode' product='2' /> option to <Cmd sid='user.deviceDefault' product='2' /> lets you authenticate based on the method set on the device.

<Image src='/img/biostarx-new-user-credential-authmod-default.png' />

## Private authentication mode

Setting the <Cmd sid='common.authMode' product='2' /> option to <Cmd sid='user.privateMode' product='2' /> lets you set different authentication methods for each user.

<Image src='/img/biostarx-new-user-credential-authmod-private.png' />

Click <Cmd sid='button.addplus' product='2' /> to open the <Cmd sid='device.addNewAuthMode' product='2' /> window. Set the authentication method to use.

<Image src='/img/biostarx-new-user-credential-authmod-private-add.png' />

* <Cmd sid='user.authMode.toggle' product='2' />: Turn extended authentication mode on or off. Extended authentication mode lets you combine facial authentication and fingerprint authentication.

* <Cmd sid='common.authMode' product='2' />: Drag and drop to set the authentication modes to use.

  <Image src='/img/biostarx-new-user-credential-authmod-private-join.png' />

To enroll the configured authentication methods, click <Cmd sid='button.apply' product='2' />.

:::info

* The <Cmd sid='user.authMode.toggle' product='2' /> option is supported on the BioStation 3 Max, BioEntry W3, BioStation 3, and FaceStation F2 models.

* Setting <Cmd sid='user.includeDeviceDefaultAuthMode' product='2' /> lets you use both the authentication modes set on the device and the private authentication modes set in **BioStar X**.

  <Image src='/img/biostarx-new-user-credential-authmod-note-image.png' />

* Setting <Cmd sid='user.excludeDeviceDefaultAuthMode' product='2' /> lets you use only the private authentication modes set in **BioStar X**.

:::
