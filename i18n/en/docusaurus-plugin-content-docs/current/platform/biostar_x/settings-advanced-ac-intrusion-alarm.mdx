Learn how to set up intrusion alarms. Intrusion alarm settings lock doors or trigger an alarm when an intrusion is detected.

:::info

<Glossary termid='intrusion_alarm_zone' />

:::

## Register an intrusion alarm {/* #addIntrusionAlarmZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.intrusion' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the intrusion alarm setting to add.

   <Image src='/img/biostarx-settings-adv-ac-add-intrusion.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the details for intrusion alarm settings. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='zone.intrusion.armConfiguration' product='2' /> section, add authentication settings for arming and disarming. For more information, see <DocLink inner='#armConfiguration' />.

   <Image src='/img/biostarx-settings-adv-ac-add-intrusion-set-arm.png' />

   :::note

   The <Cmd sid='zone.intrusion.armConfiguration' product='2' /> section appears when you select a door in the <Cmd sid='common.information' product='2' /> section.

   :::

8. In the <Cmd sid='zone.intrusion.intrusionSetting' product='2' /> section, set intrusion detection signals. For more information, see <DocLink inner='#intrusionSetting' />.

   <Image src='/img/biostarx-settings-adv-ac-add-intrusion-set-intrusion.png' />

9. In the <Cmd sid='common.alarm' product='2' /> section, set the actions to run when specific events occur.

10. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='zone.intrusion.armConfiguration' product='2' />, <Cmd sid='zone.intrusion.intrusionSetting' product='2' />, and <Cmd sid='common.alarm' product='2' /> sections are available only if the <Cmd sid='zone.pause.doorselected' product='2' /> option is set in the <Cmd sid='common.setting' product='2' /> section.

:::

## Setting options {/* #setting */}

Detailed intrusion alarm settings are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Set the scope. Intrusion alarm settings support only <Cmd sid='zone.globalZone.local' product='2' /> mode and can be set only with entry devices and devices connected via RS-485.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.pause.doorselected' product='2' />: Select the door to apply the intrusion alarm feature to.

## Arm and disarm settings {/* #armConfiguration */}

Add authentication settings for arming and disarming.

<Image src='/img/biostarx-settings-adv-ac-add-intrusion-set-arm.png' />

* <Cmd sid='zone.intrusion.delayTime' product='2' />: Set the delay time for arming or disarming. In other words, the arming delay is the time from authentication until arming starts, and the disarming delay is the time from intrusion detection until the alarm is triggered.

* <Cmd sid='zone.intrusion.accessCard' product='2' />: Add cards authorized for arming or disarming. You can add up to 128 arm/disarm cards.

* <Cmd sid='zone.intrusion.accessGroup' product='2' />: Select groups authorized for arming or disarming. You can register up to 128 arming/disarming groups.

* <Cmd sid='zone.intrusion.armInput' product='2' />: Set arming/disarming by device or by input signal. Click <Cmd sid='button.plusAdd' product='2' /> and configure each item.

### Add arm/disarm by device {/* #addArmInput */}

Click <Cmd sid='button.plusAdd' product='2' /> in the <Cmd sid='zone.intrusion.armInput' product='2' /> (<Cmd sid='common.device' product='2' />) option. Select the device that controls the intrusion alarm feature, and select <Cmd sid='zone.intrusion.armType' product='2' />.

In <Cmd sid='zone.intrusion.inputType' product='2' />, select <Cmd sid='zone.intrusion.inputType.card' product='2' />, <Cmd sid='zone.intrusion.inputType.key' product='2' />, or <Cmd sid='zone.intrusion.inputType.cardOrKey' product='2' />. Devices without an LCD screen can use only <Cmd sid='zone.intrusion.inputType.card' product='2' /> as the input type.

<Image src='/img/biostarx-settings-advanced-ac-intusion-add-device.png' />

### Add arm/disarm by input signal {/* #addArmInputBySignal */}

Click <Cmd sid='button.plusAdd' product='2' /> in the <Cmd sid='zone.intrusion.armInput' product='2' /> (<Cmd sid='zone.intrusion.inputType.input' product='2' />) option. Select the device that controls the intrusion alarm feature. Click <Cmd sid='zone.intrusion.inputType.port' product='2' /> to select the input port of the selected device.

Select <Cmd sid='zone.intrusion.armType' product='2' /> and then set the switch type and the signal duration.

<Image src='/img/biostarx-settings-advanced-ac-intusion-add-signal.png' />
