Learn how to configure attendance rules by setting up work schedules by hour, day, and week.

If this is your first time setting up attendance rules, follow the steps below in order.

<Steps>
<Step>

## <Cmd sid='tab.payCode' product='2' className='bold' />

You can set time codes for time card management, overtime, and absences. You can set hourly weights and assign colors so you can identify them at a glance.

For more information about the <Cmd sid='tab.payCode' product='2' className='normal' /> settings, see <DocLink docId='platform/biostar_x/tna-rule-shift-paycode' />.

</Step>
<Step>

## <Cmd sid='tab.shift' product='2' className='bold' />

You can set a shift on a daily (24-hour) basis. A shift includes time code settings by time period, day start time settings, and time rounding rules.

For more information about the <Cmd sid='tab.shift' product='2' className='normal' /> settings, see <DocLink docId='platform/biostar_x/tna-rule-shift-day' />.

</Step>
<Step>

## <Cmd sid='tab.scheduleTemplate' product='2' className='bold' />

You can set up a schedule template based on the configured shift. You can set up schedule templates by week or by day.

For more information about the <Cmd sid='tab.scheduleTemplate' product='2' className='normal' /> settings, see <DocLink docId='platform/biostar_x/tna-rule-shift-schedule' />.

</Step>
<Step>

## <Cmd sid='rule.rule' product='2' className='bold' />

This is useful when you do not add an overtime time code to a shift. Overtime set in a shift has start and end times, but <Cmd sid='rule.rule' product='2' /> calculates the total time beyond regular hours. <Cmd sid='rule.rule' product='2' /> is useful for managing total overtime hours on a daily, weekly, or monthly basis. When you set <Cmd sid='rule.rule' product='2' />, it applies instead of the overtime time codes added to the shift.

For more information about the <Cmd sid='rule.rule' product='2' className='normal' /> settings, see <DocLink docId='platform/biostar_x/tna-rule-shift-overtime' />.

</Step>
<Step>

## Work schedule

You can set the period, users, rules, and leave schedules to apply the work schedule set in the previous step.

For more information about the <Cmd sid='ta.schedule' product='2' className='normal' /> settings, see <DocLink docId='platform/biostar_x/tna-rule-schedule' />.

</Step>
</Steps>
