After you set up floors and facilities, you can set up areas. You can manage and check the areas you are securing on the map. When you set up an area, the <Cmd sid='shell.header.arena' /> page lets you enter the facility and floor for that area to monitor it.

<Image src='/img/monitoring-map-open-map.png' />

:::info

* Register floors and facilities before you set up areas. For more information about registering floors and facilities, see the following:

  * <DocLink docId='platform/biostar_x/settings-map-manage-floor' />

  * <DocLink docId='platform/biostar_x/settings-map-manage-facility' />

* For more information about map monitoring, see <DocLink docId='platform/biostar_x/monitoring-map' />.

* Adding and setting up areas is available as an add-on option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

## Add an area {/* #add-area */}

You can set up and manage areas for the security areas you are currently managing on the map.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.map.root' /> → <Cmd sid='setting.menu.map.area' /> in the left sidebar.

3. Click <Cmd sid='setting.area.table.action.newArea' /> in the upper-right corner of the area list screen.

   <Image src='/img/biostarx-settings-map-add-area.png' />

4. On the <Cmd sid='setting.area.page.title' /> screen, enter the name and description of the area to add in the <Cmd sid='setting.area.information.section.title' /> section.

5. On the map in the <Cmd sid='setting.area.configuration.section.title' /> section, set the location of the area to add.

6. Right-click the map and select <Cmd sid='setting.area.label.setArea' />.

   <Image src='/img/biostarx-settings-map-area-add-01.png' />

7. Set the area in the shape you need. Click to start, and drag to define the area.

   <Image src='/img/biostarx-settings-map-area-drawing.gif' alone />

   :::note

   To define the area again, you must delete the existing area. To delete the area, click <IcFremove />.

   :::

8. To add a facility to the defined area, right-click and select <Cmd sid='map.menu.add.facility' />.

   <Image src='/img/biostarx-settings-map-area-add-02.png' />

   :::note

   When you add an area, you must set at least one facility, door, or camera.

   * To add a door, right-click and select <Cmd sid='setting.area.label.addDoor' />.

   * To add a camera, right-click and select <Cmd sid='setting.area.label.addCamera' />.

   :::

9. When the <Cmd sid='setting.area.label.addFacility' /> window appears, select the facility to add and click <Cmd sid='common.apply' />.

   <Image src='/img/biostarx-settings-map-area-add-03.png' />

   :::note

   When you add a door or camera, the <Cmd sid='setting.area.label.addDoor' /> or <Cmd sid='setting.area.label.addCamera' /> window also appears. Select the entry to add and click <Cmd sid='common.apply' />.

   :::

10. Once the area settings are complete, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

* The input field in the upper-left corner of the map lets you search for a location. To return to your current location, click <IcCurP />.

  <Image src='/img/biostarx-settings-map-area-find-point.png' />

* When you add an area on the map, you can define it only as a single polygon. When you define an area, make sure the start and end points are the same. After you set up an area, you cannot change its shape. To edit an area, delete it and add it again.

* Reposition added facilities, doors, and cameras by drag-and-drop on the map.

:::

## Edit an area {/* #edit-area */}

You can delete an existing area and set it up again, or add or remove facilities, doors, or cameras.

### Reset an area

To reset an area on the map, delete the existing area and add it again. 

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.map.root' /> → <Cmd sid='setting.menu.map.area' /> in the left sidebar.

3. Select the area to reset from the area list. 

4. On the map in the <Cmd sid='setting.area.configuration.section.title' /> section, click <IcFremove /> in the upper-left corner of the existing area.

   <Image src='/img/biostarx-settings-map-area-reset.png' alone />

5. Right-click on the map and select <Cmd sid='setting.area.label.setArea' /> from the pop-up menu.

6. To set the area as desired and save, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

### Delete a facility, door, or camera

Click the facility, door, or camera to delete on the map. The <IcFremove /> icon appears. Click the icon to delete the selected facility.

<Image src='/img/biostarx-settings-map-area-x-btn.png' alone />

### Set camera coverage

Set the camera coverage area on the map. Right-click the icon where the camera is placed, and select <Cmd sid='setting.area.button.addCoverage' />.

<Image src='/img/biostarx-settings-map-area-camera-setting.png' />

* To change the coverage area, click and drag the green coverage area in the direction you need.

  <Image src='/img/biostarx-settings-map-area-camera-rot.png' alone />

* To adjust the coverage, click and drag an end corner of the range to resize it.

  <Image src='/img/biostarx-settings-map-area-camera-adjust.png' alone />

* To delete the coverage area, click <IcFremove />.

:::caution

The coverage you set is only for easier security management and does not reflect the camera's actual coverage.

:::

## Delete an area

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.map.root' /> → <Cmd sid='setting.menu.map.area' /> in the left sidebar.

3. Select the checkbox for the area to delete in the area list.

   <Image src='/img/biostarx-settings-map-area-remove-item.png' />

4. Click <Cmd sid='common.delete' /> in the upper-right corner of the screen.

5. When the confirmation message appears, click <Cmd sid='common.dialog.yes' />.
