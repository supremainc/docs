Learn how to view and manage registered users on the user list page. Find users quickly with general and advanced search, and use features such as list sorting, column settings, and printing.

To access the <Cmd sid='shell.header.user' /> page, click <Cmd sid='shell.header.user' /> in the <Cmd sid='shell.header.launcher' /> or select <Cmd sid='shell.header.user' /> from the menu in the upper-left corner of the screen.

## View the user list {/* #view-user-list */}

On the user list page, you can check users' basic information and status, and view or edit each user's details.

<Image src='/img/biostarx-users-list.png' />

The user list shows all registered users and, by default, shows each user's ID, name, email address, usage period, enrolled credential status, and status. Users appear in the list in ID order.

* To view a user's details, click the user in the user list. The user's profile information appears in the right pane. Click <Cmd sid='team.user.preview.button.seeMore' /> in the user profile information to navigate to the page where you can edit detailed user information.

  <Image src='/img/biostarx-users-list-view-profile.png' />

* To edit a user's details, double-click the user in the user list. The page for editing the user's details opens.

:::info

* For more information about editing user information, see <DocLink docId='platform/biostar_x/edit-user' />.

* You can change the column layout in the user list. For more information about changing the column layout, see <DocLink docId='platform/biostar_x/view-users#user-list-column-settings' />.

:::

## Select view options {/* #select-view-options */}

You can change the display options for the user list using the tool button in the upper-right corner of the screen.

### Go to the user list page {/* #user-list-page-moves */}

The user list shows 10 users by default. You can click the button at the top of the screen to go to another page.

<Image src='/img/biostarx-users-list-pagenation.png' />

* <IcFirst /> : Goes to the first page of the user list.

* <IcFw /> : Goes to the previous page of the user list.

* <IcBw /> : Goes to the next page of the user list.

* <IcLast /> : Goes to the last page of the user list.

* Go to the desired page, enter the page number in the number input field and press the <Kbd>Enter</Kbd>.

### Change the number of users shown in the list {/* #change-number-of-users-list-indications */}

You can change the number of users shown in the user list. Select the desired number of users from the list box in the upper-right corner of the screen. The available options are 50, 100, and 200 users.

<Image src='/img/biostarx-users-list-select-row.png' />

### Sort the user list {/* #user-list-alignment */}

You can change the sorting criteria of the user list. To sort in ascending or descending order, click a column header at the top of the list. For example, when you click the <Cmd sid='team.user.table.name' /> column header, the list sorts users by name in ascending or descending order. The clicked column header shows an ascending (<IcAscend />) or descending (<IcDescend />) icon.

<Image src='/img/biostarx-users-list-order.png' />

:::info

Some columns cannot be sorted, depending on the column type.

:::

## Search users {/* #user-search */}

Learn how to search for a specific user. On the user list page, use the search feature to quickly find a user.

:::info

* Search keywords are case-insensitive.

* The user's basic information must be entered to search. For more information about entering basic user information, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

:::

### General search {/* #general-search */}

You can search by the user's ID, name, or email. Enter a keyword in the search input field at the top of the screen, and press <Kbd>Enter</Kbd>. Users that match the keyword appear in the list. The number of search results appears at the top of the list.

<Image src='/img/biostarx-users-search-result.png' />

### Advanced search {/* #advanced-search */}

You can search by user ID, name, email address, or phone number. 

1. Click <IcAdvSearch /> next to the search input field at the top of the screen. 

2. When the advanced search window opens, enter the search criteria and click <Cmd sid='common.search' />.

<Image src='/img/biostarx-users-advanced-search.png' />

:::info

* Fields with the <IcTips /> icon support only exact-match search because personal data is encrypted in the database.

* To reset the criteria entered the advanced search window, click <Cmd sid='common.clearAll' />.

* Advanced search supports searching for <Cmd sid='setting.server.custom_field.title' product='2' />. For more information about <Cmd sid='setting.server.custom_field.title' product='2' />, see <DocLink docId='platform/biostar_x/settings-server-server#custom-field' />.

:::

## Set up user list columns {/* #user-list-column-settings */}

You can change the column settings shown in the user list. Select the columns to show, or change their order.

1. Click <IcMoreW /> at the top right of the user list screen.

2. Click <Cmd sid='team.menu.columnLayout' />.

3. When the <Cmd sid='common.dialog.columnSetting.title' /> window appears, select or clear columns to show.

   <Image src='/img/biostarx-users-list-column-layout.png' />

4. To change the column order, drag the columns.

5. To save the settings, click <Cmd sid='common.apply' />.

:::info

* Column settings are saved for each user account.

* To reset the column layout settings, click <Cmd sid='columnSetting.button.defaultColumn' product='2' />.

:::

## Print the user list {/* #print-user-list */}

You can save the user list you are viewing as a PDF or SVG file.

1. Click <IcMoreW /> at the top right of the user list screen.

2. Click <Cmd sid='team.menu.print' />.

3. When the <Cmd sid='printOption.dialog.header' product='2' /> window appears, select a format under <Cmd sid='printOption.fileFormat' product='2' /> and set the other options.

   <Image src='/img/biostarx-users-print-list.png' />

4. Enter <Cmd sid='printOption.printReason' product='2' /> (optional), and click <Cmd sid='team.menu.print' />.

You can print the PDF or SVG file that opens in the browser.

:::info

<Cmd sid='printOption.printReason' product='2' /> is optional. <Cmd sid='printOption.printReason' product='2' /> records are available in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::
