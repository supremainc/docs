Set the email subject, company name, company logo, and contact details to send face enrollment mobile links or issue QR/barcodes.

:::info

* To send a face enrollment mobile link to users or issue a QR/barcode, an email address must be registered in the user information. For more information about user details, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

* The following devices support **facial authentication**.

  * FaceStation F2, BioStation 3, BioEntry W3, BioStation 3 Max

* The following devices support **QR/Barcode authentication with a scanner**.

  * X-Station 2 (XS2-QDPB, XS2-QAPB)

* The following devices support **QR/Barcode authentication with a camera**.

  * BioStation 3 Max firmware v1.0.0 or later

  * BioStation 3 firmware v1.1.0 or later

  * X-Station 2 (XS2-ODPB, XS2-OAPB, XS2-DPB, XS2-APB) firmware v1.2.0 or later

  * X-Station 2 (XS2-QDPB, XS2-QAPB) firmware v1.4.1 or later

* To use **QR/Barcode authentication with a camera**, you need a separate device license. For more information about device licenses, see <DocLink docId='platform/biostar_x/settings-license-device-license' />.

:::

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid="setting.menu.emailSetting.root" /> in the left sidebar.

3. Set each option.

4. To save the settings, click <Cmd sid="button.apply" product='2' />.

## Set up a mobile link for face enrollment

To send a face enrollment mobile link to the user by email, turn on <Cmd sid="common.use" product='2' />.

<Image src='/img/biostarx-settings-email-visual-face.png' />

* <Cmd sid="common.emailContent.title" product='2' />: Enter the email subject for sending the mobile link for face enrollment.

* <Cmd sid="common.emailContent.companyName" product='2' />: Enter the company name.

* <Cmd sid="common.emailContent.companyLogo" product='2' />: Upload the company logo image.

  :::info

  * Supported image file formats are GIF, JPG, JPEG, JPE, JFIF, and PNG.

  * The maximum supported image file size is 5 MB.

  :::

* <Cmd sid="common.emailContent.adminContact" product='2' />: Enter the contact information of the person in charge.

* <Cmd sid="printOption.footer" product='2' />: Enter information for users who enroll their faces, such as legal notices. It appears at the bottom of the email sent with the mobile link for face enrollment.

  :::info

  The footer can be up to 5,000 characters long.

  :::

## Set up QR/Barcode issuance

To issue a QR code or barcode to the user by email, turn on <Cmd sid="common.use" product='2' />.

<Image src='/img/biostarx-settings-email-qr.png' className='none' />

* <Cmd sid="common.emailContent.title" product='2' />: Enter the subject of the email to send the QR code or barcode.

* <Cmd sid="common.emailContent.companyName" product='2' />: Enter the company name.

* <Cmd sid="common.emailContent.companyLogo" product='2' />: Upload the company logo image.

  :::info

  * Supported image file formats are GIF, JPG, JPEG, JPE, JFIF, and PNG.

  * The maximum supported image file size is 5 MB.

  :::

* <Cmd sid="common.emailContent.adminContact" product='2' />: Enter the contact information of the person in charge.
