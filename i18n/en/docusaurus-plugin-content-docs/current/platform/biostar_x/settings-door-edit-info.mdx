Learn how to edit settings for registered doors. Change detailed settings for an individual door, or select multiple doors to batch edit shared fields.

## Edit information for one door {/* #edit-one-door-info */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.door.root' /> in the left sidebar.

3. In the door list, click the door to edit.

4. Edit the details in each section.

5. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* For more information about each section of the edit door information screen, see <DocLink docId='platform/biostar_x/settings-door-add' />.

* After a door is included in an access group, set up the <Cmd sid='door.authDoorControl.title' product='2' /> feature. For more information, see <DocLink docId='platform/biostar_x/settings-door-auth-control' />.

:::

## Batch edit multiple doors {/* #edit-multiple-door-info */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.door.root' /> in the left sidebar.

3. In the door list, select the checkboxes for the doors to edit. Select two or more doors.

4. Click <Cmd sid='button.batchEdit' product='2' /> in the upper-right corner of the screen.

5. When the <Cmd sid='button.batchEdit' product='2' /> window appears, set the options.

   <Image src='/img/biostarx-setting-door-edit-batch.png' />

   * <Cmd sid='door.openTime' product='2' />: Set how long the door stays unlocked after authentication is complete. After this time, the door locks automatically.

6. After you complete all settings, click <Cmd sid='button.apply' product='2' />.

:::info

<Cmd sid='button.batchEdit' product='2' /> is enabled only when you select two or more doors in the door list.

:::
