Learn how to synchronize and manage users by integrating **Microsoft Entra ID** (hereafter **Entra ID**) or **Active Directory** with **BioStar X**. 

Integrating with **Entra ID** or **Active Directory** provides the following convenient features. This improves security and convenience.

* You can log in to **BioStar X** using your **Entra ID** account through the Single Sign-On (SSO) feature provided by **Entra ID**.

* You can log in to **BioStar X** using Lightweight Directory Access Protocol (LDAP) authentication provided by **Active Directory**.

* You can synchronize users and groups configured in **Entra ID** or **Active Directory** with **BioStar X**.

* You can map user information such as job title, department, and group used in **Entra ID** or **Active Directory** to the custom fields of **BioStar X**.

:::info

The **Entra ID** or **Active Directory** settings feature is available as an add-on option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

## Set up directory integration {/* #intergratewithentraid */}

<Tabs>
<TabItem label='Entra ID' value='entraid'>

1. Log in to **BioStar X** with an administrator account.

2. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

3. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.directoryIntegration.root' /> in the left sidebar.

4. In <Cmd sid='settings.activeDirectory.title' product='2' />, select <Cmd sid='settings.activeDirectory.AdServerNew' product='2' />.

   <Image src='/img/biostarx-setting-directory-integ-entraid.png' />

5. Set each field as instructed below.

:::info

To integrate with Entra ID, go to <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.server' product='2' /> and set <Cmd sid='setting.userDevice.useridType' product='2' /> to <Cmd sid='setting.userDevice.useridType.alphanumeric' product='2' />.

:::

<Image src='/img/biostarx-setting-directory-server.png' />

* <Cmd sid='settings.activeDirectory.ClientID' product='2' />: Enter the **Client ID** of the application registered in **Entra ID**.

* <Cmd sid='settings.activeDirectory.ClientSecret' product='2' />: Enter the client secret added under **Client secrets** in **Certificates & secrets** for the application registered in **Entra ID**.

* <Cmd sid='settings.activeDirectory.PrimaryDomain' product='2' />: Enter the primary domain name that you entered when you created your organization in **Entra ID**.

:::info

* For more information about registering an application in **Entra ID**, see [the following link](https://learn.microsoft.com/entra/identity-platform/quickstart-register-app).

* For more information about configuring **Certificates & secrets** in **Entra ID**, see [the following link](https://learn.microsoft.com/entra/identity-platform/how-to-add-credentials?tabs=client-secret).

* Find the **Tenant ID** in **Overview** for the application registered in **Entra ID**.

* Find the <Cmd sid='settings.activeDirectory.PrimaryDomain' product='2' /> information in **Overview** in **Entra ID**.

## Handle unsupported characters {/* #unsupportedcharacter */}

If a user ID or user name in **Entra ID** or **Active Directory** includes unsupported characters, the system synchronizes the user after removing only the unsupported characters.

> For example, if a directory service user ID is `john/doe` and the user name is `John<Doe>`, **BioStar X** registers them as `johndoe` and `JohnDoe`.

:::info

* Periods (`.`) and apostrophes (`'`) in user names are not treated as unsupported characters, so the system registers the directory service values as is. 

  > Example: `O'Brien`, `John.Doe` → registered with the directory service values as is

* Periods (`.`) in user IDs are excluded from unsupported characters and are registered as is, but apostrophes (`'`) are removed because user IDs cannot include them. 

  > Directory service user ID examples:
  >
  > * `O'Brien` → registered as `OBrien` 
  > * `john.doe` → registered as `john.doe`

* For more information about user ID and name input rules, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

:::

## Exclude from directory integration {/* #excludeintegration */}

When integrating with **Entra ID** or **Active Directory** via the <Cmd sid='setting.menu.directoryIntegration.root' /> feature, users who do not exist in the directory service may be deleted from **BioStar X**. If any users should not be deleted, exclude them from the integration using the following method.

1. Log in to **BioStar X** with an administrator account.

2. Go to the <Cmd sid='common.user' product='2' /> menu.

3. In the <Cmd sid='menu.user.allUserGroups' product='2' /> list, click the user to exclude from integration.

4. When the selected user's details screen appears, turn on the <Cmd sid='user.adsync.exclude' product='2' /> option in the <Cmd sid='common.advanced' product='2' /> section.

   <Image src='/img/biostarx-user-advance-exclude-sync.png' />

5. Click <Cmd sid='button.apply' product='2' />.

The selected users will be excluded from integration when using the <Cmd sid='setting.menu.directoryIntegration.root' /> feature.

:::info

The system automatically excludes these users from directory integration.

* When a user name starts with `&@~`

* When the user ID or user name is blank

* When the user ID (up to 32 characters) or user name (up to 48 characters) exceeds the length limit

* When the user ID matches a system-reserved value, such as `admin`

* When the user ID is a single period (`.`) or two periods (`..`)

:::

## Disable directory integration {/* #disableIntegration */}

To disable the <Cmd sid='settings.activeDirectory.title' product='2' /> feature, follow these steps.

1. Log in to **BioStar X** with an administrator account.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.directoryIntegration.root' />.

3. In <Cmd sid='settings.activeDirectory.title' product='2' />, select <Cmd sid='settings.activeDirectory.notUse' product='2' />.

   <Image src='/img/biostarx-setting-directory-unset.png' />

4. When the <Cmd sid='alert.warning' product='2' /> message appears, click <Cmd sid='button.continue' product='2' />.

   <Image src='/img/biostarx-setting-directory-unset-warn-message.png' />

5. Click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::caution

When <Cmd sid='settings.activeDirectory.title' product='2' /> is set to <Cmd sid='settings.activeDirectory.notUse' product='2' />, all settings for integration with **Entra ID** or **Active Directory** in **BioStar X** are disabled. Integrated user and group information is not deleted, but it is no longer synchronized. Make sure you check before disabling integration.

:::
