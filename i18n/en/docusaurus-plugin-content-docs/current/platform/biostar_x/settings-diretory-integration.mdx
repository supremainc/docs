This document provides guidance on how to synchronize and manage users by integrating **Microsoft Entra ID** (hereafter **Entra ID**) or **Active Directory** with **BioStar X**. 

Integrating with **Entra ID** or **Active Directory** provides the following convenient features, enhancing both security and usability. This enhances both security and convenience.

* You can log in to BioStar 2 using your **Entra ID** account via Single Sign-On (SSO) provided by **Entra ID**.

* You can log in to **BioStar X** using Lightweight Directory Access Protocol (LDAP) authentication provided by **Active Directory**.

* Users and groups configured in **Entra ID** or **Active Directory** can be synchronized with **BioStar X**.

* You can map user information such as job title, department, and group used in **Entra ID** or **Active Directory** to the custom fields of **BioStar X**.

:::info

The **Entra ID** or **Active Directory** settings feature is available as an add-on with the **Essential** license or higher. For more information on licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

2. Click <Cmd sid='shell.header.setting' /> on the <Cmd sid='shell.header.launcher' /> page.

3. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.directoryIntegration.root' /> on the left sidebar.

4. Select <Cmd sid='settings.activeDirectory.AdServerNew' product='2' /> in <Cmd sid='settings.activeDirectory.title' product='2' />.

   <Image src='/img/biostarx-setting-directory-integ-entraid.png' />

5. Set each item as instructed below.

:::info

To integrate with Entra ID, go to <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.server' product='2' /> and set <Cmd sid='setting.userDevice.useridType' product='2' /> to <Cmd sid='setting.userDevice.useridType.alphanumeric' product='2' />.

* <Cmd sid='settings.activeDirectory.PrimaryDomain' product='2' />: Enter the primary domain name that you input when creating your organization in **Entra ID**.

## Handle unsupported characters {/* #unsupportedcharacter */}

If a user ID or name in **Entra ID** or **Active Directory** includes unsupported characters, the system synchronizes the user after removing them.

> For example, if a directory service user id is `john/doe` and the user name is `John<Doe>`, **BioStar X** registers them as `johndoe` and `JohnDoe`.

:::info

* The system excludes periods(`.`) and apostrophes(`'`) in user names from unsupported characters and saves the original directory service values. 

  > Example: `O'Brien`, `John.Doe` → Saved with the original directory service values

* The system excludes periods(`.`) from unsupported characters in user IDs and saves the original directory service values, but removes apostrophes(`'`) because user IDs cannot include them. 

  > Directory service user ID examples:
  >
  > * `O'Brien` → Saved as `OBrien` 
  > * `john.doe` → Saved as `john.doe`

* For more information about user ID and name input rules, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

:::

## Exclude from directory integration {/* #excludeintegration */}

When integrating with **Entra ID** or **Active Directory** via the <Cmd sid='setting.menu.directoryIntegration.root' /> feature, users who do not exist in the directory service may be deleted from **BioStar X**. If there are users that you do not want to be deleted, you can exclude them from the integration using the following method.

1. Log in to **BioStar X** with an administrator account.

2. Go to the <Cmd sid='common.user' product='2' /> menu.

3. Click on the user you want to exclude from the integration in the <Cmd sid='menu.user.allUserGroups' product='2' /> list.

4. When the selected user's details screen appears, in the <Cmd sid='common.advanced' product='2' /> section, enable the <Cmd sid='user.adsync.exclude' product='2' /> option.

   <Image src='/img/biostarx-user-advance-exclude-sync.png' />

5. Click <Cmd sid='button.apply' product='2' />.

The selected users will be excluded from integration when using the <Cmd sid='setting.menu.directoryIntegration.root' /> feature.

:::info

The system automatically excludes these users from integration.

* When a user name starts with `&@~` consecutively at the beginning

* User id or user name is blank

* The user ID (up to 32 characters) or user name (up to 48 characters) exceeds the length limit

* user id matches a system-reserved value, such as `admin`

* The user ID is a single period (`.`) or two periods (`..`)

:::

## Disable directory integration {/* #disableIntegration */}

To disable the <Cmd sid='settings.activeDirectory.title' product='2' /> feature, follow the steps:

1. Log in to **BioStar X** with an administrator account.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.directoryIntegration.root' />.

3. Select <Cmd sid='settings.activeDirectory.notUse' product='2' /> in <Cmd sid='settings.activeDirectory.title' product='2' />.

   <Image src='/img/biostarx-setting-directory-unset.png' />

4. When the <Cmd sid='alert.warning' product='2' /> message appears, click <Cmd sid='button.continue' product='2' />.

   <Image src='/img/biostarx-setting-directory-unset-warn-message.png' />

5. Click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::caution

When the <Cmd sid='settings.activeDirectory.title' product='2' /> is set to <Cmd sid='settings.activeDirectory.notUse' product='2' />, all integration settings with **Entra ID** or **Active Directory** in **BioStar X** will be removed. The integrated user and group information will not be deleted, but will no longer be synchronized. Please make sure to check before disabling the integration.

:::
