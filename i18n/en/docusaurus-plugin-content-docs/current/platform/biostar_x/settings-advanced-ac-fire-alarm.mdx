Learn how to set up fire alarms. A fire alarm is a feature that unlocks or locks all doors or elevators when a fire occurs.

## Register a fire alarm {/* #addFireAlarm */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.fireAlarm' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the fire alarm to add.

   <Image src='/img/biostarx-settings-adv-ac-add-fire-alarm.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the fire alarm details. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='common.alarm' product='2' /> section, set the actions to run when a fire alarm occurs.

8. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='common.alarm' product='2' /> section is available only when <Cmd sid='zone.pause.doorselected' product='2' /> is set.

:::

## Setting options {/* #setting */}

The details for setting up a fire alarm are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Set the scope.

  * <Cmd sid='zone.globalZone.local' product='2' />: Applies only to devices connected to the entry device via RS-485.

  * <Cmd sid='zone.globalZone.global' product='2' />: Select to use all devices registered in **BioStar X**.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.pause.doorselected' product='2' />: Select the doors to assign a fire alarm rule to.

* <Cmd sid='zone.pause.liftselected' product='2' />: Select the elevators to assign a fire alarm rule to.

* <Cmd sid='zone.deviceInput' product='2' />: Click <Cmd sid='button.addplus' product='2' /> and set the devices to trigger fire alarm signals.

:::info

* If you set <Cmd sid='zone.globalZone' product='2' /> to <Cmd sid='zone.globalZone.local' product='2' />, you can set up the fire alarm feature for doors or elevators, but not both.

* If you set <Cmd sid='zone.globalZone' product='2' /> to <Cmd sid='zone.globalZone.global' product='2' />, you can set up the fire alarm feature for doors and elevators at the same time.
