Click the generated report table to edit time cards.

:::info

* To edit time cards, first generate a report. For more information about generating reports, see <DocLink docId='platform/biostar_x/tna-report' />.

* Clock-in/clock-out records for users without a registered T&A schedule cannot be edited.

:::

1. To edit a record, click the entry in the list of generated reports.

2. Edit time cards or add an absence using one of the following methods.

## Edit in the list

<Image src='/img/biostarx-tna-report-edit-list.png' className='none' />

<Calloutlists className='svg-none-style'>

1. <Cmd sid='timeCard.dateRange' product='2' />: Set the period of time cards to show in the list.

2. **Daily time cards**: Shows daily time cards.

   * Click the clock-in/clock-out time to add, edit, or delete a time card entry. After you click the clock-in/clock-out time, click <IcEdit /> to edit the existing time card entry, and click <Cmd sid='button.apply' product='2' /> to save the changes.

   * To add an absence, click <IcEdit />. To add leave, you need a time code set up for absence. Click <IcTrash2 /> next to the added user absence to delete it.

3. **Time card summary**: Shows time cards for the set period.

4. **Refresh** / **View in calendar**

   * <IcRefresh />: Refreshes the time card list.

   * <IcCalc />: Shows time cards in a calendar format.

</Calloutlists>

:::info

For more information about creating time rules, see <DocLink docId='platform/biostar_x/tna-rule-shift-paycode' />.

:::

## Edit in the calendar

<Image src='/img/biostarx-tna-report-edit-calendar.png' className='none' />

<Calloutlists className='svg-none-style'>

1. **Event type**: Select event types to show or hide on the calendar.

2. **Month**: To move to the previous or next month, click <IcFw /> or <IcBw />.

3. **Daily time cards**: Shows daily time cards.

   * Click working hours (in white) to add, edit, or delete a time card entry. Click <IcEdit /> to edit the existing time card entry, and click <Cmd sid='button.apply' product='2' /> to save the changes.

   * To add a user absence, click a shift (in gray). To add a user absence, you need a time code set up for absence. Click <IcTrash2 /> next to the added user absence to delete it.

4. **Time card summary**: Shows monthly time cards.

5. **Refresh** / **View in list**

   * <IcRefresh />: Refreshes the time card list.

   * <IcList />: Shows time cards in a list.

</Calloutlists>

:::info

For more information about creating time rules, see <DocLink docId='platform/biostar_x/tna-rule-shift-paycode' />.

:::
