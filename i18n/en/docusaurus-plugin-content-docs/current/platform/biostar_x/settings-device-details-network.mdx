Learn how to set up network settings for a registered device. The <Cmd sid='device.info.network' product='2' /> section lets you configure network settings for the device, such as TCP/IP, RS-485, and server communication.

<Image src='/img/biostarx-setting-device-edit-network.png' />

:::info

* The available network options may differ depending on the device type.

* If you made changes, click <Cmd sid='button.apply' product='2' />. Unsaved changes are not applied to the device.

:::

## TCP/IP settings

The <Cmd sid='device.info.tcpIpSetting' product='2' /> group lets you set the device IP address.

:::info

For more information about IP address settings when registering a device, see <DocLink docId='platform/biostar_x/settings-adding-devices#setipaddress' />.

:::

### Dynamic IP settings

To set the device to use dynamic IP, select the <Cmd sid='device.info.useDhcp' product='2' /> checkbox. The device automatically receives an IP address from the DHCP server. In this case, the device IP address may change.

### Static IP settings

To set a static IP address for the device, clear the <Cmd sid='device.info.useDhcp' product='2' /> checkbox. Enter the device network information in the fields below. 

* <Cmd sid='device.info.ipAddress' product='2' />: Enter the device IP address. Enter the IP address in `xxx.xxx.xxx.xxx` format. Each octet must be a number from 0 to 255.

* <Cmd sid='device.info.subnetMask' product='2' />: Enter the device subnet mask.

* <Cmd sid='device.info.gateway' product='2' />: Enter the device gateway address.

* <Cmd sid='device.info.devicePort' product='2' />: Enter the device port number.

* <Cmd sid='device.info.dnsServerAddress' product='2' />: Enter the device DNS server address.

## Wireless LAN settings

In the <Cmd sid='device.info.wlan' product='2' /> group, you can turn the device's wireless LAN on or off. You can set the details on the device; for more information, see the device's user guide.

:::info

For devices that support wireless LAN settings, see below.

* BioStation 2

* BioStation A2

* FaceStation 2

* BioStation 3

:::

## Server communication settings

In the <Cmd sid='device.info.server' product='2' /> group, you can set how the device communicates with the **BioStar X** server.

* <Cmd sid='device.info.deviceToServerConnection' product='2' />: Select this option to enter the IP address and port number of the **BioStar X** server that the device connects to.

* <Cmd sid='device.info.serverIP' product='2' />: Enter the IP address or domain name of the **BioStar X** server.

* <Cmd sid='device.info.serverPort' product='2' />: Enter the port number of the **BioStar X** server.

:::tip

This feature is useful when the IP address of the **BioStar X** server changes. If you set this option on multiple devices before changing the **BioStar X** server IP address, the devices automatically connect to the updated IP address.

:::

## Serial communication settings

In the <Cmd sid='device.info.serialSetting' product='2' /> group, you can set the mode, transmission speed, and authentication results to display for devices connected via RS-485.

* <Cmd sid='device.info.rs485' product='2' />: Set the RS-485 mode.

* <Cmd sid='device.info.baudRate' product='2' />: Set the RS-485 communication speed.

* <Cmd sid='device.info.osdpAuthResult' product='2' />: Select the authentication result to show on the device screen when you use the device with a third-party controller.

  * <Cmd sid='device.info.osdpControllerResult' product='2' />: Shows the authentication result from the third-party controller on the device.

  * <Cmd sid='device.info.osdpDeviceResult' product='2' />: Shows the device's authentication result.

:::info

The <Cmd sid='device.info.osdpAuthResult' product='2' /> option is enabled when the <Cmd sid='device.info.rs485' product='2' /> option is set to <Cmd sid='device.rs485.slave' product='2' /> or <Cmd sid='device.rs485.default' product='2' />.

:::

## Intelligent slave settings

In the <Cmd sid='device.info.intelligentPD' product='2' /> group, set the device to send the result as [Open Supervised Device Protocol (OSDP)](../../reference/glossary#osdp) card data when a user authenticates with a fingerprint on a Suprema device connected to a third-party controller. This supports multiple 1:1 or 1:N matching.

* <Cmd sid='device.info.ipdUseFailCode' product='2' />: To record accurate logs when an exception such as an authentication failure occurs while you use intelligent slave, enter the exception code in decimal (0 to 18446744073709551615) or hexadecimal (0 to FFFFFFFFFFFFFFFF) format. Hexadecimal values can contain numbers and letters.

  <Image src='/img/biostarx-setting-device-edit-network-exception-code.png' />

* <Cmd sid='device.info.ipdCardFormat' product='2' />: Select whether to output the card ID or user ID when authentication succeeds.

* <Cmd sid='device.info.ipdOsdpID' product='2' />: Enter the device's OSDP address. Enter a number from 0 to 126.

:::info

* Enter up to 8 bytes of data for <Cmd sid='device.info.ipdUseFailCode' product='2' />.

* The <Cmd sid='device.info.intelligentPD' product='2' /> option is enabled when the <Cmd sid='device.info.rs485' product='2' /> option is set to <Cmd sid='device.rs485.default' product='2' />.

:::
