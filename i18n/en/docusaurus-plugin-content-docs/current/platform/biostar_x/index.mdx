## Welcome to the BioStar X User Guide

**BioStar X** is Suprema's next-generation integrated security platform that combines AI-based access control with intelligent video analytics. It goes beyond access management to integrate and manage security operations across your organization. **BioStar X** combines AI-based access control with intelligent video analytics to run real-time access management, video monitoring, and abnormal behavior detection on one platform. Beyond access control, it includes AI video analytics features such as intrusion detection, loitering detection, and fall detection for proactive response.

This guide covers **BioStar X** features and how to set them up. Detailed guidance helps you get the most out of every **BioStar X** feature. Follow the step-by-step instructions to deploy **BioStar X** quickly and easily.
