This page lets you check a card's issuance status, change the Wiegand card data format, and manage CSN mobile card deletion history.

## Card management

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.card' /> in the left sidebar.

3. The card list screen shows enrolled cards.

<Image src='/img/biostarx-settings-credentail-card.png' />

Click Issuance Status in the left sidebar to filter cards by issuance status. The card issuance statuses are as follows.

* <Cmd sid='setting.card.unassignedCard' product='2' />: A card that is not assigned to a user.

* <Cmd sid='setting.card.assignedCard' product='2' />: A card assigned to a specific user. The card list shows the assigned user's ID and name.

* <Cmd sid='setting.card.blacklistCard' product='2' />: A card registered on the blacklist. The cardholder cannot authenticate for access.

* <Cmd sid='setting.card.deletedCsnMobileCard' product='2' />: A deleted mobile access card.

:::info

If you blocked a user's card, the <Cmd sid='setting.card.blacklistCard' product='2' /> list shows the card information. To unblock a card, select the card and click <Cmd sid='setting.card.unblocked' product='2' />.

:::

## Change Wiegand card data format

This feature lets you change the Wiegand card data format in use all at once.

:::caution

Note that this also changes the data format of cards already assigned to users.

:::

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.card' /> in the left sidebar.

3. Click <IcMoreW /> in the upper-right corner of the card list, and select <Cmd sid='setting.card.more.changeDataFormat' product='2' />.

   <Image src='/img/biostarx-settings-credentail-card-change-card-type-btn.png' />

4. When the <Cmd sid='setting.card.changeDataFormat.title' product='2' /> window appears, select the card data format to change from the <Cmd sid='setting.card.changeDataFormat.currentType' product='2' /> list.

   <Image src='/img/biostarx-settings-credentail-card-change-data-format.png' />

5. Select the target card data format from the <Cmd sid='setting.card.changeDataFormat.targetType' product='2' /> list.

6. To change the card data format, click <Cmd sid='button.apply' product='2' />.

## Guidelines for managing CSN mobile card deletions

When you use CSN mobile cards by integrating an Airfob Portal Regular Site with **BioStar X**, the same card ID can be issued to another user even if the cardholder deletes the card. However, if the same card ID is issued to another user, the original cardholder can still access the premises.

To resolve this issue, BioStar X provides a feature to manage the deletion history after you delete CSN mobile cards.

### Manage deleted CSN mobile cards separately

Deleted CSN mobile cards are recorded in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.card' /> in the <Cmd sid='setting.card.deletedCsnMobileCard' product='2' /> list. The list shows <Cmd sid='setting.card.cardType' product='2' />, <Cmd sid='user.cardList.th.cardFormat' product='2' />, <Cmd sid='setting.card.cardId' product='2' />, and <Cmd sid='setting.card.lastCardHolder' product='2' />.

<Image src='/img/biostarx-settings-credentail-mobile-removed-card.png' />

### Prevent reissuing deleted card IDs

If you try to issue a CSN mobile card with a deletion history to another user, the system marks the request as failed.

To issue a card with a deleted card ID, first exclude the CSN mobile card from the <Cmd sid='setting.card.deletedCsnMobileCard' product='2' /> list.

<Image src='/img/biostarx-settings-credentail-mobile-card-exclude.png' />

:::info

CSN mobile cards included in the <Cmd sid='setting.card.deletedCsnMobileCard' product='2' /> list cannot be deleted from the <Cmd sid='setting.card.unassignedCard' product='2' /> list.

To delete a card from the <Cmd sid='setting.card.unassignedCard' product='2' /> list, first exclude the card from the <Cmd sid='setting.card.deletedCsnMobileCard' product='2' /> list, and then try again.

:::
