Learn how to set up scheduled unlock. Scheduled unlock unlocks doors at specific times. This feature strengthens access control and is useful for allowing access during specific time periods.

:::info

Scheduled unlock supports only <Cmd sid='zone.globalZone.local' product='2' /> mode.

:::

## Register scheduled unlock {/* #addScheduledUnlockZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.scheduledUnlock' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name for the scheduled unlock feature you are adding.

   <Image src='/img/biostarx-settings-adv-ac-add-schedule-unlock.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the scheduled unlock details. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='zone.forcedUnlock.firstManInTitle' product='2' /> section, select an access group that includes users who can start scheduled unlock.

8. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## Setting options {/* #setting */}

The detailed settings for scheduled unlock are as follows.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.forcedUnlock.firstManIn' product='2' />: If set to <Cmd sid='zone.pause.activated' product='2' />, the <Cmd sid='zone.forcedUnlock.firstManInTitle' product='2' /> section appears. Users in the user group selected in <Cmd sid='zone.forcedUnlock.firstManInGroups' product='2' /> must authenticate according to the specified schedule to start scheduled unlock.

* <Cmd sid='zone.selectoption' product='2' />: Select the door or elevator to apply the scheduled unlock feature to.

  * Selecting <Cmd sid='common.door' product='2' /> activates the door list. Select the door to apply the scheduled unlock feature to. You can select multiple doors.

  * Selecting <Cmd sid='common.elevator' product='2' /> activates the elevator list. Select the elevator to apply the scheduled unlock feature to. You can select multiple elevators.

  :::note

  The <Cmd sid='zone.selectoption' product='2' /> option appears when elevators are registered. If no elevators are registered, only the <Cmd sid='common.door' product='2' /> option appears. For more information about registering an elevator, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

  :::

* <Cmd sid='common.schedule' product='2' />: Select a schedule. If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it.

* <Cmd sid='common.floor' product='2' />: Select floors for the selected elevator.

:::info

* In <Cmd sid='zone.globalZone.local' product='2' /> mode, you can select multiple doors to configure the scheduled unlock feature.

* If you select an elevator already included in another scheduled unlock setting, you cannot select the same floor more than once.

* For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::
