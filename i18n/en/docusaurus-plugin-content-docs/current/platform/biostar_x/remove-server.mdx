Learn how to uninstall the **BioStar X** server from a computer. If <Cmd sid='setting.sever.secure.comm.menu' product='2' /> is not in use, you can uninstall without backing up or restoring certificates.

If <Cmd sid='setting.sever.secure.comm.menu' product='2' /> is in use, make sure to back up the server security certificate set (root CA/server certificate/key) before uninstalling **BioStar X**. This backup is the only way to reconnect existing devices after reinstalling the same server. Unlike the system [restore feature](settings-system-system-restore), if you need to reuse only secure communication certificates and keep the database and settings, see <DocLink inner='#restoreCertificate' />.

## Uninstall the BioStar X server {/* #uninstallServer */}

:::caution

Uninstalling **BioStar X** deletes all installation files, including certificates, and may also delete content (user information). To preserve the database, settings, and keys, back up the system before uninstalling. For more information, see <DocLink docId='platform/biostar_x/settings-system-system-backup' />.

:::

1. In Windows, go to **Settings** → **Apps** → **Installed apps**.

2. Find **BioStar X** in the list, click <IcMoreB title='More' />, and select **Uninstall**.

   <Image src='/img/biostarx-uninstall-apps-list.png' />

3. If <Cmd sid='setting.sever.secure.comm.menu' product='2' /> is in use, the certificate backup dialog appears. Click **Location...** and set the backup path. If this option is not in use, continue to step 7 without the certificate backup procedure.

   <Image src='/img/biostarx-uninstall-cert-backup.png' />

   :::caution

   Don't use the **BioStar X** installation path as the backup location. This is because the backup is deleted along with the **BioStar X** installation folder when you uninstall **BioStar X**. Make sure to select a path other than the **BioStar X** installation path.

   :::

4. After you set the path and **Back up and uninstall** becomes active, click it.

   <Image src='/img/biostarx-uninstall-cert-backup-path.png' />

5. If a certificate backup file already exists in the selected location, a dialog asks whether to overwrite it. To overwrite the existing backup, click **Yes**. To set a different path, click **No**.

   <Image src='/img/biostarx-uninstall-cert-backup-overwrite.png' />

6. When the certificate backup completes, an information dialog appears. Click **OK**.

   <Image src='/img/biostarx-uninstall-cert-backup-success.png' />

7. When prompted to confirm uninstalling **BioStar X** and all related components, click **Yes**.

   <Image src='/img/biostarx-uninstall-confirm.png' />

8. Wait while the uninstallation is in progress.

   <Image src='/img/biostarx-uninstall-progress.png' />

9. A dialog asks whether to delete all content (user information). To delete all data, including user information stored in the database, click **Yes**; to keep it, click **No**.

   <Image src='/img/biostarx-uninstall-delete-content.png' />

   :::caution

   If you click **Yes**, the system deletes all data, including user information stored in the database, and you cannot recover it. To keep the data, click **No**, or back up the system before uninstalling **BioStar X**. For more information, see <DocLink docId='platform/biostar_x/settings-system-system-backup' />.

   :::

10. If **USB Device Agent** is installed, a window appears asking whether to remove it as well. Click **Yes**.

    <Image src='/img/biostarx-uninstall-usb-agent-confirm.png' />

    :::note

    Depending on the components in use, additional uninstall windows for related drivers may appear. Follow the on-screen instructions to complete the uninstallation.

    :::

11. When component removal completes, a window appears. Click **OK**.

    <Image src='/img/biostarx-uninstall-usb-agent-success.png' />

12. When **BioStar X** removal completes, a window appears. Click **OK**.

    <Image src='/img/biostarx-uninstall-success.png' />

## Restore backed-up security certificates {/* #restoreCertificate */}

After reinstalling the server that used the <Cmd sid='setting.sever.secure.comm.menu' product='2' /> option, you must restore the secure communication certificate to reconnect existing devices. The [System restore tool](settings-system-system-restore) restores the entire system, including the database and settings, but this method reuses only the secure communication certificate without restoring the system. Restore the backed-up certificate files directly to the installation path without a dedicated tool.

:::info

In an environment with a main server and a Multi Communications Server, each server uses its own secure communication certificate. After restoring the certificate, install and add the Multi Communications Server; the system copies its certificate automatically, so no separate restore is required.

:::

1. Install **BioStar X** again. For installation instructions, see <DocLink docId='platform/biostar_x/express-install' /> or <DocLink docId='platform/biostar_x/custom-install' />.

2. After installing **BioStar X**, in Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**.

3. When the **BioStar X Service Manager** window appears in the web browser, click <Cmd>SERVICES</Cmd>.

4. To stop all services, click <Cmd>Stop All</Cmd> in the upper-right corner of the screen.

   <Image src='/img/common/biostarx-tutoria-service-manager-services-stop.png' alone />

5. Copy all backed-up certificate files (root CA, server certificate, and key) to the *cert* folder under the **BioStar X** installation path.

   > Example: *C:\\Program Files\\BioStar X\\cert*

   :::note

   The file names match the certificate files created during the new installation, so when a prompt asks to overwrite files, click **Yes**.

   :::

6. To restart all services, click <Cmd>Start All</Cmd> in the <Cmd>SERVICES</Cmd> menu.

7. If you use the Multi Communications Server, install it in a separate environment. For installation instructions, see <DocLink docId='platform/biostar_x/install-communication-server' />.

8. In **BioStar X Service Manager** on the main server, add the Multi Communications Server. For instructions on adding, see <DocLink docId='platform/biostar_x/install-communication-server#check-after-install' />.

When you add the Multi Communications Server, the security certificate files in the *cert* folder on the main server are automatically copied to the Multi Communications Server.

:::caution

If you installed and added the Multi Communications Server before restoring the certificates (before steps 4 to 6), it already has the pre-restoration certificates. In this case, follow the procedure below to replace the certificate on the Multi Communications Server separately.

1. On the server where the Multi Communications Server is installed, run **BioStar X Service Manager** and stop all services.

2. Copy the backed-up certificate files to the *cert* folder under the Multi Communications Server installation path.

   > Example: *C:\\Program Files\\BioStar X Communications Server\\cert*

3. On both the main server and the Multi Communications Server, restart all services in **BioStar X Service Manager**.

:::

:::info

* For more information about using **BioStar X Service Manager**, see <DocLink docId='platform/biostar_x/manage-server' />.

* For more information about the <Cmd sid='setting.sever.secure.comm.menu' product='2' /> option, see <DocLink docId='platform/biostar_x/settings-system-security#communicationByDevice' />.

* A Multi Communications Server license is required to install and connect the Multi Communications Server. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::
