You can set the alert types and messages that appear on the screen when events occur on devices, doors, or zones. You can also set the system to play a sound file that you uploaded when an alert occurs.

## Set Up Alerts

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.event.root' /> → <Cmd sid='setting.menu.event.alert' /> in the left sidebar.

3. Select the events to display on the screen from the event list in each category.

4. After you complete all settings, click <Cmd sid='button.apply' product='2' />.

<Image src='/img/biostarx-settings-alert.png' />

## Edit an alert message {/* #edit-alert-message */}

To edit an alert message, click <IcEdit2 /> in the event list. When the <Cmd sid='setting.alert.alertMessage' product='2' /> window appears, set each field and click <Cmd sid='button.apply' product='2' />.

<Image src='/img/biostarx-settings-alert-edit-message.png' />

* <Cmd sid='common.name' product='2' />: Enter a new name for the alert message.

* <Cmd sid='common.message' product='2' />: Enter the message to display on the screen.

* <Cmd sid='setting.alert.config.soundFile' product='2' />: If you uploaded a sound file to play when the event occurs, select it from the list.

* <Cmd sid='setting.alert.config.playOption' product='2' />: If you selected a sound file, select how many times to play it.

:::info

If you do not have a sound file to play, upload one by following <DocLink docId='platform/biostar_x/settings-preferences#sound' />.

:::
