The <Cmd sid='shell.header.launcher' /> page is the first page you see after logging in to **BioStar X** and serves as a hub to access the main features of **BioStar X**. This page is designed so you can easily navigate and use all features of **BioStar X**. The UI components of the Launcher page are as follows.

<Image src='/img/biostarx-launcher.png' className='none' />

The <Cmd sid='shell.header.launcher' /> page provides links to the <Cmd sid='shell.header.user' />, <Cmd sid='shell.header.arena' />, <Cmd sid='shell.header.data' />, <Cmd sid='shell.header.dashboard' />, and <Cmd sid='shell.header.setting' /> pages.

* <Cmd sid='shell.header.user' />: Manages users with features such as user group management, user management, user template management, and viewing users by access permission, and strengthens security with permissions. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-user' />.

* <Cmd sid='shell.header.arena' />: Monitors doors, devices, video, and events in various ways. It supports controlling related features and monitoring with live video. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-monitoring' />.

* <Cmd sid='shell.header.data' />: Shows user information and events that match specific conditions, and generates reports at regular intervals. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-data' />.

* <Cmd sid='shell.header.dashboard' />: Adds and arranges widgets based on the data you select in **BioStar X** to build a dashboard. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-dashboard' />.

* <Cmd sid='shell.header.setting' />: Sets up **BioStar X** for your environment with settings for devices, access control, user permissions, language, and time. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-settings' />.

:::info

* For more information about the header area at the top of the screen, see <DocLink docId='platform/biostar_x/ui-common' />.

* At the bottom of the screen, you can use features installed through plugins. A plugin license is required to use plugin features. 

  * For more information about using plugins, see <DocLink docId='platform/biostar_x/plugins' />.

  * For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::
