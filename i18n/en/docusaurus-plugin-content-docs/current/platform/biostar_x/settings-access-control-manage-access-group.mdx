Learn how to set up access groups using access levels and user group information. Access groups are an important element for setting door access permissions. Setting up an access group lets you manage users' door access permissions.

## Before you start {/* #beforeStart */}

Before you register an access group, check the following.

* Set up access levels. For more information about registering access levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' />.

* Set up floor levels. For more information about registering floor levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-floor-level' />.

* Set up user groups. For more information about registering user groups, see <DocLink docId='platform/biostar_x/user-group-manage' />.

## Register an access group {/* #addAccessGroup */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addAccessGroup' product='2' />.

   <Image src='/img/biostarx-settings-access-group.png' />

4. On the <Cmd sid='accessGroup.addNewAccessGroup' product='2' /> screen, enter <Cmd sid='common.name' product='2' /> and <Cmd sid='common.description' product='2' />.

   <Image src='/img/biostarx-settings-add-access-group.png' />

5. In the <Cmd sid='common.accessLevel' product='2' /> field, click <Cmd sid='button.addplus' product='2' /> and select the access levels to apply to the access group.

6. In the <Cmd sid='ag.floorLevel.title' product='2' /> field, click <Cmd sid='button.addplus' product='2' /> and select the floor levels to apply to the access group.

7. In the <Cmd sid='accessGroup.userGroup' product='2' /> field, click <Cmd sid='button.addplus' product='2' /> and select the user groups to apply to the access group.

8. In the <Cmd sid='common.user' product='2' /> field, click <Cmd sid='button.addplus' product='2' /> and select users for the access group.

9. To register the access group, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* If the desired access level is not available, you will need to register a new access level. For more information about registering access levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-level' />.

* If the floor level you need is not available, register a new floor level. For more information about registering floor levels, see <DocLink docId='platform/biostar_x/settings-access-control-manage-floor-level' />.

* To delete added items, click <IcTrash2 />.

* To search for a desired item, click <IcSearch />.

:::

## Edit an access group {/* #editAccessGroup */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='access_control.tab.access_group' product='2' />.

   <Image src='/img/biostarx-settings-access-group-tab.png' />

4. In the access group list, click the access group to edit.

5. Edit the fields as needed.

6. After you finish editing, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## Delete an access group {/* #deleteAccessGroup */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='access_control.tab.access_group' product='2' />.

4. In the access group list, select the checkbox for the access group to delete.

5. Click <Cmd sid='button.deleteAccessGroup' product='2' /> in the upper-right corner of the screen.

<Image src='/img/biostarx-settings-delete-access-group.png' />
