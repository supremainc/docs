In the <Cmd sid='device.info.information' product='2' /> section, you can set basic device information. Shows the device name and group, time zone, and hardware and firmware versions. You can change the device name and group or upgrade the device firmware.

<Image src='/img/biostarx-setting-device-edit-info.png' />

The following basic information is set on the device and you cannot change it.

* <Cmd sid='device.info.deviceId' product='2' />: Shows the device ID.

* <Cmd sid='device.info.deviceType' product='2' />: Shows the device type.

* <Cmd sid='device.info.productName' product='2' />: Shows the device model name.

* <Cmd sid='device.info.kernelVersion' product='2' />: Shows the device [kernel](../../reference/glossary#kernel) version.

* <Cmd sid='device.info.hwVersion' product='2' />: Shows the device hardware version.

:::info

If you made changes, click <Cmd sid='button.apply' product='2' />. Unsaved changes are not applied to the device.

:::

## Change the device name

You can change the default device name. Enter the device name in the <Cmd sid='device.info.name' product='2' /> field. The device name can be up to 48 characters. The device name is used to identify the device in the device list.

## Change the device group

You can change the group that the device belongs to. Select the device group in the <Cmd sid='device.info.group' product='2' /> field.

:::info

For more information about creating, renaming, or deleting device groups, see <DocLink docId='platform/biostar_x/settings-manage-device-group' />.

:::

## Firmware upgrade

To view the device firmware version, check the <Cmd sid='device.info.firmwareVersion' product='2' /> field. To upgrade the firmware, click <Cmd sid='button.firmwareUpgrade' product='2' />.

:::info

For more information about upgrading device firmware, see <DocLink docId='platform/biostar_x/settings-device-upgrade-firmware' />.

:::

## Set the device date and time

You can set the device date and time using the options below. 

* <Cmd sid='device.info.timeZone' product='2' />: Select the time zone where the device is located.

* <Cmd sid='device.info.timeSync' product='2' />: Synchronize the device time with the **BioStar X** server time.

* <Cmd sid='common.dst' product='2' />: Select the daylight saving time to apply to the device. To add a new daylight saving time, see <DocLink docId='platform/biostar_x/settings-system-daylight-saving-time' />.

* <Cmd sid='device.info.date' product='2' />: Set the device date and time manually. After setting both date and time, click <Cmd sid='device.info.setTime' product='2' />.

  :::note

  This feature is available when the <Cmd sid='device.info.timeSync' product='2' /> option is not selected.

  :::

* <Cmd sid='common.dateFormat' product='2' />: Select the date format shown on the device.

* <Cmd sid='device.info.getTime' product='2' />: Gets the time set on the device.

:::caution

The date and time you set are recorded in the event log and the real-time log. If the device date and time are incorrect, logs may be recorded incorrectly.

:::

## Unlock the device

When the device is locked by triggers and actions, click <Cmd sid='device.info.unlock' product='2' /> in the <Cmd sid='device.info.locked' product='2' /> field. The device is unlocked.

:::info

For more information about trigger conditions and action settings, see <DocLink docId='platform/biostar_x/settings-triger-and-action' />.

:::

## Initialize the device

To initialize the device settings, select one of the following features in the <Cmd sid='device.info.factoryDefault' product='2' /> field.

* <Cmd sid='device.info.reset' product='2' />: Initializes all device settings.

* <Cmd sid='device.info.reset.withoutNetwork' product='2' />: Keeps network settings and initializes the other settings.
