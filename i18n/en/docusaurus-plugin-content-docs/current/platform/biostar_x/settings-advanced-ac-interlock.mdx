Interlock is an access control method used in areas where security is critical. When you set up interlock in a location with two or more doors, it operates as follows.

* It monitors the status of each door in real time through door sensors and relays.

* If one door is open or unlocked, all other doors automatically become locked.

* You can set it to block additional access while a user remains in the area.

This prevents multiple doors from opening at the same time and enhances security.

:::info

* A single interlock zone can include up to four doors.

* You can set up interlock only for doors made up of devices connected to CoreStation.

* Devices used in an interlock zone cannot be used in another interlock zone.

* Doors used in an interlock zone cannot be used in other settings, except fire alarm settings.

:::

## Register an interlock {/* #addInterlockZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.interLock' product='2' />, then click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the interlock zone to add.

   <Image src='/img/biostarx-settings-adv-ac-add-interlock.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the details for the interlock zone. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='common.option' product='2' /> section, you can set access to be blocked while a user is present.

8. In the <Cmd sid='common.alarm' product='2' /> section, set the actions to run when specific events occur in the interlock zone.

:::info

The <Cmd sid='common.option' product='2' /> and <Cmd sid='common.alarm' product='2' /> sections are available only when, in the <Cmd sid='common.setting' product='2' /> section, you set <Cmd sid='zone.pause.doorselected' product='2' />.

:::

## Setting options {/* #setting */}

The detailed settings for interlock zones are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Set the scope. Interlock zone settings support only <Cmd sid='zone.globalZone.local' product='2' /> mode and require devices connected to CoreStation via RS-485.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.pause.doorselected' product='2' />: Select the doors to include in the interlock zone. You must select at least two doors, and you can add only doors with a door sensor connected.
