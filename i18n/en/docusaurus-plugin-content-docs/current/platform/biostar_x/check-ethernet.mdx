Learn how to check and set the server's network priority before installing **BioStar X**.

## When is it needed?

You need to check and set the network priority in the following situations.

* When two or more network adapters (LAN cards) are installed on the server

* When a specific network adapter must be used for the **BioStar X** service

* When you need to prevent network connection issues after installing **BioStar X**

:::info

If none of the above situations apply, you do not need to change the network priority. Skip this step and continue installing **BioStar X**. For more information about installing **BioStar X**, see <DocLink docId='platform/biostar_x/express-install' />.

:::

:::warning

During **BioStar X** installation, the network adapter with a lower network metric value (higher priority) is automatically selected. Since it may be difficult to change this setting after installation, **make sure you check and adjust the network priority before installation**.

:::

## Check Network Priority

### Check in Command Prompt

1. To open **Command Prompt**, search for `cmd` in the **Start** menu.

2. Enter the following command.

   ```cmd
   route print
   ```

3. In the output, look for entries in the **IPv4 Route Table** section where **Network Destination** is `0.0.0.0`.

4. Check the value in the **Metric** column. **The lower the value, the higher the priority**.

<PageBreak />

**Example output:**

<Image src='/img/common/biostarx-install-check-network-cmd.png' alone />

In the example above, the `192.168.40.123` interface has a metric value of **20**, so it has a higher priority.

### Check network adapter information

Verify which network adapter each interface corresponds to.

1. In the **Command Prompt** window, enter the command below.

   ```cmd
   ipconfig /all
   ```

2. Match each network adapter's **IPv4 address** with the **Gateway** address you checked earlier to identify the adapter.

<PageBreak />

## Change network priority

To increase the priority of the selected network adapter, follow these steps.

:::info

These steps are based on Windows 11. Menu locations may vary depending on your Windows version.

:::

<Steps>
<Step>

### Open network settings

1. In the **Start** menu, type **View Network Connections**.

   <Image src='/img/biostarx-install-check-start-network-search.png' />

2. Click **View Network Connections** in the search results.

3. Double-click the adapter connected to the internet in the list.

   <Image src='/img/biostarx-install-check-control-network-connections.png' />

</Step>
<Step>

### Open adapter options

1. When the **Ethernet Status** window appears, click **Properties**.

   <Image src='/img/biostarx-install-check-ethernet-status.png' />

2. When the Ethernet Properties window appears, select <b>Internet Protocol Version 4 (TCP/IPv4)</b> from the list.

   <Image src='/img/biostarx-install-check-ethernet-properties.png' />

3. Click **Properties**.

4. When the **Internet Protocol Version 4 (TCP/IPv4) Properties** window appears, click **Advanced**.

   <Image src='/img/biostarx-install-check-protocol-properties.png' />

</Step>
<Step>

### Metric settings

1. Clear the **Automatic Metric** checkbox.

   <Image src='/img/biostarx-install-check-set-metrics.png' />

2. Enter the value to use in the **Interface Metric** field.

   * For the highest priority, enter `1`.

   * For a higher priority than other adapters, enter a number smaller than the other adapters' metric values.

3. To save the settings and close all windows, click **OK**.

:::info

The **Interface Metric** field accepts values from `1` to `9999`. Lower values have higher priority.

:::

</Step>
<Step>

### Check settings

1. Reopen **Command Prompt** and run the `route print` command.

2. Check whether the metric value has changed.

</Step>
</Steps>

## Troubleshooting

* If the setting does not apply, restart the computer or disable and then re-enable the network adapter.

* If the network connection is lost, revert to the original settings and select the **Automatic Metric** checkbox again. Contact the network administrator to verify the correct settings.

:::info

If you need to change network settings after installing **BioStar X**, you should completely uninstall the program and then reinstall it.

:::
