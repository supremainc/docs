Learn how to manage BioStar X server services using **BioStar X Service Manager**. You can start or stop each service.

## BioStar X Service Manager {/* #biostar-x-setting */}

**BioStar X Service Manager** provides a tool to manage the status of the **BioStar X** server. In Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**. The <Cmd>BioStar X Service Manager</Cmd> window opens.

<Image src='/img/common/biostarx-tutoria-service-manager-main.png' alone />

:::info

If you changed the **BioStar X** server time setting, stop and restart the **BioStar X Core Service**. If you do not restart the service, **BioStar X** may not operate properly.

:::

### Stop a service {/* #end-service */}

To shut down **BioStar X**, click <Cmd>Stop</Cmd> for individual services in the <Cmd>SERVICES</Cmd> menu. To stop all services, click <Cmd>Stop All</Cmd> in the upper-right corner of the screen.

<Image src='/img/common/biostarx-tutoria-service-manager-main.png' alone />

### Start the server {/* #start-the-server */}

To restart **BioStar X**, in the <Cmd>SERVICES</Cmd> menu, click <Cmd>Start</Cmd> for each service whose <Cmd>Status</Cmd> column shows <Cmd>Stopped</Cmd>. To restart all services, click <Cmd>Start All</Cmd> in the upper-right corner of the screen.

<Image src='/img/common/biostarx-tutoria-service-manager-main-restart.png' alone />
