Set [Daylight Saving Time (DST)](../../reference/glossary#dst) to automatically adjust the system time to match local official time. This ensures accurate access logs and prevents time synchronization issues with other systems.

:::info

Set daylight saving time in the following cases.

* If you operate the system in a country or region that observes daylight saving time

* If you need to integrate with an attendance management system and record accurate access times

* If you manage an integrated security system that operates across multiple time zones

:::

## Add daylight saving time

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='common.dst' product='2' /> in the left sidebar.

3. Click <Cmd sid="button.plusAdd" product='2' />.

   <Image src='/img/biostarx-settings-system-daylight-saving-time-init.png' />

4. Set each field, and then click <Cmd sid="button.add" product='2' />.

   <Image src='/img/biostarx-settings-system-daylight-saving-time.png' className='none' />

5. To save the added settings, click <Cmd sid="button.apply" product='2' /> in the lower-right corner of the screen.

:::info

* Daylight saving time settings in use cannot be edited or deleted. Check daylight saving time settings in use in the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.preferences.root' /> menu. 

* For more information about applying the newly added Daylight Saving Time settings to the system, see <DocLink docId='platform/biostar_x/settings-preferences#language-timezone' />.

:::

## Edit daylight saving time

:::info

Settings in use cannot be edited. To edit, first click <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.preferences.root' />, and then clear the selection in the <Cmd sid='preference.languageTimezone' product='2' /> section.

:::

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='common.dst' product='2' /> in the left sidebar.

3. Click <IcEdit /> for the item you want to modify from the Daylight Saving Time list.

4. When the <Cmd sid='setting.dst.alert.edit.title' product='2' /> window appears, edit the fields to update.

   <Image src='/img/biostarx-settings-system-daylight-saving-time-edit.png' />

5. When you finish editing, click <Cmd sid='button.edit' product='2' />.

6. To save the modified settings, click <Cmd sid="button.apply" product='2' /> in the lower-right corner of the screen.

:::info

For more information about applying Daylight Saving Time settings to the system, see <DocLink docId='platform/biostar_x/settings-preferences#language-timezone' />.

:::

## Delete daylight saving time

Delete unused daylight saving time settings.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='common.dst' product='2' /> in the left sidebar.

3. Click <IcTrash2 /> for the item you want to delete from the Daylight Saving Time list.

4. When the confirmation message appears, click <Cmd sid='button.yes' product='2' />.

5. To save the changes, click <Cmd sid="button.apply" product='2' /> in the lower-right corner of the screen.
