Set Lock Override permissions so that specific users can access all doors in an emergency. When a door is unlocked with a card that has Lock Override permissions, the door stays unlocked so that anyone can enter.

## Before you start

Before you set Lock Override permissions, add a card credential. For more information about adding card credentials, see <DocLink docId='platform/biostar_x/enroll-credential-card' />.

:::info

* Only card credentials are supported.

* All card credentials are supported except smart cards (AoC) and ToM mobile access cards (ToM AoC).

* Some devices might not support Lock Override. For supported devices and firmware versions, see the following list.

  * BioStation 3 Max firmware v1.0.0 or later

  * XPass Q2 firmware v1.0.0 or later

  * BioStation 3 firmware v1.4.0 or later

:::

## Set Lock Override permissions

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, double-click the user to set Lock Override permissions for.

   Alternatively, select the user, and then click <Cmd sid='team.user.preview.button.seeMore' /> in the profile on the right side of the screen.

3. When the user details screen appears, go to the <Cmd sid='team.user.credential.title' /> section.

4. For each card credential to use for Lock Override, select the <Cmd sid='team.user.table.lockOverride' /> checkbox.

   <Image src='/img/biostarx-user-credential-set-emergency-opening.png' />

5. When a warning message appears, review it, and then click <Cmd sid='common.button.continue' />.

   <Image src='/img/biostarx-user-credential-set-emergency-opening-warning.png' width='60%' />

6. Click <Cmd sid='common.save' /> in the upper-right corner of the screen.

Lock Override permissions are set.

:::caution

The user can unlock all doors with an access card that has Lock Override permissions.

:::

:::info

* You can grant Lock Override permissions to one or more card credentials.

* To remove Lock Override permissions, clear the <Cmd sid='team.user.table.lockOverride' /> checkbox for the card credential.

:::
