Learn about the user interface of the <Cmd sid='shell.header.arena' /> page. The <Cmd sid='shell.header.arena' /> page lets you monitor security status in real time by door, map, or device. It also lets you view events in real time and take action when needed. The UI components of the <Cmd sid='shell.header.arena' /> page are as follows.

<Image src='/img/biostarx-ui-monitoring.png' className='none' />

<Calloutlists>

1. Enter a keyword in the search field to search for devices, doors, cameras, and more.

2. <Cmd sid='arena.tree.door.title' />, <Cmd sid='arena.tree.map.title' />, and <Cmd sid='arena.tree.device.title' /> appear as a group-based tree list for viewing and monitoring.

   * For more information about monitoring <Cmd sid='arena.tree.door.title' />, see <DocLink docId='platform/biostar_x/monitoring-door' />.

   * For more information about monitoring <Cmd sid='arena.tree.map.title' />, see <DocLink docId='platform/biostar_x/monitoring-map' />.

   * For more information about monitoring <Cmd sid='arena.tree.device.title' />, see <DocLink docId='platform/biostar_x/monitoring-device' />.

3. The **video tile** shows real-time video or maps for doors, cameras, and areas. It lets you monitor multiple camera feeds simultaneously.

   * For more information about monitoring camera feeds, see <DocLink docId='platform/biostar_x/monitoring-video' />.

   * For more information about map monitoring, see <DocLink docId='platform/biostar_x/monitoring-map' />.

4. Click <Image src='/img/menus/ico-more-black.svg' ico alone /> to close all elements in the video tile using the <Cmd sid='arena.monitoring.contextMenu.closeAll' /> feature.

5. The **control panel** lets you control the features of the selected door or device. For more information, see <DocLink docId='platform/biostar_x/control-door' />.

6. The **event list** shows real-time events in chronological order. For each event, view details, status, related users, and device information, and take immediate action when needed. For more information, see <DocLink docId='platform/biostar_x/monitoring-event' />.

</Calloutlists>
