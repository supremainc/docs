title: Roll Call
description: Learn how to set up roll call.
---

Roll Call quickly generates a personnel list based on entry records within a specific time and place. When an emergency occurs, the system can determine whether a user has arrived at the roll call location by authenticating through the entry or exit device at a predesignated location.

Use it for emergency response, safety checks, and providing information to rescue teams. This lets you manage personnel status efficiently using access logs.

:::info

Roll call settings are available as an add-on option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

## Register roll call {/* #addRollcallZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.rollCall' product='2' />, then click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name and description for the roll call setting to add.

   <Image src='/img/biostarx-settings-adv-ac-add-rollcall.png' />

6. In the <Cmd sid='device.info.configuration' product='2' /> section, set the detailed settings. For more information, see <DocLink inner='#setting' />.

7. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

In <Cmd sid='common.name' product='2' />, enter up to 48 characters, and use a name different from other settings.

:::

## Setting options {/* #setting */}

The details for roll call settings are as follows.

<Image src='/img/biostarx-settings-adv-ac-add-rollcall-config.png' />

* <Cmd sid='zone.globalZone' product='2' />: Shows the scope. Roll call settings are supported only in <Cmd sid='zone.globalZone.global' product='2' /> mode, and can be set for all devices registered in **BioStar X**.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.rollCall.onSiteOnly' product='2' />: If set to <Cmd sid='common.use' product='2' />, the system locks roll call targets to **users who last authenticated at an on-site entry device** when roll call starts. The default is <Cmd sid='common.notUse' product='2' />, and in this case all configured users (user groups + individual users) are roll call targets.

   :::note

   The system determines whether each user is on site based on authentication records from on-site entry or exit devices within the last 7 days. At roll call start, if the most recent authentication occurred at an on-site entry device, the user is considered on site; if it occurred at an on-site exit device, the user is considered off site. Users without authentication records within the last 7 days are considered off site and are excluded from the target list.

   The target list is finalized once when roll call starts, and it does not change if users enter or exit while roll call runs.

   :::

  The following options are available when <Cmd sid='zone.rollCall.onSiteOnly' product='2' /> is set to <Cmd sid='common.use' product='2' />.

  * <Cmd sid='zone.rollCall.siteEntryDevices' product='2' />: Select the device to use for on-site entry authentication.

  * <Cmd sid='zone.rollCall.siteExitDevices' product='2' />: Select the device to use for on-site exit authentication.

* <Cmd sid='zone.rollCall.manualStatusChange' product='2' />: Turn on to allow manual status changes.

* <Cmd sid='zone.rollCall.entryDevices' product='2' />: Select the device to use when entering. Select from the list of registered devices.

* <Cmd sid='zone.rollCall.exitDevices' product='2' />: Select the device to use when exiting. Select from the list of registered devices.

* <Cmd sid='common.users' product='2' />: Select user groups or individual users who can enter.

:::info

* You can't set the same device for both <Cmd sid='zone.rollCall.entryDevices' product='2' /> and <Cmd sid='zone.rollCall.exitDevices' product='2' /> at the same time.

* You can select up to 10 devices for <Cmd sid='zone.rollCall.entryDevices' product='2' /> and <Cmd sid='zone.rollCall.exitDevices' product='2' />.

* For more information about registering devices, see the following documents.

  * <DocLink docId='platform/biostar_x/settings-adding-devices' />

  * <DocLink docId='platform/biostar_x/settings-adding-wiegand' />

  * <DocLink docId='platform/biostar_x/settings-adding-slave-device' />

:::

## Check roll call list status {/* #rollCallZoneList */}

The roll call list shows details and status for each roll call setting.

<Image src='/img/biostarx-settings-adv-ac-rollcall-list.png' />

* <Cmd sid='common.name' product='2' />: Shows the name.

* <Cmd sid='zone.rollCall.entryDevices' product='2' /> / <Cmd sid='zone.rollCall.exitDevices' product='2' />: Shows the selected devices.

* <Cmd sid='common.userGroup' product='2' /> / <Cmd sid='common.users' product='2' />: Shows the selected user groups and users.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Shows the activation status.

* <Cmd sid='zone.rollCall.onSiteOnly' product='2' />: Shows whether it is turned on.

* <Cmd sid='zone.rollCall.siteEntryDevices' product='2' /> / <Cmd sid='zone.rollCall.siteExitDevices' product='2' />: Shows the selected on-site entry or exit devices.

* <Cmd sid='common.status' product='2' />: Shows the roll call progress status (for example, <Cmd sid='zone.rollCall.notStart' product='2' /> and <Cmd sid='zone.rollCall.inProgress' product='2' />).

* <Cmd sid='common.description' product='2' />: Shows the description.

## Activate or deactivate {/* #activateDeactivateRollCall */}

Activate disabled roll call settings or deactivate active settings.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. In the list, click <Cmd sid='zone.rollCall' product='2' />.

4. In the roll call settings list, select the checkbox for the entry to activate or deactivate.

   <Image src='/img/biostarx-settings-adv-ac-rollcall-list-enable.png' />

5. Click <Cmd sid='zone.pause.activate' product='2' /> or <Cmd sid='zone.pause.deactivate' product='2' /> in the upper-right corner of the screen.

:::info

* Click <Cmd sid='zone.pause.deactivate' product='2' />, and a confirmation message appears. Click <Cmd sid='button.yes' product='2' /> or <Cmd sid='button.no' product='2' />.

* You cannot deactivate a roll call in progress. Check, and then try again.

:::

## Delete {/* #deleteRollCall */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. In the list, click <Cmd sid='zone.rollCall' product='2' />.

4. In the roll call settings list, select the checkbox for the entry to delete.

   <Image src='/img/biostarx-settings-adv-ac-rollcall-list-delete.png' />

5. Click <Cmd sid='button.deleteZone' product='2' /> in the upper-right corner of the screen.

6. When the warning message appears, click <Cmd sid='button.continue' product='2' />.

:::info

You cannot delete a roll call in progress. End the roll call, and then try again.

## View roll call reports {/* #viewRollCallReport */}

To view the roll call report, follow these steps.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.data' />.

2. Click <Cmd sid='data.sidebar.events' /> → <Cmd sid='data.sidebar.rollCall' /> in the left sidebar.

3. When the <Cmd sid='data.dialog.rollCall.selectRollCall' /> window appears, select the roll call item you want to check in the report, then click <Cmd sid='data.button.next' />.

   <Image src='/img/biostarx-settings-adv-ac-rollcoll-report-01.png' />

   :::note

   If the roll call entry is not visible, adjust the time range at the top of the screen.

   :::

4. In the option settings window, select the data to include in the report, then click <Cmd sid='data.button.generate' />.

   <Image src='/img/biostarx-settings-adv-ac-rollcoll-report-02.png' />

The system generates a report. The report shows each user's information, entry time, exit time, last location, and notes.

<Image src='/img/biostarx-settings-adv-ac-rollcoll-report-generated.png' caption />

In roll call reports with unconfirmed users, <Cmd sid='data.header.rollCall.endReason' product='2' /> appears.

<Image src='/img/biostarx-settings-adv-ac-rollcoll-report-generated-uncounted-reason.png' caption />
