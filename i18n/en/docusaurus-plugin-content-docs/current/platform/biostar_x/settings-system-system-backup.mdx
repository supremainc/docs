You can back up key information such as the **BioStar X** database, various settings, and keys. Backup files also include user-defined values, such as the encryption key (enc key) and the image log path. Use the <Cmd sid="common.backup" product='2' /> feature to prevent data loss on the server or when you move the system to a new PC.

The supported backup methods are as follows.

* **Manual backup**: You create a backup file manually.

* **Automatic backup**: The system automatically creates backup files at set intervals.

:::info

* If you restore **BioStar X** on a new PC using a **BioStar X** backup file created on the previous PC, you must have the license reissued.

* If the SQL Server database and **BioStar X** are installed on different servers, you cannot use **BioStar X** system backup and restore.

* For more information about system restore, see <DocLink docId='platform/biostar_x/settings-system-system-restore' />.

:::

## Manual backup

You can create a backup file manually.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid="common.backup" product='2' /> in the left sidebar.

3. In the <Cmd sid='common.backup.general' product='2' /> section, set the path to save backup files and the maximum number of backup files.

   <Image src='/img/biostarx-settings-system-system-backup-general.png' className='none' />

   * <Cmd sid='backup.filePath' product='2' />: Enter the path to save backup files. Enter a directory path that already exists.

   * <Cmd sid='backup.numberFileToKeep' product='2' />: Set the maximum number of backup files.

4. To create a backup file, click <Cmd sid="backup.backupNow" product='2' />.

5. When a warning message appears, review it and click <Cmd sid='button.continue' product='2' />.

Backup files are saved in *zip* format at the path specified in the <Cmd sid='backup.filePath' product='2' /> option. The file name is generated in the format `BioStar_X_Backup_YYYYMMDD_HHMMSS.zip`. Here, `YYYYMMDD` represents the backup date, and `HHMMSS` represents the backup time.

:::info

* If the number of backups exceeds the maximum, the system automatically deletes the oldest backup files first.

* Enter a number from 1 to 100 in <Cmd sid="backup.numberFileToKeep" product='2' />.

:::

## Set up automatic backups

If you set up automatic backups, the system creates backup files at defined intervals.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid="common.backup" product='2' /> in the left sidebar.

3. In the <Cmd sid='common.backup.autoBackup' product='2' /> section, choose the <Cmd sid='common.backup.frequency' product='2' /> option.

   <Image src='/img/biostarx-settings-system-system-backup-automatic.png' className='none' />

   * <Cmd sid="backup.daily" product='2' />: Automatically backs up every day. In the <Cmd sid='backup.time' product='2' /> option, set the backup time.

   * <Cmd sid="backup.weekly" product='2' />: Automatically backs up every week. Set the day for automatic backup in the <Cmd sid='backup.day' product='2' /> option, and set the backup time in the <Cmd sid='backup.time' product='2' /> option.

   * <Cmd sid="backup.monthly" product='2' />: Automatically backs up every month. In the <Cmd sid='backup.date' product='2' /> option, set the date for automatic backup, and in the <Cmd sid='backup.time' product='2' /> option, set the backup time.

4. To save the settings, click <Cmd sid="button.apply" product='2' />.

After you set up automatic backups, backups run at defined intervals. If an automatic backup fails, the failure is recorded in the event log and audit trail, and the log files show details about the cause.

Backup files are saved as *zip* files in the path specified by the <Cmd sid='backup.filePath' product='2' /> option in the <Cmd sid='common.backup.general' product='2' /> section. The file name is generated in the format `BioStar_X_Backup_YYYYMMDD_HHMMSS.zip`. Here, `YYYYMMDD` represents the backup date, and `HHMMSS` represents the backup time.

:::info

* If you set the automatic backup frequency to <Cmd sid="backup.monthly" product='2' /> and set the date to 29, 30, or 31, automatic backups do not run in months without that date.

* Time is based on the standard time zone that you set in <Cmd sid='setting.menu.preferences.root' />. For more information about time zone settings, see <DocLink docId='platform/biostar_x/settings-preferences#language-timezone' />.

:::
