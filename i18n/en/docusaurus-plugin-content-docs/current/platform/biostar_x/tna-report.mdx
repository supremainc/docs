Generate T&A reports from attendance events collected by the system, edit time records, or export them to CSV or PDF.

You can easily use the seven preset report filters, and administrators can also set filters themselves.

## Before you start

### Before using multilingual reports

**BioStar X** supports Korean and English by default. To use multilingual reports, set the language to use by following the instructions below.

1. Navigate to the following path. *C:\Program Files\BioStar X\plugin\ta\dist\setup\report_fonts*

2. Create a folder named for the language you use. For language names, see ISO 639-1. For example, to use Spanish, create a folder named "es."

3. Copy and paste the font into the folder you created. Only one TrueType font is supported.

### Before updating the report

**BioStar X** uses MariaDB as the default database. If you use an MS SQL Server database, check the following first.

When you use **BioStar X** with an MS SQL Server database and many users are registered, PC memory usage can build up each time you update a report. Reset the maximum server memory for the MS SQL Server database.

1. Run **Microsoft SQL Server Management Studio**.

2. In Object Explorer, right-click the **BioStar X** database.

3. Click on **Properties** in the pop-up menu.

4. Click **Memory**, and then reduce the value of **Maximum server memory**.

:::info

For more information about MariaDB and MS SQL Server settings during **BioStar X** installation, see <DocLink docId='platform/biostar_x/custom-install' />.

:::

## View T&A reports

### Generate a T&A report

Learn how to generate a T&A report for registered users.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.report.title' product='2' /> tab in the left sidebar.

   <Image src='/img/biostarx-tna-report.png' />

3. Click the report filter in the left sidebar.

4. In <Cmd sid='common.userGroup' product='2' /> or <Cmd sid='common.user' product='2' />, click <IcSearch />, then specify the group or user.

5. To generate the report, click <Cmd sid='button.updateReport' product='2' />.

6. When the report list appears at the bottom of the screen, click an entry to view details.

<Image src='/img/biostarx-tna-report-update-list.png' />

### Set filter conditions

Set filter conditions to generate a new T&A report.

<Image src='/img/biostarx-tna-report-filter-setting.png' />

* <Cmd sid='common.name' product='2' />: Enter the report name.

* <Cmd sid='ta.report.condition.reportType' product='2' />: Select the report type. The available report types are as follows.

  * <Cmd sid='report.daily' product='2' />, <Cmd sid='report.dailySummary' product='2' />, <Cmd sid='report.individual' product='2' />, <Cmd sid='report.individualSummary' product='2' />, <Cmd sid='report.leave' product='2' />, <Cmd sid='report.exception' product='2' />, <Cmd sid='report.modifiedPunchLogHistory' product='2' />, <Cmd sid='report.workweek' product='2' />

  :::info

  Selecting <Cmd sid='ta.report.condition.reportType' product='2' /> as <Cmd sid='report.individual' product='2' /> lets you set whether to include the user's access records in the report.

  <Image src='/img/biostarx-tna-report-individual-types.png' />

  * <Cmd sid='report.individual.optionSummary' product='2' />: Outputs only the user's clock-in and clock-out records in the report.

  * <Cmd sid='report.individual.optionDetail' product='2' />: Outputs all of the user's access records in the report.

  :::

* <Cmd sid='grid.columnSetting' product='2' />: Changes the column order in the report table or hides columns.

  <Image src='/img/biostarx-tna-report-filter-setting-column.png' />

  :::info

  After changing the column order, click <Cmd sid='columnSetting.defaultColumn' product='2' /> to restore to defaults.

  :::

* <Cmd sid='report.filter' product='2' />: Activates only when <Cmd sid='ta.report.condition.reportType' product='2' /> is set to <Cmd sid='report.leave' product='2' /> or <Cmd sid='report.exception' product='2' />, and lets you select detailed conditions for absence or exception records.

* <Cmd sid='common.userGroup' product='2' /> / <Cmd sid='common.user' product='2' />: Select the user group or user to generate the report.

* <Cmd sid='ta.report.condition.saveFilter.button' product='2' />: Saves the configured T&A report as a filter.

  <Image src='/img/biostarx-tna-report-filter-saving.png' />

### Set report period

Learn how to set the report period.

<Image src='/img/biostarx-tna-report-period-setting.png' />

Set the report period to <Cmd sid='timeCard.daily' product='2' />, <Cmd sid='timeCard.weekly' product='2' />, or <Cmd sid='timeCard.monthly' product='2' />. To generate a report for a specific period, select <Cmd sid='timeCard.custom' product='2' />.

### Export a report

* <Cmd sid='button.downloadToCsv' product='2' />: Saves the generated report as a CSV file.

* <Cmd sid='button.exportPdf' product='2' />: Saves the generated report as a PDF file.

## Generate a working alarm time report

You can generate T&A reports for users who have reached the specified working hours or notify administrators by email. Working alarm time reports are generated weekly.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.report.title' product='2' /> tab in the left sidebar.

3. Click <Cmd>Working Alarm Time Report</Cmd> in the filter list in the left sidebar.

   <Image src='/img/biostarx-tna-report-working-alarm.png' />

4. Set each field in <Cmd sid='ta.report.condition.filterConditions' product='2' /> and <Cmd sid='ta.report.condition.reportPeriod' product='2' />.

5. To generate the report, click <Cmd sid='button.updateReport' product='2' />.

:::info

To send email notifications to administrators for users who have reached the specified working hours, set <Cmd sid='ta.report.condition.autoEmail' product='2' />. For more information, see <DocLink inner='#autoEmail' />.

:::

### Set up automatic email sending {/* #autoEmail */}

The system can automatically send alarm emails to administrators for users who have reached the specified working hours.

<Image src='/img/biostarx-tna-report-working-alarm-auto-email.png' />

* <Cmd sid='common.email' product='2' />: Select the checkbox to automatically send emails to administrators.

* <Cmd sid='setting.dst.dayOfWeek' product='2' />: Select the day of the week to send emails to administrators.

* <Cmd sid='shift.time' product='2' />: Set the time to send emails to administrators.

* <Cmd sid='setting.triggerAction.recipient' product='2' />: Select the administrators to receive the email. Click <Cmd sid='button.edit' product='2' /> to open the <Cmd sid='setting.triggerAction.recipient' product='2' /> pop-up window. Enter the email address. You can specify one or more administrators.

  <Image src='/img/biostarx-tna-report-working-alarm-auto-email-receipt.png' />

:::info

* To set the <Cmd sid='ta.report.condition.autoEmail' product='2' /> feature, set the filter conditions and then save the filter.

* The sender information of automatically sent emails can be set in <Cmd sid='setting.setting' product='2' />(<IcSet />) → <Cmd sid='setting.triggerAction.senderInfor' product='2' /> in the left sidebar. For more information, see <DocLink docId='platform/biostar_x/tna-settings#senderInfo' />.

:::
