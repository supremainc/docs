Create a shift by applying different time codes based on the time within a 24-hour period. Select fixed, flexible, or floating shifts, and set the start time of the day and time rounding rules.

## <Cmd sid='shift.addShift' product='2' className='bold' />

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click <Cmd sid='tab.shift' product='2' /> → <Cmd sid='tab.shift' product='2' /> in the left sidebar.

3. Click <Cmd sid='shift.addShift' product='2' />.

   <Image src='/img/biostarx-tna-shift-day.png' />

4. When the <Cmd sid='shift.addShift' product='2' /> screen appears, set each field.

:::info

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

* To add a schedule template next, click <Cmd sid='payCode.applyAndAddShift' product='2' />.

* To add another <Cmd sid='tab.shift' product='2' /> after you save the settings, click <Cmd sid='ta.apply_add_another' product='2' />.

:::

## Schedule options

Depending on the shift type, you can select <Cmd sid='shift.type.fixed' product='2' />, <Cmd sid='shift.type.flexible' product='2' />, or <Cmd sid='shift.type.floating' product='2' />. Setting options may vary depending on the selected shift type.

### <Cmd sid='shift.type.fixed' product='2' className='normal' />

A shift where the employee clocks in and out at set times. Enter the name and description for <Cmd sid='tab.shift' product='2' className='normal' />, and set <Cmd sid='form.type' product='2' /> to <Cmd sid='shift.type.fixed' product='2' />.

<Image src='/img/biostarx-tna-shift-day-adding-fixed.png' />

import Shift from '../../common/_tna-rule-shift-settings.mdx';

<Shift type='fixed' />

:::info

* Only one time code set to <Cmd sid='payCode.countAsAttendance' product='2' /> is allowed in <Cmd sid='tab.shift' product='2' className='normal' />.

* For a time code set to <Cmd sid='payCode.accumulateTowardOvertime' product='2' />, you can set <Cmd sid='shift.startTime' product='2' />, <Cmd sid='shift.endTime' product='2' />, <Cmd sid='shift.minDuration' product='2' />, and <Cmd sid='shift.rounding' product='2' />.

:::

### Flexible shift

A shift that sets daily work hours and flexibly adjusts clock-in and clock-out times based on the start time of the day. Enter the name and description for <Cmd sid='tab.shift' product='2' className='normal' />, and set <Cmd sid='form.type' product='2' /> to <Cmd sid='shift.type.flexible' product='2' />.

<Image src='/img/biostarx-tna-shift-day-adding-flexible.png' />

<Shift type='flexible' />

:::info

You cannot add a time code set to <Cmd sid='payCode.accumulateTowardOvertime' product='2' />.

:::

### Floating shift

A shift that lets you set clock-in and clock-out times freely. Enter the name and description for <Cmd sid='tab.shift' product='2' className='normal' />, and set <Cmd sid='form.type' product='2' /> to <Cmd sid='shift.type.floating' product='2' />.

<Image src='/img/biostarx-tna-shift-day-adding-floating.png' />

<Shift type='floating' />

:::info

* A shift can consist of up to five time slots. Click <Cmd sid='button.addplus' product='2' /> to add a time slot.

* Select the <Cmd sid='shift.timeSegmentSet.default' product='2' /> option when setting absences. In <Cmd sid='shift.timeSegmentSet.default' product='2' />, select one of the time slots that make up the shift.

  <Image src='/img/biostarx-tna-shift-day-adding-floating-timesegment.png' />

* For a time code set to <Cmd sid='payCode.accumulateTowardOvertime' product='2' />, you can set <Cmd sid='shift.startTime' product='2' />, <Cmd sid='shift.endTime' product='2' />, <Cmd sid='shift.minDuration' product='2' />, and <Cmd sid='shift.rounding' product='2' />.

:::
