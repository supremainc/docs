Muster is an essential setting for effective personnel management and safety during emergencies. With this feature, you can designate a location as a muster point to define in advance where users gather during emergencies.

The muster setting serves the following purposes.

* **Emergency response**: Designate a location where users can safely gather during emergencies such as fires or earthquakes

* **Occupancy monitoring**: Check the current headcount and the entry list for a location in real time

* **Long-stay detection**: Detect users who remain in a location longer than the set time and send a notification to the administrator

* **Enhanced security**: Continuously monitor access to sensitive locations to improve security levels

These features help you build a more systematic and efficient security management framework.

## Register a muster zone {/* #addMusterZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.muster' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the muster setting to add.

   <Image src='/img/biostarx-settings-adv-ac-add-muster.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the details for the muster settings. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='common.alarm' product='2' /> section, set the actions to run when specific events occur in the muster settings.

8. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='common.alarm' product='2' /> section is available only after you set both <Cmd sid='zone.entryDevices' product='2' /> and <Cmd sid='zone.exitDevices' product='2' />.

:::

### Setting options {/* #setting */}

The details for muster settings are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Shows the scope. Muster settings support only <Cmd sid='zone.globalZone.global' product='2' /> mode, and you can set them up on all devices registered in **BioStar X**.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.entryDevices' product='2' />: Select the devices to use for entry. Select from the list of registered devices.

* <Cmd sid='zone.exitDevices' product='2' />: Select the devices to use for exit. Select from the list of registered devices.

* <Cmd sid='zone.muster.accessGroup' product='2' />: Select the access group for users who stay in the muster location. You can set up to 16 access groups.

* <Cmd sid='zone.muster.timeLimit' product='2' />: Set the maximum time a user can stay in the muster location. The maximum is 4320 minutes, and an alarm occurs if a user stays in the muster location longer than the specified time.
