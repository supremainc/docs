You can view all events that occurred in **BioStar X** or only the alarm history. You can filter and generate custom reports based on user-defined conditions.

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.data' />, or select <Cmd sid='shell.header.data' /> from the shortcut list in the upper-left corner of the screen.

## View all events

You can view all events that occurred in **BioStar X**. Click <Cmd sid='data.sidebar.events' /> → <Cmd sid='data.sidebar.allEvents' /> in the left sidebar.

<Image src='/img/biostarx-data-generate-report.png' />

* To go to the previous or next page of the list, click <IcFw title='Previous' /> or <IcBw title='Next' /> in the upper-right corner of the screen.

* To change the number of rows in the list, click the drop-down menu in the upper-right corner of the screen, and then select a value. The list can show from 25 to 200 rows.

  <Image src='/img/biostarx-data-all-events-set-rows.png' />

{/* 기간 설정 */}

<SetPeriod />

### Set query conditions

You can filter the list by setting conditions in the header of the query list. You can set conditions for all columns except the date. 

1. In the header section of the event list, click <IcFilter title='Filter' /> for the column.

2. When the filter condition window appears, select the values to filter by.

   <Image src='/img/biostarx-data-report-add-filter.png' />

3. Once you finish selecting, click <Cmd sid='button.addCondition' product='2' />.

Only events that match the selected conditions appear in the list.

<Image src='/img/biostarx-data-all-events-filtered.png' />

### Clear query conditions

To clear the query conditions, click <IcClose /> in the conditions below the header section. The set conditions are cleared, and all events appear in the list again.

<Image src='/img/biostarx-data-all-events-disable-filter.png' />

### Save a report

You can save events as a report with the query period and conditions you set. 

1. Click <Cmd sid='data.button.saveReport' /> in the upper-left corner of the event list.

   <Image src='/img/biostarx-data-all-events-filtered-save-report.png' />

2. When the message indicating the report template was saved appears, click <Cmd sid='button.ok' product='2' />.

3. Saved reports appear under <Cmd sid='reportApp.savedReports' product='2' /> in the left sidebar.

<Image src='/img/biostarx-data-all-events-filtered-save-report-result.png' />

<ReportSaveNotes />

### View event videos

If a camera is connected to the device where a specific event occurred, the <Cmd sid='data.column.customReport.view' /> column shows the <IcReportVid /> icon for that event in the event list. To view the video from the time of the event in a pop-up window, click the icon.

<Image src='/img/biostarx-data-all-events-video-log.png' />

:::info

* If you connect one or more cameras in the camera rule settings, the system plays video from the first camera. For more information about setting up camera rules, see <DocLink docId='platform/biostar_x/settings-videos-rule' />.

* For more information about linking cameras and doors, see <DocLink docId='platform/biostar_x/settings-videos-rule' />.

* This feature is available by purchasing add-on options with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

### Export to CSV

You can export the event list as a CSV file. 

1. Click <Cmd sid='reportApp.export' product='2' /> in the upper-right corner of the screen.

2. When the <Cmd sid='reportApp.exportReport' product='2' /> window appears, in <Cmd sid='reportApp.fileFormat' product='2' />, select <Cmd>CSV</Cmd>.

   <Image src='/img/biostarx-data-export-all-report-csv.png' />

3. In <Cmd sid='reportApp.fileName' product='2' />, you can change the name of the file to save.

4. Enter <Cmd sid='auditTrail.export.reason' product='2' /> (optional) and click <Cmd sid='reportApp.export' product='2' />.

5. Save the CSV file to a location on your computer.

:::info

<Cmd sid='auditTrail.export.reason' product='2' /> is optional. Export reasons are recorded in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

## Generate a custom report {/* #custom-report */}

You can filter and generate custom reports based on the conditions you specify. You can save the generated report as a template and reuse it to generate reports with the same conditions later.

1. Click <Cmd sid='data.sidebar.events' /> → <Cmd sid='data.sidebar.customReport' /> in the left sidebar.

2. In the <Cmd sid='data.dialog.customReport.events' /> window, select events.

   <Image src='/img/biostarx-data-custom-report-set-filter.png' />

3. After you finish selecting events, click <Cmd sid='common.button.next' />.

   <Image src='/img/biostarx-data-custom-report-select-items.png' />

   * In the search (<IcSearch />) input field, you can search for entries.

   * To remove a selected event, click <IcRepTrash /> in the rightmost list.

4. Set the query period and click <Cmd sid='common.button.next' />.

   <Image src='/img/biostarx-data-custom-report-set-period.png' className='none' />

   * <Cmd sid='data.static' />: Set a specific date and time for the query period.

   * <Cmd sid='data.dynamic' />: Set the start date, end date, and time based on today. This is useful when generating reports for a specific period repeatedly.

5. Set conditions by user, door, and device, either by group or individually.

   <Image src='/img/biostarx-data-custom-report-select-filters.png' className='none' />

   * To remove a selected entry, click <IcRepTrash /> in the list on the right.

6. Select the conditions, and click <Cmd sid='common.button.next' />.

7. In the column settings window, select the columns to show in the report.

   <Image src='/img/biostarx-data-custom-report-set-columns.png' />

8. After you finish selecting the columns, click <Cmd sid='data.button.generate' />.

9. A report is generated with the conditions you set.

   <Image src='/img/biostarx-data-custom-report-complete.png' />

10. To save the generated report as a template, click <Cmd sid='data.button.saveReport' /> in the upper-left corner of the list. Saved reports appear under <Cmd sid='data.sidebar.savedReports' /> in the left sidebar.

    <Image src='/img/biostarx-data-custom-report-saved.png' />

## Manage reports {/* #report-management */}

### Save a report file

To export the report as a PDF or CSV file, click <Cmd sid='data.button.export' />. When the <Cmd sid='data.exportReport' /> window appears, set each option and click <Cmd sid='data.button.export' />.

<Image src='/img/biostarx-data-custom-report-export.png' />

:::info

<Cmd sid='auditTrail.export.reason' product='2' /> is optional. Export reasons are recorded in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

### Print a report

To print the report using a printer connected to your PC, click <Cmd sid='data.button.print' />. When the <Cmd sid='data.printReport' /> window appears, set each option and click <Cmd sid='data.button.print' />.

<Image src='/img/biostarx-data-custom-report-print.png' />

The print preview screen appears in a new tab of your web browser. To start printing, click **Print** in the upper-right corner of the screen.

:::info

<Cmd sid='printOption.printReason' product='2' /> is optional. You can view the print reasons in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

### Delete a report

To delete a saved report, right-click the report under <Cmd sid='data.sidebar.savedReports' /> in the left sidebar. Click <Cmd sid='data.sidebar.deleteSavedReport' /> in the pop-up menu.

<Image src='/img/biostarx-data-custom-report-remove.png' />

### Set columns

You can change the column settings of the report. Select the columns to show, or change their order.

1. Click <Cmd sid='data.dialog.customReport.columns' /> in the upper-right corner of the report.

2. When the <Cmd sid='common.dialog.columnSetting.title' /> window appears, select or clear the columns to show.

   <Image src='/img/biostarx-data-column-setting.png' />

3. To change the column order, drag the columns.

4. To save the settings, click <Cmd sid='common.apply' />.

:::info

* To restore the default column layout, click <Cmd sid='columnSetting.button.defaultColumn' product='2' />.

* The columns you can select vary by report.

:::
