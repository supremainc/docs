On the <Cmd sid='shell.header.user' /> page, the <Cmd sid='team.sidebar.user' /> menu lets you manage users efficiently with features such as user group management, user management, and viewing users by access permission, and strengthen security through permissions. The UI components on the <Cmd sid='shell.header.user' /> page are as follows.

<Image src='/img/biostarx-ui-user.png' className='none' />

<Calloutlists>

1. Shows user groups or access groups.

   * For more information about <Cmd sid='team.tree.userGroup' />, see <DocLink docId='platform/biostar_x/user-group-manage' />.

   * For more information about <Cmd sid='team.tree.accessExplorer' />, see <DocLink docId='platform/biostar_x/view-user-by-access' />.

2. Shows user groups or access groups in a tree structure. Expands or collapses the tree structure, and shows the users in a group when you click it.

3. Shows the number of users in the user group selected in the left sidebar.

4. To select all displayed users in the user list, click <Cmd sid='common.selectAll' />. The number of selected users appears in <Cmd sid='team.user.selected' />.

5. Enter a keyword to search for users. For more information about searching for users, see <DocLink docId='platform/biostar_x/view-users#user-search' />.

6. Click the page navigation button provided in the upper-right corner of the screen to check the next or previous user lists. Alternatively, specify a page to go to. For more information, see <DocLink docId='platform/biostar_x/view-users#select-view-options' />.

7. Click <Image src='/img/menus/ico-more-white.svg' ico alone /> to use various user-related features.

   * <Cmd sid='team.menu.export.title' />: Saves the user list as a CSV file or a Data file. For more information, see <DocLink docId='platform/biostar_x/export-import-user-info' />.

   * <Cmd sid='team.menu.import.title' />: Imports the user list from a CSV file or a Data file, or imports facial authentication information. For more information, see <DocLink docId='platform/biostar_x/export-import-user-info' />.

   * <Cmd sid='team.menu.transferToDevice' />: Sends registered user information to devices. For more information, see <DocLink docId='platform/biostar_x/transfer-user-info-to-device' />.

   * <Cmd sid='team.menu.faceMigration' />: Upgrades faces enrolled in earlier versions of **BioStar X** with the latest algorithm to improve authentication performance. For more information, see <DocLink docId='platform/biostar_x/migration-face' />.

   * <Cmd sid='team.menu.columnLayout' />: Changes the column headers in the user list. For more information, see <DocLink docId='platform/biostar_x/view-users#user-list-column-settings' />.

   * <Cmd sid='team.menu.print' />: Prints the user list.

8. Lets you register users and batch edit or delete them.

   * <Cmd sid='common.batchEdit' />: Edits information or access rights for multiple users at once. For more information, see <DocLink docId='platform/biostar_x/edit-user#user-information-collective-modification' />.

   * <Cmd sid='common.delete' />: Deletes the selected users. For more information, see <DocLink docId='platform/biostar_x/delete-user' />.

   * <Cmd sid='team.user.newUser' />: Registers a new user. For more information, see <DocLink docId='platform/biostar_x/add-user' />.

</Calloutlists>
