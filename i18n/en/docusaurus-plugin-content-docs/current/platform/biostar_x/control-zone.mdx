Learn how to control doors or devices set to advanced access control. These features help you respond quickly to issues and manage efficiently.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.arena' />, or select <Cmd sid='shell.header.arena' /> from the shortcut list in the upper-left corner of the screen.

2. Click the <Cmd sid='arena.tree.door.title' /> tab in the left sidebar, and then click <Cmd sid='arena.tree.door.allZones' />. 

3. Select an advanced access control entry, and then right-click. Select a feature from the pop-up menu.

<Image src='/img/biostarx-monitoring-door-zone-popup.png' />

:::info

* Available features vary depending on the type of advanced access control. The types of advanced access control are as follows.

  * **Anti-passback**

  * Fire Alarm

  * Scheduled lock/unlock

  * Intrusion Alarm

  * Interlock

  * Muster

  * Occupancy Limit

  * Roll Call

* For more information about each advanced access control feature, see <DocLink docId='platform/biostar_x/settings-advanced-ac' />.

* To select and control multiple advanced access control settings at once, see <DocLink docId='platform/biostar_x/monitoring-batch-control' />.

:::

## Clear APB {/* #apb-release */}

Clear the APB alarm for doors or devices set to **Anti-Passback**. Click <Cmd sid='arena.tree.contextMenu.clearApb' /> in the pop-up menu. A completion message appears at the top of the screen.

:::info

* The <Cmd sid='arena.tree.contextMenu.clearApb' /> feature is available only in **Anti-Passback**.

* For more information about **Anti-Passback** settings, see <DocLink docId='platform/biostar_x/settings-advanced-ac-apb' />.

* For more information about **Anti-Passback**, see <DocLink docId='reference/glossary#apb' />.

:::

## Clear alarm {/* #alarm */}

Clear alarms that occur on a door or device. Click <Cmd sid='arena.tree.contextMenu.clearAlarm' /> in the pop-up menu. A completion message appears at the top of the screen.

:::info

<Cmd sid='arena.tree.contextMenu.clearAlarm' /> cannot be used in the occupancy limit feature.

:::

## Enable/disable {/* #zone-revitalizationdisabled */}

You can enable advanced access control features or disable unused features. Deactivated advanced access control appears dimmed. Click <Cmd sid='arena.tree.contextMenu.enable' /> or <Cmd sid='arena.tree.contextMenu.disable' /> in the pop-up menu.

<Image src='/img/biostarx-monitoring-door-zone-disabled.png' />

## Arm/disarm {/* #security-zone-control */}

Arm or disarm a door or device. Click <Cmd sid='arena.tree.contextMenu.arm' /> or <Cmd sid='arena.tree.contextMenu.disarm' /> in the pop-up menu.

:::info

* <Cmd sid='arena.tree.contextMenu.arm' /> or <Cmd sid='arena.tree.contextMenu.disarm' /> can be used only for advanced access control set to intrusion alarm.

* For more information about intrusion alarm settings, see <DocLink docId='platform/biostar_x/settings-advanced-ac-intrusion-alarm' />.

:::

## View muster report {/* #confirmation-of-muster-reports */}

To view the muster report, click <Cmd sid='arena.tree.contextMenu.musterReport' />. When a new window opens, the user list and devices set to muster show entry times, exit times, and stay time overages.

:::info

* The <Cmd sid='arena.tree.contextMenu.musterReport' /> feature is available only in muster.

* For more information about the muster feature, see <DocLink docId='platform/biostar_x/settings-advanced-ac-muster' />.

:::

## Monitor occupancy limits {/* #monitoring-of-restrictions-on-the-number-of-people */}

Check the status of devices set to the occupancy limit feature. Click <Cmd sid='arena.tree.contextMenu.occupancyMonitoring' /> in the pop-up menu. When a new window opens, go to the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> menu. Check the status in the <Cmd sid='zone.occupancy.title' product='2' /> list.

:::info

* The <Cmd sid='arena.tree.contextMenu.occupancyMonitoring' /> feature is available only for entries set to the occupancy limit feature.

* For more information about occupancy limit settings, see <DocLink docId='platform/biostar_x/settings-advanced-ac-occupancy' />.

:::

## View details {/* #detail-view */}

View detailed information and event history for advanced access control. Click <Cmd sid='arena.tree.contextMenu.viewDetail' /> in the pop-up menu. Detailed information and event history appear in the right pane of the screen.

<Image src='/img/biostarx-monitoring-door-ac-details.png' />

* **Advanced access control controls**: Provides control features for the selected advanced access control.

* **Detailed information**: Shows the name and status of the advanced access control feature and device information.

* <Cmd sid='arena.recentEvent' />: Shows a list of recent events that occurred in the selected advanced access control.

:::info

For more information about each item in the advanced access control details section, see <DocLink docId='platform/biostar_x/settings-advanced-ac' />.

:::
