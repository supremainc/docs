Learn how to enroll a PIN so users can access by entering a PIN on the device. You can enroll a PIN for an individual user or batch enroll PINs for multiple users by importing a CSV file.

## Enroll a PIN

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='user.pin' product='2' />.

   <Image src='/img/biostarx-new-user-credential-pin.png' />

2. When the input field becomes active, enter the PIN.

3. In <Cmd sid='user.confirmPin' product='2' />, enter the same PIN.

4. Click <Cmd sid='button.enroll' product='2' />.

:::info

* The PIN must be from 4 to 16 digits long and contain only numbers.

* You can enroll up to one PIN credential per user.

:::

## Enroll a PIN via CSV import

Use the CSV import feature to register multiple users at once.

1. Add a `pin` column to the CSV file to import.

2. Enter the user's PIN in the `pin` column and save the CSV file.

3. Go to the <Cmd sid='shell.header.user' /> page.

4. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.csv' />.

5. Follow the on-screen instructions to select the CSV file and set the import options.

:::info

* You can enroll up to one PIN credential per user.

* For more information about the CSV import feature, see <DocLink docId='platform/biostar_x/export-import-user-info#csvimport' />.

:::
