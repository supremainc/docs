Activate the <Cmd sid="setting.server.license.device" product='2' /> issued by Suprema to use the specific features included in the license.

<Cmd sid="setting.server.license.device" product='2' /> lets you activate a device license using **BioStar X** and a USB drive.

:::info

import DocumentA from '../../common/_device-license-info.mdx'

<DocumentA />

* To check license error codes, see [the following link](https://reprisesoftware.com/docs/isv/appendix/appendix-b-rlm-status-values.html).

:::

## Before you start {/* #before-start */}

Before you activate the device license, check the following.

* Prepare a valid device license file. Contact the reseller for the device license file.

* Make sure the target device is registered in **BioStar X**. For more information about adding devices, see <DocLink docId='platform/biostar_x/settings-adding-devices' />.

## Apply a device license {/* #apply-device-license */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.license.root' /> → <Cmd sid="setting.server.license.device" product='2' /> in the left sidebar.

3. Click <Cmd sid="user.list.csvImport.browse" product='2' />.

   <Image src='/img/biostarx-settings-license-device-license.png' className='none' />

4. Get the device license file from the location where it is saved.

5. Information for the loaded license appears in the <Cmd sid="setting.server.license.name" product='2' />, <Cmd sid="setting.server.license.device.count" product='2' />, and <Cmd sid="setting.server.license.device.list" product='2' /> fields.

   <Image src='/img/biostarx-settings-license-device-license-loaded.png' />

6. Check <Cmd sid="setting.server.license.device.list" product='2' />, and click <Cmd sid="setting.server.license.button.activate" product='2' /> to activate the device license.

:::info

If license activation fails, an error message appears. Try to activate the license again.

:::

## Device license information {/* #device-license-info */}

When you load a device license file, the following information appears.

* <Cmd sid="setting.server.license.name" product='2' />: Shows the type of license included in the device license file.

  * **Camera QR**

    :::note

    The devices that support **Camera QR** are as follows.

    * BioStation 3 Max firmware v1.0.0 or later

    * XPass Q2 firmware v1.0.0 or later

    * X-Station 2 (XS2-ODPB, XS2-OAPB, XS2-DPB, XS2-APB) firmware v1.2.0 or later

    * X-Station 2 (XS2-QDPB, XS2-QAPB) firmware v1.4.1 or later

    * BioStation 3 firmware v1.1.0 or later

    :::

  * <Cmd sid='device.info.multiFaceAuth.label' product='2' className='bold' />

    :::note

    The following devices can use the <Cmd sid='device.info.multiFaceAuth.label' product='2' className='bold' /> license.

    * BioStation 3 firmware v1.5.0 or later

    To set the <Cmd sid='device.info.multiFaceAuth.label' product='2' /> option on devices with this license activated, see <DocLink docId='platform/biostar_x/settings-device-details-auth#faceDetectionSettings' />.

    :::

  * **Wireless Door Lock**

    :::note

    * Supported OSDP antennas and wireless door locks are as follows.

      * U&Z OSDP antenna: CX8936

      * U&Z Wireless Door Lock: CX217x (Handle), CX212x (Knob)

    * You can obtain device licenses for up to 12 devices, based on the number of wireless door locks you connect.

    * The maximum number of wireless door locks that can be connected with a device license is 12. Even if you activate multiple device licenses, you cannot exceed 12 devices.

    :::

* <Cmd sid="setting.server.license.device.count" product='2' />: Shows the number of devices included in the device license file.

* <Cmd sid="setting.server.license.device.licenseCount" product='2' />: Shows the number of wireless door locks that a device license can activate.

* <Cmd sid="setting.server.license.device.list" product='2' />: Shows detailed information about the devices included in the device license file.

  * <Cmd sid="setting.server.license.device.id" product='2' />: Shows the unique ID of the device.

  * <Cmd sid="setting.server.license.device.name" product='2' />: Shows the device name.

  * <Cmd sid="setting.server.license.device.product" product='2' />: Shows the device model name.

  * <Cmd sid="setting.server.license.device.status" product='2' />: Shows the current device status. You can activate a license only on devices in the <Cmd sid="setting.server.license.device.list.normal" product='2' /> state.

    * <Cmd sid="setting.server.license.device.list.normal" product='2' />, <Cmd sid="setting.server.license.device.list.disconnected" product='2' />, <Cmd sid="setting.server.license.device.list.notSupported" product='2' />, <Cmd sid="setting.server.license.device.list.unregistered" product='2' />

    :::note

    <Cmd sid='setting.server.license.device.status' product='2' /> shows <Cmd sid='setting.server.license.device.list.notSupported' product='2' /> if the device model does not support the license feature or the firmware version is too low. Check the supported models and firmware versions for the feature.

    :::

  * <Cmd sid="setting.server.license.status" product='2' />: Shows whether the license is activated. You can activate a license only on devices in the <Cmd sid="setting.server.license.device.list.notActivated" product='2' /> state.

    * <Cmd sid="setting.server.license.device.list.notActivated" product='2' />, <Cmd sid="setting.server.license.device.list.activated" product='2' />, <Cmd sid="setting.server.license.device.list.na" product='2' />

  * <Cmd sid="setting.server.license.device.activatedCount" product='2' />: Shows the connection status of wireless door locks.

:::info

* Values for <Cmd sid="setting.server.license.device.licenseCount" product='2' /> and <Cmd sid="setting.server.license.device.activatedCount" product='2' /> appear only when a wireless door lock device license is loaded.

:::
