The <Cmd sid='shell.header.setting' /> page lets you manage various settings for **BioStar X**. The UI components of this page are as follows.

<Image src='/img/biostarx-ui-settings.png' className='none' />

<Calloutlists className='svg-none-style'>

1. The <Cmd sid='shell.header.setting' /> menu shows various settings options. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-settings' />.

2. A tool for navigating the page list. Use it to move between pages or go to a specific page.

   <Image src='/img/biostarx-settings-access-control-status-pagenation.png' />

   * <IcFirst2 />: Moves to the first page.

   * <IcFw2 />: Moves to the previous page.

   * <IcBw2 />: Moves to the next page.

   * <IcLast2 />: Moves to the last page.

   * To go to a specific page, enter the page number in the number input field.

   * To set the number of entries shown per page, click the row selection box.

   :::info

   This may not be supported in some settings menus.

   :::

3. Click <IcMoreW /> to access additional options.

   :::info

   Supported features may vary depending on the settings menu.

   :::

</Calloutlists>
