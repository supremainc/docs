Use the **multi-factor authentication** feature to enhance security when you log in to **BioStar X**. Turning on <Cmd sid='team.user.permission.multiFactorAuth' /> adds a fingerprint authentication step, using a fingerprint scanner, to the user ID and password combination.

:::info

* To use the <Cmd sid='team.user.permission.multiFactorAuth' /> feature, a user must have a fingerprint enrolled and must have an ID, password, and operator level set.

* To use <Cmd sid='team.user.permission.multiFactorAuth' />, connect a fingerprint scanner that supports multi-factor authentication login to the **BioStar X** client PC. For supported fingerprint scanner devices, see the list below.

  * BioMini

  * BioMini Plus 2

  * BioMini Slim 2

* If you use the <Cmd sid='settings.activeDirectory.title' product='2' className='normal' /> account with the <Cmd sid='biostar.login' product='2' /> option, you cannot use <Cmd sid='team.user.permission.multiFactorAuth' />.

* Administrators who set <Cmd sid='team.user.permission.multiFactorAuth' /> cannot log in to **BioStar X** services other than access control (attendance management and video) for the first time. To use those services, log in after turning off the <Cmd sid='team.user.permission.multiFactorAuth' /> setting. Then you can turn on the <Cmd sid='team.user.permission.multiFactorAuth' /> setting again.

:::

:::caution

* Make sure fingerprint authentication is available after you set up multi-factor authentication for the administrator account (ID 1), or you cannot log in.

* If you cannot log in using fingerprint authentication, contact <Support />.

:::

## Multi-factor authentication settings {/* #multifactorauthenticationsetting */}

To set <Cmd sid='team.user.permission.multiFactorAuth' />, follow these steps.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, double-click the user to set <Cmd sid='team.user.permission.multiFactorAuth' />.

   Alternatively, select a user and click <Cmd sid='team.user.preview.button.seeMore' /> in the profile displayed on the right screen.

3. When the user preview screen appears, in the <Cmd sid='team.user.permission.title' /> section, set <Cmd sid='common.fingerprintLogin' product='2' /> to <Cmd sid='common.use' />.

   <Image src='/img/biostarx-edit-user-mfa-use.png' />

4. Click <Cmd sid='common.save' /> in the upper-right corner of the screen.

Multi-factor authentication setup is complete.

## Multi-factor authentication batch settings {/* #multifactorauthenticationbatchset */}

:::note

**Before you start**

To use multi-factor authentication for login, you must meet the following conditions.

* The user must have a fingerprint credential enrolled.

* <Cmd sid='team.userTemplate.table.operator' />, <Cmd sid='user.loginId' product='2' />, and <Cmd sid='common.password' product='2' /> must be set. For more information, see <DocLink docId='platform/biostar_x/set-permission' />.

:::

You can use the batch edit feature to apply <Cmd sid='team.user.permission.multiFactorAuth' /> to multiple users.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. To set up multi-factor authentication, select the checkbox to the left of the user in the user list.

3. Click <Cmd sid='common.batchEdit' /> in the upper-right corner of the screen.

4. When the batch edit window appears, in the <Cmd sid='team.user.permission.title' /> section, select the checkbox for the <Cmd sid='common.fingerprintLogin' product='2' /> option and set it to <Cmd sid='common.use' />.

   <Image src='/img/biostarx-batch-edit-user-mfa-use.png' />

5. Click <Cmd sid='common.save' /> in the upper-right corner of the screen.

Multi-factor authentication is set for the selected users.

:::info

Users among the selected who do not meet the conditions required to activate the <Cmd sid='common.fingerprintLogin' product='2' /> feature can be confirmed through the pop-up message of <Cmd sid='user.batchedit.popup.notavailableuser' product='2' />. Check the prerequisites for the setting and try again.

:::

## Log in with multi-factor authentication {/* #loginwithmultifactorauthentication */}

1. In a web browser, go to the **BioStar X** login screen.

2. Enter your user ID and password, then click <Cmd sid='auth.login' />.

3. When the fingerprint input screen appears, scan your fingerprint using the fingerprint scanner.

   <Image src='/img/biostarx-mfa-login-scan-fingerprint.png' />

Login is complete.

:::info

* The fingerprint scan time limit is fixed at 18 seconds and cannot be changed.

* You can scan your fingerprint up to three times in a row, and authentication fails if the fingerprint is not scanned correctly within three tries.

* If authentication fails, click <Cmd sid='button.retry' product='2' /> to retry fingerprint authentication. You can retry up to two times. If authentication fails on every retry, the initial login screen appears.

:::
