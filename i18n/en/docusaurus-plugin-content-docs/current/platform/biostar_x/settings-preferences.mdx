To use **BioStar X** efficiently, you need preferences that match your environment. Learn how to set up preferences for the following situations.

* Initial settings for a newly installed **BioStar X**

* Change the interface language to your preferred language

* Set the time for your local time zone

* Customize the event notification sound

## Access preferences {/* #preference */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.preferences.root' /> in the left sidebar.

3. Set the options in each section.

   * <Cmd sid='preference.languageTimezone' product='2' />: Interface language and time zone, daylight saving time

   * <Cmd sid='preference.dateTimeFormat' product='2' />: Date and time format

   * <Cmd sid='device.info.sound' product='2' />: Event notification sound

4. After completing all settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

## Set language and time zone {/* #language-timezone */}

Set the interface language, time zone, and daylight saving time rules for **BioStar X**.

<Image src='/img/biostarx-settings-preference-language-timezone.png' className='none' />

* <Cmd sid='common.language' product='2' />: Select the interface language to use.

* <Cmd sid='common.timeZone' product='2' />: Select the time zone for your current location.

* <Cmd sid='common.dst' product='2' />: Select the daylight saving time rules to apply to the **BioStar X** server. If the option you need isn't available, see <DocLink docId='platform/biostar_x/settings-system-daylight-saving-time' /> to add it.

To save the settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

## Set date and time display format {/* #date-time-format */}

Set the date and time display formats used across the system.

<Image src='/img/biostarx-settings-preference-date-time.png' className='none' />

* <Cmd sid='common.dateFormat' product='2' />: Select the date format.

  * **mm/dd/yyyy**: 01/31/2025

  * **yyyy/mm/dd**: 2025/01/31

  * **dd/mm/yyyy**: 31/01/2025

* <Cmd sid='common.timeFormat' product='2' />: Select the time format.

  * **hh:mm**: 23:59, 24-hour format

  * **hh:mm a**: 11:59 PM, 12-hour format

  * **a hh:mm**: PM 11:59, 12-hour format

To save the settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

## Set event notification sound {/* #sound */}

You can upload a sound file to use when an event occurs.

<Image src='/img/biostarx-settings-preference-sound.png' className='none' />

1. Click <Cmd sid='button.plusAdd' product='2' />.

2. When the <Cmd sid='setting.preference.sound.alert.add' product='2' /> window appears, click <Cmd sid='setting.preference.sound.alert.addSound.browse' product='2' />.

   <Image src='/img/biostarx-settings-preference-add-sound.png' className='none' />

3. Select the *.wav* or *.mp3* file to upload, and click **Open**.

4. To upload a sound file, click <Cmd sid='button.add' product='2' />.

To save the settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

* Only *.wav* or *.mp3* sound files can be uploaded.

* The maximum file size you can upload is 10 MB.

* For more information about applying the uploaded sound file when an event occurs, see <DocLink docId='platform/biostar_x/settings-alert#edit-alert-message' />.

:::
