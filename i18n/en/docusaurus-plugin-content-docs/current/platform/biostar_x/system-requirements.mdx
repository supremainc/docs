**BioStar X** provides a reliable and scalable integrated security management solution for large enterprise environments. The system can efficiently manage over a thousand devices through a distributed architecture consisting of a main server and a Multi Communications Server.

The main server handles the system's core management features, and the Multi Communications Server handles device communication to distribute the load and optimize performance. Additionally, you can access the system through a web browser on a client PC and run all management tasks. Check the system requirements below and set up the optimal environment for the size of your organization.

:::info

For more information about license configuration and optimization, contact the <Support />.

:::

## Main server {/* #main-server */}

The main server is where the central management system for **BioStar X** is installed. You access the system through a web browser to manage it and handle all tasks, such as setting user information or access permissions. It is also responsible for monitoring the overall system status and managing event logs and alarms.

:::info

* **BioStar X** can only be installed on 64-bit operating systems.

* MS SQL Server secure communication supports TLS 1.2.

* If MS SQL Server and **BioStar X** are installed on different PCs, install the [Microsoft OLE DB Driver for SQL Server](https://learn.microsoft.com/sql/connect/oledb/download-oledb-driver-for-sql-server) on the PC where **BioStar X** is installed.

* For large organizations, we recommend installing an MS SQL Server database.

* If you use an MS SQL Server database and **BioStar X T&A**, install the [Microsoft ODBC Driver 17 for SQL Server](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver16#version-17) for your environment.

* The Windows virtual environment provided by Boot Camp on macOS is not supported.

* Up to 1,000 devices can connect via Ethernet (TCP/IP). Add a Multi Communications Server to connect more devices.

:::

### SQL Server license requirements {/* #sqlserver-requriements */}

If you use SQL Server as the database, you need an appropriate SQL Server license for the number of connected devices to run **BioStar X** reliably. Review the recommended license settings for each environment, and select a license that fits your organization's size and needs.

:::info

For more information about SQL Server licenses, see [Microsoft SQL Server Licensing](https://www.microsoft.com/sql-server/sql-server-2022-pricing).

:::

## Multi Communications Server {/* #communication-server */}

The Multi Communications Server handles communication with access control devices. Installing it separately from the main server helps you manage large numbers of devices reliably. A single Multi Communications Server can connect up to 1,000 devices. Add multiple Multi Communications Servers as needed.
