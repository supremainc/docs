Learn how to delete a registered elevator.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.elevator.root' /> in the left sidebar.

3. In the elevator list, select the checkbox for the elevator to delete.

4. Click <Cmd sid='elevator.list.deleteButton' product='2' /> in the upper-right corner of the screen.

The selected elevator is deleted. A deleted elevator cannot be recovered.

:::info

The <Cmd sid='elevator.list.deleteButton' product='2' /> button is enabled only when you select one or more elevators in the elevator list.

:::
