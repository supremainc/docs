Learn how external visitors who are not internal users request access using the visit request PC.

:::info

* Set up the visit request PC separately, and set up the visitor settings first. For more information about visitor settings, see <DocLink docId='platform/biostar_x/settings-visitor' />.

* If the visit request PC does not have a shortcut icon for the visit request page, see <DocLink docId='platform/biostar_x/settings-visitor#settings-visitor-pc-link' /> and create a shortcut icon.

:::

## New visit request

Learn how first-time visitors request access on the visit request PC.

1. Open the visit request page on the visit request PC. The URL for the visit request page is in the format `https://{biostar_x_server_ip}/#/register-welcome`.

   <Image src='/img/biostarx-visitor-register-welcome.png' />

2. Click <Cmd sid='visitor.welcome.first.time' product='2' /> in the center of the screen.

3. After agreeing to the terms and privacy policy for access to the site, click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

4. Enter the information required for the visit request.

   <Image src='/img/biostarx-visitor-register-info.png' />

   * <Cmd sid='common.visitor' product='2' />: Enter the visitor's name and phone number.

   * <Cmd sid='visitor.host' product='2' />: Enter the host's name and phone number.

   * <Cmd sid='visitor.accessInfo' product='2' />: Set the access area and visit period.

5. After entering the information, click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

6. Set the credential.

   <Image src='/img/biostarx-visitor-register-access-credential.png' />

   * <Cmd sid='common.fingerPrint' product='2' />: To use fingerprint authentication, click <Cmd sid='button.addFingerprint' product='2' /> and then enroll your fingerprint.

   * <Cmd sid='common.card' product='2' />: To use card authentication, set it to <Cmd sid='visitor.request' product='2' /> and then get a card from the administrator.

7. After completing the settings, click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

8. After confirming all the information provided, click <Cmd sid='button.register' product='2' /> in the lower-right corner of the screen.

   <Image src='/img/biostarx-visitor-register-complete.png' />

:::info

* For more information about creating terms of use and a privacy policy for visitor access, see <DocLink docId='platform/biostar_x/settings-visitor#settings-visitor-terms' />.

* The name can be up to 48 characters.

* For more information about adding custom fields to visitor information, see <DocLink docId='platform/biostar_x/settings-visitor#settings-visitor-custom-field' />.

* You can select only the access groups of the site assigned to the visitor PC. For more information, see <DocLink docId='platform/biostar_x/settings-visitor#settings-visitor-site' />.

* For more information about access groups, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />.

* To return to the previous step and modify the visit information, click <Cmd sid='button.previousPage' product='2' />.

* To scan a fingerprint, a fingerprint enrollment device must be connected to the visit request PC.

:::

## Request a visit with existing information

If a fingerprint is enrolled at the site, you can search for the fingerprint and request a visit using the existing visit information.

1. Open the visit request page on the visit request PC. The URL for the visit request page is in the format `https://{biostar_x_server_ip}/#/register-welcome`.

   <Image src='/img/biostarx-visitor-register-welcome.png' />

2. Click <Cmd sid='visitor.welcome.search' product='2' /> below the fingerprint icon in the center of the screen.

3. Scan your fingerprint on the fingerprint scanning device. The system searches for a registered user using the scanned fingerprint.

4. If the fingerprint matches a visitor who previously enrolled a fingerprint, a confirmation message appears.

   <Image src='/img/biostarx-visitor-register-confirm-message.png' />

5. If the searched visitor is correct, click <Cmd sid='button.yes' product='2' />.

6. After agreeing to the terms and privacy policy for access to the site, click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

7. Check the visit information set during your previous visit. To modify existing information, edit each item and then click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

   <Image src='/img/biostarx-visitor-register-saved-info.png' />

8. Check the credential set during your previous visit. To change the existing credential, edit the fields to change, and then click <Cmd sid='button.nextPage' product='2' /> in the lower-right corner of the screen.

   <Image src='/img/biostarx-visitor-register-saved-access-credential.png' />

9. After confirming all the information provided, click <Cmd sid='button.register' product='2' /> in the lower-right corner of the screen.

   <Image src='/img/biostarx-visitor-register-complete.png' />
