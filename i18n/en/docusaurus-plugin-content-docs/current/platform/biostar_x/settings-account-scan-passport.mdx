title: Set Up ID Scan
description: Learn how to select user data to import during ID scans and set the face credential enrollment method.
---

Before you register users by scanning an ID, set the user name and profile image to import, and set the face credential enrollment method. Learn how to set up ID scanning.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' /> in the left sidebar.

   <Image src='/img/biostarx-settings-account-passport-scan-setting.png' />

3. Select the data to import when scanning an ID.

   * <Cmd sid='setting.passportScan.name' />: Imports the name printed on the identification card.

   * <Cmd sid='setting.passportScan.profileImage' />: Imports the profile image printed on the identification card.

   * <Cmd sid='setting.passportScan.face' />: Enrolls the face image printed on the identification card as a face credential.

     * <Cmd sid='setting.passportScan.faceAlwaysConfirm' />: Always asks for confirmation when enrolling the face image printed on the identification card as a face credential.

     * <Cmd sid='setting.passportScan.faceDoNotAsk' />: Enrolls the face image printed on the identification card as a face credential without asking for confirmation.

4. To save the settings, click <Cmd sid='button.apply' product='2' />.

:::info

* If <Cmd sid='setting.passportScan.profileImage' /> is not selected, you cannot select <Cmd sid='setting.passportScan.face' />.

* For more information about registering or updating users by scanning ID, see <DocLink docId='platform/biostar_x/add-user-by-scanning-passport' />.

:::
