This guide describes how to edit the setting information of the registered elevator. You can change the detailed settings of individual elevators or select multiple elevators to make bulk changes to common items.

## Edit information for one elevator {/* #edit-one-elevator-info */}

1. Click <Cmd sid='shell.header.setting' /> on the <Cmd sid='shell.header.launcher' /> page.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.elevator.root' /> on the left sidebar.

3. Click the elevator you want to edit in the elevator list.

4. Modify the details in each section.

5. Once all configurations are complete, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

For more information on each section on the edit elevator information screen, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

:::

## Batch edit multiple elevators {/* #edit-multiple-elevator-info */}

1. Click <Cmd sid='shell.header.setting' /> on the <Cmd sid='shell.header.launcher' /> page.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.elevator.root' /> on the left sidebar.

3. Click the checkboxes of the elevators you want to edit from the elevator list. Select two or more elevators.

4. Click <Cmd sid='button.batchEdit' product='2' /> at the top right of the screen.

5. When the <Cmd sid='button.batchEdit' product='2' /> window appears, set your desired options.

   <Image src='/img/biostarx-setting-elevator-batch-edit.png' />

6. After completing all settings, click <Cmd sid='button.apply' product='2' />.

:::info

* <Cmd sid='button.batchEdit' product='2' /> will be activated only when two or more elevators are selected from the elevator list.

* In batch editing, modify only the <Cmd sid='door.openTime' product='2' /> option.

:::
