Learn how to edit settings for a registered elevator. Change detailed settings for an individual elevator, or select multiple elevators to batch edit common fields.

## Edit information for one elevator {/* #edit-one-elevator-info */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.elevator.root' /> in the left sidebar.

3. In the elevator list, click the elevator to edit.

4. Edit the details in each section.

5. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

For more information about each section on the edit elevator information screen, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

:::

## Batch edit multiple elevators {/* #edit-multiple-elevator-info */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.elevator.root' /> in the left sidebar.

3. In the elevator list, select the checkbox for the elevator to edit. Select two or more elevators.

4. Click <Cmd sid='button.batchEdit' product='2' /> in the upper-right corner of the screen.

5. When the <Cmd sid='button.batchEdit' product='2' /> window appears, set the options.

   <Image src='/img/biostarx-setting-elevator-batch-edit.png' />

6. After you complete all settings, click <Cmd sid='button.apply' product='2' />.

:::info

* The <Cmd sid='button.batchEdit' product='2' /> button is enabled only when you select two or more elevators in the elevator list.

* During batch editing, only the <Cmd sid='door.openTime' product='2' /> option can be edited.

:::
