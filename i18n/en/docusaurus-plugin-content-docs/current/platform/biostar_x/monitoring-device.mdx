Learn how to use the device and camera monitoring features. Check the status of devices and cameras, view details, and play camera video in real time. Also, learn how to check recent events to manage device and camera status efficiently.

To access the <Cmd sid='arena.title' /> page, click <Cmd sid='arena.title' /> in the <Cmd sid='shell.header.launcher' /> or select <Cmd sid='arena.title' /> from the menu in the upper-left corner of the screen.

## Check device and camera status

Click the <Cmd sid='arena.tree.device.title' /> tab in the left sidebar. Check the status of all devices and cameras. See below for the status of devices and cameras.

<div className='col2--20-80 overflow-x'>

| Status Icon | Description |
| :-: | --- |
| <IcDeviceOn width='35px' height='35px'/> | The device is connected properly. |
| <IcDeviceOff width='35px' height='35px' /> | The device is off or disconnected. |
| <IcCamOk width='auto' height='35px'/> | The camera is connected. |
| <IcCamFail width='auto' height='35px'/> | The camera is off or disconnected. |

</div>

### View devices that need attention {/* #checkAttentionFilter */}

Administrators can view only devices that require action in one list. Click the <Cmd sid='arena.tree.door.entitiesNeedAttention' /> in the left sidebar. You can check device status and take action on devices with issues.

<Image src='/img/biostarx-monitoring-device-attention-filter.png' />

### Criteria for action-required devices {/* #attention-criteria */}

In the device tree, the system marks abnormal devices as action-required.

| Abnormal status type | Status indicator | Description |
| --- | --- | --- |
| Disconnected | <Cmd sid='arena.tree.disconnected' /> | The device is disconnected from the network |
| Synchronization error | <Cmd sid='arena.tree.syncError' /> | Connected, but data is out of sync |
| Multi Communications Server error | <Cmd sid='arena.tree.communicationError' /> | An error has occurred on the device's Multi Communications Server |
| Lock device | <Cmd sid='arena.tree.deviceLocked' /> | The device is locked due to trigger conditions and actions |
| Authentication failure lockout | <Cmd sid='arena.preview.device.authFailLockout.title' /> | The device is locked after authentication fails at least the specified number of times |

:::info

* The <Cmd sid='arena.tree.deviceLocked' /> condition is determined by the trigger conditions and actions set in <DocLink docId='platform/biostar_x/settings-triger-and-action' />. To learn how to check and clear this status, see <DocLink inner='#deviceLockRelease' />.

* You can set the <Cmd sid='arena.preview.device.authFailLockout.title' /> condition in device settings. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-auth#howToAuth' />. To learn how to check and clear this status, see <DocLink inner='#authFailLockout' />.

:::

## Device control

Select the desired device from the list in the left sidebar and right-click. Select a feature from the pop-up menu.

<Image src='/img/biostarx-monitoring-device-popup.png' />

The control features shown may vary depending on the device type.

| Device type | Control feature |
| --- | --- |
| [Master device](../../reference/glossary#master_device), a device that connects directly to the server without slave devices | <Cmd sid='arena.tree.contextMenu.stopAction' />, <Cmd sid='arena.tree.contextMenu.reboot' />, <Cmd sid='arena.tree.contextMenu.deviceUnlock' />, <Cmd sid='arena.batchResult.action.clearLockout' />, <Cmd sid='arena.tree.contextMenu.reconnect' /> (only when the server connects to the device) |
| [Slave device](../../reference/glossary#slave_device) | <Cmd sid='arena.tree.contextMenu.stopAction' />, <Cmd sid='arena.tree.contextMenu.reboot' />, <Cmd sid='arena.tree.contextMenu.deviceUnlock' />, <Cmd sid='arena.batchResult.action.clearLockout' /> |
| OSDP communication device | <Cmd sid='arena.tree.contextMenu.deviceUnlock' />, <Cmd sid='arena.tree.contextMenu.reconnect' /> (depends on the connection method) |
| Wiegand device | <Cmd sid='arena.tree.contextMenu.deviceUnlock' /> |
| Expansion modules (Secure I/O 2, DM-20, OM-120, IM-120) | <Cmd sid='arena.tree.contextMenu.stopAction' /> |
| Devices using device-to-server connections | <Cmd sid='arena.tree.contextMenu.stopAction' />, <Cmd sid='arena.tree.contextMenu.reboot' />, <Cmd sid='arena.tree.contextMenu.deviceUnlock' />, <Cmd sid='arena.batchResult.action.clearLockout' /> |
| Wireless antenna module | None |

### Reconnect a device

Regardless of the device connection status, click <Cmd sid='arena.tree.contextMenu.reconnect' /> in the pop-up menu. Use this to reconnect disconnected devices, or resend settings and clear abnormal states on connected devices. When the device reconnects, the status icon changes to normal status (<IcDeviceOn />).

:::info

The <Cmd sid='arena.tree.contextMenu.reconnect' /> feature does not support devices set to the <Cmd sid='device.info.deviceToServerConnection' product='2' /> option. For more information about registering devices, see <DocLink docId='platform/biostar_x/settings-adding-devices#setipaddress' />.

:::

### Restart device

To restart the device, click <Cmd sid='arena.tree.contextMenu.reboot' /> in the pop-up menu. When the warning message window appears, click <Cmd sid='common.button.ok' />.

### Unlock the device {/* #deviceLockRelease */}

When the device locks due to administrator-defined conditions and actions, <Cmd sid='arena.tree.deviceLocked' /> appears under the device name in the left sidebar. When you select the device, the same banner appears at the top of the preview panel in the right pane.

<Image src='/img/biostarx-monitoring-device-lock.png' />

* The pop-up menu shows <Cmd sid='arena.tree.contextMenu.deviceUnlock' /> only when the device is locked. Select the locked device, then click <Cmd sid='arena.tree.contextMenu.deviceUnlock' /> in the pop-up menu.

* To unlock the device, select the locked device and click <Cmd sid='arena.preview.banner.unlock' /> in the banner at the top of the preview panel in the right pane.

:::info

The <Cmd sid='arena.tree.contextMenu.deviceUnlock' /> feature appears only for users with <Cmd sid='setting.account.administrator' /> or <Cmd sid='setting.account.monitoringOperator' /> privileges.

:::

### Clear authentication failure lockout {/* #authFailLockout */}

If authentication fails at least as many times as set in <Cmd sid='device.info.authFailLockout.label' product='2' />, the device switches to the locked state. When the device is locked, <Cmd sid='arena.preview.device.authFailLockout.title' /> appears under the device name in the left sidebar, and when you select the device, the same banner appears at the top of the preview panel on the right side of the screen with the event time and device information.

The pop-up menu shows <Cmd sid='arena.batchResult.action.clearLockout' /> only when the device is in authentication failure lockout. Select the locked device, then click <Cmd sid='arena.batchResult.action.clearLockout' /> in the pop-up menu.

<Image src='/img/biostarx-monitoring-device-auth-fail-lock.png' />

:::info

* Only users with <Cmd sid='setting.account.administrator' /> or <Cmd sid='setting.account.monitoringOperator' /> privileges see the <Cmd sid='arena.batchResult.action.clearLockout' /> menu.

* After the set lockout time (<Cmd sid='device.info.authFailLockout.firstLockout' product='2' />/<Cmd sid='device.info.authFailLockout.secondLockout' product='2' />) elapses, the device unlocks automatically. The lockout clears without additional action. For more information about lockout conditions and lockout time settings, see <DocLink docId='platform/biostar_x/settings-device-details-auth#howToAuth' />.

:::

### Stop an action

To stop all alarm-based and trigger-based actions running on the device, click <Cmd sid='arena.tree.contextMenu.stopAction' /> in the pop-up menu. A success message for stopping the action appears at the top of the screen.

### View device details

To view detailed information about the device, click <Cmd sid='arena.tree.contextMenu.viewDetail' /> in the pop-up menu. Alternatively, double-click the device. Device details appear in the right pane.

<Image src='/img/biostarx-monitoring-device-details.png' />

* **Device control**: Stops device tasks, restarts the device, or reconnects it.

* **Device details**: Shows the device ID, group, model name, uptime, and IP address.

* <Cmd sid='arena.recentEvent' />: Shows the list of recent events on the selected device.

## Control multiple devices at once {/* #batch-control */}

Learn how to select multiple devices and run commands such as reconnect, restart, or unlock. Select two or more devices in the <Cmd sid='arena.tree.device.title' /> tab in the left sidebar. The batch control panel appears on the right.

<Image src='/img/biostarx-monitoring-device-multi-select.png' />

:::info

Cameras are not included in batch control. For more information about camera control, see <DocLink inner='#controlCamera' />.

:::

### Select multiple devices {/* #select-multiple-devices */}

Use the following methods to select devices in the <Cmd sid='arena.tree.device.title' /> tab in the left sidebar.

* **<Kbd>Ctrl</Kbd> + Click**: Adds the clicked device to the selection list or removes it from the list. This keeps the remaining selection.

* **<Kbd>Shift</Kbd> + Click**: Selects a range from the last clicked device to the clicked device. Device groups are excluded from range selection.

* **Click a group (<IcGroup />)**: Click the group name to add all devices under it to the selection list. Currently selected devices remain selected.

:::info

* If you select only an empty group with no devices, the right pane closes.

* If you select one device, the device details panel appears; if you select two or more, it switches to the batch control panel.

:::

### Check execution results {/* #batch-result */}

* If all selected devices succeed, only a success message appears.

  <Image src='/img/biostarx-monitoring-device-batch-action-success.png' caption />

* If any device fails, a failure message appears, along with the <Cmd sid='arena.batchResult.showDetails' /> button. 

  <Image src='/img/biostarx-monitoring-device-batch-action-fail-toast.png' caption />

  Click <Cmd sid='arena.batchResult.showDetails' /> to view results grouped into <Cmd sid='arena.batchResult.successChip' />, <Cmd sid='arena.batchResult.failChip' />, and <Cmd sid='arena.batchResult.skippedChip' />. To copy the names and reasons for failed entries to the clipboard, click <Cmd sid='arena.batchResult.copyFailList' />.

  <Image src='/img/biostarx-monitoring-device-batch-action-fail-detail.png' caption />

:::info

* The <Cmd sid='monitoring.multiControl.reconnect' /> button is an exception. After the system accepts the request, only a success message appears, and it does not provide failure status or a detailed results window. Check the status tree to confirm whether the connection succeeded.

* <Cmd sid='monitoring.multiControl.unlockDevice' /> and <Cmd sid='monitoring.multiControl.clearLockout' /> are processed separately, and separate result windows appear.

:::

## Control the camera {/* #controlCamera */}

Select the desired camera from the list in the left sidebar and right-click. Select a feature from the pop-up menu.

<Image src='/img/biostarx-monitoring-camera-popup.png' />

### Play camera video

To place the camera video in the video tile and monitor in real-time, click <Cmd sid='arena.tree.contextMenu.openVideo' /> in the pop-up menu.

:::note

You can also add camera video to video tiles in the following ways.

* Double-click the camera to play the video from the camera in the left sidebar. 

* Alternatively, drag and drop the camera into the video tile area to add video.

:::

:::info

* Videos are added to the video tiles in order, starting in the upper-left corner of the screen; if the current screen has no space, an error message appears.

* For more information about video controls and the tools displayed on the video, see <DocLink docId='platform/biostar_x/monitoring-video' />.

* If you do not see a camera in the <Cmd sid='arena.tree.device.allCameraGroups' /> list, check the camera group permissions. If an administrator with custom permissions has not set camera group permissions, cameras might not appear. For more information about setting camera group permissions, see <DocLink docId='platform/biostar_x/settings-videos-camera#addCameraPermission' />.

:::

### View camera details

To view the camera details, click <Cmd sid='arena.tree.contextMenu.viewDetail' /> in the pop-up menu. Check the camera group, description, ID, and IP address.

<Image src='/img/biostarx-monitoring-camera-details.png' />
