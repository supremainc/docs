User groups can share common properties and permissions. When a user becomes a group member, the user automatically inherits all properties of that group. A user can belong to only one user group.

* Instead of setting access permissions for each user, create user groups by department or role to apply the same permissions at once.

* When you change a group's access permissions, the changes apply automatically to all users in the group, reducing your workload. Adjust permissions quickly when the organization changes or a new project starts.

* Set permissions by group to prevent unnecessary access and improve security.

* Analyze access logs for a specific group separately, which makes security audits and log management easier.

* User groups integrate with access levels to apply detailed policies such as access time limits and restricted areas.

## Add a group {/* #group-additional */}

Create groups to efficiently manage multiple users. Register the group name using the user's organization to make groups easier to manage.

:::info

* Register the group name as the organization or department name to make management easier.

* You can create subgroups under a group, one level at a time, up to 8 levels deep.

* You can enter up to 48 characters for a user group name.

* When you select a group from the user group list, only users in that group appear in the user list.

:::

### Create a top-level group {/* #creating-a-higher-group */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the left sidebar, select <Cmd sid='team.user.tree.userGroupRootName' /> from the <Cmd sid='team.tree.userGroup' /> tab and right-click.

   <Image src='/img/biostarx-user-group-add.png' />

3. Click <Cmd sid='arena.tree.contextMenu.addNewGroup' /> in the pop-up menu.

4. After the group is created, enter the group name.

   <Image src='/img/biostarx-user-group-add-input.png' />

### Create a subgroup {/* #creating-a-lower-group */}

1. Select the parent group in the <Cmd sid='team.tree.userGroup' /> tab in the left sidebar, and then right-click.

   <Image src='/img/biostarx-user-sub-group-add.png' />

2. Click <Cmd sid='arena.tree.contextMenu.addNewGroup' /> in the pop-up menu.

3. After the group is created, enter the group name.

:::info

* You must select a parent group to create a subgroup, and you can create up to 8 levels.

* Drag a group to another group to set it as a subgroup of the target group. Move a group to <Cmd sid='team.user.tree.userGroupRootName' /> to set it as a top-level group.

:::

## Rename a group {/* #group-name-change */}

Change the name of the group that the user belongs to. We recommend changing the group name when the organization or department name changes.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Select the group to rename in the <Cmd sid='team.tree.userGroup' /> list in the left sidebar, and then right-click.

   <Image src='/img/biostarx-user-group-rename.png' />

3. Click <Cmd sid='arena.tree.contextMenu.renameGroup' /> in the pop-up menu.

4. Enter the new group name.

Check the changes in the <Cmd sid='team.tree.userGroup' /> list.

:::info

You can enter up to 48 characters for a user group name.

:::

## Delete a group {/* #group-deletion */}

Delete a group that the user belongs to.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Select the group to delete in the <Cmd sid='team.tree.userGroup' /> list in the left sidebar, and then right-click.

3. Click <Cmd sid='arena.tree.contextMenu.deleteGroup' /> in the pop-up menu.

   <Image src='/img/biostarx-user-group-remove.png' />

4. When the confirm message appears, click <Cmd sid='team.user.tree.dialog.delete.yes' />.

In the <Cmd sid='team.tree.userGroup' /> list, confirm that the selected group is deleted.

## View users by group {/* #viewgroupuser */}

View the users in the user group. On the <Cmd sid='shell.header.user' /> page, select a user group in the left sidebar. Users in the selected user group appear in the list.

<Image src='/img/biostarx-user-group-select-group-user.png' />

## Expand or collapse the group list

Expand or collapse the user group list. In the <Cmd sid='team.tree.userGroup' /> tab, select <Cmd sid='team.user.tree.userGroupRootName' /> and right-click. Click <Cmd sid='team.expandAll' /> or <Cmd sid='team.collapseAll' /> in the pop-up menu.

<Image src='/img/biostarx-user-group-expand-collapse.png' />

If the group has subgroups, you can expand or collapse them. Select the parent group and right-click. Click <Cmd sid='common.tree.contextMenu.expandBelow' /> or <Cmd sid='common.tree.contextMenu.collapseBelow' /> in the pop-up menu.

<Image src='/img/biostarx-user-sub-group-expand-collapse.png' />
