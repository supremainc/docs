Set attendance rules, review work records recorded on devices, or print reports. The <Cmd sid='shell.header.tna' className='normal' /> feature is provided as a plugin and requires a separate license.

:::info

The <Cmd sid='shell.header.tna' className='normal' /> feature is available through an add-on option. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

### Install the plugin

To use the <Cmd sid='shell.header.tna' className='normal' /> feature, download and install a separate installation file. Follow the instructions below to install the plugin.

1. Go to the [Suprema Download Center](https://download.supremainc.com/) and download the <Cmd sid='shell.header.tna' className='normal' /> plugin installation file (*BioStar X TA.X.Y.Z.BB.exe*).

2. Run the installation file, and then follow the prompts to complete the installation.

3. Run the downloaded installation file.

4. Select the language to use, and then click <Cmd code='biostar2.install.ok' className='bold'/>.

   <Image src='/img/biostarx-install-select-language.png' />

5. To continue the installation, select <Cmd code='biostar2.install.agree' className='bold'/>, and then click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-tna-install-agree.png' />

6. Enter the root account password for the database and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-tna-install-input-db-pw.png' />

7. Read the information about the management and responsibility of personal information stored in the database, and click <Cmd code='biostar2.install.next' className='bold'/> to continue the installation.

   <Image src='/img/biostarx-tna-install-read-covenant.png' />

8. Set the port for communication with **BioStar X** and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-tna-install-set-port.png' />

   :::note

   You can use the default port number (3002) or change it to a different port number. If you change the port number, make sure the port is open in the firewall.

   :::

9. Select the installation components and click <Cmd code='biostar2.install.next' className='bold'/>.

   <Image src='/img/biostarx-tna-install-additional.png' />

10. When you finish preparing for installation, click <Cmd code='biostar2.install.btnInstall' className='bold'/>.

    <Image src='/img/biostarx-tna-install-complete.png' />

:::info

* In the downloaded file name, `X.Y.Z` is the version information, and `BB` is the build number.

* For the database root account password, use the password you used when installing **BioStar X**.

:::

## Initial setup

1. When you log in to the <Cmd sid='shell.header.tna' className='normal' /> feature for the first time, you must add a device for Time & Attendance for initial setup. Click <Cmd sid='common.setting' product='2' /> on the screen.

   <Image src='/img/biostarx-tna-initial-setting.png' />

2. Select a device for Time & Attendance from the device list.

   <Image src='/img/biostarx-tna-initial-setting-register-device.png' />

3. Click <IcAdd /> <Cmd sid='setting.register' product='2' /> when it is enabled.

   <Image src='/img/biostarx-tna-initial-setting-select-device.png' />

4. If the selected device appears in the <Cmd sid='setting.registerDevices' product='2' /> list, click <Cmd sid='setting.setting' product='2' />.

   <Image src='/img/biostarx-tna-initial-setting-selected-device.png' />

5. When the <Cmd sid='setting.setting' product='2' /> window appears, complete the basic settings for Time & Attendance.

### Set attendance mode

Set the attendance mode and attendance events.

<Image src='/img/biostarx-tna-initial-setting-device-setting.png' />

* <Cmd sid='device.info.mode' product='2' />: Select how to log attendance events.

  * <Cmd sid='device.tna.mode.byUser' product='2' />: Users can select an attendance event during authentication.

  * <Cmd sid='device.tna.mode.bySchedule' product='2' />: Attendance events automatically change based on the schedule you set. You can select a schedule to apply to attendance events.

  * <Cmd sid='device.tna.mode.lastChoice' product='2' />: Users can continue using the last attendance event they used.

  * <Cmd sid='device.tna.mode.fixed' product='2' />: Only the selected attendance event can be used.

  * <Cmd sid='device.tna.mode.unused' product='2' />: Does not log attendance events.

* <Cmd sid='device.info.tnaRequired' product='2' />: Set whether to require logging an attendance event during authentication. Available when <Cmd sid='device.info.mode' product='2' /> is set to <Cmd sid='device.tna.mode.byUser' product='2' />.

* <Cmd sid='device.info.tnaEvent' product='2' />: Edits attendance event names or adds schedules used when <Cmd sid='device.info.mode' product='2' /> is set to <Cmd sid='device.tna.mode.bySchedule' product='2' />.

  * <Cmd sid='device.tna.eventKey' product='2' />: Shows a list of keys you can use to log attendance.

  * <Cmd sid='device.tna.label' product='2' />: Edits attendance event names for each attendance key.

  * <Cmd sid='device.tna.schedule' product='2' />: Set the schedule to switch to automatically when <Cmd sid='device.info.mode' product='2' /> is set to <Cmd sid='device.tna.mode.bySchedule' product='2' />. For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::info

* Devices that do not support an LCD screen can set <Cmd sid='device.info.mode' product='2' /> to <Cmd sid='device.tna.mode.bySchedule' product='2' /> or <Cmd sid='device.tna.mode.fixed' product='2' />. You can log fixed attendance events or attendance events that change based on a preset schedule. 

* These device models support the <Cmd sid='device.tna.mode.bySchedule' product='2' /> and <Cmd sid='device.tna.mode.fixed' product='2' /> modes: XPass Q2, XPass 2, XPass D2, BioEntry W3, BioEntry P2, and BioEntry W2.

* For more information about the <Cmd sid='setting.setting' product='2' /> menu, see <DocLink docId='platform/biostar_x/tna-settings' />.

:::
