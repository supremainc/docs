If an issue occurs in **BioStar X** or you need to revert to a previous state, you can restore it using a system backup file. The restore feature restores the database, settings, and license information to the state at the time of the backup.

## Before you start

Before starting the system restore, check the following.

* The restore cannot proceed if the **BioStar X** version at the time of the backup differs from the current version. To check the version of **BioStar X**, click <IcInfo /> in the upper-right corner of the screen.

  <Image src='/img/biostarx-settings-system-restore-check-ver.png' />

* To check the **BioStar X** version at the time of the backup, extract the backup file and check the `biostarVersion` value in the *sysbackup.conf* file.

* If the SQL Server database and **BioStar X** are installed on different servers, you cannot use **BioStar X** system backup and restore.

* If the restore target server's IP address differs from the backup server's:

  * **BioStar X v1.0.2 or later**: During a restore, BioStar X detects the restore target's IP address and automatically reissues the certificate based on the new IP address. After the certificate is reissued, services that use the certificate automatically reconnect, so no additional action is required.

  * **BioStar X v1.0.1 or earlier**: The restore may fail. Verify the server IP address before proceeding with the restore.

* Even if the encryption key and image log path have changed, the restore uses the current path settings of the target **BioStar X**. If no custom path is set, the restore uses the default path of the target **BioStar X**.

* When you run a restore, the current data is automatically backed up, so even if the restore fails, the system can revert to the state before the restore.

:::info

For more information about creating a system backup, see <DocLink docId='platform/biostar_x/settings-system-system-backup' />.

:::

## System restore

1. In Windows, run <Start/> → **BioStar X** → **BioStar X Restore**.

   > Program path: *C:\Program Files\BioStar X\biostar-restore.exe*

2. Click **Select File**, and then select the backup file to restore.

   <Image src='/img/common/setting-system-restore.png' className='none' alone />

3. To start the restore, click **Restore**.

4. The backup file is validated.

5. When the **You can proceed to restore** message appears, enter the database password and click **Restore**.

   <Image src='/img/common/setting-system-restore-validate.png' className='none' alone />

6. Review the confirmation message, and then click **Restore** to continue the restore.

   <Image src='/img/common/setting-system-restore-confirm.png'  className='none' alone />

7. A message appears showing the restore progress. Wait until the restore is complete.

   <Image src='/img/common/setting-system-restore-continues.png' className='none' alone />

If the **Restore has already been completed** message appears, the restore is complete. Log in to **BioStar X** and verify the restored data.

<Image src='/img/common/setting-system-restore-complete.png' className='none' alone />

:::info

* If the PC shuts down unexpectedly during the restore, run **BioStar X Restore** again to retry the restore.

* If the restore server IP address differs from the backup server IP address and a Multi Communications Server is connected, you must reissue the certificate. For more information about how to reissue the certificate for the Multi Communications Server, see <DocLink docId='platform/biostar_x/change-ip#communicationServer' />.

:::
