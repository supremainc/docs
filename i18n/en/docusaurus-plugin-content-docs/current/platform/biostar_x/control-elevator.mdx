Learn how to control elevators. Use the available features to control elevators or view details.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.arena' />, or select <Cmd sid='shell.header.arena' /> from the shortcut list in the upper-left corner of the screen.

2. In the <Cmd sid='arena.tree.door.title' /> tab in the left sidebar, go to <Cmd sid='arena.tree.door.allElevatorGroups' />. 

3. Select an elevator in the group, and then right-click. Select a feature from the pop-up menu.

:::info

* For more information about setting up elevators and configuring groups, see <DocLink docId='platform/biostar_x/settings-manage-elevators' />.

* To control multiple elevators and floors at once, see <DocLink docId='platform/biostar_x/monitoring-batch-control' />.

:::

## Control Elevators

Clear alarms triggered by the elevator or view details.

<Image src='/img/biostarx-monitoring-door-elevator-popup.png' />

### Clear alarm {/* #clear-alarm */}

Clear alarms triggered by the selected elevator. Click <Cmd sid='arena.tree.contextMenu.clearAlarm' /> in the pop-up menu. A completion message appears in the upper-right corner of the screen.

### View details {/* #detail-view */}

View detailed information about the elevator and the event history. Click <Cmd sid='arena.tree.contextMenu.viewDetail' /> in the pop-up menu. Elevator details and the event history appear in the right pane.

<Image src='/img/biostarx-monitoring-door-elevator-details.png' />

* **Elevator control**: Changes the elevator status to locked or unlocked.

  <Image src='/img/biostarx-monitoring-door-elevator-details-control.png' />

* <Cmd sid='arena.preview.elevator.showFloorsList' />: Shows the list of floors set for the elevator.

  <Image src='/img/biostarx-monitoring-door-elevator-details-floor-list.png' className='none' />

* <Cmd sid='arena.preview.elevator.normalizeAllFloors' />: Available when an administrator has manually unlocked or locked all floors.

* **Elevator details**: Shows the elevator name, location, status, and more.

* <Cmd sid='arena.recentEvent' />: Shows the recent event list for the selected elevator.

:::info

For more information about each entry in the Elevator details section, see <DocLink docId='platform/biostar_x/settings-elevators-add' />.

:::

## Floor access control {/* #floor-access-control */}

Control the floors that the elevator can access. Click the relay for the floor set on the elevator, and then right-click. Select a feature from the pop-up menu.

<Image src='/img/biostarx-monitoring-door-elevator-floor-popup.png' />

### Unlock a floor {/* #floor-open */}

Anyone can access an unlocked floor. Click <Cmd sid='arena.tree.contextMenu.unlock' /> in the pop-up menu, and then select an option.

* <Cmd sid='arena.tree.contextMenu.unlockOnce' />: Unlocks the floor once.

* <Cmd sid='arena.tree.contextMenu.unlockPermanent' />: Unlocks the floor regardless of time.

:::tip

Temporarily unlock the selected floor when external guests visit so they can enter easily. After unlocking a floor, make sure to set it to <Cmd sid='arena.tree.contextMenu.normalize' />.

:::

### Normalize a floor {/* #floor-unlock */}

When you set the selected floor to <Cmd sid='arena.tree.contextMenu.normalize' />, only authorized users can access it. Click <Cmd sid='arena.tree.contextMenu.normalize' /> in the pop-up menu.

### Lock a floor {/* #floor-lock */}

When you set the selected floor to <Cmd sid='arena.tree.contextMenu.lock' />, no one can access it. Click <Cmd sid='arena.tree.contextMenu.lock' /> in the pop-up menu.
