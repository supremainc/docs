Learn how to delete a registered door.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessPoint.root' /> → <Cmd sid='setting.menu.door.root' /> in the left sidebar.

3. In the door list, select the checkbox for the door to delete.

4. Click <Cmd sid='button.deleteDoor' product='2' /> in the upper-right corner of the screen.

   <Image src='/img/biostarx-setting-door-delete.png' />

5. Click <Cmd sid='button.yes' product='2' /> when the confirmation message window appears.

The selected door is deleted. Deleted doors cannot be recovered.

:::info

The <Cmd sid='button.deleteDoor' product='2' /> button is enabled only when you select one or more doors in the door list.

:::
