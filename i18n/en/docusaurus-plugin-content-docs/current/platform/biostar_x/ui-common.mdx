The user interface (UI) of **BioStar X** is designed so you can easily navigate and use the system. Learn about the common UI components of **BioStar X**. This document helps you understand the UI of **BioStar X** and use the system more efficiently.

The header area appears on every page and provides link buttons to access various features of **BioStar X**.

<Image src='/img/biostarx-header.png' />

<Calloutlists>

1. **BioStar X logo**: Returns you to the <Cmd sid='shell.header.launcher' /> page in **BioStar X**.

2. **Shortcuts**: Provides links to key pages in **BioStar X**.

3. <Cmd sid='shell.header.action' />: Runs the **action** feature set by the server user. The action list appears when you click the button. For more information, see <DocLink docId='platform/biostar_x/settings-custom-interface' />.

4. <IcSvTime width='26' height='26' /> **Server time**: Shows the current server time of the running **BioStar X** server. When you hover over the button, the current server time appears.

5. <IcInfo width='26' height='26' /> **Information**: Shows version information for the installed **BioStar X**.

6. <IcHelp width='26' height='26' /> **Help**: A link button that takes you to the **BioStar X** help page.

7. <IcAccount width='26' height='26' /> **Account**: Opens the <Cmd sid='setting.menu.preferences.root' /> menu or lets you change the password of the currently logged-in user.

   * For more information about the <Cmd sid='setting.menu.preferences.root' /> menu, see <DocLink docId='platform/biostar_x/settings-preferences' />.

   * For more information about changing the password of the currently logged-in user, see <DocLink docId='platform/biostar_x/set-permission#changeLoginUserPassword' />.

8. <IcLogout width='26' height='26' /> **Logout**: Ends the session for the currently logged-in user and logs you out.

</Calloutlists>
