You can register devices for Time & Attendance or set sender information for notification emails. You can also set the delimiter used to export T&A reports as CSV.

## Access Time & Attendance settings

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click <IcSet /> <Cmd sid='common.setting' product='2' /> in the left sidebar.

   <Image src='/img/biostarx-tna-access-btn.png' />

3. Set each option.

<Image src='/img/biostarx-tna-settings.png' />

## Time & Attendance settings

### <Cmd sid='setting.devices' product='2' className='normal' />

This is a list of devices that you can use for Time & Attendance. To register a device for Time & Attendance, select the device and click <Cmd sid='setting.register' product='2' />.

<Image src='/img/biostarx-tna-settings-unregister-list.png' />

### <Cmd sid='setting.registerDevices' product='2' className='normal' />

This is a list of devices currently used for Time & Attendance. 

* To unregister a device, select the device and click <Cmd sid='setting.unregister' product='2' />.

  <Image src='/img/biostarx-tna-settings-register-list.png' />

* To edit Time & Attendance settings for a registered device, click <Cmd sid='setting.setting' product='2' />. For more information about attendance settings, see <DocLink docId='platform/biostar_x/settings-device-details-advanced#attendance-management' />.

  <Image src='/img/biostarx-tna-initial-setting-device-setting.png' />

  The <Cmd sid='setting.typeCode' product='2' /> setting maps <Cmd sid='device.tna.eventKey' product='2' /> to attendance event types. Attendance event types are as follows.

  * <Cmd sid='PUNCH_TYPE_CHECK_IN' product='2' />

  * <Cmd sid='PUNCH_TYPE_CHECK_OUT' product='2' />

  * <Cmd sid='PUNCH_TYPE_BREAK_START' product='2' />

  * <Cmd sid='PUNCH_TYPE_BREAK_END' product='2' />

  * <Cmd sid='PUNCH_TYPE_MEAL_START' product='2' />

  * <Cmd sid='PUNCH_TYPE_MEAL_END' product='2' />

:::info

* You can edit a device's Time & Attendance settings only when you are connected to the device.

* If you delete a registered device from the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> menu, the registered Time & Attendance device is also deleted automatically.

* If you set the <Cmd sid='device.info.multiFaceAuth.label' product='2' /> option to <Cmd sid='common.use' product='2' />, you cannot use the device for Time & Attendance. For more information about <Cmd sid='device.info.multiFaceAuth.label' product='2' />, see <DocLink docId='platform/biostar_x/settings-device-details-auth#faceDetectionSettings' />.

:::

### <Cmd sid='setting.export' product='2' className='normal' />

The <Cmd sid='button.downloadToCsv' product='2' /> feature lets you choose the delimiter when exporting T&A reports.

<Image src='/img/biostarx-tna-settings-export-csv.png' />

### <Cmd sid='tna.settings.punchlogs.optionTitle' product='2' className='normal' />

You can set how long to store punch logs. Set the <Cmd sid='tna.settings.punchlogs.storeDays' product='2' /> option to <Cmd sid='common.active' product='2' /> and enter the period. To save the settings, click <Cmd sid='tna.settings.apply' product='2' />.

<Image src='/img/biostarx-tna-settings-save-period.png' />
