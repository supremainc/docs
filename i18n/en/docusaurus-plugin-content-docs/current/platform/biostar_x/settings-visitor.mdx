Configure visitor sites and visitor PCs for visitor management, and set entry terms and guidance text for visitors. You can also add the information you require from visitors by using custom visitor fields.

:::info

* The <Cmd sid="setting.menu.visitor.visitor" /> setting is available as an additional option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* To use the <Cmd sid="setting.menu.visitor.visitor" /> menu, turn on the <Cmd sid="setting.server.automaticUserSync" product='2' /> or <Cmd sid="setting.server.serverMatching.use" product='2' /> option. For more information, see <DocLink docId='platform/biostar_x/settings-server-server' />.

:::

## Visitor settings {/* #settings-visitor */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.visitor.root' /> → <Cmd sid="setting.menu.visitor.visitor" /> in the left sidebar.

3. Follow the instructions below to configure visitor settings.

<Steps>
<Step>

### Visitor site settings {/* #settings-visitor-site */}

Set the access group and whether to use cards on the visit request PC or visitor management PC for each site. If you use cards, you can also set the card type and data format.

<Image src='/img/biostarx-settings-visitor-site-settings.png' className='none' />

* <Cmd sid="setting.server.custom_field.configure.th.name" product='2' />: Enter the site name.

  :::info

  * The site name can be up to 48 characters.

  :::

* <Cmd sid="visitor.accessGroup" product='2' />: Select the access group to assign to the visitor.

  :::info

  If you set up access groups for visitors in advance, management is easier. For more information about access group settings, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />.

  :::

* <Cmd sid="common.card" product='2' /> <Cmd sid="common.use" product='2' />: Select whether to use cards.

* <Cmd sid="user.cardType" product='2' />: Select the card type to use at the site. The card type option is available only when you turn on <Cmd sid="common.card" product='2' /> <Cmd sid="common.use" product='2' />.

* <Cmd sid="user.cardEnrol.cardFormat" product='2' />: Set the format for reading card data. The <Cmd sid="user.cardEnrol.cardFormat" product='2' /> option is available only when you set <Cmd sid="user.cardType" product='2' /> to <Cmd sid="user.cardEnrol.cardTypeWiegand" product='2' />.

To save visitor site settings, click <Cmd sid="visitor.setting.button.apply" product='2' />.

</Step>
<Step>

### Visitor PC settings {/* #settings-visitor-pc */}

Set a visit request PC or a visitor management PC.

<Image src='/img/biostarx-settings-visitor-visit-pc-settings.png' className='none' />

* <Cmd sid="common.name" product='2' />: Enter the name of the visit request PC or visitor management PC.

* <Cmd sid="common.fingerPrint" product='2' /> <Cmd sid="setting.server.enrollment_device.device_name" product='2' />: Select the device to enroll visitors' fingerprints when visitors use fingerprint authentication to access the site.

* <Cmd sid="common.card" product='2' /> <Cmd sid="setting.server.enrollment_device.device_name" product='2' />: Select the device to issue cards when visitors use card authentication to access the site. The card device name option is available only when you set up a site that uses cards.

* <Cmd sid="visitor.site" product='2' />: Select the site to manage visits on this visitor PC.

To save the visitor PC settings, click <Cmd sid="visitor.setting.button.apply" product='2' />.

:::info

* The visitor PC name can be up to 48 characters.

* You can use the fingerprint and card devices at the same time, and you can select one device for each.

* You can select only one site per PC.

:::

</Step>
<Step>

### Select a visitor PC {/* #settings-visitor-assign-pc */}

Select the PC that you set in <Cmd sid="visitor.pc.setting" product='2' /> and assign it to the PC you are using.

<Image src='/img/biostarx-settings-visitor-visit-pc-select.png' className='none' />

To save the settings, click <Cmd sid="visitor.setting.button.apply" product='2' />. 

</Step>
<Step>

### Create a shortcut to the visit request page {/* #settings-visitor-pc-link */}

You can create a shortcut icon for the visit request page on the desktop of the visit request PC. Drag the URL in the <Cmd sid="visitor.link.visitPCKIOSK" product='2' /> entry to the desktop.

<Image src='/img/biostarx-settings-visitor-page-shortcut.png' />

When you open the URL in a web browser, the visit request page appears.

<Image src='/img/biostarx-settings-visitor-welcome-screen.png' />

</Step>

</Steps>

## Set up terms and visitor settings {/* #settings-visitor-terms */}

Manage key visitor settings such as terms of entry, privacy policy, and guidance messages.

<Image src='/img/biostarx-settings-visitor-terms-visitor-settings.png' className='none' />

* **Terms of entry**: Enter the terms of entry and the consent statement. Click <IcEdit /> to activate the input field, and then enter the terms and conditions and the consent statement.

  :::info

  * The terms of entry can be up to 65,535 characters.

  * The consent statement can be up to 64 characters.

  :::

* **Privacy policy**: Enter the policy for handling the personal data that visitors provide during their visit and the consent statement for the policy. Click <IcEdit /> to activate the input field, and then enter the privacy policy and the consent statement for the policy.

  :::info

  * The privacy policy can be up to 65,535 characters.

  * The consent statement for the privacy policy can be up to 64 characters.

  :::

* <Cmd sid="visitor.periodKeepSensitive" product='2' />: Set the retention period for personal data that visitors provide during their visit. Click <IcEdit /> to activate the input field, and then enter the personal data retention period in days.

  :::info

  * In the <Cmd sid="common.visitor" product='2' /> menu, you can delete visitors whose personal and sensitive data retention period has expired.

  :::

* <Cmd sid="visitor.guideAfterRegister" product='2' />: Enter the guidance message that appears in a pop-up when a visitor completes a visit request. Click <IcEdit /> to activate the input field, and then enter the guidance message.

  :::info

  * The guidance message shown after a visit request is completed can be up to 65,535 characters.

  * If you do not enter a guidance message, the pop-up does not appear after a visit request is completed.

  :::

* <Cmd sid="visitor.defaultActivePeriod" product='2' />: Set how long visitors are allowed access. Click <IcEdit /> to activate the input field, and then enter the default visitor access period in days.

## Set custom visitor fields {/* #settings-visitor-custom-field */}

You can add fields for entering additional visitor information, and the added fields appear on the visit request page.

<Image src='/img/biostarx-settings-visitor-custom-visitor-field.png' className='none' />

* <Cmd sid="setting.server.custom_field.configure.th.order" product='2' />: Set the order of the custom input fields.

* <Cmd sid="setting.server.custom_field.configure.th.name" product='2' />: Set the name of the custom input field.

* <Cmd sid="setting.server.custom_field.configure.th.type" product='2' />: Select Text Input Box, Number Input Box, or Combo Box.

* <Cmd sid="setting.server.custom_field.configure.th.data" product='2' />: Enter the options to show in the combo box list. Each option is separated by a semicolon (;). The Data field is available only when <Cmd sid="setting.server.custom_field.configure.th.type" product='2' /> is set to <Cmd sid="setting.server.custom_field.type.combobox" product='2' />.

To save the settings, click <Cmd sid="visitor.setting.button.apply" product='2' />.

:::info

* A custom visitor field added as <Cmd sid="setting.server.custom_field.type.textbox" product='2' /> accepts numbers and characters.

* A custom visitor field added as <Cmd sid="setting.server.custom_field.type.numericbox" product='2' /> accepts only numbers, and it does not accept characters.

* In a custom visitor field added as <Cmd sid="setting.server.custom_field.type.combobox" product='2' />, visitors select an option. To set a custom visitor field, enter **Option 1**; **Option 2**; **Option 3**; **Option 4** in the data field.

:::
