Learn how to select multiple doors, elevators, and advanced access control settings and run commands such as unlock, lock, or clear alarm.

* If you select two or more entries in the status tree, the batch control panel appears on the right side of the screen. Commands run in one action, so you do not need to control each entry individually.

* This lets you respond quickly during an emergency or when you need to control multiple entrances at the same time.

* Batch control supports doors, elevators (floors), and advanced access control settings. Batch control is not available when you select mixed types.

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.arena' />, or select <Cmd sid='shell.header.arena' /> from the shortcut list in the upper-left corner of the screen. If you select two or more entries in the status tree in the left sidebar, the batch control panel appears on the right side of the screen.

<Image src='/img/biostarx-monitoring-batch-main.png' />

:::info

* Cameras are not included in batch control. Even if you select them with other entries, they are removed from the selection list.

* This page covers how to control multiple entries at once. To control a single door, elevator, or advanced access control setting, see the following document.

## Select multiple entries {/* #select-multiple */}

To select doors, elevators, floors, or advanced access control in the status tree in the left sidebar, do the following. This works the same way as selecting multiple files in Windows File Explorer.

* **Click**: Selects one entry. This clears the previous selection.

* **<Kbd>Ctrl</Kbd> + Click**: Adds the clicked entry to the selection list or removes it from the list. This keeps the remaining selection.

* **<Kbd>Shift</Kbd> + Click**: Selects the visible range from the last clicked entry to the current entry. This replaces the current selection with this range.

* **<Kbd>Ctrl</Kbd> + <Kbd>Shift</Kbd> + Click**: Adds a range without clearing the current selection. Use this to select multiple nonadjacent entries.

* **Click a group**: Click a group (<IcGroup />) name to select all doors, elevators, floors, and advanced access control settings under it at once. To expand or collapse a group, click the arrow (<IcBw />) before the group name.

:::info

The batch control panel does not open when no entries are selected or when only one entry is selected. When only one entry remains selected, the details view for the entry appears, and when all selections are cleared, the right pane disappears.

:::

## Batch door control {/* #bulk-door */}

When you select only two or more doors, the same basic and advanced controls as for single-door control are available.

<Column className='padding--l40'>

**Basic control**

* <Cmd sid='monitoring.multiControl.once3sec' />: Applies the unlocked state once.

* <Cmd sid='monitoring.multiControl.timed' />: Keeps the locked or unlocked state for the entered time.

* <Cmd sid='monitoring.multiControl.permanent' />: Sets the locked or unlocked state regardless of time.

Select the command to apply, and click <Cmd sid='common.apply' />.

**Advanced control**

The following buttons are available when at least one selected entry meets the conditions below.

* <Cmd sid='monitoring.multiControl.clearAlarm' />: Available when at least one selected door has an active alarm.

* <Cmd sid='monitoring.multiControl.clearApb' />: Available when at least one selected door has anti-passback enabled. For more information, see <DocLink docId='platform/biostar_x/control-door#apb-reset' />.

* <Cmd sid='monitoring.multiControl.normalizeOverrides' />: Available when at least one selected door was manually unlocked or locked by an administrator. This excludes statuses changed by schedules or emergency situations.

* <Cmd sid='monitoring.multiControl.arm' />/<Cmd sid='monitoring.multiControl.disarm' />: Appears only when at least one door is set to intrusion alarm, an advanced access control setting.

</Column>
</Columns>

:::info

* When you click <Cmd sid='monitoring.multiControl.clearAlarm' /> or <Cmd sid='monitoring.multiControl.normalizeOverrides' />, a pop-up appears. To clear it, you must click <Cmd sid='monitoring.multiControl.clearAlarm' /> or <Cmd sid='monitoring.multiControl.normalizeOverrides' /> in the pop-up. In contrast, <Cmd sid='monitoring.multiControl.arm' />/<Cmd sid='monitoring.multiControl.disarm' /> switches the status without a confirmation dialog.

* Advanced access control settings are available by purchasing an add-on with an **Essential** license, or with an **Enterprise** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

## Batch control for elevators and floors {/* #bulk-elevator */}

Select an elevator to control all configured floors together. To control only specific floors, select the floors directly.

The differences from doors are as follows.

| Control feature | Door | Elevator, floor |
| --- | --- | --- |
| <Cmd sid='monitoring.multiControl.unlock' /> | <Cmd sid='monitoring.multiControl.once3sec' />, <Cmd sid='monitoring.multiControl.timed' />, <Cmd sid='monitoring.multiControl.permanent' /> | <Cmd sid='monitoring.multiControl.once3sec' />, <Cmd sid='monitoring.multiControl.permanent' /> |
| <Cmd sid='monitoring.multiControl.lock' /> | <Cmd sid='monitoring.multiControl.timed' />, <Cmd sid='monitoring.multiControl.permanent' /> | <Cmd sid='monitoring.multiControl.permanent' /> |
| <Cmd sid='monitoring.multiControl.normalizeOverrides' /> | Supported | Supported |
| <Cmd sid='monitoring.multiControl.clearAlarm' /> | Supported | Appears when the selection includes an elevator; does not appear when only floors are selected |
| <Cmd sid='monitoring.multiControl.clearApb' /> | Supported | Not supported |

:::info

If you select an elevator and its floors and then unlock or lock them, the system sends one command per elevator, not one per floor.

:::

## Batch control of advanced access control {/* #bulk-acs */}

Select multiple advanced access control settings to control them at once. When you select two or more, the right pane switches to the batch control panel. Selection, range, and filter actions are the same as for doors and elevators.

Advanced access control settings do not have lock relays or administrator unlock/lock concepts, so their control options differ from doors and elevators. The following control buttons appear depending on the selected setting type.

<Image src='/img/biostarx-monitoring-acs-batch-control.png' />

* <Cmd sid='arena.tree.contextMenu.enable' />/<Cmd sid='arena.tree.contextMenu.disable' />: Appears for all advanced access control settings.

* <Cmd sid='monitoring.multiControl.arm' />/<Cmd sid='monitoring.multiControl.disarm' />: Appears only when the selection includes an intrusion alarm setting.

* <Cmd sid='monitoring.multiControl.clearAlarm' />: Appears only when the selection includes alarm-triggering settings (anti-passback, fire alarm, schedule lock, intrusion alarm, interlock, or muster). Does not appear when only non-alarm settings are selected, such as Occupancy limit or Headcount check.

* <Cmd sid='monitoring.multiControl.clearApb' />: Appears only when the selection includes the anti-passback setting. Clicking this button opens a user selection window, where you can clear the APB alarm for users who violated anti-passback. For more information, see <DocLink docId='platform/biostar_x/control-zone#apb-release' />.

:::info

* Batch control does not include <Cmd sid='monitoring.multiControl.lock' />, <Cmd sid='monitoring.multiControl.unlock' />, or <Cmd sid='monitoring.multiControl.normalizeOverrides' />. The batch control panel also does not provide features that open other screens, such as checking muster reports or monitoring occupancy limits. These features are available on the details screen when one setting is selected.

* For more information about advanced access control, see <DocLink docId='platform/biostar_x/control-zone' />.

:::

## Check execution results {/* #result */}

* If all selected entries succeed, a success message appears at the top of the screen.

  <Image src='/img/biostarx-monitoring-doors-control-success.png' caption />

* If any entry fails, a failure message appears with the <Cmd sid='arena.batchResult.showDetails' /> button.

  <Image src='/img/biostarx-monitoring-doors-control-fail.png' caption />

  Click <Cmd sid='arena.batchResult.showDetails' /> to view results grouped into <Cmd sid='arena.batchResult.successChip' />, <Cmd sid='arena.batchResult.failChip' />, and <Cmd sid='arena.batchResult.skippedChip' />. To copy the names and reasons for failed entries to the clipboard, click <Cmd sid='arena.batchResult.copyFailList' />.

  <Image src='/img/biostarx-monitoring-doors-control-fail-details.png' caption />
