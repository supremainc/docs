Integrate the [Airfob Portal](https://portal.airfob.com/) so you can issue or delete mobile access cards for users in **BioStar X**.

Users can receive a mobile access card through a link sent by email without signing up for the Airfob Portal or enrolling a mobile access card separately.

:::info

* Mobile access cards can use either **CSN Mobile** or **Template on Mobile**, but not both.

* The following devices and firmware versions support the **CSN Mobile** card.

  <details>
  <summary>View devices and firmware versions that support the **CSN Mobile** card</summary>

  * BioStation 3 Max firmware v1.0.0 or later

  * XPass Q2 firmware v1.0.0 or later

  * BioEntry W3 firmware v1.0.0 or later

  * BioStation 3 firmware v1.0.0 or later

  * X-Station 2 firmware v1.0.0 or later

  * FaceStation F2 firmware v1.0.0 or later

  * XPass 2 firmware v1.1.0 or later

  * FaceLite firmware v1.2.0 or later

  * BioLite N2 firmware v1.3.0 or later

  * XPass D2 (Rev 2) firmware v1.4.0 or later

  * FaceStation 2 firmware v1.4.0 or later

  * BioEntry W2 (Rev 2) firmware v1.6.0 or later

  * BioStation A2 firmware v1.8.0 or later (NFC-supported model)

  * BioStation 2 firmware v1.9.0 or later (NFC-supported model)

  </details>

* The following devices and firmware versions support **Template on Mobile**.

  * BioStation 3 Max firmware v1.0.0 or later

  * BioEntry W3 firmware v1.0.0 or later

  * BioStation 3 firmware v1.2.0 or later

:::

To use Suprema mobile access cards, you must sign up for the Airfob Portal and create a site. After you sign up for the Airfob Portal, you can manage mobile access cards in **BioStar X**.

<Steps>
<Step>

## Sign up for the Airfob Portal and create a site {/* #airfob-portal-setup */}

In Airfob Portal, set up mobile access cards and registered devices, and manage sites and credits.

1. Go to the [Airfob Portal](https://portal.airfob.com/).

2. To sign up and create a site, click **Get Started**.

3. In the email field, enter the email address of the Airfob Portal administrator, and then click **Get Started**. A verification code is sent to the email address you entered.

4. In the verification code field, enter the verification code sent to your email, and then click **Confirm**.

   :::note

   The verification code is a 6-digit number.

   :::

5. Review the privacy policy and terms, and then click **Agree**.

6. Set a password and nickname for the Airfob Portal, and then click **Create Account**. Your account is created.

7. After your account is created, click **Sign In**.

8. Enter your email and password, and then click **Sign In**.

9. To create a site, click **Create Site**.

   :::note

   **Site** refers to the organization or company using mobile access cards.

   :::

10. Set the site name and country, and then click **Next**.

11. Select the site type.

    <SiteType />

12. Click **Create**. The site is created.

13. To open the Airfob Portal for the site, click the site name.

:::info

For more information about using the Airfob Portal, see the [Airfob Support Center](https://airfob.zohodesk.com/portal/home).

:::

</Step>
<Step>

## Set up mobile access cards in BioStar X {/* #biostar-x-mobile-access-setup */}

Set whether to use mobile access cards, and manage the settings for Airfob Portal integration. You can also register devices that use mobile access cards.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.mobileAccess' /> in the left sidebar.

3. Set each option.

   <Image src='/img/biostarx-settings-credentail-mobile-access.png' />

   * <Cmd sid='setting.mobileCredential.setting' product='2' />: Set whether to use mobile access cards. When this option is set to <Cmd sid='common.use' product='2' />, you can issue mobile access cards to users.

   * <Cmd sid='setting.mobileCredential.siteId' product='2' />: Enter the site ID created in the Airfob Portal. You can find the site ID in the Airfob Portal under **Settings** → **Site**.

   * <Cmd sid='setting.mobileCredential.email' product='2' />: Enter the email address of the mobile access card administrator account.

   * <Cmd sid='setting.mobileCredential.password' product='2' />: Enter the password of the mobile access card administrator account.

4. After you complete all settings, click <Cmd sid='setting.mobileCredential.connect' product='2' />.

:::info

To use mobile access cards in **BioStar X**, first complete Airfob Portal sign-up and initial setup. For more information, see <DocLink inner='#airfob-portal-setup' />.

:::

</Step>
<Step>

## Register a device {/* #registerDevice */}

You can register devices that use mobile access cards in the Airfob Pass application or directly in **BioStar X**.

<Image src='/img/biostarx-settings-credentail-mobile-access-connection.png' />

After you complete the Airfob Portal integration settings, click <Cmd sid='setting.mobileCredential.connect' product='2' />. The <Cmd sid='setting.mobileCredential.registerDeviceTable' product='2' /> option becomes available.

1. To add a device that uses mobile access cards, click <Cmd sid='button.addplus' product='2' />.

   <Image src='/img/biostarx-settings-credentail-mobile-access-register-device.png' />

2. In the device list of the <Cmd sid='setting.mobileCredential.registerDeviceTable' product='2' /> window, select the checkbox for each device that uses mobile access cards.

   <Image src='/img/biostarx-settings-credentail-mobile-access-register-device-popup.png' />

3. After you select all devices, click <Cmd sid='button.add' product='2' />.

The device list shows the added devices.

* To resend the mobile access card certificate, click <IcRefresh />.

* To delete a registered device, click <IcTrash2 />.

:::info

* The following devices and firmware versions support mobile access cards.

  * BioStation 3 Max firmware v1.0.0 or later

  * XPass Q2 firmware v1.0.0 or later

  * BioEntry W3 firmware v1.0.0 or later

  * BioStation 3 firmware v1.0.0 or later

  * X-Station 2 firmware v1.0.0 or later

  * FaceStation F2 firmware v1.0.0 or later

  * XPass 2 firmware v1.1.0 or later

  * FaceLite firmware v1.2.0 or later

  * BioLite N2 firmware v1.3.0 or later

* You can also register devices using the Airfob Pass application.

* If you delete a registered device, BioStar X also deletes the mobile access card certificate sent to the device.

:::
