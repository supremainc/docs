Based on your organization's security policy, you can set different **BioStar X** operational privileges and access permissions for each user. You can restrict access to key menus through administrator levels and control access to physical spaces through access groups. You can also strengthen security through IP address restrictions and multi-factor authentication.

Go to the <Cmd sid='shell.header.launcher' /> → <Cmd sid='shell.header.user' /> page, and set access permissions using the two methods below.

In the <Cmd sid='team.user.permission.title' /> section, you can set the following options. See the description for each option, and set the appropriate user permissions.

## Select administrator level {/* #operatorLevel */}

The menus you can access are limited based on the administrator level. In the <Cmd sid='team.user.permission.title' /> section, select the user's administrator level under <Cmd sid='user.bioStarOperator' product='2' />. See the list below for the administrator levels you can assign to users.

import AccountList from '../../common/_account-list.mdx';

<AccountList />

### Set login ID and password

If you selected an administrator level, you must set the ID and password the user uses to log in to **BioStar X**.

<Image src='/img/biostarx-new-user-permission-set-login.png' />

:::info

**Notes for setting an ID and password**

* Set the ID to a combination of letters, numbers, and periods (`.`), from 8 to 32 characters long. Do not use single quotes (`'`).

* For more information about configuring password policies, see <DocLink docId='platform/biostar_x/settings-system-security#password-policy-configuration' />.

* Avoid using weak passwords.

  * Consecutive letters or numbers (for example, abcd, 1234)

  * Common words or patterns (for example, qwerty, password)

:::

### Change the logged-in user's password {/* #changeLoginUserPassword */}

The user can change their password after logging in to **BioStar X**.

1. Log in to **BioStar X**.

2. Click <IcAccount width='26' height='26' /> in the upper-right corner of the screen.

   <Image src='/img/biostarx-user-account-popup.png' />

3. Click <Cmd sid='auth.passwordChange.title' /> in the drop-down menu.

4. When the <Cmd sid='auth.passwordChange.title' /> window appears, enter the current password and a new password.

   <Image src='/img/biostarx-user-change-pw.png' />

5. After you enter all fields, click <Cmd sid='common.button.change' />.

## Set up multi-factor authentication {/* #multiFactorAuth */}

Turning on <Cmd sid='common.fingerprintLogin' product='2' /> lets users add fingerprint authentication when they log in to **BioStar X**.

:::info

For more information about configuring **multi-factor authentication**, see <DocLink docId='platform/biostar_x/login-with-mfa' />.

:::

## Set up login with a user's IP address {/* #userIp */}

If you register the user's IP address, the user can log in to the PC only when it matches the account IP address. This strengthens security. In the <Cmd sid='team.user.permission.title' /> section, enter the user's IP address in the <Cmd sid='team.user.permission.userIp' /> field.

:::info

* IP addresses can be entered in the format xxx.xxx.xxx.xxx, and each octet must be a number from 0 to 255.

* If no IP address is registered, PC login is allowed regardless of IP address information.

:::

## Select an access group {/* #accessGroup */}

Set the user's access group to restrict access by organization or department. In the <Cmd sid='team.user.permission.title' /> section, select an access group in the <Cmd sid='team.user.permission.accessGroup' /> field.

:::info

For more information about adding and configuring access groups, see <DocLink docId='platform/biostar_x/settings-access-control-manage-access-group' />.

:::
