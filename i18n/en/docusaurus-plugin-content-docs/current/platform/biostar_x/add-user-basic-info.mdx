Learn how to enter a user's basic information in detail. The system uses the user information you enter for search and management. Managing user information clearly helps you comply with your organization's security policies and privacy policies.

* Systematically entering basic information such as name, department, job title, and group lets you easily search for, categorize, and manage users.

* You can set more granular access permissions based on the user's department, job title, and group information.

* This helps security and auditing because you can accurately track each user's activity history and access logs.

Go to the <Cmd sid='shell.header.launcher' /> → <Cmd sid='shell.header.user' /> page, and enter user information in one of the two ways below.

The fields you can set in the <Cmd sid='team.user.information' /> section are as follows. Enter user information based on the description for each field.

<Image src='/img/biostarx-new-user-information.png' />

* **Photo**: Add a photo of the user. You can take a photo with a webcam or upload a photo from your PC. When you hover over the profile, available tools appear.

  <Columns>
  <Column className='width--20'><Image src='/img/common/biostarx-new-user-photo.png' alone /></Column>
  <Column className='padding--l10'>

  * <IcCamera/>: Takes a photo with the webcam connected to your PC and adds it.

  * <IcUpload/>: Uploads an image file saved on your PC.

  For more information, see <DocLink docId='platform/biostar_x/enroll-credential-face#erollbywebcambyphoto' />.

  </Column>
  </Columns>

* <Cmd sid='team.user.table.id' />: Enter a unique ID to assign to the user.

* <Cmd sid='team.user.table.name' />: Enter the user's name.

* <Cmd sid='team.user.table.email' />: Enter the email address.

* <Cmd sid='team.user.table.phone' />: Enter the phone number.

* <Cmd sid='team.user.table.department' />: Enter the user's department.

* <Cmd sid='team.user.table.title' />: Enter the user's job title.

* <Cmd sid='team.user.table.group' />: Select the user's group. For more information about adding and managing user groups, see <DocLink docId='platform/biostar_x/user-group-manage' />.

* <Cmd sid='team.user.table.period' />: Set the period for using the user account. Click the date and time area to enter values directly, or click <IcCalc /> to select a date and time.

* <Cmd sid='team.user.table.status' />: Set this to temporarily deactivate the user account.

To save the basic information you entered, click <Cmd sid='user.save' product='2' /> in the upper-right corner of the screen.

:::info

* Values you can set for <Cmd sid='team.user.table.id' /> depend on the <Cmd sid="setting.userDevice.useridType" product='2' /> option in the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.server.server' /> menu. For more information, see <DocLink docId='platform/biostar_x/settings-server-server#userid-type' />.

  * <Cmd sid="setting.userDevice.useridType.numeric" product='2' />: Enter a number from 1 to 4294967294.

  * <Cmd sid="setting.userDevice.useridType.alphanumeric" product='2' />: Enter a combination of letters and numbers.

* To display the user's photo, department, and position on the mobile access card, make sure to add a photo and enter the department and position.

* Position and department names support up to 64 characters, including the special symbols `space` and `_`.

* If you use a mobile access card, enter the user's email when you send the card by email.

* To use face mobile enrollment or BioStar X QR, enter the user's email address.

:::

:::tip

To enter additional user information beyond the default input fields provided by **BioStar X**, add custom fields using the <Cmd sid='team.userTemplate.table.customField' /> feature. <Cmd sid='team.userTemplate.table.customField' /> is a useful feature for extending user information to meet your organization's requirements.

For more information about adding <Cmd sid='team.userTemplate.table.customField' />, see <DocLink docId='platform/biostar_x/settings-server-server#custom-field' />.

:::
