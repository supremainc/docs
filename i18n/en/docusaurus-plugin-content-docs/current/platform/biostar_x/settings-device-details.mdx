Learn how to set up and manage the detailed features of registered devices. You can set details such as device information, network, authentication, and advanced settings. The details may vary depending on the RS-485 connection method or device type.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.device' /> in the left sidebar.

3. In the device list, click the device to set details for.

4. Set device information by referring to the details in each section.

   * <Cmd sid='device.info.information' product='2' />: Lets you view and change the device name, group, time zone, and hardware and firmware versions. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-info' />.

   * <Cmd sid='device.info.network' product='2' />: Lets you set up the device network, including TCP/IP, RS-485, and server communication. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-network' />.

   * <Cmd sid='device.info.authentication' product='2' />: Lets you set up options related to user authentication for the device. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-auth' />.

   * <Cmd sid='device.info.advanced' product='2' />: Lets you set up the master administrator, device administrators, display/sound, triggers and actions, and more. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-advanced' />.

   * <Cmd sid='device.info.temperMask' product='2' /> / <Cmd sid='device.info.mask' product='2' />: Lets you set up details for using a thermal camera and mask detection. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-thermal-mask' />.

   * <Cmd sid='device.info.interphone' product='2' />: Lets you set up details for Intercom use. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-interphone' />.

   * <Cmd sid='device.info.rtsp' product='2' />: Lets you set up details for **Real Time Streaming Protocol** (RTSP) streaming. For more information, see <DocLink docId='platform/biostar_x/settings-device-details-rtsp' />.

5. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* You can also edit information for multiple devices at once. Select two or more devices, then click <Cmd sid='button.batchEdit' product='2' /> in the upper-right corner of the screen.

  <Image src='/img/biostarx-setting-device-batch-edit.png' />

* Depending on the selected device type, the details that appear in the <Cmd sid='device.batchEdit' product='2' /> window may vary.

* If you select a master device and slave devices at the same time and click Batch Edit, you can change only some options in <Cmd sid='device.info.authentication' product='2' /> and <Cmd sid='device.info.displaySound' product='2' />.

* <Cmd sid='device.info.authenticationMode' product='2' /> can be batch edited only when you select devices with the same model name.

:::
