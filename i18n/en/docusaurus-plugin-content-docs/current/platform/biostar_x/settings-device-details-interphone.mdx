In the <Cmd sid='device.info.interphone' product='2' /> section, set detailed options for using Intercom.

:::info

* This feature is supported on the BioStation 3 Max, BioStation 3, FaceStation 2, and BioStation A2 models.

* If you made changes, click <Cmd sid='button.apply' product='2' />. Unsaved changes are not applied to the device.

:::

## Intercom settings {/* #ip-interphone-settings */}

Set each option to register the device with the **Session Initiation Protocol** (SIP) server.

<Image src='/img/biostarx-setting-device-edit-ipinterphone.png' />

* <Cmd sid='device.info.interphone' product='2' />: To use the device as an Intercom, set this to <Cmd sid='device.info.enabled' product='2' />.

* <Cmd sid='device.intercom.ipAddr' product='2' />: Enter the SIP server address.

* <Cmd sid='device.intercom.port' product='2' />: Enter the SIP server port. The default is 5060.

* <Cmd sid='device.intercom.account.new' product='2' />: Enter the username for the SIP account.

* <Cmd sid='device.intercom.password.new' product='2' />: Enter the password for the SIP account.

* <Cmd sid='device.intercom.authorization.id' product='2' />: Enter the authorization ID for the SIP account.

* <Cmd sid='device.intercom.registration.duration' product='2' />: Enter the registration duration in seconds. The device tries to register with the SIP server each time the registration duration expires.

* <Cmd sid='device.intercom.doorOpenButton' product='2' />: Specify a button that can unlock the door during a call.

* <Cmd sid='device.intercom.transport' product='2' />: Select the SIP transport method when you set up SIP server settings for Intercom.

* <Cmd sid='device.intercom.outbound.proxy.server' product='2' />: Set this to <Cmd sid='device.info.enabled' product='2' /> to use SIP services through a separate (outbound) proxy server.

  * <Cmd sid='device.intercom.outbound.proxy.server.ipAddress' product='2' />: Enter the outbound proxy server address.

  * <Cmd sid='device.intercom.outbound.proxy.server.port' product='2' />: Enter the outbound proxy server port.

* <Cmd sid='device.intercom.resolution' product='2' />: Select the resolution of the video output when you use Intercom. The default is <Cmd>360 x 640</Cmd>.

* <Cmd sid='device.intercom.extension.display' product='2' />: To hide extension numbers on the device, set this to <Cmd sid='device.info.disable' product='2' />. If extension numbers are hidden, you cannot tell recipients apart on the call screen.

* <Cmd sid='device.intercom.extension' product='2' />: Register up to 128 extension numbers. To add or edit extension numbers, click <Cmd sid='device.intercom.extension.editBtn' product='2' />. For more information, see <DocLink inner='#edit-extension' />.

:::info

* The <Cmd sid='device.intercom.account.new' product='2' /> and <Cmd sid='device.intercom.authorization.id' product='2' /> options accept only numbers, English letters (case-sensitive), and special characters.

* The <Cmd sid='device.intercom.registration.duration' product='2' /> option can be set from 60 seconds to 600 seconds.

* The <Cmd sid='device.intercom.transport' product='2' /> and <Cmd sid='device.intercom.resolution' product='2' /> options are supported on firmware v1.3.0 or later of BioStation 3.

* **Session Initiation Protocol** (SIP) is an internet protocol-based communication protocol for multimedia communications such as VoIP and video conferencing. A SIP server manages these communications and establishes connections.

:::

## Edit extension numbers {/* #edit-extension */}

Learn about the features available in the <Cmd sid='device.intercom.extension.popup.title' product='2' /> window.

<Image src='/img/biostarx-setting-device-edit-ipinterphone-extension.png' />

* <Cmd sid='device.intercom.extension.popup.sendToTop' product='2' />: Moves the selected extension number to the top of the list.

* <Cmd sid='device.intercom.extension.popup.csvImport' product='2' />: Imports a CSV file that contains extension numbers.

* <Cmd sid='device.intercom.extension.popup.csvExport' product='2' />: Exports the saved extension numbers to a CSV file.

* <Cmd sid='device.intercom.extension.popup.add' product='2' />: Adds an extension number.

* <Cmd sid='device.intercom.extension.popup.delete' product='2' />: Deletes an extension number.

* <Cmd sid='device.intercom.list.reorder' product='2' />: Changes the order of extension numbers by dragging them with the mouse.

:::info

* The FaceStation 2 and BioStation A2 models can save up to 16 extension numbers.

* You cannot import a CSV file that contains more extension numbers than the maximum supported.

* Extension numbers can include only numbers, English letters (case-sensitive), and special characters.

:::
