Learn how to register a new user. Enter information such as the user's photo, name, email, and phone number, and set the user's access permissions and biometric information.

Follow this order: enter user information and set access permissions, then enroll credentials.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <Cmd sid='team.user.newUser' /> in the upper right corner of the <Cmd sid='shell.header.user' /> page.

   <Image src='/img/biostarx-user-add-user-01.png' />

3. Enter user information on the <Cmd sid='user.addNewUser' product='2' /> screen.

   <Image src='/img/biostarx-user-add-user-02.png' />

4. Enter the user's basic information in the <Cmd sid='team.user.information' /> section.

5. Enroll the user's biometric information in the <Cmd sid='team.user.credential.title' /> section.

6. In the <Cmd sid='team.user.permission.title' /> section, set the user's **BioStar X** operational permissions and access permissions.

7. In the <Cmd sid='common.advanced' product='2' /> section, you can enter a message to show on the device when the user requests access.

8. Enter all information and click <Cmd sid='user.save' product='2' /> in the upper-right corner of the screen.

The registered user appears in the user list. For more information about entries and settings by section, see below.

:::info

* Access permissions and biometric information are optional. You can add or edit them after you enter and save the basic information.

* To print user information as a card using the card template, click <Cmd sid="button.printCard" product='2' /> in the upper-right corner of the screen. For more information, see <DocLink docId='platform/biostar_x/settings-card-printer' />.

* Click <Cmd sid="button.cancel" product='2' /> in the upper-right corner of the screen to cancel user registration.

:::
