Learn how to control doors. You can lock a door for a set time, view the camera linked to the door, and clear alarms that occur.

* Control doors remotely to manage access. You can unlock or lock the door for a set time.

* The linked camera provides real-time monitoring of access activity.

* The [anti-passback](../../reference/glossary#apb) feature prevents unauthorized access and manages access logs accurately.

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.arena' />, or select <Cmd sid='shell.header.arena' /> from the shortcut list in the upper-left corner of the screen. Select the door to control, and then right-click. Select a feature from the pop-up menu.

<Image src='/img/biostarx-monitoring-door-popup.png' />

:::info

* To monitor or control door status, the <Cmd sid='setting.server.logUploadType' product='2' /> feature must be turned on. Turn on this feature in the <Cmd sid='common.general' product='2' /> section under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.server.server' />.

* To use the <Cmd sid='arena.tree.contextMenu.openVideo' /> option, the VMS must be integrated, and the door and camera must be linked. Additionally, this feature is available through an add-on option with an **Essential** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* To control multiple doors at once, see <DocLink docId='platform/biostar_x/monitoring-batch-control' />.

:::

## Unlock door {/* #door-open */}

Anyone can access an unlocked door. Click <Cmd sid='arena.tree.contextMenu.unlock' /> in the pop-up menu, and then select an option.

<Image src='/img/biostarx-monitoring-door-popup.png' />

* <Cmd sid='arena.tree.contextMenu.unlockOnce' />: Unlocks the door once.

* <Cmd sid='arena.tree.contextMenu.unlockTimed' />: Unlocks the door for a set time. Enter the time in seconds.

* <Cmd sid='arena.tree.contextMenu.unlockPermanent' />: Unlocks the door permanently.

Temporarily unlocking the door changes the door relay icon from <IcFixedLock title='Lock' height='20' width='20' /> to <IcFixedUnlock title='UnLock' height='20' width='20' />. Unlocking the door with the <Cmd sid='arena.tree.contextMenu.lockTimed' /> or <Cmd sid='arena.tree.contextMenu.lockPermanent' /> option changes the icon to <IcFixedUnlock height='20' width='20' />.

:::tip

Temporarily unlock the door when guests visit so they can enter easily. After you unlock the door, make sure to set it to <Cmd sid='arena.tree.contextMenu.normalize' />.

:::

## Normalize door {/* #door-unlock */}

When you set the door to <Cmd sid='arena.tree.contextMenu.normalize' />, only authorized users can access it. Click <Cmd sid='arena.tree.contextMenu.normalize' /> in the pop-up menu.

<Image src='/img/biostarx-monitoring-door-popup-normalize.png' />

## Lock door {/* #door-lock */}

When you set the door to <Cmd sid='arena.tree.contextMenu.lock' />, nobody can access it. Click <Cmd sid='arena.tree.contextMenu.lock' /> in the pop-up menu, and then select an option.

<Image src='/img/biostarx-monitoring-door-popup-lock.png' />

* <Cmd sid='arena.tree.contextMenu.unlockTimed' />: Locks the door for a set time. Enter the time in seconds.

* <Cmd sid='arena.tree.contextMenu.lockPermanent' />: Changes the door to a locked state regardless of time.

Locking the door changes the door relay icon to <IcFixedLock width='20' height='20' />.

## Check door camera {/* #door-camera */}

You can view the camera linked to the door. Click <Cmd sid='arena.tree.contextMenu.openVideo' /> in the pop-up menu. You can add footage from the selected camera to a video tile in the <Cmd sid='shell.header.arena' /> section and play it.

<Image src='/img/monitoring-door-control-open-video.png' />

Alternatively, select a camera and right-click it. To add footage from the selected camera and play it, click <Cmd sid='arena.tree.contextMenu.openVideo' /> in the pop-up menu.

<Image src='/img/monitoring-door-camera-control-open-video.png' />

:::info

* If there is more than one camera linked to the door, the first linked camera appears in the video tile.

* Videos are added to the video tiles in order, starting in the upper-left corner of the screen; if the current screen has no space, an error message appears.

* For more information about video monitoring, see <DocLink docId='platform/biostar_x/monitoring-video' />.

* If the camera linked to the door is not visible, check the camera group permissions. If an administrator with custom permissions has not set camera group permissions, cameras might not appear. For more information about setting camera group permissions, see <DocLink docId='platform/biostar_x/settings-videos-camera#addCameraPermission' />.

* This feature is available by purchasing add-on options with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

## Clear alarm {/* #alarm-reset */}

You can clear an alarm that occurred at the door. Click <Cmd sid='arena.tree.contextMenu.clearAlarm' /> in the pop-up menu. An alarm message appears in the upper-right corner of the screen.

<Image src='/img/biostarx-monitoring-door-popup-clear-alarm.png' />

## Clear anti-passback {/* #apb-reset */}

When an anti-passback violation occurs, you can clear the APB alarm. 

1. Click <Cmd sid='arena.tree.contextMenu.clearApb' /> in the pop-up menu. 

   <Image src='/img/biostarx-monitoring-door-popup-clear-apb.png' />

2. When the <Cmd sid='arena.tree.contextMenu.clearApb' /> window appears, it shows a list of all users.

   <Image src='/img/monitoring-door-monitoring-disable-apb.png' />

3. Select the user who violated anti-passback and click <Cmd sid='common.apply' />.

A completion message appears in the upper-right corner of the screen.

:::info

* <Glossary termid='apb'/>

* For more information about setting up **anti-passback** for a door, see <DocLink docId='platform/biostar_x/settings-door-add#antipassback' />.

:::

## Arm and disarm

If arming is set up for the door, you can arm or disarm it. Click <Cmd sid='arena.tree.contextMenu.arm' /> or <Cmd sid='arena.tree.contextMenu.disarm' /> in the pop-up menu.

<Image src='/img/biostarx-monitoring-door-arm-status.png' />

When a door is armed, its arm status icon changes from <IcDisarm title='Disarm' width='20' height='20' /> to <IcArm title='Arm' width='20' height='20' />. The <IcArm title='Arm' width='20' height='20' /> icon also applies to the corresponding access control setting.

:::info

This feature is available by purchasing add-on options with an **Essential** license, or with an **Enterprise** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

## View details {/* #detail-view */}

You can view detailed information about the door and its event history. Click <Cmd sid='arena.tree.contextMenu.viewDetail' /> in the pop-up menu. A panel appears in the right pane that shows door control, door details, and event history.

<Image src='/img/biostarx-monitoring-door-view-details.png' />

* **Door control**: Changes the door status to locked, unlocked, armed, or disarmed.

  <Image src='/img/biostarx-monitoring-door-details-control.png' className='none' />

* <Cmd sid='monitoring.multiControl.normalizeOverrides' />: Available when an administrator has manually unlocked or locked the door.

* **Door details**: Shows the door name, location, status, and connected slave device information.

* <Cmd sid='arena.recentEvent' />: Shows the list of recent events that occurred at the selected door.

:::info

For more information about the fields in the door details section, see <DocLink docId='platform/biostar_x/settings-door-add' />.

:::
