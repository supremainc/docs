Create schedules by assigning the configured <Cmd sid='tab.shift' product='2' className='normal' />, <Cmd sid='rule.rule' product='2' className='normal' />, period, and holidays to users.

You can also add temporary schedules or personal leave to a created schedule.

:::info

Before you create a schedule, make sure that you have correctly created the <Cmd sid='tab.payCode' product='2' className='normal' />, <Cmd sid='tab.shift' product='2' className='normal' />, <Cmd sid='tab.scheduleTemplate' product='2' className='normal' />, and holidays to use. 

* For more information about these settings, see the following documents.

  * <DocLink docId='platform/biostar_x/tna-rule-shift-paycode' />

  * <DocLink docId='platform/biostar_x/tna-rule-shift-day' />

  * <DocLink docId='platform/biostar_x/tna-rule-shift-schedule' />

  * <DocLink docId='platform/biostar_x/tna-rule-shift-overtime' />

* For more information on holiday settings, see <DocLink docId='platform/biostar_x/settings-schedule#addHolidaySchedule' />.

:::

## Work schedule

### Add a schedule

To add a schedule for registered users, follow these steps.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.schedule' product='2' /> tab in the left sidebar.

3. Click <Cmd sid='schedule.addSchedule' product='2' />.

   <Image src='/img/biostarx-tna-schedule-template.png' />

4. When the <Cmd sid='schedule.addSchedule' product='2' /> screen appears, set each option.

:::info

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

* To save the settings and then add another <Cmd sid='ta.schedule' product='2' />, click <Cmd sid='ta.apply_add_another' product='2' />.

:::

### Schedule options

Set the following options for the schedule.

<Image src='/img/biostarx-tna-schedule-template-adding.png' />

* <Cmd sid='form.name' product='2' />: Enter the name of the schedule.

* <Cmd sid='form.description' product='2' />: Enter a description of the schedule.

* <Cmd sid='rule.rule' product='2' />: Select a configured <Cmd sid='rule.rule' product='2' className='normal' />. When you set a <Cmd sid='rule.rule' product='2' className='normal' />, the overtime rules set in the <Cmd sid='tab.shift' product='2' className='normal' /> do not apply. If you do not use this option, select <Cmd sid='common.none' product='2' />.

  :::info

  If the <Cmd sid='rule.rule' product='2' className='normal' /> you need does not exist, you can add one. For more information, see <DocLink docId='platform/biostar_x/tna-rule-shift-overtime' />.

  :::

* <Cmd sid='scheduleTemplate.scheduleTemplate' product='2' />: Select a configured <Cmd sid='scheduleTemplate.scheduleTemplate' product='2' className='normal' />. After it is set, the <Cmd sid='scheduleTemplate.scheduleTemplate' product='2' className='normal' /> cannot be changed.

  :::info

  If the <Cmd sid='scheduleTemplate.scheduleTemplate' product='2' className='normal' /> you need does not exist, you can add one. For more information, see <DocLink docId='platform/biostar_x/tna-rule-shift-schedule' />.

  :::

* <Cmd sid='schedule.period' product='2' />: Set the period for collecting attendance events.

  :::info

  After the start date is set, it cannot be changed. You can change the end date later. If you change it to an earlier date, the absence events for the removed period are deleted.

  :::

* <Cmd sid='schedule.holiday' product='2' />: Select a configured holiday schedule. If you do not use this option, select <Cmd sid='common.none' product='2' />.

  :::info

  If the holiday schedule you need does not exist, you can add one. For more information, see <DocLink docId='platform/biostar_x/settings-schedule#addHolidaySchedule' />.

  :::

* <Cmd sid='schedule.users' product='2' />: Add the users to apply the rules to.

:::info

The total number of users in all schedules cannot exceed the maximum number of users that your registered T&A license supports. For the maximum number of users for each license, see <DocLink docId='platform/biostar_x/licensing' />.

:::

### Edit a schedule

Edit a registered schedule.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.schedule' product='2' /> tab in the left sidebar.

3. In the <Cmd sid='ta.schedule' product='2' /> list, click the schedule to edit. Alternatively, click <IcEdit /> next to the schedule in the left sidebar.

4. Edit the options, and then click <Cmd sid='button.apply' product='2' />.

### Delete a schedule

Delete a registered schedule.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.schedule' product='2' /> tab in the left sidebar.

3. In the <Cmd sid='ta.schedule' product='2' /> list, select the checkbox for the schedule to delete.

   <Image src='/img/biostarx-tna-schedule-remove-item.png' />

4. Click <Cmd sid='schedule.deleteSchedule' product='2' /> in the upper-right corner of the screen. Alternatively, click <IcTrash2 /> next to the schedule in the left sidebar.

5. When the confirmation message appears, click <Cmd sid='button.yes' product='2' />.

## Add a temporary schedule

If a schedule is already registered, you can temporarily apply different rules to a user.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.schedule' product='2' /> tab in the left sidebar.

3. In the list on the left side of the screen, click <IcBw2 title='Expand' /> for the schedule.

4. The users assigned to the schedule appear. When you select the user to apply the temporary schedule to, a calendar appears.

   <Image src='/img/biostarx-tna-schedule-template-add-temp-user.png' />

5. On the calendar, click the date to add the temporary schedule to.

   <Image src='/img/biostarx-tna-schedule-template-add-temp-schedule.png' />

6. Click <Cmd sid='schedule.addTemporarySchedule' product='2' /> in the pop-up menu.

7. When the <Cmd sid='schedule.addTemporarySchedule' product='2' /> settings window appears, set each option.

   <Image src='/img/biostarx-tna-schedule-template-add-temp-schedule-setting.png' />

   To apply the same schedule to other users, click <IcSearch /> and select the users.

8. To apply the rules you set, click <Cmd sid='button.apply' product='2' />.

:::info

To delete a temporary schedule applied to a user, click the temporary schedule on the calendar. When the confirmation message appears, click <Cmd sid='button.yes' product='2' />.

:::

## Add and delete leave

Add a leave schedule for a user.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.tna' />.

2. Click the <Cmd sid='ta.schedule' product='2' /> tab in the left sidebar.

3. In the list on the left side of the screen, click <IcBw2 title='Expand' /> for the schedule.

4. The users assigned to the schedule appear. When you select the user to apply the leave schedule to, a calendar appears.

   <Image src='/img/biostarx-tna-schedule-template-add-temp-user.png' />

5. On the calendar, click the date to add the leave schedule to.

   <Image src='/img/biostarx-tna-schedule-template-add-temp-schedule.png' />

6. Click <Cmd sid='schedule.addLeave' product='2' /> in the pop-up menu.

7. When the <Cmd sid='leave.editLeave' product='2' /> settings window appears, set each option.

   <Image src='/img/biostarx-tna-schedule-template-add-leave-setting.png' />

   To apply the same leave schedule to other users, click <IcSearch /> and select the users.

8. To apply the leave schedule you set, click <Cmd sid='button.apply' product='2' />.

:::info

* If the Time Code you need for leave does not exist, you can add one. For more information on adding Time Codes, see <DocLink docId='platform/biostar_x/tna-rule-shift-paycode' />.

* To delete a leave schedule applied to a user, click <IcTrash2 /> on the leave schedule in the calendar. When the confirmation message appears, click <Cmd sid='button.yes' product='2' />.

  <Image src='/img/biostarx-tna-schedule-remove-leave-item.png' alone />

:::
