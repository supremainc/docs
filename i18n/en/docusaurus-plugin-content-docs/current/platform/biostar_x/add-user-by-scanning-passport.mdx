title: Register and Edit Users by Scanning an ID
description: This guide explains how to scan an ID to automatically get user information and register or edit a user.
---

Instead of entering user details one by one, you can scan an ID to get the user’s name and ID photo, then register or edit the user.

## Before you start

* Connect the DESKO ID Scanner to the client PC to use scan ID.

* Before registering a user with a ID scan, select the data to get from the ID. For more information on Scan ID settings, see <DocLink docId='platform/biostar_x/settings-account-scan-passport' />.

:::info

The <Cmd sid='button.passportScan' product='2' /> feature currently supports only passport scans.

:::

## Register a user by ID scan

1. Click <Cmd sid='shell.header.user' /> on the <Cmd sid='shell.header.launcher' /> page.

2. Click <Cmd sid='team.user.newUser' /> in the upper right corner of the <Cmd sid='shell.header.user' /> page.

   <Image src='/img/biostarx-user-add-user-01.png' />

3. Click <Cmd sid='button.passportScan' product='2' /> in the upper right of the <Cmd sid='user.addNewUser' product='2' /> screen.

   <Image src='/img/biostarx-user-add-by-scanning-passport-btn.png' />

4. When the <Cmd sid='user.passportScan.dialog.title' product='2' /> window appears, place the ID on the scanner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. After the ID scan success message appears, select whether to enroll the ID photo as a facial credential.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   This message appears when <Cmd sid='setting.passportScan.face' /> is set to <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. If you set the <Cmd sid='setting.passportScan.faceDoNotAsk' /> option, this message will not appear and it will be enrolled immediately as a facial credential.

   :::

6. Review the information from the ID scan and edit it if needed.

7. Click <Cmd sid='user.save' product='2' /> in the upper right corner of the screen to save the user.

## Edit a user by ID scan

1. Click <Cmd sid='shell.header.user' /> on the <Cmd sid='shell.header.launcher' /> page.

2. In the user list, double-click the user to edit with a ID scan.

3. Click <Cmd sid='button.passportScan' product='2' /> in the upper right of the edit user screen.

   <Image src='/img/biostarx-user-edit-by-scanning-passport-btn.png' />

4. When the <Cmd sid='user.passportScan.dialog.title' product='2' /> window appears, place the ID on the scanner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. After the ID scan success message appears, select whether to enroll the ID photo as a facial credential.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   This message appears when <Cmd sid='setting.passportScan.face' /> is set to <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. If you set the <Cmd sid='setting.passportScan.faceDoNotAsk' /> option, this message will not appear and it will be enrolled immediately as a facial credential.

   :::

6. Review the information from the ID scan and edit it if needed.

7. Click <Cmd sid='user.save' product='2' /> in the upper right corner of the screen to save the updates from the scan.

:::info

If the user has 2 or more facial credentials enrolled, editing via ID scan overwrites the first enrolled facial credential.

:::

## Error messages

If a problem occurs while scanning a ID, a message appears with the cause and solution. Use the information below to resolve the error.

### Scan failed

If a problem occurs while the system automatically reads the ID on the scanner, one of the following messages appears.

| Cause | Error message |
| --- | --- |
| ID security feature (UV pattern, etc.) verification failed | <Cmd sid='user.passportScan.error.invalidPassport' product='2' /> |
| The ID was not recognized within the specified time | <Cmd sid='user.passportScan.error.timeout' product='2' /> |
| Other scan errors, such as the ID moving during scanning or page detection failure | <Cmd sid='user.passportScan.error.cannotScan' product='2' /> |

If this message appears, click <Cmd sid='button.recognizePassport' product='2' /> and scan again. Check that the ID is placed correctly on the scanner, then try again.

:::info

Click <Cmd sid='button.recognizePassport' product='2' /> to restart automatic recognition from the <Cmd sid='user.passportScan.scanning.title' product='2' /> instructions.

:::

### Scanner connection error

If the scanner connection fails, the following message appears. This error does not provide a retry button. Follow the instructions, then click <Cmd sid='button.passportScan' product='2' /> again to start scanning from the beginning.

| Scenario | Error message | Solution |
| --- | --- | --- |
| The scanner is not connected to the client PC | <Cmd sid='user.passportScan.scannerNotFound.description' product='2' /> | Check the connection between the ID Scanner and the client PC. |

### USB Agent Required

Install the latest version of USB Agent before using the ID Scanner. If USB Agent is missing or outdated, an error dialog appears after clicking the <Cmd sid='button.passportScan' product='2' /> button.

<Image src='/img/biostarx-user-scan-passport-error-usb-agent.png' />

* <Cmd sid='button.cancel' product='2' />: Close the error window and do not scan.

* <Cmd sid='button.goToUsbAgentSettings' product='2' />: Go to <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' />. On that screen, upgrade USB Agent to the latest version, then try scanning again.
