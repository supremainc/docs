title: Register and Edit Users by Scanning an ID
description: Learn how to scan an ID to automatically get user information and register or edit a user.
---

Instead of entering user information, scan an ID to automatically get the name and photo, then register a user or edit existing user information.

## Before you start

* To scan an ID, connect the DESKO scanner to the client PC.

* Before you register a user by scanning an ID, make sure you select the data to get from the ID. For more information about Scan ID settings, see <DocLink docId='platform/biostar_x/settings-account-scan-passport' />.

:::info

The <Cmd sid='button.passportScan' product='2' /> feature currently supports only passport scans.

:::

## Register a user by scanning an ID

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <Cmd sid='team.user.newUser' /> in the upper right corner of the <Cmd sid='shell.header.user' /> page.

   <Image src='/img/biostarx-user-add-user-01.png' />

3. Click <Cmd sid='button.passportScan' product='2' /> in the upper-right corner of the <Cmd sid='user.addNewUser' product='2' /> screen.

   <Image src='/img/biostarx-user-add-by-scanning-passport-btn.png' />

4. When the <Cmd sid='user.passportScan.dialog.title' product='2' /> window appears, place the ID on the scanner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. After the ID scan success message appears, select whether to enroll the ID photo as a facial credential.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   This message appears when <Cmd sid='setting.passportScan.face' /> is set to <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. If you set the <Cmd sid='setting.passportScan.faceDoNotAsk' /> option, the message does not appear and a face credential is enrolled immediately.

   :::

6. Review the information from the ID scan and edit it if needed.

7. To save the user, click <Cmd sid='user.save' product='2' /> in the upper-right corner of the screen.

## Edit a user by ID scan

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. To edit a user by scanning an ID, double-click the user in the user list.

3. Click <Cmd sid='button.passportScan' product='2' /> in the upper-right corner of the Edit User Information screen.

   <Image src='/img/biostarx-user-edit-by-scanning-passport-btn.png' />

4. When the <Cmd sid='user.passportScan.dialog.title' product='2' /> window appears, place the ID on the scanner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. After the ID scan success message appears, select whether to enroll the ID photo as a facial credential.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   This message appears when <Cmd sid='setting.passportScan.face' /> is set to <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> under <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. If you set the <Cmd sid='setting.passportScan.faceDoNotAsk' /> option, the message does not appear and a face credential is enrolled immediately.

   :::

6. Review the information from the ID scan and edit it if needed.

7. To save the updates from the scan, click <Cmd sid='user.save' product='2' /> in the upper-right corner of the screen.

:::info

If the user has two or more facial credentials enrolled, editing the user by scanning an ID overwrites the first enrolled facial credential.

:::

## Error messages

If a problem occurs while scanning an ID, a message appears with the cause and solution. Use the information below to resolve the error.

### Scan failure

If a problem occurs while the system automatically recognizes the ID on the scanner, one of the following messages appears.

| Cause | Error message |
| --- | --- |
| Failed to verify ID security features (for example, UV patterns) | <Cmd sid='user.passportScan.error.invalidPassport' product='2' /> |
| The ID was not recognized within the specified time | <Cmd sid='user.passportScan.error.timeout' product='2' /> |
| Other scan errors, such as the ID moving during scanning or page recognition failure | <Cmd sid='user.passportScan.error.cannotScan' product='2' /> |

If the message above appears, click <Cmd sid='button.recognizePassport' product='2' /> shown on the screen, then scan again. Make sure the ID is placed correctly on the scanner, and then try again.

:::info

When you click <Cmd sid='button.recognizePassport' product='2' />, automatic recognition restarts at the <Cmd sid='user.passportScan.scanning.title' product='2' /> message.

:::

### Scanner connection error

If there is a problem with the scanner connection, the following message appears. This error has no retry button, so follow the instructions, then click <Cmd sid='button.passportScan' product='2' /> again to start scanning from the beginning.

| Scenario | Error message | Solution |
| --- | --- | --- |
| The scanner is not connected to the client PC | <Cmd sid='user.passportScan.scannerNotFound.description' product='2' /> | Check the connection between the ID scanner and the client PC. |

### USB Agent required

To use the ID scanner, the latest version of USB Agent must be installed. If USB Agent is not installed or is outdated, an error dialog appears when you click <Cmd sid='button.passportScan' product='2' />.

<Image src='/img/biostarx-user-scan-passport-error-usb-agent.png' />

* <Cmd sid='button.cancel' product='2' />: Closes the error window and does not continue scanning.

* <Cmd sid='button.goToUsbAgentSettings' product='2' />: Goes to the <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' /> screen. On that screen, upgrade USB Agent to the latest version, and then try scanning again.
