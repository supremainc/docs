The video settings feature of **BioStar X** lets you manage access control and video security in an integrated manner. Integrate with a **Video Management System** (VMS) to use powerful security management features such as real-time video monitoring, event-linked recording, and automatic bookmark generation.

:::info

The video settings feature is available through additional options with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::

## Video settings overview

Video settings consist of the following three steps.

<Steps>
<Step>

### Integrate a VMS server

Set up the connection between the VMS server and **BioStar X**, and configure certificates. This is an essential step for building an integrated video security management system. For more information, see <DocLink docId='platform/biostar_x/settings-video-integration' />.

</Step>
<Step>

### Set up the camera

Select the required cameras from the VMS-connected cameras, and create groups for efficient management. For more information, see <DocLink docId='platform/biostar_x/settings-videos-camera' />.

</Step>
<Step>

### Set up rules

Create rules that link access events to video to use advanced features such as automatic bookmarks and event logging. For more information, see <DocLink docId='platform/biostar_x/settings-videos-rule' />.

</Step>

</Steps>

## Key features

* **Integrated monitoring**: Lets you manage access control and video security from a single interface.

* **Automatic event logging**: Records associated video automatically and generates tags when access events occur.

* **Efficient search**: Lets you quickly search video footage and collect evidence using bookmarks and event tags.

* **Real-time response**: Lets you instantly check relevant camera footage when a security situation occurs.
