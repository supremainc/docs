In the <Cmd sid='device.info.rtsp' product='2' /> section, you can set the details for **Real Time Streaming Protocol** (RTSP) streaming. You can stream live video through the device's camera.

<Image src='/img/biostarx-setting-device-edit-rtsp.png' />

* <Cmd sid='device.info.rtsp' product='2' />: To use RTSP streaming, set it to <Cmd sid='device.info.enabled' product='2' />.

* <Cmd sid='device.info.rtsp.address' product='2' />: The RTSP server address is fixed. Click <Cmd sid='device.info.rtsp.copy' product='2' /> to copy the RTSP address.

* <Cmd sid='device.info.rtsp.port' product='2' />: Set the RTSP port.

* <Cmd sid='device.info.rtsp.id' product='2' />: Enter the RTSP server ID.

* <Cmd sid='device.info.rtsp.password' product='2' />: Enter the RTSP server password.

* <Cmd sid='device.info.rtsp.resolution' product='2' />: Select the video resolution for RTSP output. The default is <Cmd>180 x 320</Cmd>.

:::info

* This feature is supported on the BioStation 3 Max, BioStation 3, and BioEntry W3 models.

* The <Cmd sid='device.info.rtsp.resolution' product='2' /> option is supported on BioStation 3 firmware v1.3.0 or later.

* If you made changes, click <Cmd sid='button.apply' product='2' />. Unsaved changes are not applied to the device.

:::
