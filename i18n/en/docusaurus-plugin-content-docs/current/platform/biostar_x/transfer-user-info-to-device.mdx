This feature transfers user information registered on the **BioStar X** server to devices for access control. When you transfer user information to a device, the device uses it to determine access permissions and can run authentication offline.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, select the checkbox at the far left of the user whose information to transfer. You can select one or more users.

3. Select the <IcMoreW/> button in the upper-right corner of the screen and click <Cmd sid='team.menu.transferToDevice' />.

   <Image src='/img/biostarx-user-list-transfer-device.png' />

4. When the <Cmd sid='team.menu.transferToDevice' /> window appears, select the device to transfer user information to from the device list.

   <Image src='/img/biostarx-user-transfer-to-devices.png' width='50%' />

5. To overwrite information that differs for the same ID with the information on the **BioStar X** server, select the <Cmd sid='user.overwriteWhenTransfer' product='2' /> checkbox.

6. After you select all devices to transfer to, click <Cmd sid='common.apply' />.

User information is transferred to the selected devices.

:::info

* You can also search for devices by entering a keyword in the search field.

* To transfer user information, make sure the device is connected to the **BioStar X** server.

* If you change information for a user already registered on the device, you must resend the user information to apply the changes to the device. For more information about using the <Cmd sid='setting.server.automaticUserSync' product='2' /> option to synchronize user information with devices, see <DocLink docId='platform/biostar_x/settings-server-server#user-sync' />.

* Each device has a limit to the number of users that can be registered. Check the number of users that can be registered on the device.

:::
