id: data-settings
title: Set the Report Save Path
description: If you set up an auto-generation schedule, set the path to save reports.
keywords:
  - Report Save
  - Automatic generation
---

If you set up <Cmd sid='reportApp.mainMenu.schedule' product='2' />, set the path to save reports.

1. Click <Cmd sid='reportApp.mainMenu.settings' product='2' />.

2. Enter the path to save reports.

   <Image src='/img/biostarx-data-settings.png' className='none' />

   * <Cmd sid='reportApp.exportReportPath' product='2' />: Saves reports to the specified path, and if you do not enter a path, reports are automatically saved to the *Documents\BioStarX* folder on your PC.

3. To save the settings, click <Cmd sid="reportApp.apply" product='2' />.
