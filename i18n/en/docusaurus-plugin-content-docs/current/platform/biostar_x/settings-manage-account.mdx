Learn how to grant operator permissions to registered users and add and set up custom permissions. Operator permissions are a feature that controls what a user can do in **BioStar X**. **Custom permissions** are a feature that lets you set additional permissions beyond the default operator permissions.

## Check permission types

On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> in the left sidebar. See the default accounts provided for each permission level.

## Grant operator permissions to users {/* #addUserPermission */}

Learn how to grant operator permissions to regular users.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> in the left sidebar.

3. Click an account type in the account list.

4. In the <Cmd sid='settings.account.addUser' product='2' /> option, click <Cmd sid='button.plusAdd' product='2' />.

   <Image src='/img/biostarx-settings-account-add-permission.png' caption />

5. In the user list, select the user to grant operator permissions to.

6. After you select the users, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

* If it is difficult to find a user because there are many users, click <IcSearch /> to search for and select the user.

* You can also grant operator permissions when you add or edit user information. For more information, see <DocLink docId='platform/biostar_x/set-permission' />.

* If permissions are already set when you add or edit user information, they appear in the <Cmd sid='settings.account.addUser' product='2' /> option.

:::

## Remove operator permissions

Learn how to remove operator permissions granted to a user.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> in the left sidebar.

3. Click an account type in the account list.

4. In the <Cmd sid='settings.account.addUser' product='2' /> option, click <IcTrash2 /> next to the user to remove operator permissions from.

   <Image src='/img/biostarx-settings-account-exclude-permission.png' caption />

5. To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

## View operator permission details

To view operator permission details for an account, click the account in the account list in the <Cmd sid='setting.menu.account.account' /> menu.

<Image src='/img/biostarx-settings-account-detail.png' />

* <Cmd sid='common.name' product='2' />: Shows the name of the selected operator permission.

* <Cmd sid='settings.accountList.columnDesc' product='2' />: Shows a brief description of the permission.

* <Cmd sid='settings.account.menu.detailSetting' product='2' />: Shows the groups that have been granted permissions for each entry.

* <Cmd sid='settings.account.menu.setting' product='2' />: Shows the permissions to access menus.

  * <Cmd sid='settings.account.menu.fullAccess' product='2' />: Grants permission to add, edit, and delete entries in the menu.

  * <Cmd sid='settings.account.menu.readOnly' product='2' />: Grants permission to enter the menu and view the settings only.

* <Cmd sid='settings.account.addUser' product='2' />: Shows the users who have been granted permissions.

:::info

For more information about how to grant permissions to a specific user, see <DocLink inner='#addUserPermission' />.

:::
