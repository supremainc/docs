Learn how to check the list of doors that a user can access. When you check access permission status, you can manage the doors that a user can access and the permissions for those doors. Use the filter feature to sort results, and save the list as a CSV file. 

## Check access permission status

You can view access permissions by door or floor, or by user.

<Image src='/img/biostarx-settings-access-control-status.png' />

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.accessControl.root' /> in the left sidebar.

3. Click <Cmd sid='common.status' product='2' />.

4. In the status list under the <Cmd sid='common.status' product='2' /> tab, click an entry.

   * <Cmd sid='access_control.status.access_control_status_by_door.list_name' product='2' />

   * <Cmd sid='access_control.status.access_control_status_by_user.list_name' product='2' />

   * <Cmd sid='ac.status.elevatorbyFloor.title' product='2' />

   * <Cmd sid='ac.status.elevatorbyUser.title' product='2' />

You can check the access permission status for the selected entry.

## Save a filter

To sort results, click <IcFilter2 /> in the header of the access permission list table. You can add filter conditions.

After you set the filter, you can save it. Click <Cmd sid='monitoring.saveFilter' product='2' />. Saved filters appear in the status list under the <Cmd sid='common.status' product='2' /> tab.

<Image src='/img/biostarx-settings-access-control-status-filter.png' />

* To rename the filter, click <IcEditUL />.

* To delete the filter, click <IcTrash2 />.

## Export to CSV

You can export the access permission status list you are viewing as a CSV file. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='button.downloadToCsv' product='2' />.

## Set columns

You can hide or show columns in the access permission status list table you are viewing. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='columnSetting.dialog.header' product='2' />.

<Image src='/img/biostarx-settings-access-control-status-column-setting.png' />

* In <Cmd sid='columnSetting.columnList' product='2' />, select the columns to show. The selected columns appear in the list table. Unselected columns are hidden from the list table.

* To initialize the settings, click <Cmd sid='columnSetting.defaultColumn' product='2' />.

After you finish all settings, click <Cmd sid='button.apply' product='2' />.
