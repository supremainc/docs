Register a purchased **BioStar X** license.

How to register <Cmd sid='setting.menu.license.biostarXLicense' /> varies depending on your network environment. Follow the provided instructions to check the network status and activate the license.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.menu.license.biostarXLicense' /> in the left sidebar.

:::info

* For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* To check license error codes, see [the following link](https://reprisesoftware.com/docs/isv/appendix/appendix-b-rlm-status-values.html).

:::

## Check license activation results {/* #checkResult */}

Depending on the activation results for the entered license key, the following message appears.

* If all entered license keys are valid, a success message appears.

  <Image src='/img/biostarx-license-success.png' />

* If only some keys activate or all keys fail, the system shows each key's status and failure reason. The fields for successful keys clear, and failed keys remain in their fields for reentry.

  <Columns>
   <Column><Image src='/img/biostarx-license-fail.png' /></Column>
   <Column><Image src='/img/biostarx-license-fail-alone.png' /></Column>
   </Columns>

* If all keys fail because there is no internet connection, a message tells you to check the connection and try again, and the <Cmd sid='setting.xlicense.offlineActivation' product='2' /> button appears. If you are on a closed network, click this button to register offline.

:::info

To copy failed keys, click <Cmd sid='setting.xlicense.activation.copyFailedKeys' product='2' />.

:::

## Check activated licenses

The registered **BioStar X** license information appears in <Cmd sid='setting.xlicense.myLicense' product='2' />.
