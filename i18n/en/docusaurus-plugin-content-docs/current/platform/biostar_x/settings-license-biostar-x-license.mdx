Register the purchased **BioStar X** license.

How to register <Cmd sid='setting.menu.license.biostarXLicense' /> varies depending on the network environment. Check your network status and activate your license according to the provided instructions.

1. Click <Cmd sid='shell.header.setting' /> on the <Cmd sid='shell.header.launcher' /> page.

2. Click <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.menu.license.biostarXLicense' /> on the left sidebar.

:::info

* For more information on the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

* For more information about license error codes, refer to [the following link](https://reprisesoftware.com/docs/isv/appendix/appendix-b-rlm-status-values.html).

:::

## Check license activation results {/* #checkResult */}

Depending on the activation results for the entered license key, the following message appears.

* If all entered license keys are valid, a success message appears.

  <Image src='/img/biostarx-license-success.png' />

* If the system activates only certain keys or fails to activate all keys, check each key’s status and failure reason. The fields for successful keys clear, and failed keys remain for reentry.

  <Columns>
   <Column><Image src='/img/biostarx-license-fail.png' /></Column>
   <Column><Image src='/img/biostarx-license-fail-alone.png' /></Column>
   </Columns>

* If all keys fail without an internet connection, a message tells you to check the connection and retry. The <Cmd sid='setting.xlicense.offlineActivation' product='2' /> button appears. If the network is closed, click this button to register offline.

:::info

Click <Cmd sid='setting.xlicense.activation.copyFailedKeys' product='2' /> to copy the failed keys.

:::

## Verify activated license

Check the registered **BioStar X** license information in <Cmd sid='setting.xlicense.myLicense' product='2' />.
