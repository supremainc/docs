Occupancy limit is a key access control feature for ensuring the safety and efficiency of spaces. With this feature, set the maximum number of people who can enter each location at the same time to prevent overcrowding and manage spaces systematically.

The main applications of the occupancy limit setting are as follows.

* **Safety management**: Prevention of safety incidents by limiting the maximum number of occupants based on fire safety regulations or building capacity limits

* **Space efficiency**: Optimization of the work environment by maintaining appropriate occupancy in meeting rooms, laboratories, and workspaces

* **Infectious disease response**: Management of personnel in situations requiring social distancing or crowd density restrictions

* **Real-time monitoring**: Check the current occupancy and entry/exit status for each location in real time

* **Automatic alerts**: Immediate notifications to administrators upon reaching the set occupancy limit, enabling swift responses

With these features, you can establish customized occupancy policies for each space and ensure safe and efficient facility operations.

:::info

* You can add up to 100 occupancy limit settings.

* The supported devices and firmware versions for occupancy limit settings are as follows.

  * FaceStation F2 firmware v1.1.0 or later

  * FaceStation 2 firmware v1.5.0 or later

:::

## Register an occupancy limit {/* #addOccupancyZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.occupancy.title' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the occupancy limit setting to add.

   <Image src='/img/biostarx-settings-adv-ac-add-occupancy.png' />

6. In the <Cmd sid='common.configuration' product='2' /> section, set the details for the occupancy limit setting. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='zone.occupancy.countByPass' product='2' /> section, select the access groups that can bypass the occupancy limit setting. For more information, see <DocLink inner='#countByPass' />.

8. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

In <Cmd sid='common.name' product='2' />, enter up to 48 characters, and use a name different from other settings.

:::

## Setting options {/* #setting */}

The details for the occupancy limit setting are as follows.

* <Cmd sid='zone.globalZone' product='2' />: Shows the scope. Occupancy limit settings support only <Cmd sid='zone.globalZone.global' product='2' /> mode and can be applied to all devices registered to **BioStar X**.

* <Cmd sid='common.activate' product='2' />: Turn on to activate the setting, or turn off to deactivate it temporarily.

* <Cmd sid='zone.entryDevices' product='2' />: Select the devices to use for entry. Select from the list of registered devices.

* <Cmd sid='zone.exitDevices' product='2' />: Select the devices to use for exit. Select from the list of registered devices.

* <Cmd sid='zone.occupancy.limit' product='2' />: Enter the maximum number of people allowed to enter. When the number of people inside reaches the set limit, entry is restricted. Enter a number from 0 to 10,000, and set it to 0 to allow access with no occupancy limit.

* <Cmd sid='zone.occupancy.autoCountReset' product='2' />: Set the time to automatically initialize the stored occupancy count. At the set time each day, the system initializes the occupancy count and bypass count.

* <Cmd sid='zone.occupancy.list.almostFull' product='2' />: Sends an alert to the administrator in advance or records an event in the event log before the occupancy count reaches the configured limit. When occupancy pre-alerts are turned on, the <Cmd sid='zone.occupancy.1stLevel' product='2' /> input field is enabled. To set <Cmd sid='zone.occupancy.2stLevel' product='2' />, click <IcAdd className='border radius' />.

* <Cmd sid='zone.occupancy.networkFailureAction' product='2' />: Sets whether to allow users to enter and exit when a network error occurs on the configured device. When set to allow entry and exit, entry restriction stops if the device loses network connection, and users can enter even when the occupancy count exceeds the limit.

:::info

* The same device cannot be set for both <Cmd sid='zone.entryDevices' product='2' /> and <Cmd sid='zone.exitDevices' product='2' /> at the same time.

* Select up to 128 devices for <Cmd sid='zone.entryDevices' product='2' /> and <Cmd sid='zone.exitDevices' product='2' />.

* A device configured with <Cmd sid='door.dualAuthentication' product='2' /> on a door cannot be assigned to <Cmd sid='zone.entryDevices' product='2' /> or <Cmd sid='zone.exitDevices' product='2' />.

* Set the time for the <Cmd sid='zone.occupancy.autoCountReset' product='2' /> option while considering the standard time zone of the actual location. For example, if you set the occupancy auto-reset time to 00:00 on a **BioStar X** server in a UTC+1:00 region, occupancy is automatically reset at 01:00 on a **BioStar X** client in a UTC+2:00 region.

* Set up to two <Cmd sid='zone.occupancy.list.almostFull' product='2' /> values, and enter only numbers less than the configured limit value. <Cmd sid='zone.occupancy.1stLevel' product='2' /> and <Cmd sid='zone.occupancy.2stLevel' product='2' /> cannot be set to the same value.

* For more information about registering devices, see the following documents.

  * <DocLink docId='platform/biostar_x/settings-adding-devices' />

  * <DocLink docId='platform/biostar_x/settings-adding-wiegand' />

  * <DocLink docId='platform/biostar_x/settings-adding-slave-device' />

:::

## Set up bypass users {/* #countByPass */}

Select the access groups that can bypass the occupancy limit setting. Users who belong to a bypass group can enter and exit regardless of the occupancy count, and they are not included in the occupancy count. Check the bypass users currently present in the **Bypass Count** column of the occupancy limit settings list.

:::info

* When a thermal camera is connected to the device and <Cmd sid='device.thermal.mode' product='2' /> is set to <Cmd sid='device.thermal.authTemperatureOnlyMode' product='2' />, the bypass setting does not work even if you set bypass users.

* Set up to 16 <Cmd sid='zone.occupancy.bypassGroup' product='2' /> groups.

:::

## Check the list status {/* #occupancyZoneList */}

View the occupancy limit settings list. Check the status of each setting and the occupancy count, and change the settings as needed.

* <Cmd sid='zone.occupancy.list.name' product='2' />: Shows the name.

* <Cmd sid='zone.occupancy.list.status' product='2' />: Shows the status.

  * <Cmd sid='zone.occupancy.list.normal' product='2' />: Indicates that the number of users present is less than the number set in <Cmd sid='common.limit' product='2' />, <Cmd sid='zone.occupancy.almostFull' product='2' /> (<Cmd sid='zone.occupancy.1stLevel' product='2' />, <Cmd sid='zone.occupancy.2stLevel' product='2' />). Users can enter this location.

  * <Cmd sid='zone.occupancy.almostFull' product='2' />: Indicates that the number of users present has reached the value set in <Cmd sid='zone.occupancy.1stLevel' product='2' /> or <Cmd sid='zone.occupancy.2stLevel' product='2' />.

  * <Cmd sid='zone.occupancy.list.full' product='2' />: Indicates that the number of users present has reached the limit set. Further entry is restricted.

* <Cmd sid='zone.occupancy.list.countLimit' product='2' />: Shows the current number of occupants compared to the capacity. In special situations such as network errors, the occupancy count may not match the actual number of users present. In that case, the administrator can click <IcAdd className='border radius' /> or <IcMinus className='border radius' />, or click the occupancy count to edit it directly.

* <Cmd sid='zone.occupancy.countByPass' product='2' />: Shows the number of bypass users who are currently inside.

* <Cmd sid='zone.occupancy.list.deviceStatus' product='2' />: Shows the status of the configured devices.

  * <Cmd sid='zone.occupancy.list.normal' product='2' />: The network for all configured devices is functioning normally.

  * <Cmd sid='zone.occupancy.networkFailure' product='2' />: Indicates that a network error has occurred on one or more devices.

* <Cmd sid='zone.occupancy.list.fullscreen' product='2' />: Shows the current status of the occupancy limit settings in full-screen mode.

:::info

When <Cmd sid='zone.occupancy.limit' product='2' /> is set, the maximum occupancy count you can enter is 50,000. If <Cmd sid='zone.occupancy.limit' product='2' /> is not set, the maximum count you can enter is 999,999. You cannot enter values above the maximum, and any occupancy above it is not recorded in the database.

:::

## Reset the occupancy count {/* #resetOccupancy */}

You can reset the occupancy count and bypass count. If you reset the occupancy count, all user entry and exit information is deleted, and the count may be inaccurate depending on the network connection status.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='zone.occupancy.title' product='2' /> in the list.

4. Select the checkbox for the setting to reset in the occupancy limit settings list.

5. Click <Cmd sid='zone.occupancy.list.reset' product='2' /> in the upper-right corner of the screen.

6. When a confirmation message appears, click <Cmd sid='button.apply' product='2' />.

## Activate or deactivate {/* #activateDeactivateOccupancyZone */}

You can activate a deactivated occupancy limit setting or deactivate an activated setting. When you deactivate the setting, <Cmd sid='zone.occupancy.fullscreen.currentOccupancy' product='2' /> and <Cmd sid='zone.occupancy.list.countBypass' product='2' /> are reset.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='zone.occupancy.title' product='2' /> in the list.

4. Select the checkbox for the entry to activate or deactivate in the occupancy limit settings list.

5. Click <Cmd sid='zone.occupancy.list.activate' product='2' /> or <Cmd sid='zone.occupancy.list.deactivate' product='2' /> in the upper-right corner of the screen.

## Delete {/* #deleteOccupancyZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='zone.occupancy.title' product='2' /> in the list.

4. Select the checkbox for the entry to delete in the occupancy limit settings list.

5. Click <Cmd sid='zone.occupancy.list.deleteZone' product='2' /> in the upper-right corner of the screen.

6. When a confirmation message appears, click <Cmd sid='button.apply' product='2' />.
