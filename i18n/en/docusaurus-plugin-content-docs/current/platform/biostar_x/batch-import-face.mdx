Learn how to batch enroll users’ faces. You can batch enroll multiple users’ faces by using the CSV import feature or importing face photos with filenames that match user IDs. Alternatively, you can email face enrollment links to multiple users so they can enroll their faces directly on mobile devices.

## Before you start

Prepare users’ face images before starting batch face enrollment. 

* All face image files must be saved in one folder. Face image filenames must match user IDs.

* The maximum supported image file size is 10 MB.

* The supported image formats are JPG, JPEG, and PNG.

## Enroll faces by importing a CSV file {/* #import-csv */}

You can batch enroll users’ faces using the CSV import feature.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, select the checkbox for the user to enroll a face. You can select one or more users.

3. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.export.title' /> → <Cmd sid='team.menu.export.csv' />.

4. When the CSV export window appears, click <Cmd sid='common.button.download' />.

5. Save the CSV file to a location on your computer.

6. Open the CSV file and add the `face_image_file1` and `face_image_file2` columns.

7. Enter the face image filenames, including extensions, in the added columns, and save the file.

8. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.csv' />.

9. Select the modified CSV file.

10. When the CSV import window appears, set <Cmd sid='user.list.csvImport.importStartRow' /> and click <Cmd sid='common.button.next' />.

    <Image src='/img/biostarx-user-import-01.png' />

11. Select whether to keep user data already registered in **BioStar X** or overwrite it with the CSV file information, and click <Cmd sid='common.apply' />.

    <Image src='/img/biostarx-user-import-03.png' />

12. Click <Cmd sid='button.browse' product='2' /> in <Cmd sid='user.list.csvImport.visualFaceImageFolder' product='2' />.

    <Image src='/img/biostarx-new-user-credential-face-import-csv.png' />

13. Select the path where the face images are saved, and click <Cmd sid='button.upload' product='2' />.

14. To complete the CSV import, click <Cmd sid='common.button.next' />.

If an error occurs while importing the CSV file information, you can recheck and upload only the CSV data that caused the error.

:::info

Use the same path for the CSV file and the face image files to import.

:::

## Import faces {/* #import-face */}

You can import face photos with filenames that match user IDs and enroll faces for facial authentication. Before you start, prepare users’ face image files. Face image filenames must match user IDs.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click <IcMoreW /> in the upper-right corner of the screen, then select <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.face' />.

3. When the <Cmd sid='user.list.visualFaceImport.title' /> window appears, click <Cmd sid='common.button.browse' />.

   <Image src='/img/biostarx-new-user-credential-face-import.png' />

4. Select the path where the face images are stored.

5. In the <Cmd sid='user.list.visualFaceImport.newImport' /> option, select how to import face images.

   * <Cmd sid='user.list.visualFaceImport.default' />: Loads images with filenames matching the user IDs.

   * <Cmd sid='user.list.visualFaceImport.createUser' />: If registered user IDs match the face image filenames, the images are loaded; if they do not match, a new user is created using the file name as the user ID and enrolled as a face authentication method.

6. In the <Cmd sid='user.list.visualFileImport.duplicateUser' /> option, select <Cmd sid='user.list.csvImport.duplicateUser.preserve' product='2' /> or <Cmd sid='user.list.csvImport.duplicateUser.overwrite' product='2' />.

   * <Cmd sid='user.list.csvImport.duplicateUser.preserve' />: Keeps the face images of registered users.

   * <Cmd sid='user.list.csvImport.duplicateUser.overwrite' />: Replaces the face images of registered users with the newly imported face images.

7. To use the imported face images as profile images, turn on <Cmd sid='team.user.credential.visualFace.useAsProfileImage' />.

8. Click <Cmd sid='common.start' />.

If an error occurs while importing face image files, a list of photos with errors appears. Check the list and try again.

:::info

You can import up to one face image per user ID.

:::

## Enroll faces using a mobile device {/* #mobile-device */}

You can send face enrollment links to users by email. Users can open the link on a mobile device and enroll their face.

### Before you start

* Before using mobile face enrollment, complete the email settings, including SMTP settings. For more information, see <DocLink docId='platform/biostar_x/settings-email-setting' />.

* To use the mobile face enrollment feature, turn on <Cmd sid='setting.menu.remoteAccess.root' />. For more information about <Cmd sid='setting.menu.remoteAccess.root' />, see <DocLink docId='platform/biostar_x/settings-remote-access' />.

### Send a face enrollment link

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, select the checkbox for the user to enroll a face. You can select one or more users.

3. Click <IcMoreW /> in the upper-right corner of the screen and select <Cmd sid='team.menu.sendFaceMobileEnrollLink' />.

   <Image src='/img/biostarx-user-face-mobile-link.png' />

4. When the message window appears, click <Cmd sid='common.button.ok' />.

   <Image src='/img/biostarx-user-face-mobile-link-warning.png' width='60%' />

The face enrollment link is sent to the email address of the selected users. When the user completes the upload, the face credential is added to the user information.

:::info

* The email sending status appears in <Cmd sid='monitoring.auditTrail' product='2' />. For more information, see <DocLink docId='platform/biostar_x/settings-system-audit-trail' />.

* The language shown on the page accessed through the face enrollment mobile link follows the mobile browser language settings.

* When the user opens the face enrollment mobile link, the face enrollment service starts as shown below. Follow the instructions on the screen.

  <Image src='/img/biostarx-new-user-credential-face-mobile-app.png' className='none' />

* The maximum supported image file size is 10 MB.

* The supported image formats are JPG, JPEG, and PNG.

* The sent face enrollment mobile link expires after 24 hours.

* When the user uploads a face photo and mobile face enrollment succeeds, an enrollment success message appears on the screen. If enrollment fails, a failure message and the reason appear, and the user can try face enrollment again using a different photo.

:::
