The **Video Management System** (VMS) is a video management system that integrates and manages video from multiple cameras and supports recording and playback. Integrating BioStar X with VMS lets you manage access control and video security on a single platform.

VMS integration supports the following features.

* **Real-time monitoring**: Lets you view live video from cameras connected to doors.

* **Integrated event management**: Lets you assess security situations by linking access events with video.

* **Efficient evidence collection**: Lets you quickly search for and play back recorded video from a specific time.

* **Bookmark feature**: Adds video tags at key event times for easy searching and review.

## Before you start

To integrate with the **Video Management System** (VMS), check the following.

* The VMS integration feature is available through an add-on option with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* Make sure that the VMS server is correctly installed and set up. The VMS server must be online and able to connect to **BioStar X**.

<Include lang='ko'>

* Use a VMS that is compatible with **BioStar X**. You can use [BioStar X VMS](https://www.supremainc.com/ko/platform/video-ac-integrated-system-biostar-x-vms.asp) or the **Nx Witness v5.1.5**, **v6.x.x** series of VMS.

</Include>

<Xclude lang='ko'>

* Use a VMS that is compatible with **BioStar X**. You can use **Nx Witness v5.1.5** or **Nx Witness v6.x.x**.

</Xclude>

* Prepare the IP address, port number, and administrator account information for the VMS server. This information is required for **BioStar X** to connect to the VMS server.

## Set up VMS server integration

Follow these steps to integrate the VMS server with **BioStar X**.

<Steps>
<Step>

### Activate VMS integration

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.vmsIntegration' /> in the left sidebar.

3. If this is your first time logging in, log in with the **BioStar X** administrator account.

   <Image src='/img/biostarx-settings-video-integration-login.png' />

4. Set the <Cmd sid='video.setting.integration.title' product='2' /> option to <Cmd sid='common.use' product='2' />.

   <Image src='/img/biostarx-settings-video-integration.png' />

5. Enter the VMS server information.

   <Image src='/img/biostarx-settings-video-vms-server-info.png' />

   * <Cmd sid='video.setting.integration.serverAddress' product='2' />: Enter the IP address of the VMS server.

   * <Cmd sid='video.setting.integration.port' product='2' />: Enter the port number of the VMS server.

   * <Cmd sid='video.setting.integration.loginId' product='2' />: Enter the administrator account ID for the VMS server.

   * <Cmd sid='video.setting.integration.password' product='2' />: Enter the administrator account password for the VMS server.

6. Once you have entered all the VMS server information, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

* If integration with the VMS server fails and an error message appears, check the server address and administrator account information again. Also check whether the VMS server is online and whether firewall settings block the network connection.

* For more information about the settings in the <Cmd sid='video.setting.tag.title' product='2' /> section, see <DocLink inner='#vms-event-bookmark' />.

:::

</Step>
<Step>

### Install the certificate on the VMS server {/* #install-vms-certification */}

To play back recorded video from the VMS server, you must use the HTTPS protocol. Standard SSL certificates are issued for domain names, so they aren't valid in environments where you access the VMS server by IP address. Therefore, you need to create a separate certificate that includes the VMS server's IP address.

:::info

You must install a certificate whether the VMS server and **BioStar X** are installed on the same server or on separate servers.

:::

When the <Cmd sid='video.setting.integration.title' product='2' /> option is set to <Cmd sid='common.use' product='2' />, the <Cmd sid='video.setting.vmsCert.title' product='2' /> section becomes available.

<Image src='/img/biostarx-settings-video-set-cert.png' />

1. To download the certificate installer, click <Cmd sid='video.setting.vmsCert.step1.downloadButton' product='2' /> on the server where VMS is installed.

2. Run the downloaded *vmsCertMaker.exe* file.

3. Enter the IP address in the **VMS server IP** field.

   <Image src='/img/biostarx-vms-cert-installation-tool-01.png' alone />

   :::note

   Enter the IP address in IPv4 address format. For example, 192.168.0.10

   :::

4. If you enter an IP address in the correct format, **Next** becomes available. Click **Next**.

5. Select the VMS certificate installation path.

   * For compatible VMS, the installer detects the installation path automatically.

     <Image src='/img/biostarx-vms-cert-installation-tool-02-found.png' alone />

   * If the installer does not detect the installation path automatically, click **Browse for folder** and select the path manually.

     <Image src='/img/biostarx-vms-cert-installation-tool-02.png' alone />

      :::note

      The certificate installation path may vary depending on the VMS. See the examples below.

     * **BioStar 2 VMS**: *C:\Windows\System32\config\systemprofile\AppData\Local\Suprema Inc\Suprema Inc. Media Server\ssl*

     * **Digital Watchdog**: *C:\Windows\System32\config\systemprofile\AppData\Local\Digital Watchdog\Digital Watchdog Media Server\ssl*

     * **Hanwha Wave**: *C:\Windows\System32\config\systemprofile\AppData\Local\Hanwha\Hanwha Media Server\ssl*

     * **NX**: *C:\Windows\System32\config\systemprofile\AppData\Local\Network Optix\Network Optix Media Server\ssl*

      :::

   * If multiple VMS certificate paths exist, all paths appear. Click **Select another folder**, and then select a path.

     <Image src='/img/biostarx-vms-cert-installation-tool-02-list.png' alone />

6. Click **Next** or **Proceed with selected folder**.

7. After certificate generation completes, the **Certificate generated successfully** message appears.

   <Image src='/img/biostarx-vms-cert-installation-tool-03.png' alone />

8. After you click **OK**, the certificate installation path appears. Make sure the certificate file (*cert.pem*) is created.

9. After certificate installation completes, click **Close**.

   <Image src='/img/biostarx-vms-cert-installation-tool-04.png' alone />

10. Reboot the VMS server.

:::info

If certificate installation fails, the message shows the reason. Review the message, then take the required action.

<Image src='/img/biostarx-vms-cert-installation-tool-fail.png' alone />

:::

</Step>
<Step>

### Install the certificate on the client PC {/* #install-client-certification */}

If any of the following situations occur, resolve the issue by installing the certificate from the VMS server on the client PC.

* When you access **Video Management System** (VMS) through a browser and a 'Not secure' warning appears

* When real-time video plays on the <Cmd sid='shell.header.arena' /> page but recorded video does not play

:::caution

Registering the certificate only on the client PC, without installing it on the VMS server, prevents normal operation.

:::

---

1. Access **BioStar X** in a web browser.

2. Download the HTTPS certificate installer (*cert-register.zip*) from the login screen or <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid="setting.menu.server.https" />.

3. Extract the downloaded file, and then run the **cert-register.exe** file. The **Enroll Certificate** window appears.

4. Select **VMS** for **Target System** and enter the following information.

   <Image src='/img/common/biostarx-settings-server-enrollment-vms-certification.png' alone />

   * **Server Address**: IP address of the VMS server

   * **Port**: Enter the port number for the VMS server (default: 7001)

5. Click **Enrollment**.

6. Read the security warning message, and then click **Yes**.

Restart the web browser, and then check whether the recorded video from the VMS server plays normally on the <Cmd sid='shell.header.arena' /> page.

</Step>
<Step>

### Check and set up cameras {/* #check-camera-setting */}

If the VMS server is integrated successfully, you can check the connected cameras in <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.video' />. For more information, see <DocLink docId='platform/biostar_x/settings-videos-camera' />.

</Step>
</Steps>

### Troubleshooting {/* #video-troubleshooting */}

If the integration does not work properly after you first integrate with the VMS server, restart the services manually as follows.

1. In Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**.

2. In the **All Services** list, click **Stop** for the services below to stop them.

   <Image src='/img/common/biostarx-sm-restart-service-video.png' alone />

   * **BioStar X Unified Gateway Service**

   * **BioStar X Core Web Service**

3. When the status of the service you stopped changes from **Pending** to **Stopped**, click **Start** to restart the service.

   <Image src='/img/common/biostarx-sm-restart-service-video-start.png' alone />

## VMS event and bookmark settings {/* #vms-event-bookmark */}

You can send bookmark tag and event tag information to the integrated VMS server. You can also select options to send the event log, door name, device name, and user ID. Select the desired options and click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

<Image src='/img/biostarx-settings-video-event-bookmark.png' />

* <Cmd sid='common.language' product='2' />: Select the language for event and bookmark tags sent to the VMS server. Available options are Korean and English.

* <Cmd sid='video.setting.tag.bookmark' product='2' />: Bookmark tags are a feature that assigns markers and names to videos stored on the VMS server so you can easily find and review them. Select the information to send with bookmark tags.

* <Cmd sid='video.setting.tag.event' product='2' />: Sends events that occur at a specific time to the VMS server so they can be recorded. Select the information to send with event tags.

:::info

* For more information about the bookmark function in VMS, see [the following link](https://resources.vmsproxy.com/nx_vms_help/using_bookmarks.html).

* For more information about the event function in VMS, see [the following link](https://resources.vmsproxy.com/nx_vms_help/configuring_events_and_actions.html).

* If bookmark or event tags include the following characters, the system automatically removes them before sending them to the VMS server.

  * Event tag: `\` `'` `,` `#` `%` `=` `&` `<` `>`

  * Bookmark tag: `<` `'`

:::

## Disconnect VMS server integration

To disconnect the integrated VMS server, follow these steps. Disconnecting VMS integration deletes all video settings, registered cameras, and rules.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.vmsIntegration' /> in the left sidebar.

3. Set the <Cmd sid='video.setting.integration.title' product='2' /> option to <Cmd sid='common.notUse' product='2' />.

4. Click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

5. Check the message window and click <Cmd sid='button.yes' product='2' />.
