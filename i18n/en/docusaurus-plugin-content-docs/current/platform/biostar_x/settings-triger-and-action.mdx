You can set a device or **BioStar X** to run selected actions when a specific event occurs on a device, door, or zone.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.triggerAndAction.root' /> in the left sidebar. 

3. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='button.func.addTriggerAndAction' product='2' /> in the upper-left corner of the screen.

   <Image src='/img/biostarx-settings-trigger-and-action.png' />

Follow the on-screen instructions to set the details.

<Image src='/img/biostarx-settings-trigger-and-action-add.png' />

<Steps>

<Step>

## Enter a name

<Cmd sid='common.name' product='2' />: Enter a name for the triggers and actions.

</Step>
<Step>

## Set a schedule

<Cmd sid='triggerAction.schedule' product='2' />: Select the schedule that applies to the triggers and actions.

:::info

* If no schedule is available when you select <Cmd sid='triggerAction.input' product='2' /> to set custom conditions, click <Cmd sid='button.plusAddSchedule' product='2' /> to add one.

* For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::

</Step>
<Step>

## Use as a quick action

When you set <Cmd sid='common.quickAction' product='2' />, you can control multiple doors at once with the <Cmd sid='common.quickAction' product='2' /> button on the **BioStar X** main screen. Select the <Cmd sid='triggerAction.quickAction' product='2' /> checkbox.

:::info

* This feature is available only when the <Cmd sid='triggerAction.schedule' product='2' /> option is set to <Cmd>Always</Cmd>.

* <Cmd sid='common.quickAction' product='2' /> can be set in <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.customInterface.root' />. For more information about <Cmd sid='common.quickAction' product='2' />, see <DocLink docId='platform/biostar_x/settings-custom-interface' />.

:::

</Step>
<Step>

## Select devices, doors, and advanced access control {/* #select-device-door-advanced-ac */}

Select the targets to send event signals to. You can select multiple devices, and each one operates independently even if its connection to **BioStar X** is lost.

:::info

The <Cmd sid='common.zone' product='2' /> option is available through an add-on option with an **Essential** license or higher. For more information about the licensing policy, see <DocLink docId='platform/biostar_x/licensing' />.

:::

</Step>
<Step>

## Set trigger condition events

Set the condition events. You must select one or more events.

:::info

Depending on the options you selected in the [previous step](#select-device-door-advanced-ac), different event lists become available.

:::

</Step>
<Step>

## Set actions

Select the device to run the actions. You can select actions for a device, door, or **BioStar X**.

In the <Cmd sid='triggerAction.action' product='2' /> section, set the signals to send when the selected condition events occur. To receive logs by email, set this in **BioStar X**.

:::info

* When you click the <Cmd sid='common.device' product='2' />, <Cmd sid='common.door' product='2' />, or <Cmd>BioStar X</Cmd> tab, the content in the Actions section changes.

* To set the email server information, on the <Cmd>BioStar X</Cmd> tab, click <IcSet2 />. When the <Cmd sid='setting.triggerAction.smtpOption' product='2' /> window appears, enter the email server information and click <Cmd sid='button.apply' product='2' />. For more information, see <DocLink docId='platform/biostar_x/settings-email-setting#email-contents-setting' />.

* For more information about email server details, contact your system administrator.

:::

</Step>

</Steps>

After you complete all settings, click <Cmd sid='button.apply' product='2' />.
