Enroll a user's face as an authentication credential for access. IR Face enrollment is an authentication method that captures the user's face with an infrared camera.

:::note

**Precautions for enrolling IR Face**

import EnrollingFace from '../../common/_enrolling-face-warning.mdx';

<EnrollingFace />

:::

## Enroll by device {/* #enrolldevice */}

In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='button.addIRFace' product='2' />. When the <Cmd sid='userCredential.enroll.IRfaceEnroll' product='2' /> window appears, set each field and click <Cmd sid='button.enroll' product='2' />.

<Image src='/img/biostarx-new-user-credential-ir-face.png' />

* <Cmd sid='common.device' product='2' />: Select the device to enroll IR Face.

* <Cmd sid='userCredential.enroll.poseSensitivity' product='2' />: Set the sensitivity for face position, angle, and distance when enrolling IR Face. Set it to High to get an accurate IR Face template.

* <Cmd sid='button.addplus' product='2' />: Adds an IR Face credential. You can add up to five IR faces.

* <Cmd sid='button.scan' product='2' />: Click the added <Cmd>Nth</Cmd> button to scan the IR face. Follow the on-screen instructions on the device to scan the face.

  <Image src='/img/biostarx-new-user-credential-ir-face-nth.png' />

* <Cmd sid='userCredential.enroll.useProfile' product='2' />: Select this checkbox to use the enrolled IR Face image as the profile image.

* <Cmd sid='button.delete' product='2' />: Deletes the IR Face credential. Select the number to delete and click Delete.

:::info

* For devices that support enrolling IR Face, see below.

  * FaceStation 2

  * FaceLite

* If the facial authentication rate is low, delete the face information and enroll a new face.

:::
