The **BioStar X** platform supports the following devices and minimum firmware versions for each device. If the device firmware is earlier than the version below, upgrade the firmware, and then use the device.

:::info

A device may not support certain **BioStar X** features, depending on its specs or firmware version. See the documentation for each feature for supported devices and firmware versions.

:::
