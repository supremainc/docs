Tracking and reviewing a user's access history is critical to strengthening security and improving operational efficiency. Access history helps prevent security threats and optimize operations. Access history shows users who tried to access areas they are not authorized to access or at unauthorized times. This lets you respond quickly to security threats. Identifying anomalies, such as repeated authentication failures or access at unusual times, helps you detect security threats early.

Follow these steps to check a user's access history.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. In the user list, click the user to check the user's access history.

3. The selected user's profile information appears in the right pane.

<Image src='/img/biostarx-users-list-view-profile.png' />

In the <Cmd sid='team.event.trace' /> section below the preview pane, the user's access history appears. 

:::info

* Real-time access events appear on the <Cmd sid='shell.header.arena' /> page. For more information, see <DocLink docId='platform/biostar_x/monitoring-event' />.

* Past access events appear on the <Cmd sid='shell.header.data' /> page. For more information, see <DocLink docId='platform/biostar_x/how-to-guide-data' />.

:::
