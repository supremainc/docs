By integrating with Suprema's Airfob Portal, you can issue mobile access cards to users. You can enroll a mobile access card for each user individually, or register multiple users at once by using the CSV import feature.

You must enter the user's email based on the mobile access card delivery method set in the Airfob Portal.

:::info

* You can use only one of **CSN Mobile Card** or **Template on Mobile**.

* This feature is available only when integrated with the Airfob Portal. For more information about integrating with the Airfob portal and using mobile access cards, see <DocLink docId='platform/biostar_x/settings-credential-mobile-access-card' />.

:::

## CSN mobile {/* #csnmobilecard */}

You can issue CSN mobile access cards to users.

### Card assignment

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='common.mobileCredential' product='2' />.

2. When the <Cmd sid='user.header.mobile' product='2' /> window appears, select <Cmd sid='user.cardEnrol.cardTypeCsnMobile' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

3. Select <Cmd sid='common.assignCard' product='2' /> from the <Cmd sid='common.registrationOption' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-mobile-csn-assign.png' className='none' />

   <AirFobNote />

4. In the card list, select or search for the card to assign.

5. Set the <Cmd sid='common.information' product='2' /> and <Cmd sid='common.validPeriod' product='2' />.

6. Click <Cmd sid='button.enroll' product='2' />.

:::info

<MobileNotes />

:::

### Enter manually

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='common.mobileCredential' product='2' />.

2. When the <Cmd sid='user.header.mobile' product='2' /> window appears, select <Cmd sid='user.cardEnrol.cardTypeCsnMobile' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

3. Select <Cmd sid='common.enterManually' product='2' /> from the <Cmd sid='common.registrationOption' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-mobile-csn.png' className='none' />

   <AirFobNote />

4. Select the <Cmd sid='zone.intrusion.inputType' product='2' /> option.

   * <Cmd sid='user.random.cardid' product='2' />: Automatically generates a card ID.

   * <Cmd sid='common.useUserId' product='2' />: Uses the user ID as the card ID. Available only when the user ID consists only of numbers.

   * <Cmd sid='user.manual.input' product='2' />: Allows manual entry of the card ID.

5. Set the <Cmd sid='common.information' product='2' /> and <Cmd sid='common.validPeriod' product='2' />.

6. Click <Cmd sid='button.enroll' product='2' />.

:::info

<MobileNotes />

* If the user has lost or deleted the activation link sent via email, click **resend** to reissue the activation link.

* For more information about the CSN mobile application, see the [following link](https://www.csn.edu/csn-mobile-apps).

:::

## <Cmd sid='team.user.tom' className='normal' /> {/* #template-on-mobile */}

**Template on Mobile** is a mobile access card that stores the user's biometric template on the mobile device. It supports biometric authentication without storing user data on the **BioStar X** server, Airfob Portal, or devices.

This feature is useful in environments that need to use biometrics as credentials but cannot store biometric information on the server or devices due to privacy concerns. Since issuance and biometric template enrollment are separate, users can enroll their face on **Template on Mobile**-supported devices without meeting an administrator.

1. In the <Cmd sid='common.credential' product='2' /> section, click <Cmd sid='common.mobileCredential' product='2' />.

2. When the <Cmd sid='user.header.mobile' product='2' /> window appears, select <Cmd sid='user.cardEnroll.cardTypeTemplateOnMobile' product='2' /> from the <Cmd sid='user.cardType' product='2' /> options.

   <Image src='/img/biostarx-new-user-credential-mobile-tom.png' className='none' />

   <AirFobNote />

3. Select a card type from the <Cmd sid='user.cardModeLong' product='2' /> options.

   * <Cmd sid='user.accessOnCard' product='2' />: Stores user information (card ID, PIN, access group, period, personal authentication mode) on the card.

   * <Cmd sid='user.secureCredentialCard' product='2' />: A secure credential card. Stores the user's card ID and PIN data on the card.

4. Set the <Cmd sid='common.information' product='2' /> and <Cmd sid='common.validPeriod' product='2' />.

5. Click <Cmd sid='button.enroll' product='2' />.

Sends an issuance email to the registered user's email address. To use it, install the Airfob Pass application through the link in the email, and complete **Template on Mobile** issuance on the mobile device.

:::tip

**Template on Mobile authentication method**

The user tags the mobile device that holds the issued **Template on Mobile** on the device, and then follows the on-screen instructions for facial authentication.

:::

:::info

<MobileNotes />

* For the devices and firmware versions that support **Template on Mobile**, see the list below.

  * BioStation 3 Max firmware v1.0.0 or later

  * BioEntry W3 firmware v1.0.0 or later

  * BioStation 3 firmware v1.2.0 or later

  * FaceStation F2 firmware v2.2.0 or later

* You can issue only one mobile access card: either a **CSN Mobile Card** or **Template on Mobile**.

:::
