If you need to delete a user registered in **BioStar X** due to resignation, contract termination, or security violation, follow the steps below.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.user' />.

2. Click the checkbox to the left of the user you want to delete from the user list. You can select one or more users.

3. Click <Cmd sid='common.delete' /> in the upper-right corner of the screen.

   <Image src='/img/biostarx-remove-users.png' />

4. Click <Cmd sid='common.delete' /> to confirm the message appears.

Confirm that the selected user has been deleted from the user list.

:::info

* User with ID `1` cannot be deleted.

* For more information about deleting user information from the device, see <DocLink docId='platform/biostar_x/settings-device-manage-device-users' />.

:::
