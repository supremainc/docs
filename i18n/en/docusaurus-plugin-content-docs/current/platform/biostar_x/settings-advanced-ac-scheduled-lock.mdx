Guidance on how to set up schedule lock. Schedule lock provides the ability to lock doors at specific times. This feature enhances access control and is useful for restricting access during certain periods.

:::info

Schedule lock settings only support <Cmd sid='zone.globalZone.local' product='2' /> mode.

:::

## Register scheduled lock {/* #addScheduledLockZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.scheduledLock' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. Enter the name of the schedule lock feature to add in the <Cmd sid='common.information' product='2' /> section.

   <Image src='/img/biostarx-settings-adv-ac-add-schedule-lock.png' />

6. Set the details of the schedule lock feature in the <Cmd sid='common.setting' product='2' /> section. For more information, see <DocLink inner='#setting' />.

7. Set the action to take when a schedule lock violation occurs in the <Cmd sid='common.alarm' product='2' /> section.

8. Select the access group that can bypass the schedule lock in the <Cmd sid='zone.forcedLock.bypass' product='2' /> section. Users in this group can bypass the schedule lock.

9. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='common.alarm' product='2' /> section must set <Cmd sid='zone.pause.doorselected' product='2' /> to be usable.

:::

## Setting options {/* #setting */}

The details for setting schedule lock are as follows.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.forcedLock.doorLockType' product='2' />: You can set it to lock only the entrance device or to lock both entrance and exit devices.

* <Cmd sid='zone.pause.doorselected' product='2' />: Select the doors to specify schedule lock rules.

* <Cmd sid='common.schedule' product='2' />: Select a schedule. If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it.

:::info

* You can select multiple doors to configure schedule lock functionality in <Cmd sid='zone.globalZone.local' product='2' /> mode.

* For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::
