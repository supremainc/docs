Learn how to set up scheduled lock. Scheduled lock locks doors at specific times. This feature strengthens access control and helps restrict access during specific time periods.

:::info

Scheduled lock settings are supported only in <Cmd sid='zone.globalZone.local' product='2' /> mode.

:::

## Register scheduled lock {/* #addScheduledLockZone */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.advancedAc.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addZone' product='2' />.

4. Select <Cmd sid='zone.scheduledLock' product='2' /> and click <Cmd sid='button.apply' product='2' />.

5. In the <Cmd sid='common.information' product='2' /> section, enter the name of the scheduled lock to add.

   <Image src='/img/biostarx-settings-adv-ac-add-schedule-lock.png' />

6. In the <Cmd sid='common.setting' product='2' /> section, set the details of scheduled lock. For more information, see <DocLink inner='#setting' />.

7. In the <Cmd sid='common.alarm' product='2' /> section, set the action to run when a scheduled lock violation occurs.

8. In the <Cmd sid='zone.forcedLock.bypass' product='2' /> section, select the access group that can bypass scheduled lock. Users in this group can bypass scheduled lock.

9. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

The <Cmd sid='common.alarm' product='2' /> section is available only when <Cmd sid='zone.pause.doorselected' product='2' /> is set.

:::

## Setting options {/* #setting */}

The detailed settings for scheduled lock are as follows.

* <Cmd sid='zone.pause.activatedAndDeactivated' product='2' />: Turn the setting on, or turn it off temporarily.

* <Cmd sid='zone.forcedLock.doorLockType' product='2' />: Set whether to lock only entry devices or both entry and exit devices.

* <Cmd sid='zone.pause.doorselected' product='2' />: Select the doors to apply scheduled lock rules to.

* <Cmd sid='common.schedule' product='2' />: Select a schedule. If the schedule you need isn't in the list, click <Cmd sid='button.plusAddSchedule' product='2' /> to add it.

:::info

* In <Cmd sid='zone.globalZone.local' product='2' /> mode, you can select multiple doors to configure scheduled lock.

* For more information about schedule settings, see <DocLink docId='platform/biostar_x/settings-schedule' />.

:::
