Rules are settings that combine events from cameras and doors to send events and bookmarks to the VMS server. Proper video rule settings provide the following security management features.

* **Automatic bookmark creation**: When specific access events occur, bookmarks are created automatically so you can easily find important footage.

* **Efficient monitoring**: Monitor live video from cameras linked to doors, and check events immediately when they occur.

* **Integrated event management**: Link access events with footage to get a full picture of the security situation.

:::info

* The video rule feature is available as an add-on with an **Essential** license or higher. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

* To link a door to a camera, you must have permission for the camera's group. For more information about setting camera group permissions, see <DocLink docId='platform/biostar_x/settings-videos-camera#addCameraPermission' />.

:::

## Add a rule {/* #add-camera-rule */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.video' /> in the left sidebar.

3. Click <Cmd sid='video.addRule.button' product='2' /> in the upper-left corner of the screen.

When the <Cmd sid='video.rule.addRule.title' product='2' /> screen appears, set up the rule by following the instructions below. To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

### Enter rule information

In the <Cmd sid='video.rule.detail.information.title' product='2' /> section, enter the name and description of the new rule.

<Image src='/img/biostarx-settings-video-add-rule-info.png' />

:::info

<Cmd sid='video.rule.detail.description' product='2' /> is optional. Use it to enter a short description so you can easily identify the purpose or features of the rule.

:::

### Video log settings

<Cmd sid='video.addRule.label.videoLog' product='2' /> is a feature that automatically records footage before and after a specific event occurs. It retains footage for the specified period so you can understand the context before and after the event.

<Image src='/img/biostarx-settings-video-add-rule-video-log.png' />

* <Cmd sid='video.addRule.label.videoLog' product='2' />: Turn on or turn off the <Cmd sid='video.addRule.label.videoLog' product='2' className='normal' /> feature for the current rule.

  * <Cmd sid='video.addRule.label.enabled' product='2' />: Automatically records footage for the time before and after an event occurs.

  * <Cmd sid='video.addRule.label.disabled' product='2' />: Turns off the <Cmd sid='video.addRule.label.videoLog' product='2' className='normal' /> feature.

* <Cmd sid='video.addRule.label.videoLogLength' product='2' />: Set the range of footage to record around 10 seconds before and after the event time. The maximum is 60 seconds.

When you turn on the <Cmd sid='video.addRule.label.videoLog' product='2' /> option, the video log (<IcVidLog />) icon appears next to event entries in the event panel on the Monitoring screen. When you click an event entry with the video log icon, detailed information appears in the right pane. This lets you view video from when the event occurred.

<Image src='/img/biostarx-monitoring-camera-event-video-log.png' />

:::info

The longer the range you set for <Cmd sid='video.addRule.label.videoLogLength' product='2' />, the more storage space it may require. Set an appropriate length based on system performance and storage capacity.

:::

### Set the events to record in the VMS

In the <Cmd sid='video.rule.detail.event.title' product='2' /> section, select the events to record on the VMS server and set whether to send bookmarks or events.

<Image src='/img/biostarx-settings-video-add-rule-event.png' />

* <Cmd sid='video.rule.detail.event.itemName' product='2' />: Select the event type to send to the VMS server. When you select an event from the left event list, it is added to the list on the right.

* <Cmd sid='video.rule.detail.vmsBookmark.itemName' product='2' />: Set whether to create a bookmark on the VMS server when the selected event occurs.

* <Cmd sid='video.rule.detail.vmsEvent.itemName' product='2' />: Set whether to create an event record on the VMS server when the selected event occurs.

:::info

* Selecting events is optional.

* Use the search field at the top of the left event list to quickly find an event.

* To remove an event from the list on the right, click <IcTrash2 />.

* Set the message language when sending bookmarks and events to the VMS server. For more information, see <DocLink docId='platform/biostar_x/settings-video-integration#vms-event-bookmark' />.

::: 

### Link a door to a camera {/* #link-door-camera */}

In the <Cmd sid='video.rule.detail.doorCameraLinkage.title' product='2' /> section, link doors and cameras to send events that occur at the doors to the VMS server along with footage from the linked cameras. This makes it easy to view footage related to access events.

<Image src='/img/biostarx-settings-video-add-rule-connect-door.png' />

1. Click <Cmd sid='button.addplus' product='2' /> in the upper-right corner of the screen.

2. When the <Cmd sid='video.rule.detail.doorCameraLinkage.popup.title' product='2' /> window appears, select a door and then select the camera associated with that door.

   <Image src='/img/biostarx-settings-video-add-rule-connect-door-add.png' />

3. After you select both the door and the camera, click <Cmd sid='button.add' product='2' />.

The list shows the cameras linked to the door.

<Image src='/img/biostarx-settings-video-add-rule-connect-door-complete.png' />

:::info

* Administrators without permission for a camera group cannot view or select cameras in that group. For more information about setting camera group permissions, see <DocLink docId='platform/biostar_x/settings-videos-camera#addCameraPermission' />.

* You can add up to four cameras to a single door.

* Doors included in a rule cannot be used in other rules.

* You can link cameras to multiple doors without restrictions, and you can reuse cameras already linked to other doors.

* To delete a door-camera linkage rule, select the checkbox for the entry to delete in the list, and click <IcTrash2 /> <Cmd sid='button.delete' product='2' /> in the upper-right corner of the screen.

* Cameras linked to a door appear as child entries under the door in the door list on the <Cmd sid='shell.header.arena' /> page. For more information, see <DocLink docId='platform/biostar_x/check-door-status#door-tree-structure' />.

* To save the settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::

## Edit a rule {/* #edit-rule */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.video' /> in the left sidebar.

3. In the <Cmd sid='video.header.all.rules' product='2' /> list, click the rule to edit.

4. When the rule edit screen appears, edit the fields as needed.

5. To save the modified rule, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

For more information about each section of the rule editing screen, see <DocLink inner='#add-camera-rule' />.

:::

## Delete a rule

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.video' /> in the left sidebar.

3. In the <Cmd sid='video.header.all.rules' product='2' /> list, select the checkbox for the rule to delete. You can select one or more rules.

4. Click <IcTrash2 /> <Cmd sid='video.rule.delete' product='2' /> in the upper-right corner of the screen.

5. Check the message and click <Cmd sid='button.yes' product='2' />.

## List column settings

You can add, reorder, or hide columns shown in the list.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.video.root' /> → <Cmd sid='setting.menu.video.video' /> in the left sidebar.

3. In the upper-right corner of the <Cmd sid='video.header.all.rules' product='2' /> list, click <IcMoreW /> → <Cmd sid='columnSetting.dialog.header' product='2' />.

4. When the <Cmd sid='columnSetting.dialog.header' product='2' /> window appears, select or clear the checkbox for each column to show or hide it. To change the column order, drag and drop the columns.

   <Image src='/img/biostarx-settings-video-column-layout.png' />

5. After you change all column settings, click <Cmd sid='button.ok' product='2' />.

:::info

To restore the default column settings, click <Cmd sid='columnSetting.button.defaultColumn' product='2' />.

:::
