Learn how to manage access control and time and attendance efficiently by setting up access and holiday schedules. You can apply schedules to access control to manage user access times and holidays.

## Register a schedule {/* #addSchedule */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.schedule.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addSchedule' product='2' /> in the upper-left corner of the screen.

   <Image src='/img/biostarx-settings-schedule-add-btn.png' />

4. On the <Cmd sid='schedule.addNewSchedule' product='2' /> screen, set each option.

   <Image src='/img/biostarx-settings-schedule-add.png' />

5. After you complete all settings, click <Cmd sid='button.apply' product='2' /> at the bottom of the screen.

:::info

For more information about each option on the <Cmd sid='schedule.addNewSchedule' product='2' /> screen, see <DocLink inner='#addScheduleOptions' />.

:::

### Options for adding a new schedule {/* #addScheduleOptions */}

Set the following options on the <Cmd sid='schedule.addNewSchedule' product='2' /> screen.

<Image src='/img/biostarx-settings-schedule-add-extend.png' />

* <Cmd sid='common.name' product='2' />: Enter the schedule name.

* <Cmd sid='common.description' product='2' />: Enter a brief description of the schedule.

* <Cmd sid='common.type' product='2' />: Select a weekly or daily schedule. When you select <Cmd sid='schedule.daily' product='2' />, you can select <Cmd sid='schedule.cycle' product='2' /> and <Cmd sid='schedule.start_date' product='2' />.

  <Image src='/img/biostarx-settings-schedule-add-type-daily.png' />

* To set a time, click <Cmd sid='shift.timeSegment' product='2' /> in the middle area. After you finish, click <Cmd sid='button.apply' product='2' />.

  <Image src='/img/biostarx-settings-schedule-input-time-slot.png' />

  * Each day of the week or date can have up to five time slots.

  * To copy the time slot set directly above, click <IcTslot />.

  * To edit a time slot, click <IcEditUL />. To delete a time slot, click <IcEraser />.

* <Cmd sid='schedule.holidaySchedule' product='2' />: Select whether to apply holiday schedules. When you select this option, you can set the details.

  * Select a preset holiday from the <Cmd sid='common.none' product='2' /> list.  To add more holidays, click <Cmd sid='button.plusAdd' product='2' /> and set the holidays.

  * **Holiday time slots**: To set the time slots for holidays, click a time slot.

  :::info

  * To edit a time slot, click <IcEditUL />. To delete a time slot, click <IcEraser />.

  * To delete an added holiday, click <IcTrash2 />.

  * For more information about adding holiday schedules, see <DocLink inner='#addHolidaySchedule' />.

  :::

## Add a holiday schedule {/* #addHolidaySchedule */}

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.accessManagement.root' /> → <Cmd sid='setting.menu.schedule.root' /> in the left sidebar.

3. Click <Cmd sid='button.func.addHoliday' product='2' /> in the upper-left corner of the screen.

4. On the <Cmd sid='schedule.addNewHoliday' product='2' /> screen, enter <Cmd sid='common.name' product='2' /> and <Cmd sid='common.description' product='2' />.

   <Image src='/img/biostarx-settings-schedule-add-holiday.png' />

5. In the <Cmd sid='common.detail' product='2' /> section, click <Cmd sid='button.addplus' product='2' />.

6. Click <IcCalc />, select a date, and then set the number of repetitions and the period.

7. To register the holiday schedule, click <Cmd sid='button.apply' product='2' />.

:::info

To delete a holiday schedule, click <IcTrash2 />.

:::
