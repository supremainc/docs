<Cmd sid='setting.menu.credential.irFaceGroupMatching' className='normal' /> authenticates users by setting matching groups based on user groups. With this feature, you can allow access via IR face authentication only to users in specific user groups.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.setting' />.

2. Click <Cmd sid='setting.menu.credential.root' /> → <Cmd sid='setting.menu.credential.irFaceGroupMatching' /> in the left sidebar.

3. Set the <Cmd sid='globalSetting.facegroup.detail.useOption' product='2' /> option to <Cmd sid='common.use' />.

   <Image src='/img/biostarx-settings-credential-irface-group-match.png' />

4. In <Cmd sid='globalSetting.facegroup.detail.deviceTap.title' product='2' />, click <Cmd sid='button.addplus' product='2' />.

5. When the <Cmd sid='globalSetting.facegroup.detail.deviceTap.title' product='2' /> window appears, select a device, and click <Cmd sid='button.add' product='2' />.

   :::note

   Only the FaceStation 2 model can be selected.

   :::

6. In <Cmd sid='globalSetting.facegroup.detail.groupSettings' product='2' />, click <Cmd sid='button.addplus' product='2' />.

7. Set the <Cmd sid='globalSetting.facegroup.detail.groupName' product='2' /> and <Cmd sid='common.userGroup' product='2' /> fields.

8. To save the settings, click <Cmd sid='button.apply' product='2' /> in the lower-right corner of the screen.

:::info

* Up to 10 matching groups can be created.

* Each group can contain up to 3,000 IR face templates.

* Multiple user groups can be assigned to a single matching group.

* The total number of IR face templates in a matching group cannot exceed 5,000.

* If a user group contains more than 3,000 IR face templates, it cannot be set as a matching group.

* This feature is supported only by the FaceStation 2 model.

* To turn off the group matching feature, delete all configured devices and group settings.

:::
