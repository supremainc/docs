Learn how to install **BioStar X** step by step using the <Cmd code='biostar2.install.customInstall' className='bold'/> method. <Cmd code='biostar2.install.customInstall' className='bold'/> connects to an existing database (MariaDB or MS SQL Server) on a local or remote server and generates the database schema. Before you start the installation, prepare the database and user account to connect to.

## Before you start {/* #start-before */}

* The following databases are supported for use with **BioStar X**.

  * MariaDB 11.4.4

  * MS SQL Server 2012 SP3

  * MS SQL Server 2014 SP2

  * MS SQL Server 2016 SP1

  * MS SQL Server 2017

  * MS SQL Server 2019

  * MS SQL Server 2022

* MS SQL Server supports TLS 1.2 for secure communication.

* If database table creation fails after you set MS SQL Server as the database, run the scripts in *C:\Program Files\BioStar X\dbscript\mssql* to create the tables.

* When you select <Cmd code='biostar2.install.customInstall' className='bold'/> as the installation option, you cannot set **AC DB name**, **TA DB name**, and **VE DB name** to the same value.

* To use Windows authentication, [Microsoft ODBC Driver 17 for SQL Server](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver16#version-17) is required.
  Install the driver first.
