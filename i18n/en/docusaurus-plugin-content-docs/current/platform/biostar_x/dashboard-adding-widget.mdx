The **BioStar X** dashboard is a customizable monitoring screen where users can freely arrange the information they need. You can add various widgets to arrange key access control system information to suit your work environment.

You can add the following types of widgets.

* **Chart**: Visualizes access event data in bar, line, or pie charts

* **Counter**: Shows the number of daily or weekly events

* **Real-time events**: Monitors all events that occur in **BioStar X** in real time

* **Real-time access monitoring**: Shows information about users who authenticate successfully on a specific device in real time

* **System usage status**: Shows registration counts for users, devices, doors, and more

* **Door control**: Checks the status of the selected door and controls it remotely

* **Text**: Places custom text such as announcements or widget titles

Widgets on the dashboard provide the following benefits.

* **Custom layout**: Lets you select only the information you need for work and place it on one screen

* **Real-time monitoring**: Lets you immediately check access events and system status

* **Intuitive visualization**: Visually represents data with charts and counters

* **Efficient management**: Improves work efficiency by integrating monitoring and control features

## Add widgets {/* #add-widgets */}

Adding widgets to <Cmd sid='shell.header.dashboard' /> lets you view the information you need.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.dashboard' />.

2. Click <Cmd sid='reportApp.addWidget' product='2' />.

   <Image src='/img/biostarx-dashboard-add-widget.png' />

3. When the <Cmd sid='reportApp.addNewWidget' product='2' /> window appears, select an option in <Cmd sid='reportApp.widgetType' product='2' /> and enter or set the required fields.

   <Image src='/img/biostarx-dashboard-add-widget-type.png' width={400} />

4. Complete the widget settings and click <Cmd sid='reportApp.apply' product='2' />.

5. When a widget is created in the widget display area, resize it or place it in the location you need.

6. Once you have completed all settings, click <Cmd sid='reportApp.apply' product='2' /> in the upper-right corner of the screen.

:::info

If a widget has already been added, click <IcSet2 /> in the upper-right corner of the screen. Once you enter <Cmd sid='reportApp.dashboardSettings' product='2' /> mode, click <Cmd sid='reportApp.addWidget' product='2' />.

:::

## Types of widgets {/* #widget-types */}

* The default widget size varies by widget, and each widget is optimized to look best at its default size.

* All widgets can be resized by dragging the lower-right corner.

  <Image src='/img/biostarx-adjust-win-size.png' caption />

### Chart {/* #chart */}

Select chart data to show the number of events in a chart.

<Image src='/img/common/biostarx-chart.png' caption alone />

* <Cmd sid='reportApp.widgetTypes.chartData' product='2' />: Select chart data from the daily or weekly event list.

  * <Cmd sid='reportApp.dailyAccessGranted' product='2' />, <Cmd sid='reportApp.dailyAccessDenied' product='2' />, <Cmd sid='reportApp.dailyCommunicationIssue' product='2' />, <Cmd sid='reportApp.dailyAPBViolation' product='2' />, <Cmd sid='reportApp.weeklyAccessGranted' product='2' />, <Cmd sid='reportApp.weeklyAccessDenied' product='2' />, <Cmd sid='reportApp.weeklyCommunicationIssue' product='2' />, <Cmd sid='reportApp.weeklyAPBViolation' product='2' />

* <Cmd sid='reportApp.chartType' product='2' />: Select a type from <Cmd sid='reportApp.chartTypes.verticalBar' product='2' />, <Cmd sid='reportApp.chartTypes.horizontalBar' product='2' />, <Cmd sid='reportApp.chartTypes.line' product='2' />, or <Cmd sid='reportApp.chartTypes.pie' product='2' />.

* <Cmd sid='reportApp.chartColorSchemes' product='2' />: Select a color from five color schemes.

:::info

The chart values shown when selecting <Cmd sid='reportApp.chartColorSchemes' product='2' /> are random values for preview, not actual values.

:::

### Counter {/* #bar */}

Select counter data to show the number of events that occurred.

<Image src='/img/common/biostarx-counter.png' caption alone />

* <Cmd sid='reportApp.widgetTypes.counterData' product='2' />: Select counter data from the daily or weekly event list.

  * <Cmd sid='reportApp.dailyAccessGranted' product='2' />, <Cmd sid='reportApp.dailyAccessDenied' product='2' />, <Cmd sid='reportApp.dailyCommunicationIssue' product='2' />, <Cmd sid='reportApp.dailyAPBViolation' product='2' />, <Cmd sid='reportApp.weeklyAccessGranted' product='2' />, <Cmd sid='reportApp.weeklyAccessDenied' product='2' />, <Cmd sid='reportApp.weeklyCommunicationIssue' product='2' />, <Cmd sid='reportApp.weeklyAPBViolation' product='2' />

### Text {/* #text */}

Enter text and place it in the widget area of <Cmd sid='shell.header.dashboard' />. After you create it, place it where needed to use it as a widget title or as a notice.

<Image src='/img/common/biostarx-text.png' caption alone />

:::info

When you select the <Cmd sid='reportApp.widgetTypes.text.removeBackground' product='2' /> option while creating a <Cmd sid='reportApp.widgetTypes.text' product='2' /> widget, the background becomes transparent.

:::

### Real-time events {/* #realtime-events */}

Shows events that occur in **BioStar X** in real time. Filter by event, user, door, or device to view events.

<Image src='/img/biostarx-real-time-event.png' caption />

* <Cmd sid='reportApp.pause' product='2' />: Pauses real-time events.

* <Cmd sid='reportApp.play' product='2' />: Resumes paused real-time events.

* <Cmd sid='reportApp.clear' product='2' />: Deletes all authentication records.

:::info

If you go to another page and then return to <Cmd sid='shell.header.dashboard' />, the list is cleared and events are recorded again.

:::

### Real-time access monitoring {/* #real-time-access-monitoring */}

Select one device to show the profile photo and information (<Cmd sid='reportApp.user' product='2' />, <Cmd sid='reportApp.date' product='2' />, <Cmd sid='reportApp.device' product='2' />) of users who authenticate successfully on that device in real time.

<Image src='/img/biostarx-checkpoint.png' caption />

* <Cmd sid='reportApp.pause' product='2' />: Pauses real-time access monitoring.

* <Cmd sid='reportApp.play' product='2' />: Resumes paused real-time access monitoring.

* <Cmd sid='reportApp.clear' product='2' />: Deletes all authentication records.

:::info

<Cmd sid='reportApp.widgetTypes.checkpoint' product='2' /> records up to five users.

:::

Select one door to check and control its status.

<Image src='/img/biostarx-door-control.png' caption />

The following can be controlled with <Cmd sid='reportApp.doorControl.actionsBtn' product='2' />.

* <Cmd sid='reportApp.doorControl.actions.open' product='2' />, <Cmd sid='reportApp.doorControl.actions.normalize' product='2' />, <Cmd sid='reportApp.doorControl.actions.lock' product='2' />, <Cmd sid='reportApp.doorControl.actions.unlock' product='2' />, <Cmd sid='reportApp.doorControl.actions.clearAlarm' product='2' />, <Cmd sid='reportApp.doorControl.actions.clearAPB' product='2' />

:::info

The name of the <Cmd sid='reportApp.widgetTypes.doorControl' product='2' /> widget is automatically set to the door name and cannot be changed.

:::

## Set widget data refresh interval {/* #widget-refresh-interval */}

You can set the data refresh interval for widgets added to the dashboard.

1. On the <Cmd sid='shell.header.launcher' /> page, click <Cmd sid='shell.header.dashboard' />.

2. Click <IcSet2 /> in the upper-right corner of the screen.

3. After you enter <Cmd sid='reportApp.dashboardSettings' product='2' /> mode, set <Cmd sid='reportApp.autoRefreshInterval' product='2' /> in General Settings at the bottom of the screen.
