## MIPAccessControl Plugin Setup

1. Access control settings must be completed in BioStar X first.

1. Run 'Milestone XProtect Professional+ 2025 R3 Management Client'.

   Also, verify that the Access Control door license is included to enable the Suprema Plugin.

   <Image src='/img/integration/milestone/plugin-setup-license.png' alone />

1. Navigate to the **Access Control – system** node. Right-click on it and click **Create new**.

   <Image src='/img/integration/milestone/plugin-setup-create-new.png' alone />

1. Enter the name of the plugin. Select **MIPAccessControl** as the **Integration plug-in**, and enter the **BioStar X Server Address**, **Username**, and **Password**.

   <Image src='/img/integration/milestone/plugin-setup-create-integration.png' alone />

1. Plugin trigger to retrieve the BioStar X setting and completed.

   <div className='grid-container'>

   <Image src='/img/integration/milestone/plugin-setup-connecting.png' width={500} alone />

   <Image src='/img/integration/milestone/plugin-setup-associate-cameras.png' width={500} alone />

   </div>

1. Click the Plugin and tab **General settings**. You can update the access control system name, network settings, and login information.

   If you change any setting on the BioStar X then press **Refresh Configuration** button every time and don't forget the save button.

   1. BioStar X Server Address: 192.168.16.103:5002

      :::info
      
      For HTTPS, you can use (your_BioStar X_IP):(HTTPS_PORT).

      :::

   1. **Username** / **Password** : BioStar X ID / PW

   1. **Connection Timeout (ms)**: 30000

      * **Event polling interval (ms)**: 5000 (default) → 3000 (Recommended)

      * **Event polling max count**: 100

   1. [Plugin License portal access](#milestone-suprema-plugin-license-portal)

      Use the **License Portal Port** (localhost:8088) to access the license portal.

      > https://localhost:8088

   <Image src='/img/integration/milestone/plugin-setup-general-settings.png' alone />

   <div className='overflow-x'>
   | Setting | Description | Default Value | Range |
   | -- | -- | -- | -- |
   | **Connection Timeout** | Connection timeout for API calls, in milliseconds. | 30000 | 5000–120000 |
   | **Event polling interval (ms)** | Interval in milliseconds between event polling requests. | 5000 (5 seconds) | 100–7200000 |
   | **Event polling max count** | Maximum number of events retrieved per polling cycle. | 100 | 10, 50, 100, 200, 500 |
   | **Cardholder image override enabled** | Allows cardholder images to be overridden from external sources where supported. | true | true/false |
   | **Use Captured as Profile Photo** | Uses captured access control images as profile photos when available. | true | true/false |

   * **Doors and associated cameras**: You can associate the cameras with access points. See [Associating the camera](#associating-the-camera).

   * **Access control events**: You can activate or deactivate the access control event from BioStar X, also create and assign the userdefined categories.

   * **Access control actions**: You can create an access control action or command which is performed by the operator on the associated access points. For example, when a cardholder requests the door open, XProtect display a notification and then operator sending a door open command.

   * **Cardholders**: You can view or search the cardholder information. The cardholder information is synchronized with user information of BioStar X. In BioStar X, user information includes user name, access group, RFID card number, fingerprint template, face template, and PIN.

## Milestone x Suprema plugin License Portal {#milestone-suprema-plugin-license-portal}

Activate using a license key through the Suprema license service; license data is verified and stored securely. Register the license from the Suprema License server for the Plugin operational condition.

### Online Activation

1. Access at License portal, `localhost:8088` for online condition (if your server is connected to the internet). Ask Suprema license manager (mailto: int@suprema.co.kr) to get unique license key (16 characters) and project name.

   <Image src='/img/integration/milestone/license-online1.png' alone />

1. If you get the license key and project name, you can apply on it with **Activate Online**.

   <Image src='/img/integration/milestone/license-online2.png' alone />

### Offline Activation

1. Access at License portal, `localhost:8088` for offline condition (even though your server is offline (Can't access internet), license portal will be accessed with 'localhost'). Ask Suprema license manager (mailto: int@suprema.co.kr) to get unique license key (16 characters) and project name.

   <Image src='/img/integration/milestone/license-offline1.png' alone />

1. If you get the license key and project name, you can apply on it with Generate `Token.lic` on download folder (default). You send the token file to license manager.

   <Image src='/img/integration/milestone/license-offline2.png' alone />

1. The License Manager will provide the **.suprema** file, which is the result of synchronizing your system configuration data from your token with the license server. Apply 'activation token' with the **.suprema** file.

   <Image src='/img/integration/milestone/license-offline3.png' alone />

1. Offline license application successfully.

   <Image src='/img/integration/milestone/license-offline4.png' alone />

## Associating the Camera {#associating-the-camera}

If BioStar X connected correctly, the **Associate cameras** screen appears. In this step, you can associate the cameras with access points on the Milestone XProtect Management Client.

1. Find the camera in the **Cameras** pane and drag it to the associated access points.

   <Image src='/img/integration/milestone/associate-cameras1.png' alone />

1. When all access points associated with cameras, click **Next** to complete the settings.

   <Image src='/img/integration/milestone/associate-cameras2.png' alone />

1. When the success confirmation window appears, click **Close**.

   <Image src='/img/integration/milestone/associate-cameras3.png' alone />
