# Firmware Version 1.5.3 (Build No. 1.5.3_260818)

Release<Separator/>2026-08-19

:::caution

- Devices with firmware v1.5.1 or later cannot be downgraded to versions earlier than v1.5.1.

- The XP2-MAPB-H model cannot be downgraded to versions earlier than v1.4.3.

- XP2-GKDPB models with hardware v1.2.0 or later cannot be downgraded to versions earlier than v1.4.3. You can check the hardware version in the **Device** menu in BioStar 2.

- Devices with the new BLE chip cannot be downgraded to versions earlier than v1.3.1. This restriction does not apply to devices with the existing BLE chip.

To check whether your device can be downgraded and whether the new BLE chip is installed, verify the serial number and contact [Suprema](https://supremainc.com).

:::

## New Features and Improvements

---

{/* (XPASSII-707) [BDP-1593] 출입문 Toggle */}
1. Added support for unlocking or normalizing a door through user authentication.

{/* (XPASSII-562) [BDP-1561] Extended Door Open Time */}
2. Supports the **Extended Door Open Time** feature, which allows certain users to have the door remain open longer than the default door open time.

{/* (XPASSII-708) [BDP-1592] Door Unlock/Lock Improvement */}
3. Improved door control status to accurately display control results and change details in monitoring.

{/* (XPASSII-561) [BDP-962] Realtime Status of all devices connected to BSX */}
4. Supports real-time monitoring of the device's multiple statuses in BioStar X.

{/* (XPASSII-705) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경 */}
5. Improved Fire alarm zone status display and alarm clearing behavior after power restart following a fire alarm.

{/* (XPASSII-711) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) */}
6. Improved BLE stability.

{/* (XPASSII-558) [BDP-990] Relay가 Lock되었을 때 인증 실패 처리하기 */}
7. Improved so that when authentication is attempted on a door set to **Manual Lock**, an authentication failure event occurs and a locked message appears.
