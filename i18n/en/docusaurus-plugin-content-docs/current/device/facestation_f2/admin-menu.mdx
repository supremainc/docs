Provides guidance on the main menus and features accessible with administrator privileges.

## Full menu

1. Press <Image src='/img/common/ico-menu.svg' ico alone /> and authenticate with the Admin level credential.

   On the menu screen, check the device information or press <Cmd sid='ui_174' product='dev' /> to enroll a user right away.

2. Select your desired menu.

   <Image src='/img/device/fsf2-menu.png' width={300} />

:::info

If no administrator is designated, click <Image src='/img/common/ico-menu.svg' ico alone /> to display the menu screen.

:::
