# Firmware Version 1.0.4 (Build No. 1.0.4_260812)

Release<Separator/>2026-08-25

:::caution

- After upgrading the firmware to v1.0.3, it is not able to downgrade to an earlier version of the firmware.

- For more information, check the serial number of the device and contact the [Suprema](https://supremainc.com).

:::

## New Features and Improvements

---

{/* (BEW3FW-404) [BSF-2925][BDP-1634] OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기 */}
1. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

{/* (BEW3FW-421) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) - 발생버전 : V1.0.0 */}
2. Improved BLE stability.
