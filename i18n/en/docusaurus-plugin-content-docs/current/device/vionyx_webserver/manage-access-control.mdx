id: manage-access-control
title: Manage Access Control
description: Learn how to add doors and grant access permissions per user. Set the camera to control doors directly based on Facial Authentication results.
---

In the <Cmd sid='access' product='cam' /> menu, add doors connected to the camera. Set access levels to define who can access them and when. When an access control event determines access permission through facial authentication, the camera opens the relay connected to the door to grant access. Check the door status in real time, and open or lock it remotely. Set up voice prompts or webhook notifications based on the access decision. When setting up access control for the first time, create an access control event first, then configure doors, access levels, and door rules in order.

:::info

* Support for the <Cmd sid='access' product='cam' /> menu is included in firmware version 1.1.0 or later.

* The <Cmd sid='access' product='cam' /> menu is in beta. Screen layout and behavior may change in later firmware updates.

:::
