title: Manage AI Events
description: Learn how to define AI events, set rule actions and schedules, and configure detailed Facial Authentication options.
---

Setting AI events and rules lets the camera automatically execute required actions for detected situations. Create an AI event for each situation, then link the action for the event to an AI rule.

Create AI events for surveillance goals such as motion, zone intrusion, line crossing, people count, and door approach. In AI rules, specify audio, webhook, and relay actions, and apply schedules to limit when actions run. Adjust facial authentication options in advanced settings for your environment.

:::info

To use AI events, set at least one facial area that applies to all events.

:::
