This topic explains how to set a password and log in the first time you access the ViOnyx Web Server.

## Access the camera web server {/* #access-web-server */}

:::info

* Use a computer connected to the same network as the camera.

* If the device does not get an IP address after factory initialization, it changes to the default IP (`https://192.168.1.100`). Open the address in a web browser.

:::

1. Request the installation package (*VionyxTool.zip*) from the [Suprema Sales](https://www.supremainc.com/en/support/main.asp).

2. Extract the installation file, then run *ViOnyxTool_X.X.X.exe*.

   <Image src="/img/camera/web-server-settings1.png" width={800} />

3. Click <Cmd sid='search_for_cameras' product='cam' />.

4. In the list of detected cameras, find the <Cmd sid='device_id' product='cam' />(S/N) of the camera to connect, and check the <Cmd sid='ip_address' product='cam' />.

   <Image src="/img/camera/web-server-settings2.png" width={800} />

5. Open a web browser and go to the camera’s assigned IP address (`https://{IP ADDRESS}`).

   > Example: `https://192.168.1.100/`

6. The ViOnyx Web Server page appears.

## Set Password

When you first access the ViOnyx Web Server, set a password.

1. See [Access the camera web server](#access-web-server), then open a web browser and go to the IP address assigned to the camera (`https://{IP ADDRESS}`).

   > Example: `https://192.168.1.100/`

   <Image src="/img/camera/password-setting1-vionyx.png" width={572} />

2. Review the password requirements below, then enter a password in the <Cmd sid='password' product='cam' /> field.

   :::note

   **Password requirements**

   * **Length**: Enter between 12 and 64 characters.

   * **Character composition**: Must include at least 1 of each of the following: English uppercase letters (A-Z), English lowercase letters (a-z), digits (0-9), and special characters (`"` `!` `@` `#` `$` `%` `^` `&` `*` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}`).

      * Spaces, Hangul, and other Unicode characters are not allowed.

   * **Security rules**: To prevent security vulnerabilities, the following patterns are not allowed.

      * Consecutive sequences of 4 or more letters or numbers (e.g., abcd, 1234, 4321)

      * Identical characters or digits repeated 4 or more times (e.g., aaaa, 1111)

      * Contains the user ID (case-insensitive)

      * Common words or patterns that are easy to guess (e.g., password, qwerty)

   * **Password confirmation**: Values in the <Cmd sid='password' product='cam' /> and <Cmd sid='confirm_password' product='cam' /> fields must match exactly.

   :::

3. Enter the same password again in the <Cmd sid='confirm_password' product='cam' /> field.

4. When all password requirements are met, <Cmd sid='submit' product='cam' /> becomes active. Click the button to finish setting your password.

:::caution

Take care not to lose your password. If you lose your password, you will need to reset the camera.

:::

## How to Log in

After the password is set, you will be automatically redirected to the login page. Enter the administrator ID and the password you set to access the ViOnyx Web server.

<Image src="/img/camera/password-setting2-vionyx.png" width={572} />

1. Enter **admin** in the <Cmd sid='id' product='cam' /> field.

   * Change the administrator ID (**admin**) in <Cmd sid='system' product='cam' /> → <Cmd sid='account_management' product='cam' />.

2. Enter the password you set in the <Cmd sid='password' product='cam' /> field.

3. Click the <Cmd sid='sign_in' product='cam' /> button. After successfully logging in, the ViOnyx Web Server's live camera viewer will appear.

4. Refer to the [ViOnyx Web Server](../vionyx_webserver) to set up the camera.
