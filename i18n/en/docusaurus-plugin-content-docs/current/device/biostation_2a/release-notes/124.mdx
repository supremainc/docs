# Firmware Version 1.2.4 (Build No. 1.2.4_260810)

Release<Separator/>2026-08-25

:::caution

- After upgrading the firmware to v1.2.0, it is not able to downgrade to an earlier version of the firmware.

- For more information, check the serial number of the device and contact the [Suprema](https://supremainc.com).

:::

## New Features and Improvements

---

{/* (BS2AFW-275) [BDP-805] Intelligent Slave 사용 시 CP 로부터 전송받은 인증 결과(osdp_LED)를 장치 화면에 표시하기 */}
1. Supports the **Display Result from Controller** feature for displaying authentication success or failure results from a 3rd party controller on the device screen when using **Intelligent Slave**.

{/* (BS2AFW-612) [UI지원모델] 인증성공 LED Blue -> Green으로 변경 */}
2. Changed the authentication success LED color to green.

{/* (BS2AFW-629) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) */}
3. Improved BLE stability.
