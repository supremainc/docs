# Firmware Version 1.1.0 (Build No. 1.1.0_260728)

Release<Separator/>2026-07-29

## New Features and Improvements

---

1. Added support for video playback on the standby screen.

  :::note

  This feature can be configured in BioStar X. For detailed instructions, refer to **Setting Up Video Playback on the Standby Screen** in the BioStar X guide.

  :::

1. Supported EV2 Secure Messaging authentication and issuance for DESFire EV2 and EV3 cards.

1. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

1. Improved BLE stability.

1. Expanded allowed characters for User ID and User Name

  * Added support for periods (.) in User ID

  * Added support for periods (.) and apostrophes (') in User Name

1. Improved T&A message display to show on two lines.
