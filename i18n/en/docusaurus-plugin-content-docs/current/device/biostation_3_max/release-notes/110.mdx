# Firmware Version 1.1.0 (Build No. 1.1.0_260826)

Release<Separator/>2026-08-27

## New Features and Improvements

---

{/* (BS3MFW-451) 대기화면 동영상 플레이 */}
1. Added support for video playback on the standby screen.

    :::note

    This feature can be configured in BioStar X. For detailed instructions, refer to <Linkto to='platform/biostar_x/settings-device-details-advanced'>Devcie Settings → Advanced Settings</Linkto> in the BioStar X guide.

    :::

{/* (BS3MFW-412) BDP-1343 Desfire EV2 and EV3 features supported by Readers and Software */}
2. Supported EV2 Secure Messaging authentication and issuance for DESFire EV2 and EV3 cards.

{/* (BS3MFW-463) BSF-2925BDP-1634 OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기 */}
3. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

{/* (BS3MFW-541) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) */}
4. Improved BLE stability.

{/* (BS3MFW-562) [UI 지원 장치] 사용자 이름 및 사용자 ID에 Dot(.) 지원 */}
5. Expanded allowed characters for User ID and User Name

    * Added support for periods (.) in User ID

    * Added support for periods (.) and apostrophes (') in User Name

{/* (BS3MFW-95) Server / Device Private MSG관련하여 근태 표시 시 아래 이미지 처럼 표시가 되는 현상 - 1.0.0 */}
6. Improved T&A message display to show on two lines.

{/* (BS3MFW-465) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경 */}
7. Improved Fire alarm zone status display and alarm clearing behavior after power restart following a fire alarm.
