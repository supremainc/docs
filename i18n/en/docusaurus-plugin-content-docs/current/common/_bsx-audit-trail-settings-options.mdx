## Retention policy settings

<Include type={props.type} ref='accesscontrol'>

The <Cmd sid='audit.retention.sectionAccessControl' /> section consists of the following two groups.

</Include>

<Include type={props.type} ref='timeattendance'>

The <Cmd sid='audit.retention.sectionTimeAttendance' /> section consists of the following two groups.

</Include>

* <Cmd sid='audit.retention.groupChanges' />: Creation, update, and deletion logs. Logs are always recorded, and you cannot turn logging on or off.

* <Cmd sid='audit.retention.groupAccess' />: Records of view activity. You can set whether logs are recorded.

:::info

* Enter <Cmd sid='audit.retention.retentionPeriod' /> as an integer between 1 and 2,147,483,647 days.

### Change logs

Because the <Cmd sid='audit.retention.groupChanges' /> group is always recorded, select a <Cmd sid='audit.retention.labelRetention' /> option.

* <Cmd sid='audit.retention.optionEndless' />: Keep logs permanently without automatic deletion.

* <Cmd sid='audit.retention.optionCustom' />: Select this option to limit the retention period for compliance or internal policy. When the <Cmd sid='audit.retention.retentionPeriod' /> field becomes active, enter the retention period in days.

### View logs

In the <Cmd sid='audit.retention.groupAccess' /> group, set whether to record view logs.

* <Cmd sid='audit.retention.labelLogging' />: To record view logs, set to <Cmd sid='audit.retention.loggingOn' />. If not needed, set it to <Cmd sid='audit.retention.loggingOff' />.

* <Cmd sid='audit.retention.labelRetention' />: Select a retention method.

  * <Cmd sid='audit.retention.optionEndless' />: Keep view logs permanently without automatic deletion.

  * <Cmd sid='audit.retention.optionCustom' />: Activates the <Cmd sid='audit.retention.retentionPeriod' /> field. Enter the retention period in days.

:::info

When <Cmd sid='audit.retention.labelLogging' /> is set to <Cmd sid='audit.retention.loggingOff' />, view events are not recorded. You cannot view records from the earlier period even if you later set it to <Cmd sid='audit.retention.loggingOn' />.

:::

## How automatic deletion works

The server automatically deletes records that exceed the retention period set in <Cmd sid='audit.retention.optionCustom' /> during the job it runs daily at 1 a.m., regardless of user actions. Evaluation and deletion happen together in the same job, and this evaluation occurs only once a day.

> For example, if you set <Cmd sid='audit.retention.groupAccess' /> records to 30 days in <Cmd sid='audit.retention.optionCustom' />, the job run at 1 a.m. immediately deletes records older than 30 days. Records just past the retention period remain until the next day's 1 a.m. job, because the job runs only once a day.

When <Cmd sid='audit.retention.labelRetention' /> is set to <Cmd sid='audit.retention.optionEndless' />, the automatic deletion job does not run, and records are retained permanently.
