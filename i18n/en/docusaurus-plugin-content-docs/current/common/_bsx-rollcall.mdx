## Use roll call in the mobile app {/* #mobileAppRollCall */}

The roll call feature is available in the BioStar X mobile app.

<Include pages='settings-advanced-ac-roll-call'>

:::info

Install the BioStar X mobile app from the following links.

* iOS: [Apple App Store](https://apps.apple.com/kr/app/biostar-x-mobile/id6741415253)

* Android: [Google Play](https://play.google.com/store/apps/details?id=com.suprema.biostarmobile)

:::

</Include>

### Start roll call {/* #useRollCallMobileApp */}

To start roll call in the mobile app, follow these steps.

1. Launch the BioStar X mobile app on your mobile device.

2. On the app home screen, tap <Cmd>ROLL CALL</Cmd>.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-01.png' width={253} alone />

   :::note

   Alternatively, access it from the side menu. Tap <IcHamberg title='Hamburger icon' width={20} /> → <Cmd>Monitoring</Cmd> → <Cmd>Roll Call</Cmd>.

   :::

3. In the Roll Call list, tap <IcRCplay title='Start' width={20} height={20} /> next to the roll call to run.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-02.png' width={253} alone />

4. When the confirmation message appears, tap <Cmd>Yes</Cmd>.

Roll call starts, and tapping the ongoing roll call entry shows the roll call status.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-03.png' width={595} alone className='none' />

### Control an in-progress roll call {/* #controlInProgressRollCall */}

* The <IcRCdone title='Done' width={20} height={20} /> icon appears next to users who checked in. When all users check in, a message appears indicating that roll call has ended. To end the roll call, tap <Cmd>Yes</Cmd>.

* The administrator can manually change a user's check-in or status. In the user list, touch and hold the round button on the far right of the user to change the status.

  <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-change-status.png' alone className='none' width={595} />

* To initialize the roll call, tap <Cmd>Reset</Cmd>. All changes so far are deleted, and the roll call restarts from the beginning.

* If roll call is ended by another administrator, a notification message appears.

  <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-stopped.png' width={253} alone />

<Include pages='settings-advanced-ac-roll-call'>

* To view related reports after you complete the roll call, click <Cmd sid='shell.header.data' /> → <Cmd sid='data.mainMenu.generate' /> → <Cmd sid='data.sidebar.rollCall' />. For more information, see <DocLink inner='#viewRollCallReport' />.

</Include>

### View user information during roll call

You can check each user's information during roll call in the mobile app. Details such as emergency contact information and the user's last known location are available.

During roll call, swipe left on the user entry to view details. Then tap <IcRCinfo title='Information' width={20} height={20} />.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-info.png' className='none' width={595} alone />

### Leave a memo for a user during roll call

If a user does not check in during roll call in the mobile app, you can leave a memo for that user.

To enter a memo during roll call, swipe left on the user entry. Then tap <IcRCmemo title='Memo' width={20} height={20} />. On the memo screen, enter the text and then tap <Cmd>Save</Cmd>.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-memo.png' className='none' width={595} alone />

For users with a memo, the <IcRCmemo title='Memo' width={20} height={20} /> icon appears in the roll call list.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-status.png' width={253} alone />

### View roll call details {/* #viewRollCallinfo */}

You can view roll call setting details in the mobile app.

1. Launch the BioStar X mobile app on your mobile device.

2. On the app home screen, tap <Cmd>ROLL CALL</Cmd>.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-01.png' width={253} alone />

   :::note

   Alternatively, access it from the side menu. Tap <IcHamberg title='Hamburger icon' width={20} /> → <Cmd>Monitoring</Cmd> → <Cmd>Roll Call</Cmd>.

   :::

3. To view details, swipe left on the entry in the list, and then tap <IcRCinfo title='Information' width={20} height={20} />.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-info.png' width={595} alone className='none' />
