### Set the period

Set the period in <Cmd sid='data.header.customReport.period' /> in the upper-left corner of the screen. Click the date area.

<Image src='/img/biostarx-data-all-events-select-period.png' />

* You can select predefined periods from 1 day to 6 months based on today's date. The events that occurred during the selected period automatically appear in the list.

* Alternatively, select <Cmd sid='audit.retention.optionCustom' /> to manually set the period. When the period selection window appears, set the start date, end date, and time, and then click <Cmd sid='common.button.ok' />. The events that occurred during the set period automatically appear in the list.

  <Image src='/img/biostarx-data-all-events-set-custom-period.png' />

   :::info

   To select today's date, click <Cmd sid='data.dialog.rollCall.today' />.

   :::
