## Manage Plugins

**BioStar X Service Manager** lets you manage the installed plugins. 

In Windows, click <Start/> → **BioStar X** → **BioStar X Service Manager**. Click <Cmd>PLUGINS</Cmd> in the left sidebar of **BioStar X Service Manager**.

### View the plugin list

The list shows all plugins you registered.

<Image src='/img/common/biostarx-sm-plugins-list.png' alone />

### Edit a plugin

Click the plugin to edit in the plugin list. The plugin edit screen appears. You can edit <Cmd>Plugin Name</Cmd>, <Cmd>Description</Cmd>, and <Cmd>Plugin Icon</Cmd>.

<Image src='/img/common/biostarx-sm-plugins-list-edit.png' alone />

:::info

<Cmd>Plugin Address</Cmd> cannot be edited when <Cmd>Session Bridge</Cmd> is enabled.

:::

### Delete a plugin

1. In the plugin list, select the checkbox at the far left of the plugin to delete.

2. Click <IcTrash2 /> <Cmd>Delete</Cmd> in the upper-right corner of the screen.

3. When the confirmation message appears, click <Cmd>OK</Cmd>.

:::info

* The time and attendance (T&A) plugin added with the time and attendance license cannot be deleted.

* The time and attendance plugin is available as an add-on option. For more information about licensing policies, see <DocLink docId='platform/biostar_x/licensing#features-add-ons' />.

:::
