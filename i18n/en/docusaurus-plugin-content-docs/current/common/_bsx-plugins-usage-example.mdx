## Key use cases

You can integrate various external systems through the **BioStar X** plugin system. Typical use cases include the following.

* **Time and attendance management system**: Integration with external time and attendance (T&A) solutions

* **Visitor management system**: Integration with a separate visitor registration and management system

* **Reporting solution**: Integration with custom report generation and analysis tools

* **Third-party system integration**: Data integration with existing business systems such as ERP and HRM
