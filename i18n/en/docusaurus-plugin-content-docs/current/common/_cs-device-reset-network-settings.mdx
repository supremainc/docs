## Initialize Network Settings {/* #reset-network-settings */}

Initialize the device's network settings.

1. Connect the device to power.

2. Press and hold the **INIT** button for at least 3 seconds.

   <Include product='corestation_40'><Image src='/img/device/reset-network-settings-cs40.png' className='none' alone /></Include>

   <Include product='corestation_20'><Image src='/img/device/reset-network-settings-cs20.png' className='none' alone /></Include>

3. Network settings initialize as follows. In BioStar X, connect the device using the initialized network information.

   * **TCP/IP address**: DHCP is enabled, so the device gets an IP address automatically.

      :::info

      If DHCP address assignment fails, the device sets the address to 169.254.x.x.

      :::

   * **Server mode**: Prevents the device from requesting a direct connection to the server.

   * **RS-485**: Sets the communication speed to 115200 bps.
