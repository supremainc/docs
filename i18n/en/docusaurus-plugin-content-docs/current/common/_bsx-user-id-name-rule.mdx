:::note

**User ID and user name entry rules** <Anchor id='ruleUseridName'/>

* The <Cmd sid='team.user.table.id' /> value cannot include spaces.

* <Cmd sid='team.user.table.id' /> can include a period (`.`), but it cannot consist of only one period (`.`) or two periods (`..`).

* A user name can be up to 48 characters, including special characters.

  > Special characters: `~` `!` `@` `#` `$` `%` `^` `&` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}` `;` `.` `'`

* User IDs and user names cannot include the following characters. `₩` `/` `:` `*` `?` `"` `<` `>` `|` `` ` ``

* A user ID also cannot include an apostrophe (`'`).

* A user name cannot start with the sequence `&@~`. However, a user name can start with `&`, `@`, or `~` alone.

:::
