:::note

**User ID and name entry rules**

* Spaces cannot be included with the value of <Cmd sid='team.user.table.id' />.

* <Cmd sid='team.user.table.id' /> can include a period (`.`), but it cannot consist of only one period (`.`) or two periods (`..`).

* The username can be up to 48 characters, including special characters.

  > Special characters: `~` `!` `@` `#` `$` `%` `^` `&` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}` `;` `.` `'`

* User IDs and names cannot include the following characters. `₩` `/` `:` `*` `?` `"` `<` `>` `|` `` ` ``

* User IDs also cannot include an apostrophe (`'`).

* A user name cannot start with `&@~` consecutively at the beginning. However, a user name may start with `&`, `@`, or `~` alone.

:::
