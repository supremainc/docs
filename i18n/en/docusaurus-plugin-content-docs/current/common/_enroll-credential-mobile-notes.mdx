* If you have enabled the <Cmd sid='common.photo' product='2' />, <Cmd sid='common.department' product='2' />, and <Cmd sid='team.user.detail.title' product='2' /> options in the <Cmd sid='common.info' product='2' /> section, that information can be displayed on the user's mobile access card. The items displayed at this time are based on the information entered by the user. For more information on entering basic user information, see <DocLink docId='platform/biostar_x/add-user-basic-info' />.

* The system restricts issuance if the user name contains special characters incompatible with the Mobile Access Card. Only `@` `-` `_` `+` `[` `]` `,` `.` are allowed.

* If the user name includes a single quote(`'`), a notice appears. The system sends the value without the quote when saving the user. When this notice appears, the system already created the card record. Canceling the notice stops only the transfer to the Airpop portal, and the card remains unusable. In this case, the system saves the remaining user information without linking the unusable card to the user.
