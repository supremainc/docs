XPass 2 は、Suprema の最新 RFID 技術とマルチハードウェアプラットフォームを基盤とする屋外用コンパクト RFID 端末です。 マルチフォームファクター技術により、ドア枠に設置できるマリオン（Mullion）タイプ、スイッチボックスに設置できるギャングボックス（Gangbox）タイプ、キーパッドタイプのすべてをサポートし、さまざまな設置環境に完全に対応できます。

さらに、Dual-Frequency（125 kHz / 13.56 MHz）RFID 技術を採用し、EM、MIFARE、DESFire EV1 を含む多様な規格のカードと、最新のモバイル通信技術である NFC および BLE を用いたモバイルカードにも対応します。IP67 等級の防水防塵性能と IK08 等級のバンダルプルーフ構造を備え、屋外設置に最適化されており、ユーザーが望むあらゆる場所に設置できます。
