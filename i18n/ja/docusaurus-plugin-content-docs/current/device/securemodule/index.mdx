Secure I/O 2 は、外部ドアリレー 1 系統の制御と入出力拡張のための分離型コントローラーです。 Suprema の IP 入退室管理端末と暗号化通信を行うことでセキュリティを強化でき、利用環境に最適化されたソリューションを提供します。
