管理者権限でアクセスできる主なメニューと機能を案内します。

## すべてのメニュー

1. <Image src='/img/common/ico-menu.svg' ico alone /> を選択し、管理者権限の認証手段で認証します。

   メニュー画面でデバイス情報を確認するか、<Cmd sid='ui_174' product='dev' /> を押してユーザーをすぐに登録できます。

2. 目的のメニューを選択してください。

   <Image src='/img/device/fsf2-menu.png' width={300} />

:::info

管理者が指定されていない場合、<Image src='/img/common/ico-menu.svg' ico alone /> を押すとメニュー画面が表示されます。

:::
