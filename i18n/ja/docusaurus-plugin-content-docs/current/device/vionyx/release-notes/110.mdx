# Firmware Version 1.1.0 (Build No. 1.0.1_261015)

Release<Separator/>2026-10-16

## New Features and Improvements

---

    {/* (AICP-35) RS-485 설정: 지원 Master I/O 모듈 등록 및 상태 확인 (최대 8대) */}
1. Added I/O module registration and status monitoring in RS-485 settings (up to 8 devices)

    {/* (AICP-36, TASK 487) Rule Action: 인증/미인증 구분별 Relay 동작 설정 지원 */}
1. Added relay action settings based on registered/unregistered user distinction in Rule actions

    {/* (AICP-37) Schedule: 주간 일정 생성/편집 및 Rule 연결 */}
1. Added weekly schedule creation/editing and rule linking

    {/* (AICP-38, TASK 471, TASK 495) Count option: People Count 동작 옵션 제공, Count Limit 설정 시 제한 인원 이하에서도 인원 변경 시 이벤트 발행 및 초과 시 별도 이벤트 발행 */}
1. Added count functionality for AI events (**People Tracking**, **Line Crossing**, **Intrusion**)

    {/* (AICP-41) 사람 검출 영역: 사람 검출 영역을 전체/얼굴 영역/사용자 지정 영역으로 설정 지원 */}
1. Added support for setting the people detection area to **All Area**, **Face Area Only**, or **Designated Area**

    {/* (AICP-42, AIODHUB-37, AIODHUB-43, AIODHUB-95) 출입 통제 (Beta): Door, Access Level, Door Rule, AI Event, Anti-Tailgating 설정 제공, Door 설정에서 Relay/Input 포트 사용 현황 확인 */}
1. Added Access Control
    - Provides Door, Access Level, Door Rule, AI Event, and Anti-Tailgating settings
    - Check Relay/Input port usage in Door settings

    {/* (AICP-43) 시스템 로그: 출입 통제 로그 추가 */}
1. Added access control logs to system logs

    {/* (AICP-44, AIODHUB-31, AIODHUB-32) 카메라 히터 수동 제어: 히터 수동 ON/OFF 지원 (기본값 OFF, 켠 뒤 30분 후 자동 OFF) */}
1. Added manual camera **Heater** On/Off control (automatically turns off 30 minutes after being turned on)

    {/* (AICP-45, AIODHUB-49) ONVIF Profile S: Profile S 옵션 설정 지원 */}
1. Added ONVIF Profile S fallback activation option

    {/* (ACFEFW-95, ACFEFW-96, ACFEFW-98) Adaptive AE: 설정 ON/OFF 제공 (기본값 ON), 얼굴 영역 및 장면 변화에 따른 노출 제어 개선으로 과노출 상태가 지속되는 현상 개선 */}
1. Added **Adaptive AE Mode** On/Off setting (improves overexposure through exposure control based on face area and scene changes)

    {/* (AIODHUB-83, AIODHUB-85, TASK 500) 야간 IR 자동 전환: IR 자동 전환 ON/OFF 지원 (재부팅 후 설정 유지) */}
1. Added **Auto IR Switch** On/Off support (settings retained after reboot)

    {/* (AIODHUB-78, AIODHUB-79, AIODHUB-80) Line Crossing 기준점: Line Crossing 이벤트 판정 기준점(Center/Bottom) 선택 기능 추가 */}
1. Added **Line Crossing** event detection reference point (Center/Bottom) selection

    {/* (AIODHUB-87) People Count: Live View에서 Count 라벨 위치 조정 지원 */}
1. Added support for adjusting People Count label position in Live View

    {/* (AIODHUB-64) Operator 권한: Operator 계정에 날짜 및 시간 설정 권한 부여 */}
1. Granted **Date & Time** setting permission to **Operator** accounts

    {/* (AIODHUB-63, AIODHUB-96, AIODHUB-97, AIODHUB-98, AIODHUB-15) 사람 검출 및 얼굴 인증: 사람 검출 모델 1.3.5 업데이트, 얼굴 인증 모델 갱신, 인증 성공 LED 표시 시점 및 얼굴 등록 품질 검증 실패 안내 문구 개선 */}
1. Improved person detection and face authentication
    - Improved detection performance through a person detection model update
    - Updated the face authentication model
    - Improved LED display behavior on successful face authentication
    - Improved the guidance message when face enrollment quality validation fails

    {/* (ACFEFW-81, ACFEFW-82, ACFEFW-83) 네트워크: DHCP/Static 전환 시 DNS 설정 유지 및 표시 개선, Static 모드에서 Gateway를 선택 항목으로 변경 */}
1. Improved network settings
    - Improved DNS settings not being retained or displayed when switching between **DHCP**/**Static**
    - Changed **Gateway** to optional input in **Static** settings

    {/* (ACFEFW-76, ACFEFW-14, AIODHUB-74, TASK 420) 계정·초기화: 패스워드 변경 후 90일 경과 시 변경 권장 팝업 표시, Config Reset 동작 개선 및 요청 timeout 120초로 변경 */}
1. Improved password change recommendation popup to display after 90 days since the last password change

    {/* (TASK 443) 접속: 다른 계정의 동시 접속 제한으로 접속이 차단되는 제약 완화 */}
1. Eased the restriction that blocked access due to concurrent login limits from other accounts
