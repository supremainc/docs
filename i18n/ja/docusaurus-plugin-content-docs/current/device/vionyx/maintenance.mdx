カメラを工場出荷時の状態にリセットし、防湿モジュールを交換する方法を説明します。

## 工場初期化 {/* #factory-reset */}

カメラに保存されているすべての情報を削除し、設定を初期状態に戻します。

1. カメラに電源を接続した後、初期化ボタンの位置を確認してください。

   <Image src='/img/camera/factory-reset-vionyx.svg' className='none' width={350} alone />

2. 初期化ボタンを5秒以上押し続けてください。

3. 工場出荷時の初期化が完了すると、カメラは自動的に再起動します。

:::caution

工場出荷時の初期化を実行すると、ネットワーク設定を含むすべてのユーザーデータおよび設定が削除されます。

:::

:::info

* IPアドレスはデフォルトでDHCPに設定されています。

* 工場出荷状態に初期化した後に IP アドレスが割り当てられない場合は、デフォルト IP アドレス（`https://192.168.1.100`）に変更されます。こちらのアドレスを使用して接続してください。

:::

## シリカゲルモジュールを交換する {/* #change-silicagel */}

防湿性能を維持するため、少なくとも1年ごとに防湿モジュールを交換することを推奨します。

1. 使用済みのシリカゲルモジュールをカバーから取り外してください。

   <Image src='/img/camera/installation-desiccant-module1-vionyx.svg' className='none' width={480} alone />

2. 新しいシリカゲルモジュールの背面の保護フィルムをはがしてください。

   <Image src='/img/camera/installation-desiccant-module2-vionyx.svg' className='none' width={350} alone />

3. シリカゲルモジュールの溝をカバーの突起部に合わせて貼り付け、手で押してしっかり密着させてください。

   <Image src='/img/camera/installation-desiccant-module3-vionyx.svg' className='none' width={700} alone />

:::caution

* 乾燥剤モジュールは密封包装の状態で提供します。 空気にさらすと除湿性能が低下する可能性があるため、貼り付け直前に包装を開封してください。

* 交換周期は設置環境によって異なる場合があります。

:::

:::info

* 交換日を記録して、次回交換の時期を管理してください。

* 交換用の防湿モジュールは、製品の購入先でお求めいただけます。

:::
