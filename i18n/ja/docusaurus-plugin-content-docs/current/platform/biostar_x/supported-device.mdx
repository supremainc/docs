title: 対応デバイス
description: BioStar X プラットフォームが対応するデバイスと、デバイスごとの最小ファームウェア バージョンを確認してください。
---

**BioStar X** プラットフォームが対応するデバイスと、デバイスごとの最小ファームウェア バージョンです。デバイスのファームウェアが下記一覧に記載されたバージョンより低い場合、ファームウェアをアップグレードしてから使用してください。

:::info

デバイスが最小ファームウェア バージョンを満たしていても、デバイス仕様またはファームウェア バージョンによっては **BioStar X** の一部の機能を使用できない場合があります。機能ごとの対応デバイスとファームウェア バージョンは、各機能のドキュメントを確認してください。

:::
