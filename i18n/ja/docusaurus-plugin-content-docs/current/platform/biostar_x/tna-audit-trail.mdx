title: 勤怠監査ログを照会する
description: 勤怠管理に関する作成、変更、削除、照会など、すべての操作を監査ログで確認し、フィルタリングする方法を説明します。
---

<Cmd sid='setting.menu.auditTrail.taAuditLog' /> 機能は、勤務・スケジュール・レポートなど、勤怠管理に関するすべての操作を記録します。各記録は、いつ、誰が、何を、どのように変更したかを併せて示すため、セキュリティ監査やトラブルシューティングに活用できます。

:::info

<Cmd sid='setting.menu.auditTrail.taAuditLog' /> メニューは、勤怠管理（T&A）ライセンスが有効で、運用管理者にこのメニュー権限がある場合に利用できます。勤怠管理プラグインのインストール時に既定で作成される <Cmd sid='setting.account.taOperator' product='2' /> アカウントにはこの権限がないため、カスタム権限を追加して設定します。

:::

## 勤怠監査権限の追加 {/* #addTnaAuditLevel */}

1. <Cmd sid='shell.header.launcher' />ページで<Cmd sid='shell.header.setting' />をクリックします。

2. 画面左のサイドバーで <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.account' /> をクリックします。

3. <Cmd sid='setting.account.addCustomOperator' product='2' /> をクリックします。

   <Image src='/img/biostarx-settings-account-add-custom-permission.png' />

4. 勤怠監査ログを照会するための権限名と説明を入力します。

   <Image src='/img/biostarx-settings-account-add-custom-permission-details.png' />

5. <Cmd sid='settings.account.menu.setting' product='2' /> で <Cmd sid='common.auditTrail' product='2' /> メニュー配下の <Cmd sid='common.taAuditLog' product='2' /> と <Cmd sid='common.retentionSettings' product='2' /> に権限を設定します。

   <Image src='/img/biostarx-settings-custom-account-level.png' />

6. <Cmd sid='settings.account.addUser' product='2' /> で <Cmd sid='button.plusAdd' product='2' /> ボタンをクリックし、ユーザーグループまたはユーザーを選択します。

7. カスタム権限を保存するには、画面最下部の <Cmd sid='button.apply' product='2' /> をクリックします。 

## 勤怠監査ログの確認

1. <Cmd sid='shell.header.launcher' />ページで<Cmd sid='shell.header.setting' />をクリックします。

2. 画面左のサイドバーで <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.taAuditLog' /> をクリックします。

3. 勤怠関連の監査ログ一覧が画面に表示されます。

<Image src='/img/biostarx-settings-tna-audit-trail.png' />

:::info

* 保存期間などの監査ログポリシーを変更する場合は、<DocLink docId='platform/biostar_x/tna-audit-trail-settings' />を参照してください。

* バージョン1.0.3にアップグレードした後、新たに作成される監査ログは、<Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.system.security' /> メニューの <Cmd sid='setting.sever.secure.comm.encrypt.db' product='2' /> オプションに関係なく、暗号化して保存します。

* BioStar 2 から **BioStar X** にアップグレードした後、監査ログの一部が記録されない場合は <DocLink docId='platform/biostar_x/migration-x#checkCert' /> を参照してください。

:::

## テーブルの構成

監査ログ一覧テーブルは10列で構成され、現在の検索条件に該当する記録を <Cmd sid='audit.column.datetime' /> の新しい順に表示します。

| 列 | 説明 |
| --- | --- |
| <Cmd sid='audit.column.datetime' /> | イベントが発生した日時です。 |
| <Cmd sid='audit.column.user' /> | イベントを実行したユーザーです。 **id(名前)** 形式で表示されます。 |
| <Cmd sid='audit.column.accountLevel' /> | イベントを実行したユーザーの管理者レベルです。システムが自動で実行した操作は空欄にします。 |
| <Cmd sid='audit.column.action' /> | 実行された操作の種類です。<Cmd sid='action.create' />、<Cmd sid='action.update' />、<Cmd sid='action.delete' />、<Cmd sid='action.read' />、<Cmd sid='action.export' />、<Cmd sid='action.operation' /> のいずれかに分類されます。 |
| <Cmd sid='audit.column.category' /> | イベント対象のドメイン分類です。 (<Cmd sid='category.shift' />, <Cmd sid='category.schedule' />, <Cmd sid='category.report' />, <Cmd sid='category.ta_audit_log' />, <Cmd sid='category.setting' />, <Cmd sid='category.system' />) |
| <Cmd sid='audit.column.target' /> | 操作が適用された対象です。**タイプ: id(名前)** 形式で表示されます。 |
| <Cmd sid='audit.column.subAction' /> | <Cmd sid='action.operation' />、<Cmd sid='action.read' />、<Cmd sid='action.export' /> の操作でのみ表示される詳細操作名です。 |
| <Cmd sid='audit.column.modifiedFields' /> | 変更または照会されたフィールド名です。 <Cmd sid='action.operation' /> は常に空欄にします。 |
| <Cmd sid='audit.column.details' /> | 動作別の詳細情報です。（変更値、照会条件、フィールドスナップショットなど） |
| <Cmd sid='audit.column.ip' /> | ユーザーが接続したIPアドレスです。システムが自動で発行した記録は**127.0.0.1**と表示されます。 |

:::info

* <Cmd sid='audit.column.action' /> が <Cmd sid='action.update' /> の記録は、常に対象を1件のみ示します。複数の対象を一度に変更する一括編集は勤怠管理にないため、対象が複数件としてまとめて表示されません。

* <Cmd sid='audit.column.user' />、<Cmd sid='audit.column.target' />、<Cmd sid='audit.detail.changeDetails' /> に表示される名称は、その記録が発生した時点の値をそのまま保持します。その後に名称が変わったり対象が削除されたりしても、過去記録の表示名は変わりません。

* <Cmd sid='audit.column.target' />と<Cmd sid='audit.column.modifiedFields' />の値が2件以上の場合、最初の項目のみ表示し、残りは右側に残件数バッジ（例：**+208**）としてまとめて表示します。残件数が1,000件以上の場合は**+999**と表記し、正確な合計件数は詳細ポップアップのタイトルで確認できます。バッジをクリックすると、そのセルの詳細ポップアップが開きます。

  <Image src='/img/biostarx-settings-system-audit-trail-list-badge.png' />

* セルの値が長い場合は一行で省略して表示します。マウスを合わせると値全体をツールチップに表示し、ツールチップからはみ出す部分は`...`で省略して表示します。

  <Image src='/img/biostarx-settings-system-audit-trail-list-tooltip.png' />

:::

## 詳細情報の確認

値が入っている <Cmd sid='audit.column.target' />、<Cmd sid='audit.column.modifiedFields' />、<Cmd sid='audit.column.details' /> のセルには下線が付き、クリックできます。セルをクリックすると、該当行の操作に応じた詳細ポップアップが開きます。<Cmd sid='audit.filter.ok' /> ボタンまたは <IcClose /> ボタンで閉じます。

<Image src='/img/biostarx-settings-tna-audit-trail-detail-popup.png' />

ポップアップ上部の<Cmd sid='audit.detail.searchPlaceholder' />入力フィールドに検索語を入力すると、一致する項目だけを強調表示するかフィルタリングします。対象ポップアップでは、検索時にグループとグループ別件数も更新されますが、タイトルの全体件数は検索に関係なく変わりません。

## フィルターで記録を絞り込む

<Cmd sid='audit.filter.title' />セクションのフィルターを組み合わせ、目的の記録を絞り込んで探してください。同一フィルター内で複数の値を選択すると`OR`で、異なるフィルターを併用すると`AND`で結合されます。

<Image src='/img/biostarx-settings-tna-audit-trail-filtered.png' />

| フィルター | 動作方式 |
| --- | --- |
| <Cmd sid='audit.filter.datetime' /> | 開始・終了の日時を指定します。照会期間に長さ制限はありません。 |
| <Cmd sid='audit.filter.user' /> | 検索語を入力し、<Kbd>Enter</Kbd>キーを押して一致するユーザーを探してください。最初に開くと一覧は空です。 |
| <Cmd sid='audit.filter.accountLevel' /> | 検索語を入力し、<Kbd>Enter</Kbd>キーを押して一致する管理者レベルを探してください。 |
| <Cmd sid='audit.filter.category' /> | 検索可能なチェックボックス一覧から、分類を一つ以上選択してください。 |
| <Cmd sid='audit.filter.target' /> | 検索語を入力し、<Kbd>Enter</Kbd>キーを押して一致する対象を探してください。 |
| <Cmd sid='audit.filter.action' /> | チェックボックス一覧から動作を一つ以上選択してください。 |
| <Cmd sid='audit.filter.subAction' /> | 検索可能なリストから詳細操作を選択してください。 |
| <Cmd sid='audit.filter.ip' /> | 検索語を入力し、<Kbd>Enter</Kbd> キーを押して一致する IP を検索します。 |

* 適用したフィルターがない場合、現在の日付から30日前までの記録を既定で表示します。

* 各フィルターポップアップで値を選択し、<Cmd sid='audit.filter.addCondition' /> ボタンをクリックすると、検索にすぐ反映されます。 <Cmd sid='audit.filter.cancel' /> をクリックすると、選択を取り消してポップアップを閉じます。

  <Image src='/img/biostarx-settings-system-audit-trail-set-filter-popup.png' />

* 適用したフィルターは、先頭の条件と追加件数で要約して表示されます。 <IcClose title='Disable' /> をクリックすると、そのフィルターだけを解除します。値を選択していないフィルターは <Cmd sid='audit.filter.none' /> と表示されます。

  <Image src='/img/biostarx-settings-system-audit-trail-seted-filters.png' />

:::info

<Cmd sid='audit.filter.user' />、<Cmd sid='audit.filter.accountLevel' />、<Cmd sid='audit.filter.target' />、<Cmd sid='audit.filter.ip' /> フィルターは、検索語を入力すると結果が表示されます。部分一致に対応しているため、名前やIDの一部だけを入力しても検索できます。削除した対象も <Cmd sid='audit.detail.target.deleted' /> と表示して検索します。

:::

### 照会期間の指定

<Cmd sid='audit.filter.datetime' /> をクリックすると、<Cmd sid='audit.filter.dateRangeTitle' /> ポップアップが開きます。

<Image src='/img/biostarx-settings-tna-audit-trail-set-period.png' />

1. <Cmd sid='audit.filter.startDatetime' /> と <Cmd sid='audit.filter.endDatetime' /> の日時をそれぞれ指定します。 <Cmd sid='audit.filter.today' /> をクリックすると、今日の日付へ移動します。

2. 照会期間を適用するには、<Cmd sid='audit.filter.ok' /> ボタンをクリックします。

## フィルターの保存

よく使う検索条件は <Cmd sid='audit.filter.savedFilters' /> に保存し、再度読み込めます。

1. 希望する条件でフィルターを設定します。

2. <Cmd sid='audit.filter.title' /> セクションの <Cmd sid='audit.filter.save' /> ボタンをクリックします。

3. 画面左のフィルターリストに <Cmd sid='audit.filter.newFilterName' /> が追加されます。

<Image src='/img/biostarx-settings-tna-audit-trail-add-filter.png' />

* フィルター名を変更するには <IcAuditEdit title='Edit' /> ボタンをクリックし、新しい名前を入力して <Kbd>Enter</Kbd> キーを押します。

* フィルターを削除するには <IcAuditDelete title='Delete' /> ボタンをクリックします。

:::info

保存できるフィルターは最大20件です。保存したフィルターはブラウザーに保存されるため、別のPCやブラウザーでは表示されません。

:::

## 連鎖削除で残る追加記録 {/* #tna-audit-trail-cascade */}

勤務スケジュールを変更または削除すると、システムはそのスケジュールを使用していたユーザーの一時スケジュールと不在も削除する場合があります。この場合、システムは勤務スケジュール自体の変更または削除記録とは別に、実際に削除された一時スケジュールと不在ごとに追加記録を残します。

* 連鎖して削除された項目がない場合、追加記録も残りません。

* <Cmd sid='audit.column.target' /> は、原因となった勤務スケジュール 1 件と、実際に項目が削除されたユーザーだけを含みます。スケジュールに属するユーザー全員ではありません。

* <Cmd sid='audit.column.details' /> は削除件数を表示します。勤務スケジュールを削除した場合は、削除対象期間も表示します。

## CSV へのエクスポート

監査ログをCSVファイルにエクスポートし、外部分析ツールで活用してください。

1. <Cmd sid='audit.filter.title' /> セクションで必要に応じてフィルターを設定してください。

2. セクション右側の <IcMoreW /> → <Cmd sid='audit.filter.menuCsvExport' /> をクリックしてください。

3. <Cmd sid='audit.csvExport.title' /> ウィンドウが表示されたら、<Cmd sid='audit.csvExport.reasonLabel' />(任意)を入力し、<Cmd sid='common.apply' /> ボタンをクリックします。

   <Image src='/img/biostarx-settings-system-audit-trail-export-csv.png' />

エクスポートしたCSVファイルは、レコードごとに一行で10列すべてを含み、値にカンマが含まれるセルのみを引用符で囲みます。 <Cmd sid='audit.column.target' /> と <Cmd sid='audit.column.modifiedFields' /> のように複数の値が入るセルは、縦棒(`|`)で区切ります（例: **Schedule: 7(Team Schedule)| User: 12(Robert)**）。 <Cmd sid='audit.column.action' /> が <Cmd sid='action.update' /> の記録では、<Cmd sid='audit.column.details' /> は省略せず全フィールドを含みます。

:::caution

CSV ファイルは、スプレッドシートが数式として解釈できる値を元のまま含みます。ダウンロードした CSV ファイルをスプレッドシートで直ちに開かず、必要に応じてテキストのインポート機能で開いてください。

:::

:::tip

フィルターを設定した場合、フィルタリングされた結果だけをCSVファイルにエクスポートします。

:::
