購入した **BioStar X** ライセンスを登録できます。

ユーザーのネットワーク環境によって、<Cmd sid='setting.menu.license.biostarXLicense' /> を登録する方法が異なります。案内に従ってネットワーク状態を確認し、ライセンスを有効化してください。

1. <Cmd sid='shell.header.launcher' />ページで<Cmd sid='shell.header.setting' />をクリックします。

2. 画面左のサイドバーで <Cmd sid='setting.menu.license.root' /> → <Cmd sid='setting.menu.license.biostarXLicense' /> をクリックします。

:::info

* ライセンスポリシーの詳細については、<DocLink docId='platform/biostar_x/licensing' />をご参照ください。

* ライセンスのエラーコードを確認するには[次のリンク](https://reprisesoftware.com/docs/isv/appendix/appendix-b-rlm-status-values.html)を参照してください。

:::

## ライセンス有効化結果の確認 {/* #checkResult */}

入力したライセンスキーの有効化結果に応じて、次の案内を表示します。

* 入力したすべてのライセンスキーが有効な場合、成功メッセージを表示します。

  <Image src='/img/biostarx-license-success.png' />

* 一部のキーだけ有効化に成功した場合、またはすべてのキーが失敗した場合、キーごとの成功・失敗と失敗理由を確認できます。成功したキーの入力欄を初期化し、失敗したキーは再入力できるよう入力欄に残します。

  <Columns>
   <Column><Image src='/img/biostarx-license-fail.png' /></Column>
   <Column><Image src='/img/biostarx-license-fail-alone.png' /></Column>
   </Columns>

* インターネットに接続できず、すべてのキーが失敗した場合、インターネット接続を確認してから再試行するよう案内し、<Cmd sid='setting.xlicense.offlineActivation' product='2' /> ボタンを表示します。閉域ネットワーク環境の場合、このボタンをクリックしてオフラインで登録してください。

:::info

失敗したキーをコピーするには、<Cmd sid='setting.xlicense.activation.copyFailedKeys' product='2' /> ボタンをクリックしてください。

:::

## 有効化済みライセンスの確認

登録した **BioStar X** ライセンス情報は、<Cmd sid='setting.xlicense.myLicense' product='2' />で確認できます。
