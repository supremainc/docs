### ffmpeg

**BioStar X** には、動画ファイルの変換と情報の確認のために ffmpeg([https://ffmpeg.org](https://ffmpeg.org)) が含まれています。 *ffmpeg.exe* と *ffprobe.exe* のコマンドラインバイナリを提供しており、どちらのバイナリも下記の ffmpeg ソース tarball からビルドされます。 ffprobe は別のコンポーネントではなく、ffmpeg プロジェクトに含まれるツールです。

* Component: ffmpeg (ffmpeg.exe, ffprobe.exe)

* Version: 8.1

* License: GNU Lesser General Public License v2.1

   全文：[COPYING.LGPLv2.1](/opensource/opensourcelicenses.txt) を参照

* Source code: ffmpeg-8.1.tar.xz

* Upstream URL: [ffmpeg-8.1.tar.xz](https://supremadocs.blob.core.windows.net/opensource/ffmpeg-8.1.tar.xz)

* SHA-256: b072aed6871998cce9b36e7774033105ca29e33632be5b6347f3206898e0756a

```txt title="Build configuration:"
./configure \
    --arch=x86_64 \
    --target-os=mingw64 \
    --disable-gpl \
    --disable-nonfree \
    --disable-libx264 \
    --disable-libx265 \
    --disable-libxvid \
    --enable-mediafoundation \
    --enable-libmp3lame \
    --disable-doc \
    --disable-debug \
    --enable-small \
    --pkg-config-flags=--static \
    --extra-ldflags="-static" 
```

修正点: なし。アップストリームのソース tarball を変更せずそのまま使用してビルドしました。

**BioStar X** が使用するエンコーダーは次のとおりです。

* h264_mf (H.264 via Windows Media Foundation)

* libmp3lame (MP3 audio, LGPL)

### libmp3lame

**BioStar X** は MP3 オーディオのエンコードに libmp3lame を使用します。

* Component: libmp3lame (LAME MP3 Encoder)

* Version: 3.100

* License: GNU Lesser General Public License v2.1

   全文：[COPYING.LGPLv2.1](/opensource/opensourcelicenses.txt) を参照 (ffmpeg と同じ LGPL v2.1 版)

* Source code: lame-3.100.tar.gz

* Upstream URL: [lame-3.100.tar.gz](https://supremadocs.blob.core.windows.net/opensource/lame-3.100.tar.gz)

* SHA-256: ddfe36cab873794038ae2c1210557ad34857a4b6bdc515785d1da9e175b1da1e

修正点: なし。アップストリームのソース tarball を変更せずそのまま使用し、ビルド時に `--enable-libmp3lame` オプションで *ffmpeg.exe* と *ffprobe.exe* に静的にリンクしました。
