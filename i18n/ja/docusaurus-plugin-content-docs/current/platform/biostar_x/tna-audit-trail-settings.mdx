監査ログは時間とともに蓄積するため、保存容量と個人情報保護の観点から保管期間を管理する必要があります。<Cmd sid='setting.menu.system.auditTrailRetention' />で <Cmd sid='setting.menu.auditTrail.taAuditLog' /> 記録の保管期間と閲覧履歴を記録するかどうかを設定してください。

## 権限の説明

<Cmd sid='setting.account.administrator' className='normal' /> は <Cmd sid='setting.menu.system.auditTrailRetention' /> メニューで常に参照および変更できます。カスタム権限管理者は、<Cmd sid='settings.account.menu.setting' product='2' />で<Cmd sid='setting.menu.system.auditTrailRetention' />メニュー項目を<Cmd sid='settings.account.menu.readOnly' product='2' />に適用すると参照のみ行えます。<Cmd sid='settings.account.menu.fullAccess' product='2' />に適用すると参照と変更の両方を行えます。

:::info

* 勤怠管理プラグインをインストールすると既定で作成される勤怠管理者アカウントには、この権限がありません。必要に応じて、別途権限を付与してください。

* 勤怠監査権限の追加について詳しくは <DocLink docId='platform/biostar_x/tna-audit-trail#addTnaAuditLevel' />を参照してください。

:::

## 監査設定を開く

1. <Cmd sid='shell.header.launcher' />ページで<Cmd sid='shell.header.setting' />をクリックします。

2. 画面左側のサイドバーで <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.system.auditTrailRetention' /> をクリックしてください。

3. 画面を下にスクロールして <Cmd sid='audit.retention.sectionTimeAttendance' /> セクションに移動してください。
