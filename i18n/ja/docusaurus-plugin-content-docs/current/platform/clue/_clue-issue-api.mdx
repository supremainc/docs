## APIキーの発行

1. [CLUe Webポータル](https://clue.moon.supremainc.com)にログインしてください。

2. API連携のためのプレース グループを選択してください。 

3. 画面右上の <IcAirMore title='more' /> → <Cmd sid='settings_2' product='clue' /> をクリックしてください。

   <ProdImg src='/img/clue/clue-place-group-settings.png' />

4. 画面左のサイドバーで <Cmd sid='admin' product='clue' /> をクリックします。

   <ProdImg src='/img/clue/clue-place-group-settings-admin.png' />

5. <Cmd sid='manage_api_keys' product='clue' /> セクションで <Cmd sid='add_new_api_key' product='clue' /> をクリックしてください。

6. 希望の有効期間を選択してください。

   <ProdImg src='/img/clue/clue-place-group-settings-admin-new-api.png' />

   :::note

   <Cmd sid='custom' product='clue' /> を選択すると、有効期間を最大 365,000 日まで設定できます。

   :::

7. 新しい API キーを発行するには、<Cmd sid='add_2' product='clue' /> ボタンをクリックしてください。

8. 新しい API キーが作成されたら、<Cmd sid='copy' product='clue' /> ボタンをクリックして、CLUe API 呼び出し時の Bearer トークンとして使用してください。

   <ProdImg src='/img/clue/clue-place-group-settings-admin-api-copy.png' />

:::caution

API キーは CLUe API へのアクセス権限をそのまま付与するため、外部に公開しないよう安全に保管してください。 不正使用によって発生する問題について、Suprema は責任を負いません。

:::
