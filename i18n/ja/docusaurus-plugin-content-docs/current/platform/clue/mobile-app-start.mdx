CLUeモバイルアプリを使うと、スマートフォンでドアをリモート制御し、ユーザーを管理し、プレースのイベントをリアルタイムで確認できます。 この文書では、プレース管理者の招待方法からアプリのダウンロード、ログイン、主要機能まで案内します。

## CLUeモバイルアプリの管理者招待

プレースグループ管理者は、プレース設定でメールによりプレース管理者を招待できます。

1. [CLUe Webポータル](https://clue.moon.supremainc.com)にログインしてください。

2. モバイルアプリの管理者を招待するプレースを選択します。

3. 画面左のサイドバーで <Cmd sid='settings' product='clue' /> → <Cmd sid='admin' product='clue' /> をクリックします。

   <ProdImg src='/img/clue/place-invite-admin.png' />

4. メールアドレスを入力し、役割を選択します。

5. <Cmd sid='invite' product='clue' /> ボタンをクリックします。

   <ProdImg src='/img/clue/place-mobile-admin-invited.png' />

   <Cmd sid='admin_list' product='clue' /> リストで招待ステータスを確認できます。

招待が完了すると、管理者に招待メールが送信されます。 招待された管理者は、メールに含まれるリンクから参加できます。

<ProdImg src='/img/clue/clue-invite-email.png' />

参加を完了すると、管理者リストでステータスの変更を確認できます。

<ProdImg src='/img/clue/place-mobile-admin-invite-complete.png' />

:::note

**CLUeモバイルアプリで直接参加できますか?**

CLUe Webポータルにアクセスできない管理者は、CLUeアプリをダウンロードしてモバイルアプリから参加できます。 ただし、実際に使用するには、必ずプレースに招待されている必要があります。

:::

## ログイン

アプリをインストールした後、招待されたメールアドレスでログインできます。

1. モバイル端末でCLUeアプリを起動します。

2. <Cmd>メールでログイン</Cmd>を選択します。

   <ProdImg src='/img/clue/clue-app-select-login-method.png' width='250px' />

3. メールアドレスとパスワードを入力し、<Cmd>ログイン</Cmd>ボタンをタップしてください。

   <ProdImg src='/img/clue/clue-app-email-login.png' width='250px' />

4. メールアドレスに送信された認証コードを入力し、<Cmd>確認</Cmd>ボタンをタップします。

   <ProdImg src='/img/clue/clue-app-email-login-auth-number.png' width='250px' />

ログアウトするまでログイン状態が維持されます。
