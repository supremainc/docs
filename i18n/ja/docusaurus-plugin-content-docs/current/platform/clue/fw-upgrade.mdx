CLUeデバイスのファームウェアを最新バージョンにアップグレードすると、新しい機能、性能の改善、セキュリティパッチを適用できます。 アップグレードはCLUe Webポータルで数回クリックするだけで進み、完了まで約5～10分かかります。

アップグレードを開始する前に、次の事項を確認してください。

* アップグレード中はデバイスを使用できず、再起動時にロック装置の接続方式によっては出入口が一時的に開閉することがあります。

* アップグレード中にデバイス設定を変更した場合、完了後に反映されます。

## プレースへ移動

プレースに割り当てられた出入口デバイスをアップグレードするには、該当のプレースへ直接移動するか、上位のブランチ、代理店、プレース グループから移動できます。

1. [CLUe Webポータル](https://clue.moon.supremainc.com)にログインしてください。

2. 初期画面でブランチ、代理店、またはプレース グループを選択してください。

3. 画面右上の <IcAirMore title='more' /> → <Cmd sid='settings_2' product='clue' /> をクリックしてください。

   <ProdImg src='/img/clue/add-device-settings.png' />

4. 画面左側のサイドバーで <Cmd sid='device' product='clue' />をクリックしてください。

   <ProdImg src='/img/clue/add-device-go-device-tap.png' />

5. <Cmd sid='device_list' product='clue' />で、ファームウェアをアップグレードするデバイスの <Cmd sid='place' product='clue' /> 列をクリックしてください。

   <ProdImg src='/img/clue/add-device-complete.png' />

6. <IcCLMove title='move' /> ボタンが有効になったらクリックしてください。

選択したデバイスが割り当てられたプレースの <Cmd sid='device_2' product='clue' /> 画面に移動します。

## ファームウェアをアップグレードする

1. デバイスが割り当てられたプレースの <Cmd sid='device_2' product='clue' /> リストで、ファームウェアをアップグレードするデバイスをクリックしてください。

   <ProdImg src='/img/clue/clue-fw-device-list.png' />

2. 選択したデバイスの <Cmd sid='basic_settings' product='clue' /> 画面が表示されたら、<Cmd sid='firmware_version' product='clue' /> 項目で現在のファームウェアバージョンを確認してください。

   <ProdImg src='/img/clue/clue-fw-device-basic-settings.png' />

3. <Cmd sid='upgrade' product='clue' /> ボタンをクリックしてください。

4. ファームウェア選択ウィンドウが表示されたら、アップグレードするファームウェアのチェックボックスをクリックしてください。

   <ProdImg src='/img/clue/clue-fw-device-basic-select-fw-ver.png' />

   :::note

   選択できるファームウェアバージョンは1つだけです。

   :::

5. 右下の <Cmd sid='apply' product='clue' /> ボタンをクリックしてください。

6. アップグレード確認ウィンドウが表示されたら、<Cmd sid='process' product='clue' /> ボタンをクリックしてください。

   <ProdImg src='/img/clue/clue-fw-device-basic-upgrade-fw-verify.png' />

7. メッセージウィンドウが表示されたら内容を確認し、<Cmd sid='ok' product='clue' /> ボタンをクリックしてください。

   <ProdImg src='/img/clue/clue-fw-device-basic-upgrade-fw-confirm.png' />
