:::note

**ユーザーIDおよび名前の入力ルール** <Anchor id='ruleUseridName'/>

* <Cmd sid='team.user.table.id' /> の値には空白を含めることはできません。

* <Cmd sid='team.user.table.id' />にはマーク(`.`)を含められますが、マーク一つ(`.`)または二つ(`..`)だけでは入力できません。

* ユーザー名は特殊記号を含めて最大 48 文字まで入力できます。

  > 特殊記号：`~` `!` `@` `#` `$` `%` `^` `&` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}` `;` `.` `'`

* ユーザーIDおよび名前には、次の文字を使用できません。 `₩` `/` `:` `*` `?` `"` `<` `>` `|` `` ` ``

* ユーザーIDには、アポストロフィー(`'`)も使用できません。

* ユーザー名の先頭に`&@~`を連続して入力できません。ただし、`&`、`@`、`~`はそれぞれ単独でユーザー名の先頭文字に使用できます。

:::
