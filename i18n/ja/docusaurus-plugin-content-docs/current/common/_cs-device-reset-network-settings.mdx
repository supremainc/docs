## ネットワーク設定の初期化 {/* #reset-network-settings */}

装置のネットワーク設定を初期化します。

1. 装置に電源を接続してください。

2. **INIT** ボタンを3秒以上長押ししてください。

   <Include product='corestation_40'><Image src='/img/device/reset-network-settings-cs40.png' className='none' alone /></Include>

   <Include product='corestation_20'><Image src='/img/device/reset-network-settings-cs20.png' className='none' alone /></Include>

3. ネットワーク設定を次のとおり初期化します。初期化されたネットワーク情報を参照して、BioStar X で装置を接続してください。

   * **TCP/IPアドレス**：DHCP を使用するよう設定しているため、IP アドレスを自動的に割り当てます。

      :::info

      DHCP でのアドレス割り当てに失敗すると、169.254.x.x に設定します。

      :::

   * **サーバーモード**：装置がサーバーへ直接接続を要求しないよう設定します。

   * **RS-485**：通信速度を 115200 bps に設定します。
