## ネットワーク設定の初期化 {/* #reset-network-settings */}

装置のネットワーク設定を初期化します。

1. 装置の電源を入れてください。

2. 初期化ボタンを装置が自動的に再起動するまで長押ししてください。

3. ネットワーク設定を次のとおり初期化します。初期化されたネットワーク情報を参照して、BioStar X で装置を接続してください。

   * **TCP/IPアドレス**：DHCP を使用するよう設定しているため、IP アドレスを自動的に割り当てます。

      :::info

      DHCP でのアドレス割り当てに失敗すると、169.254.x.x に設定します。

      :::

   * **サーバーモード**：装置がサーバーへ直接接続を要求しないよう設定します。

   * **RS-485**：既定値です。通信速度は 115200 bps です。

4. 装置の電源を切って入れ直し、ネットワーク情報が正しく設定されていることを確認してください。
