# BS2_GetSystemExtConfig

Retrieves Master and slave device encryption settings from the device.

:::info

You are not able to retrieve a key value due to security reason.

:::

## Declaration

```cpp
#include "BS_API.h"

int BS2_GetSystemExtConfig(void* context, uint32_t deviceId, BS2SystemConfigExt* config);
```

:::info

[See BS2SystemConfigExt Structure](configuration_api#bs2systemconfigext) 

:::

## Parameter

- \[In\] `context` : Context

- \[In\] `deviceId` : Device ID

- \[Out\] `config` : Master and slave device encryption settings pointer

## Return Value

If successfully done, `BS_SDK_SUCCESS` will be returned.

If there is an error, the corresponding error code will be returned.
