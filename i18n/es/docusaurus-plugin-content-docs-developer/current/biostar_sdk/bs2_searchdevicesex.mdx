# BS2_SearchDevicesEx

:::caution

<Dep>DEPRECATED</Dep>

* This function is <Dep>deprecated</Dep> as of 2.9.13. Use [BS2_SearchDevices](bs2_searchdevices) together with [BS2_SetEnableIPV4](bs2_setenableipv4) / [BS2_SetEnableIPV6](bs2_setenableipv6) instead.

* [BS2_SearchDeviceByIP](bs2_searchdevicebyip) is not a replacement, because its argument is the address of the target device, not a host or broadcast address.

* Search for devices in a specific IP address band and update the list of devices available in the current context. The list of devices can be obtained via the [BS2_GetDevices](bs2_getdevices) function.

:::

:::info

Overwrite the old device list.

:::

## Declaration

```cpp
#include "BS_API.h"

int BS2_SearchDevicesEx(void* context, const char* hostipAddr);
```

## Parameter

- \[In\] `context` : Context

- \[In\] `hostipAddr` : Address of the UDP range

## Return Value

If successfully done, `BS_SDK_SUCCESS` will be returned.

If there is an error, the corresponding error code will be returned.
