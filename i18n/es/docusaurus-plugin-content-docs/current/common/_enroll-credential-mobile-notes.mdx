* Si ha habilitado las opciones <Cmd sid='common.photo' product='2' />, <Cmd sid='common.department' product='2' /> y <Cmd sid='team.user.detail.title' product='2' /> en la sección <Cmd sid='common.info' product='2' />, esa información puede mostrarse en la tarjeta de credenciales móviles del usuario. Los elementos que se muestran en este momento se basan en la información ingresada por el usuario. Para obtener más información sobre cómo ingresar la información básica del usuario, consulte <DocLink docId='platform/biostar_x/add-user-basic-info' />.

* El sistema restringe la emisión si el nombre de usuario contiene caracteres especiales incompatibles con la tarjeta de acceso móvil. Solo se permiten `@` `-` `_` `+` `[` `]` `,` `.`.

* Si el nombre de usuario incluye una comilla simple(`'`), aparece un aviso. El sistema envía el valor sin la comilla simple al guardar el usuario. Cuando aparece este aviso, el sistema ya creó el registro de la tarjeta. Cancelar el aviso detiene solo la transferencia al portal Airpop, y la tarjeta sigue inutilizable. En este caso, el sistema guarda el resto de la información del usuario sin vincular la tarjeta inutilizable.
