## Usar la lista de asistencia en la aplicación móvil {/* #mobileAppRollCall */}

La función de lista de asistencia está disponible en la aplicación móvil **BioStar X**.

<Include pages='settings-advanced-ac-roll-call'>

:::info

Instale la aplicación móvil BioStar X desde los siguientes enlaces.

* iOS: [Apple App Store](https://apps.apple.com/kr/app/biostar-x-mobile/id6741415253)

* Android: [Google Play](https://play.google.com/store/apps/details?id=com.suprema.biostarmobile)

:::

</Include>

### Iniciar la lista de asistencia {/* #useRollCallMobileApp */}

Para iniciar la lista de asistencia en la aplicación móvil, siga estos pasos.

1. Abre la aplicación móvil **BioStar X** en tu dispositivo móvil.

2. En la pantalla de inicio de la aplicación, toque <Cmd>ROLL CALL</Cmd>.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-01.png' width={253} alone />

   :::note

   Como alternativa, acceda desde el menú lateral. Toca <IcHamberg title='Hamburger icon' width={20} /> → <Cmd>Monitoring</Cmd> → <Cmd>Roll Call</Cmd>.

   :::

3. En la lista de listas de asistencia, toque <IcRCplay title='Start' width={20} height={20} /> junto a la lista de asistencia que desea ejecutar.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-02.png' width={253} alone />

4. Cuando aparezca el mensaje de confirmación, toca <Cmd>Yes</Cmd>.

Se inicia la lista de asistencia y, al tocar la entrada de la lista de asistencia en curso, se muestra su estado.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-03.png' width={595} alone className='none' />

### Controlar una lista de asistencia en curso {/* #controlInProgressRollCall */}

* El ícono <IcRCdone title='Done' width={20} height={20} /> aparece junto a los usuarios que se registraron. Cuando todos los usuarios se registran, aparece un mensaje que indica que la lista de asistencia ha finalizado. Para finalizar la lista de asistencia, toca <Cmd>Yes</Cmd>.

* El administrador puede cambiar manualmente el registro de entrada o el estado de un usuario. En la lista de usuarios, toque y mantenga presionado el botón redondo del extremo derecho del usuario para cambiar el estado.

  <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-change-status.png' alone className='none' width={595} />

* Para reiniciar la lista de asistencia, toque <Cmd>Reset</Cmd>. Se eliminan todos los cambios realizados hasta el momento y la lista de asistencia se reinicia desde el inicio.

* Si otro administrador finaliza la lista de asistencia, aparecerá un mensaje de notificación.

  <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-stopped.png' width={253} alone />

<Include pages='settings-advanced-ac-roll-call'>

* Para ver los informes relacionados después de completar la lista de asistencia, haga clic en <Cmd sid='shell.header.data' /> → <Cmd sid='data.mainMenu.generate' /> → <Cmd sid='data.sidebar.rollCall' />. Para obtener más información, consulte <DocLink inner='#viewRollCallReport' />.

</Include>

### Ver información del usuario durante la lista de asistencia

Puede consultar la información de cada usuario durante la lista de asistencia en la aplicación móvil. Están disponibles detalles como la información de contacto de emergencia y la última ubicación conocida del usuario.

Durante la lista de asistencia, deslice hacia la izquierda la entrada del usuario para ver los detalles. Luego, toca <IcRCinfo title='Information' width={20} height={20} />.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-info.png' className='none' width={595} alone />

### Dejar una nota para un usuario durante la lista de asistencia

Si un usuario no se registra durante la lista de asistencia en la aplicación móvil, puede dejar una nota para ese usuario.

Para ingresar una nota durante la lista de asistencia, deslice hacia la izquierda la entrada del usuario. Luego, toca <IcRCmemo title='Memo' width={20} height={20} />. En la pantalla de notas, ingrese el texto y luego toque <Cmd>Save</Cmd>.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-memo.png' className='none' width={595} alone />

Para los usuarios con una nota, el ícono <IcRCmemo title='Memo' width={20} height={20} /> aparece en la lista de listas de asistencia.

<Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-user-status.png' width={253} alone />

### Ver detalles de la lista de asistencia {/* #viewRollCallinfo */}

Puede ver los detalles de configuración de la lista de asistencia en la aplicación móvil.

1. Abre la aplicación móvil **BioStar X** en tu dispositivo móvil.

2. En la pantalla de inicio de la aplicación, toque <Cmd>ROLL CALL</Cmd>.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-01.png' width={253} alone />

   :::note

   Como alternativa, acceda desde el menú lateral. Toca <IcHamberg title='Hamburger icon' width={20} /> → <Cmd>Monitoring</Cmd> → <Cmd>Roll Call</Cmd>.

   :::

3. Para ver los detalles, deslice hacia la izquierda la entrada de la lista y luego toque <IcRCinfo title='Information' width={20} height={20} />.

   <Image src='/img/common/biostarx-settings-adv-ac-mobile-app-rollcall-info.png' width={595} alone className='none' />
