## Registrar un plugin {/* #register-plugin */}

1. En Windows, haga clic en <Start/> → **BioStar X** → **BioStar X Service Manager**.

2. Haga clic en <Cmd>PLUGINS</Cmd> en la barra lateral izquierda.

3. Haga clic en <Cmd>Add Plugin</Cmd> en la esquina superior derecha.

   <Image src='/img/common/biostarx-sm-plugins-add.png' width='60%' alone />

4. En la pantalla <Cmd>Add New Plugin</Cmd>, ingrese la información del plugin.

   <Image src='/img/common/biostarx-sm-plugins-add-new.png' width='60%' alone />

5. Ingrese la información del plugin y luego haga clic en <Cmd>Apply</Cmd> para completar el registro.

:::info

Si <Cmd>Session Bridge</Cmd> está activado, puede descargar el certificado en la parte inferior de la pantalla. Se requiere el certificado para la comunicación segura entre **BioStar X** y el conector. Si pierdes el certificado, descárgalo de nuevo. A continuación, se invalida el certificado existente.

<Image src='/img/common/biostarx-sm-plugins-download-certification.png' alone />

:::

### Introduzca información del conector

* <Cmd>Plugin Name</Cmd>: Ingrese el nombre del plugin. Ingresa hasta 48 caracteres. No uses un nombre ya registrado por otro conector.

* <Cmd>Description</Cmd>: Ingresa una descripción del conector. Ingresa hasta 500 caracteres.

* <Cmd>Plugin Address</Cmd>: Ingrese la dirección del plugin. Debe ser una URL válida que comience con `http://` o `https://`, y no puede usar la misma dirección que un plugin ya registrado.

* <Cmd>Plugin Icon</Cmd>: Cargue el ícono del plugin.

  * Los formatos compatibles son JPEG, PNG, SVG y GIF. 

  * El tamaño máximo del archivo es de 1 MB y no puede cargar archivos vacíos (0 KB). 

  * Las imágenes cargadas se redimensionan automáticamente a 104×104 píxeles. 

* <Cmd>Session Bridge</Cmd>: Actívelo para usar Session Bridge. Esta función hereda automáticamente los permisos de usuario de BioStar X, por lo que no se requiere un inicio de sesión adicional cuando acceda al plugin.

:::info

* Si no carga un ícono, se genera automáticamente un ícono a partir de la primera letra del nombre del plugin. Para eliminar el ícono cargado, haga clic en <IcTrash2 />; el ícono generado automáticamente lo reemplaza.

* Una vez que <Cmd>Session Bridge</Cmd> está activado, no se puede desactivar y la dirección del plugin no se puede cambiar por razones de seguridad.

:::

### Verifique la pantalla del lanzador

Los plugins que agregó aparecen en la pantalla <Cmd sid='shell.header.launcher' /> de **BioStar X**.
