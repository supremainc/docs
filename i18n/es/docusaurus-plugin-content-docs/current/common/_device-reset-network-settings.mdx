## Inicializar los ajustes de red {/* #reset-network-settings */}

Inicialice la configuración de red del dispositivo.

1. Encienda el dispositivo.

2. Mantenga presionado el botón Inicializar hasta que el dispositivo se reinicie automáticamente.

3. El dispositivo inicializa los ajustes de red de la siguiente manera. En BioStar X, conecte el dispositivo usando la información de red inicializada.

   * **Dirección TCP/IP**: DHCP está habilitado, por lo que el dispositivo obtiene una dirección IP automáticamente.

      :::info

      Si falla la asignación de direcciones DHCP, el dispositivo establece la dirección en 169.254.x.x.

      :::

   * **Modo de servidor**: Evita que el dispositivo solicite una conexión directa al servidor.

   * **RS-485**: Establézcalo como predeterminado, con una velocidad en baudios de 115200 bps.

4. Apague el dispositivo y vuelva a encenderlo. Confirme que la configuración de red sea correcta.
