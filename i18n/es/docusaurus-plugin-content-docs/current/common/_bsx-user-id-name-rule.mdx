:::note

**Reglas para ingresar el ID de usuario y el nombre** <Anchor id='ruleUseridName'/>

* El valor de <Cmd sid='team.user.table.id' /> no puede incluir espacios.

* <Cmd sid='team.user.table.id' /> puede incluir un punto (`.`), pero no puede consistir únicamente en un punto (`.`) o dos puntos (`..`).

* El nombre de usuario puede tener hasta 48 caracteres, incluidos los caracteres especiales.

  > Caracteres especiales: `~` `!` `@` `#` `$` `%` `^` `&` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}` `;` `.` `'`

* Los ID de usuario y los nombres no pueden incluir los siguientes caracteres. `₩` `/` `:` `*` `?` `"` `<` `>` `|` `` ` ``

* Los ID de usuario tampoco pueden incluir un apóstrofo (`'`).

* El nombre de usuario no puede comenzar con `&@~` de forma consecutiva. Sin embargo, un nombre de usuario puede comenzar solo con `&`, `@` o `~`.

:::
