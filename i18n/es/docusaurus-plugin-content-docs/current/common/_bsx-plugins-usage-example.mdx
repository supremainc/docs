## Casos de uso clave

Puede integrar varios sistemas externos mediante el sistema de plugins de **BioStar X**. Los casos de uso típicos incluyen los siguientes.

* **Sistema de gestión de tiempo y asistencia**: Integración con soluciones externas de tiempo y asistencia (T&A)

* **Sistema de gestión de visitantes**: Integración con un sistema independiente de registro y gestión de visitantes

* **Solución de informes**: Integración con herramientas personalizadas de generación y análisis de informes

* **Integración con sistemas de terceros**: Integración de datos con sistemas empresariales existentes, como ERP y HRM
