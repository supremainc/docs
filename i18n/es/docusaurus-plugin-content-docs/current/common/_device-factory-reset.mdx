## Restablecimiento de fábrica {/* #factory-default */}

Elimina toda la información almacenada en el dispositivo e inicializa la configuración.

1. Encienda el dispositivo.

2. Presione rápidamente el botón de reinicio tres veces.

   <Include product='xpass_2,xpass_2_v2'><Image src='/img/device/restoring-factory-defaults-xpd2.svg' className='none' width={200} alone /></Include>

:::info

* Utilice Factory Default solo cuando el certificado raíz esté almacenado en el dispositivo.

* Para obtener más información sobre cómo inicializar el producto, comuníquese con <Support />.

:::
