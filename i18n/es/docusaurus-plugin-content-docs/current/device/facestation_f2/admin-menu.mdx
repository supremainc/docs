Proporciona orientación sobre los menús principales y las funciones accesibles con privilegios de administrador.

## Menú completo

1. Presione <Image src='/img/common/ico-menu.svg' ico alone /> y autentíquese con la credencial de nivel de administrador.

   En la pantalla del menú, revise la información del dispositivo o presione <Cmd sid='ui_174' product='dev' /> para inscribir a un usuario de inmediato.

2. Selecciona el menú deseado.

   <Image src='/img/device/fsf2-menu.png' width={300} />

:::info

Si no se designa un administrador, haz clic en <Image src='/img/common/ico-menu.svg' ico alone /> para mostrar la pantalla del menú.

:::
