# Firmware Version 1.5.0 (Build No. 1.5.0_260819)

Release<Separator/>2026-08-19

:::caution

- If you are using a device with firmware version v1.4.0, you must upgrade to v1.4.1 before use.<br/>As important security and stability improvements are included, using the latest version after the upgrade is mandatory.

- After upgrading the firmware to v1.4.0, it is not able to downgrade to an earlier version of the firmware.

- For more information, check the serial number of the device and contact the [Suprema](https://supremainc.com).

:::

## New Features and Improvements

---

{/* (BS3FW-2302) XPQ2 지원 */}
1. Supports new device.
    * XPass Q2

{/* (BS3FW-2257) [BDP-1480] Auth Fail Lockout(EN-60839) */}
2. Added **Auth Fail Lockout** feature, which locks the device after repeated PIN authentication failures.

{/* (BS3FW-2262) [BDP-1479] Rapid Face Authentication */}
3. Added and improved face authentication features
    * Improved face authentication performance
    * Added support for sequential multi-face authentication (device license required)
    * Added support for Anti-Tailgating

{/* (BS3FW-1568) [BDP-853] Slave 장치의 Baudrate 설정 기능 */}
4. Supports feature to set the baud rate of slave devices.

{/* (BS3FW-2158) Master Admin의 크리덴셜이 2개 미만이 되었을 때 Master Admin 크리덴셜 등록 강제되도록 개선 */}
5. Improved **Master Admin** to enforce re-enrollment when fewer than two credentials remain.

{/* (BS3FW-2187) USB Export시 생성되는 파일명이 BioStarX_ 로 표시되도록 변경 요청 */}
6. Improved USB export/import file name handling
    * Changed the file name generated during USB export to start with BioStarX
    * Fixed Files exported from BioStar X not appearing in the import list

{/* (BS3FW-2268) 장치에서 지원하지 않는 이벤트에 대해 "Undefined Event"로 로그가 남도록 개선 */}
7. Improved log display for unsupported events and errors on the device.

{/* (BS3FW-2320) [UI지원모델] 인증성공 아이콘 Blue -> Green으로 변경 요청 건 */}
8. Changed the authentication success icon color to green.

{/* (BS3FW-2342) [BSF-2925][BDP-1634] OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기 */}
9. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

{/* (BS3FW-2343) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경 - 발생버전 :  V1.0.0 */}
10. Improved zone status display and alarm clearing behavior after power restart following a fire alarm.

{/* (BS3FW-2403) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) - 발생버전 : V1.0.0 */}
11. Improved BLE stability.

{/* (BS3FW-2424) [UI 지원 장치]  사용자 이름 및 사용자 ID에 Dot(.) 지원 */}
12. Expanded allowed characters for User ID and User Name
    * Added support for periods (.) in User ID
    * Added support for periods (.) and apostrophes (') in User Name
