## Generar una clave API

1. Inicie sesión en el [portal web de CLUe](https://clue.moon.supremainc.com).

2. Seleccione el Place group para la integración de API. 

3. Haga clic en <IcAirMore title='more' /> → <Cmd sid='settings_2' product='clue' /> en la esquina superior derecha de la pantalla.

   <ProdImg src='/img/clue/clue-place-group-settings.png' />

4. Haz clic en <Cmd sid='admin' product='clue' /> en la barra lateral izquierda.

   <ProdImg src='/img/clue/clue-place-group-settings-admin.png' />

5. En la sección <Cmd sid='manage_api_keys' product='clue' />, haga clic en <Cmd sid='add_new_api_key' product='clue' />.

6. Seleccione el período de validez deseado.

   <ProdImg src='/img/clue/clue-place-group-settings-admin-new-api.png' />

   :::note

   Si selecciona <Cmd sid='custom' product='clue' />, puede establecer el período de validez hasta por 365,000 días.

   :::

7. Para emitir una nueva clave de API, haga clic en el botón <Cmd sid='add_2' product='clue' />.

8. Cuando se cree la nueva clave de API, haga clic en el botón <Cmd sid='copy' product='clue' /> y úsela como token Bearer al llamar a la API de CLUe.

   <ProdImg src='/img/clue/clue-place-group-settings-admin-api-copy.png' />

:::caution

La clave de API concede acceso a la API de CLUe, así que manténgala segura y no la exponga externamente. Suprema no se hace responsable de los problemas causados por un uso indebido.

:::
