Suprema CLUe es una plataforma abierta de integración en la nube que permite crear un sistema de autenticación de acceso solo con la nube, sin un servidor local. Como el dispositivo se conecta directamente a la nube, puedes implementar fácilmente la integración de servidor a servidor mediante la API REST estándar. Combínalo con los dispositivos de control de acceso biométrico de Suprema para mejorar la seguridad, y adminístralo fácilmente mediante una app móvil y un portal web mientras obtienes soporte técnico. Se adapta a una amplia gama de empresas que necesitan gestión de miembros, como centros de fitness, oficinas compartidas y oficinas con varias Branch, y admite directamente todas las funciones necesarias para el control de acceso, para que los clientes se concentren en su negocio principal.

## Funciones clave de CLUe

* **Desarrollo simple**: Usa integración de API entre servicios web en lugar de un SDK, así que puedes conectar rápidamente las funciones de autenticación de acceso sin crear un entorno de desarrollo independiente.

* **Instalación simple**: Funciona como una solución Plug & Play que no requiere un servidor independiente, así que puedes usarla de inmediato sin un proceso de instalación complejo.

* **Mantenimiento eficiente**: Admite actualizaciones continuas y responde rápido a los problemas mediante la supervisión constante del sistema.

* **Varios métodos de autenticación**: Admite varios métodos de autenticación, incluidos códigos QR, Facial Authentication, RFID y Fingerprint.

* **Desarrollo personalizado**: Admite desarrollo personalizado para adaptarse al entorno de servicio de cada cliente.

* **Seguridad de datos**: Ha obtenido la certificación CSA STAR Level 2 y administra los datos de forma segura en cumplimiento con los estándares ISO27001 e ISO27701.
