Configure métodos de autenticación de forma flexible para cada usuario. Puede usar el método de autenticación predeterminado configurado en el dispositivo o asignar un modo de autenticación privada para cada usuario. El modo de autenticación extendida combina la autenticación facial y la autenticación por huella dactilar para aumentar la seguridad. 

## Predeterminado del dispositivo

Configurar la opción <Cmd sid='common.authMode' product='2' /> en <Cmd sid='user.deviceDefault' product='2' /> le permite autenticarse según el método configurado en el dispositivo.

<Image src='/img/biostarx-new-user-credential-authmod-default.png' />

## Modo de autenticación privada

Configurar la opción <Cmd sid='common.authMode' product='2' /> en <Cmd sid='user.privateMode' product='2' /> le permite establecer distintos métodos de autenticación para cada usuario.

<Image src='/img/biostarx-new-user-credential-authmod-private.png' />

Haga clic en <Cmd sid='button.addplus' product='2' /> para abrir la ventana <Cmd sid='device.addNewAuthMode' product='2' />. Configure el método de autenticación que se utilizará.

<Image src='/img/biostarx-new-user-credential-authmod-private-add.png' />

* <Cmd sid='user.authMode.toggle' product='2' />: Active o desactive el modo de autenticación extendida. El modo de autenticación extendida le permite combinar la autenticación facial y la autenticación por huella dactilar.

* <Cmd sid='common.authMode' product='2' />: Arrastre y suelte para configurar los modos de autenticación que se usarán.

  <Image src='/img/biostarx-new-user-credential-authmod-private-join.png' />

Para registrar los métodos de autenticación configurados, haga clic en <Cmd sid='button.apply' product='2' />.

:::info

* La opción <Cmd sid='user.authMode.toggle' product='2' /> está disponible en los modelos BioStation 3 Max, BioEntry W3, BioStation 3 y FaceStation F2.

* Configurar <Cmd sid='user.includeDeviceDefaultAuthMode' product='2' /> le permite usar tanto los modos de autenticación establecidos en el dispositivo como los modos de autenticación privados configurados en **BioStar X**.

  <Image src='/img/biostarx-new-user-credential-authmod-note-image.png' />

* Configurar <Cmd sid='user.excludeDeviceDefaultAuthMode' product='2' /> le permite usar solo los modos de autenticación privados establecidos en **BioStar X**.

:::
