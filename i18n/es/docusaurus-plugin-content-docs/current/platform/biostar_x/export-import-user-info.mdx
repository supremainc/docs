Puede usar la información de usuarios de una versión anterior o de otro servidor exportándola o importándola.

## Exportar o importar CSV {/* #csvexportimport */}

Puede guardar la información de usuarios seleccionada como un archivo CSV o importar un archivo CSV guardado. Puede transferir fácilmente la información de usuarios mediante un archivo CSV.

:::info

* Si tiene datos de campos de usuario personalizados que no añadió a **BioStar X**, no podrá importar correctamente el archivo CSV. Para obtener más información sobre cómo agregar campos de usuario personalizados, consulte <DocLink docId='platform/biostar_x/settings-server-server#custom-field' />.

* Si la información de usuarios se introduce en un idioma distinto del inglés o el coreano, guarde el archivo CSV como UTF-8.

:::

### Exportar CSV {/* #csvexport */}

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. Seleccione la casilla de verificación junto a los usuarios para guardarlos como un archivo CSV en la lista de usuarios. Puede seleccionar uno o más usuarios.

3. Haga clic en <IcMoreW /> en la esquina superior derecha de la pantalla y seleccione <Cmd sid='team.menu.export.title' /> → <Cmd sid='team.menu.export.csv' />.

   <Image src='/img/biostarx-user-export-csv.png' />

4. Cuando aparezca la ventana <Cmd sid='team.menu.export.csv' /> <Cmd sid='team.menu.export.title' />, introduzca <Cmd sid='team.menu.export.exportReason' /> (opcional) y haga clic en <Cmd sid='common.button.download' />.

   <Image src='/img/biostarx-user-export-csv-popup.png' />

5. Guarde el archivo CSV en una ubicación de su equipo.

:::info

<Cmd sid='team.menu.export.exportReason' /> es opcional. Los motivos de exportación se registran en <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

### Importar CSV {/* #csvimport */}

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. Haga clic en <IcMoreW /> en la esquina superior derecha de la pantalla y seleccione <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.csv' />.

3. Selecciona el archivo CSV guardado localmente.

4. Configure <Cmd sid='user.list.csvImport.importStartRow' /> en la ventana <Cmd sid='team.menu.export.csv' /> <Cmd sid='team.menu.import.title' /> y haga clic en <Cmd sid='common.button.next' />.

   <Image src='/img/biostarx-user-import-01.png' />

5. Los campos de datos de usuario del archivo CSV se asignan automáticamente a los campos de datos de usuario en **BioStar X**. Para volver a asignar campos con el mismo nombre, haga clic en <Cmd sid='user.list.csvImport.reMapping' product='2' />.

   <Image src='/img/biostarx-user-import-02.png' width='50%' />

6. Elija si desea conservar los datos de los usuarios cuyos ID ya existen en **BioStar X** o sobrescribirlos con los datos del CSV y, luego, haga clic en <Cmd sid='common.apply' />.

   <Image src='/img/biostarx-user-import-03.png' />

Si se produce un error al importar la información del archivo CSV, puede volver a verificar y cargar solo los datos CSV que causaron el error.

:::info

* La importación de CSV le permite emitir tarjetas de acceso móvil. Al usar el sitio estándar, se descuenta un crédito del Airfob Portal por cada tarjeta de acceso móvil cuando finaliza la importación. Para evitar emitir tarjetas de acceso móvil, elimine la asignación.

* Si el archivo CSV contiene los **mismos** datos que una tarjeta de acceso móvil emitida a un usuario registrado en **BioStar X**, puede conservar o sobrescribir los datos, y se conserva la tarjeta de acceso móvil existente.

* Si el archivo CSV contiene datos **diferentes** de una tarjeta de acceso móvil emitida a un usuario registrado en **BioStar X**, conservar los datos mantiene la tarjeta de acceso móvil existente, y sobrescribirlos emite una nueva tarjeta de acceso móvil para ese usuario.

* Cuando emita tarjetas de acceso móvil mediante la importación de CSV en un sitio dinámico, asegúrese de introducir valores en los campos `mobile_start_datetime` y `mobile_expiry_datetime`.

* Los códigos QR de **BioStar X** no se pueden emitir mediante la importación de CSV.

* La importación de CSV le permite registrar el rostro de un usuario. Para obtener más información, consulte <DocLink docId='platform/biostar_x/batch-import-face#import-csv' />.

* La importación de CSV le permite registrar el PIN de un usuario. Para obtener más información, consulte <DocLink docId='platform/biostar_x/enroll-credential-pin' />.

* Si agrega columnas que no coinciden con el archivo CSV guardado, **BioStar X** no puede importarlo.

* Si un nombre de usuario empieza con `&@~`, la importación de esa entrada del CSV falla.

* Establece el período de validez (fecha y hora de vencimiento) hasta 2037-12-31 23:59:59. La importación falla para las entradas con valores posteriores a esta fecha.

* Evita abrir el archivo CSV exportado directamente en programas de hojas de cálculo como Excel. Si un nombre de usuario comienza con el carácter `=`, el programa puede tratarlo como una fórmula y mostrar un valor diferente del valor real.

:::

## Exportar o importar archivos de datos {/* #exportimportdatafile */}

Puede almacenar la información de usuarios en un almacenamiento externo (USB) e importarla en **BioStar X** o en un dispositivo. Se pueden transferir hasta 500,000 registros de usuarios del servidor a un dispositivo o de un dispositivo a otro.

:::info

* Los datos exportados desde dispositivos que ejecutan firmware obsoleto no se pueden importar a **BioStar X**. Utilice siempre la versión de firmware más reciente.

* No se pueden importar datos cuando se utilizan diferentes formatos de plantilla de huella dactilar. Por ejemplo, los datos exportados desde dispositivos que utilizan el formato de plantilla de huella dactilar Suprema no se pueden importar en dispositivos que utilizan el formato de plantilla ISO.

* Al importar datos de usuario, si ya existen credenciales de huella dactilar y de rostro en el servidor de **BioStar X**, los datos existentes se sobrescriben.

* No se pueden importar datos desde dispositivos que ejecutan firmware obsoleto. Actualiza el firmware del dispositivo a una versión compatible. 

  <details>
  <summary>Ver dispositivos y versiones de firmware compatibles</summary>

  * Firmware BioStation 2 v1.9.0 o posterior

  * Firmware BioStation A2 v1.8.0 o posterior

  * Firmware FaceStation 2 v1.4.0 o posterior

  * Firmware FaceStation F2 v2.2.0 o posterior

  * Firmware X-Station 2 v1.0.0 o posterior

  * Firmware BioStation 3 v1.3.1 o posterior

  * Firmware BioStation 2a v1.0.0 o posterior

  </details>

:::

### Exportar datos {/* #exportdata */}

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. En la lista de usuarios, seleccione la casilla de verificación de los usuarios que desea exportar. Puede seleccionar uno o más usuarios.

3. Haga clic en <IcMoreW /> en la esquina superior derecha de la pantalla y luego seleccione <Cmd sid='team.menu.export.title' /> → <Cmd sid='team.menu.export.dataFile' />.

   <Image src='/img/biostarx-user-export-data.png' />

4. En la ventana <Cmd sid='team.menu.dialog.exprotDataFile.title' />, seleccione el dispositivo al que se aplicará el archivo de datos.

   <Image src='/img/biostarx-user-export-data-select-device.png' />

5. Ingresa <Cmd sid='team.menu.export.exportReason' /> (opcional) y haz clic en <Cmd sid='common.apply' />.

6. Guarde el archivo de datos en una ruta local.

:::info

* La exportación del archivo de datos guarda la siguiente información del usuario en un archivo: foto de perfil, ID, nombre, período de validez, grupo de acceso, PIN, modo de autenticación privada, credenciales (rostro, huella dactilar, tarjeta, tarjeta móvil, rostro, QR/Barcode) y nivel de seguridad 1:1.

* Si no selecciona el dispositivo correcto al que aplicar el archivo de datos, el dispositivo no podrá reconocer el archivo de datos.

* <Cmd sid='team.menu.export.exportReason' /> es opcional. Los motivos de exportación se registran en <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.auditTrail.root' /> → <Cmd sid='setting.menu.auditTrail.acAuditLog' />.

:::

:::caution

Para importar a un dispositivo un archivo exportado desde **BioStar X**, cambie el nombre del archivo de la siguiente manera para que el dispositivo pueda reconocerlo. Está previsto que el formato del nombre de archivo se ajuste mediante una futura actualización de firmware del dispositivo para que el dispositivo lo reconozca automáticamente.

*<b>BioStarX</b>_YYYYMMDD_HHMMSS.tgz* → *<b>BioStar2</b>_YYYYMMDD_HHMMSS.tgz*

:::

### Importar datos {/* #importdata */}

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. Haga clic en <IcMoreW /> en la esquina superior derecha de la pantalla y luego seleccione <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.dataFile' />.

   <Image src='/img/biostarx-user-import-data.png' />

3. Seleccione el archivo de datos (*.tgz*) guardado localmente.

Si el archivo de datos se importa correctamente, aparece un mensaje en la pantalla.
