Aprenda a instalar **BioStar X** paso a paso con <Cmd code='biostar2.install.expressInstall' className='bold' />. <Cmd code='biostar2.install.expressInstall' className='bold' /> instala automáticamente el servidor MariaDB integrado y crea la base de datos, lo que le permite completar la instalación rápidamente sin una configuración de base de datos por separado.

:::info
