title: Inscribir Y Editar Usuarios Al Escanear Un ID
description: Aprenda a escanear un ID para obtener automáticamente la información del usuario y registrar o editar a un usuario.
---

En lugar de ingresar la información del usuario, escanee un ID para obtener automáticamente el nombre y la foto y, luego, registre a un usuario o edite la información de un usuario existente.

## Antes de comenzar

* Para escanear un ID, conecte el escáner DESKO a la PC cliente.

* Antes de registrar a un usuario escaneando un ID, asegúrese de seleccionar los datos que se obtendrán del ID. Para obtener más información sobre la configuración de Escanear ID, consulta <DocLink docId='platform/biostar_x/settings-account-scan-passport' />.

:::info

La característica <Cmd sid='button.passportScan' product='2' /> actualmente solo admite escaneos de pasaporte.

:::

## Registrar un usuario escaneando un ID

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. Haz clic en <Cmd sid='team.user.newUser' /> en la esquina superior derecha de la página <Cmd sid='shell.header.user' />.

   <Image src='/img/biostarx-user-add-user-01.png' />

3. Haga clic en <Cmd sid='button.passportScan' product='2' /> en la esquina superior derecha de la pantalla <Cmd sid='user.addNewUser' product='2' />.

   <Image src='/img/biostarx-user-add-by-scanning-passport-btn.png' />

4. Cuando aparezca la ventana <Cmd sid='user.passportScan.dialog.title' product='2' />, coloca el ID en el escáner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. Después de que aparezca el mensaje de escaneo de ID exitoso, selecciona si inscribes la foto del ID como credencial facial.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   Este mensaje aparece cuando <Cmd sid='setting.passportScan.face' /> se establece en <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> en <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. Si configura la opción <Cmd sid='setting.passportScan.faceDoNotAsk' />, el mensaje no aparece y se inscribe una credencial facial de inmediato.

   :::

6. Revisa la información del escaneo de ID y edítala si es necesario.

7. Para guardar al usuario, haga clic en <Cmd sid='user.save' product='2' /> en la esquina superior derecha de la pantalla.

## Editar un usuario mediante un escaneo de ID

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. Para editar a un usuario escaneando un ID, haga doble clic en el usuario en la lista de usuarios.

3. Haga clic en <Cmd sid='button.passportScan' product='2' /> en la esquina superior derecha de la pantalla Editar información del usuario.

   <Image src='/img/biostarx-user-edit-by-scanning-passport-btn.png' />

4. Cuando aparezca la ventana <Cmd sid='user.passportScan.dialog.title' product='2' />, coloca el ID en el escáner.

   <Image src='/img/biostarx-user-add-import-passport-data.png' />

5. Después de que aparezca el mensaje de escaneo de ID exitoso, selecciona si inscribes la foto del ID como credencial facial.

   <Image src='/img/biostarx-user-add-face-credential-confirm.png' />

   :::note

   Este mensaje aparece cuando <Cmd sid='setting.passportScan.face' /> se establece en <Cmd sid='setting.passportScan.faceAlwaysConfirm' /> en <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' />. Si configura la opción <Cmd sid='setting.passportScan.faceDoNotAsk' />, el mensaje no aparece y se inscribe una credencial facial de inmediato.

   :::

6. Revisa la información del escaneo de ID y edítala si es necesario.

7. Para guardar las actualizaciones del escaneo, haga clic en <Cmd sid='user.save' product='2' /> en la esquina superior derecha de la pantalla.

:::info

Si el usuario tiene dos o más credenciales faciales inscritas, al editar al usuario mediante el escaneo de un ID se sobrescribe la primera credencial facial inscrita.

:::

## Mensajes de error

Si ocurre un problema al escanear un ID, aparece un mensaje con la causa y la solución. Usa la información a continuación para resolver el error.

### Fallo de escaneo

Si ocurre un problema mientras el sistema reconoce automáticamente el ID en el escáner, aparece uno de los siguientes mensajes.

| Causa | Mensaje de error |
| --- | --- |
| No se pudieron verificar las funciones de seguridad del ID (por ejemplo, patrones UV) | <Cmd sid='user.passportScan.error.invalidPassport' product='2' /> |
| El sistema no reconoció el ID dentro del tiempo especificado | <Cmd sid='user.passportScan.error.timeout' product='2' /> |
| Otros errores de escaneo, como que el ID se mueva durante el escaneo o falle el reconocimiento de páginas | <Cmd sid='user.passportScan.error.cannotScan' product='2' /> |

Si aparece el mensaje anterior, haga clic en <Cmd sid='button.recognizePassport' product='2' /> que se muestra en la pantalla y, luego, vuelva a escanear. Asegúrese de que el ID esté colocado correctamente en el escáner y, luego, vuelva a intentarlo.

:::info

Cuando hace clic en <Cmd sid='button.recognizePassport' product='2' />, el reconocimiento automático se reinicia en el mensaje <Cmd sid='user.passportScan.scanning.title' product='2' />.

:::

### Error de conexión del escáner

Si hay un problema con la conexión del escáner, aparece el siguiente mensaje. Este error no tiene botón de reintento, así que siga las instrucciones y luego haga clic en <Cmd sid='button.passportScan' product='2' /> de nuevo para iniciar el escaneo desde el principio.

| Escenario | Mensaje de error | Solución |
| --- | --- | --- |
| El escáner no está conectado a la PC cliente | <Cmd sid='user.passportScan.scannerNotFound.description' product='2' /> | Compruebe la conexión entre el escáner de ID y la PC cliente. |

### Agente USB requerido

Para usar el escáner de ID, debe estar instalada la versión más reciente de USB Agent. Si USB Agent no está instalado o está desactualizado, aparece un cuadro de diálogo de error cuando hace clic en <Cmd sid='button.passportScan' product='2' />.

<Image src='/img/biostarx-user-scan-passport-error-usb-agent.png' />

* <Cmd sid='button.cancel' product='2' />: Cierra la ventana de error y no continúa con el escaneo.

* <Cmd sid='button.goToUsbAgentSettings' product='2' />: Va a la pantalla <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.device.root' /> → <Cmd sid='setting.menu.device.usbAgent' />. En esa pantalla, actualice USB Agent a la versión más reciente y luego intente escanear de nuevo.
