title: Configurar Escaneo De ID
description: Este artículo explica cómo seleccionar los datos de usuario para importar durante escaneos de ID y cómo definir el método de inscripción de credenciales faciales.
---

Antes de inscribir usuarios con el escaneo de ID, elige nombre de usuario e imagen de perfil para importar. Luego, selecciona el método de inscripción de credenciales faciales. Este artículo explica cómo configurar el escaneo de ID.

1. Haz clic en <Cmd sid='shell.header.setting' /> en la página <Cmd sid='shell.header.launcher' />.

2. Haz clic en <Cmd sid='setting.menu.account.root' /> → <Cmd sid='setting.menu.account.passportScan' /> en la barra lateral izquierda.

   <Image src='/img/biostarx-settings-account-passport-scan-setting.png' />

3. Selecciona los datos que se importarán al escanear un ID.

   * <Cmd sid='setting.passportScan.name' />: Importa el nombre impreso en el ID.

   * <Cmd sid='setting.passportScan.profileImage' />: Importa la imagen de perfil impresa en el ID.

   * <Cmd sid='setting.passportScan.face' />: Inscribe la imagen facial impresa en el ID como una credencial facial.

     * <Cmd sid='setting.passportScan.faceAlwaysConfirm' />: Siempre solicita confirmación al inscribir la imagen facial impresa en el ID como una credencial facial.

     * <Cmd sid='setting.passportScan.faceDoNotAsk' />: Inscribe la imagen facial impresa en el ID como una credencial facial sin solicitar confirmación.

4. Haga clic en <Cmd sid='button.apply' product='2' /> para guardar la configuración.

:::info

* Selecciona <Cmd sid='setting.passportScan.profileImage' /> para activar <Cmd sid='setting.passportScan.face' />.

* Para obtener más información sobre inscribir o actualizar usuarios con el escaneo de ID, consulta <DocLink docId='platform/biostar_x/add-user-by-scanning-passport' />.

:::
