En el Dashboard, cada usuario puede agregar widgets seleccionando la información que desea mostrar y configurarlos y organizarlos libremente.

:::info

* Cada usuario puede configurar su propio <Cmd sid='shell.header.dashboard' />.

* La información disponible en <Cmd sid='shell.header.dashboard' /> puede variar según <Cmd sid='user.bioStarOperator' product='2' />.

:::
