id: settings-system-audit-trail
title: Gestionar Registro De Auditoría
description: Supervise no solo la información de acceso de los usuarios, sino también toda la información modificada en el sistema.
---

La característica <Cmd sid='setting.menu.auditTrail.root' /> registra y rastrea todas las actividades del sistema. Registra actividades como inicio/cierre de sesión, cambios de ajustes y tareas de administración del sistema. Estos registros se usan para auditorías de seguridad y monitoreo del sistema.

El grupo <Cmd sid='setting.menu.auditTrail.root' /> en la barra lateral izquierda incluye los siguientes menús.

* <Cmd sid='setting.menu.auditTrail.acAuditLog' />: Registra actividades de control de acceso, como crear, actualizar, eliminar, ver, exportar, importar y acciones administrativas relacionadas con usuarios, dispositivos y puertas.

* <Cmd sid='setting.menu.system.auditTrailRetention' />: Define el período de retención del registro de auditoría y si se registra el historial de visualización.

:::info

Para obtener más información sobre <Cmd sid='setting.menu.auditTrail.taAuditLog' />, consulte <DocLink docId='platform/biostar_x/tna-audit-trail' />. El menú <Cmd sid='setting.menu.auditTrail.taAuditLog' /> solo aparece con una licencia activa de control de tiempo y asistencia (T&A).

:::
