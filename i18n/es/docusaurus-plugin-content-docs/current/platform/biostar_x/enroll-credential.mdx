Aprenda a inscribir las credenciales de un usuario. Puede inscribir las huellas dactilares, los datos faciales, la información de tarjetas y los códigos PIN del usuario como credenciales. Las credenciales se pueden agregar o cambiar cuando registra un usuario nuevo o edita un usuario.

En la página <Cmd sid='shell.header.launcher' /> → <Cmd sid='shell.header.user' />, puede inscribir, agregar o cambiar credenciales de las dos maneras siguientes.

import EnterUserPage from '../../common/_enter-user-page.mdx';

<EnterUserPage />

En la sección <Cmd sid='team.user.credential.title' />, puede configurar lo siguiente. Consulte la descripción de cada opción y configure los permisos de usuario correspondientes.

<Image src='/img/biostarx-new-user-credential.png' />

Inscriba las credenciales y, luego, establezca el nivel de seguridad apropiado en el campo <Cmd sid='user.fingerSecurityLevel' product='2' />. Un nivel de seguridad más alto puede resultar en una menor tasa de autenticación o una mayor tasa de rechazo falso (FRR).

:::note

<Glossary termid='credential' />

:::

:::info

* Las tarjetas de acceso móvil solo están disponibles cuando están integradas con el Airfob Portal. Para obtener más información sobre la integración con el Airfob Portal y el uso de las tarjetas de acceso móvil, consulte <DocLink docId='platform/biostar_x/settings-credential-mobile-access-card' />.

:::
