Aprenda a ingresar detalladamente la información básica de un usuario. El sistema usa la información del usuario que ingresa para la búsqueda y la administración. Administrar la información de los usuarios de forma clara le ayuda a cumplir con las políticas de seguridad y privacidad de su organización.

* Ingresar de forma sistemática información básica como el nombre, el departamento, el cargo y el grupo le permite buscar, categorizar y administrar usuarios fácilmente.

* Puede configurar permisos de acceso más detallados según la información del departamento, el cargo y el grupo del usuario.

* Esto ayuda a la seguridad y a las auditorías, ya que puede hacer un seguimiento preciso del historial de actividad y los registros de acceso de cada usuario.

Vaya a la página <Cmd sid='shell.header.launcher' /> → <Cmd sid='shell.header.user' /> e ingrese la información del usuario de una de las dos maneras que se indican a continuación.

Los campos que se pueden configurar en la sección <Cmd sid='team.user.information' /> son los siguientes. Ingrese la información del usuario según la descripción de cada campo.

<Image src='/img/biostarx-new-user-information.png' />

* **Foto**: Agregue una foto del usuario. Puede tomar una foto con la cámara web o cargar una foto desde su PC. Cuando pasa el cursor sobre el perfil, aparecen las herramientas disponibles.

  <Columns>
  <Column className='width--20'><Image src='/img/common/biostarx-new-user-photo.png' alone /></Column>
  <Column className='padding--l10'>

  * <IcCamera/>: Toma una foto con la cámara web conectada a su PC y la agrega.

  * <IcUpload/>: Carga un archivo de imagen guardado en su PC.

  Para obtener más información, consulte <DocLink docId='platform/biostar_x/enroll-credential-face#erollbywebcambyphoto' />.

  </Column>
  </Columns>

* <Cmd sid='team.user.table.id' />: Ingrese un ID único para asignar al usuario.

* <Cmd sid='team.user.table.name' />: Ingrese el nombre del usuario.

* <Cmd sid='team.user.table.email' />: Ingrese la dirección de correo electrónico.

* <Cmd sid='team.user.table.phone' />: Ingrese el número de teléfono.

* <Cmd sid='team.user.table.department' />: Ingrese el departamento del usuario.

* <Cmd sid='team.user.table.title' />: Ingrese el cargo del usuario.

* <Cmd sid='team.user.table.group' />: Seleccione el grupo del usuario. Para obtener más información sobre cómo agregar y administrar grupos de usuarios, consulte <DocLink docId='platform/biostar_x/user-group-manage' />.

* <Cmd sid='team.user.table.period' />: Establezca el período de uso de la cuenta de usuario. Haga clic en el área de fecha y hora para ingresar los valores directamente, o haga clic en <IcCalc /> para seleccionar una fecha y hora.

* <Cmd sid='team.user.table.status' />: Configure esta opción para desactivar temporalmente la cuenta de usuario.

Para guardar la información básica ingresada, haga clic en <Cmd sid='user.save' product='2' /> en la esquina superior derecha de la pantalla.

:::info

* Los valores que puede configurar para <Cmd sid='team.user.table.id' /> dependen de la opción <Cmd sid="setting.userDevice.useridType" product='2' /> en el menú <Cmd sid='shell.header.setting' /> → <Cmd sid='setting.menu.system.root' /> → <Cmd sid='setting.menu.server.server' />. Para obtener más información, consulte <DocLink docId='platform/biostar_x/settings-server-server#userid-type' />.

  * <Cmd sid="setting.userDevice.useridType.numeric" product='2' />: Ingrese un número del 1 al 4294967294.

  * <Cmd sid="setting.userDevice.useridType.alphanumeric" product='2' />: Ingrese una combinación de letras y números.

* Para mostrar la foto, el departamento y el cargo del usuario en la tarjeta de acceso móvil, asegúrese de agregar una foto e ingresar el departamento y el cargo.

* Los nombres de puesto y departamento admiten hasta 64 caracteres, incluidos los símbolos especiales `space` y `_`.

* Si usa una tarjeta de acceso móvil, ingrese el correo electrónico del usuario cuando envíe la tarjeta por correo electrónico.

* Para usar el enrolamiento facial móvil o BioStar X QR, ingrese la dirección de correo electrónico del usuario.

:::

:::tip

Para ingresar información adicional del usuario más allá de los campos de entrada predeterminados proporcionados por **BioStar X**, agregue campos personalizados con la función <Cmd sid='team.userTemplate.table.customField' />. <Cmd sid='team.userTemplate.table.customField' /> es una función útil para ampliar la información del usuario y cumplir con los requisitos de su organización.

Para obtener más información sobre cómo agregar <Cmd sid='team.userTemplate.table.customField' />, consulte <DocLink docId='platform/biostar_x/settings-server-server#custom-field' />.

:::
