Si necesita eliminar un usuario registrado en **BioStar X** debido a una renuncia, el fin del contrato o una violación de seguridad, siga estos pasos.

1. En la página <Cmd sid='shell.header.launcher' />, haz clic en <Cmd sid='shell.header.user' />.

2. En la lista de usuarios, seleccione la casilla de verificación a la izquierda del usuario que desea eliminar. Puede seleccionar uno o más usuarios.

3. Haga clic en <Cmd sid='common.delete' /> en la esquina superior derecha de la pantalla.

   <Image src='/img/biostarx-remove-users.png' />

4. Cuando aparezca el mensaje de confirmación, haga clic en <Cmd sid='common.delete' />.

Confirma que el usuario seleccionado se haya eliminado de la lista de usuarios.

:::info

* El usuario con ID `1` no se puede eliminar.

* Para obtener más información sobre cómo eliminar la información del usuario del dispositivo, consulte <DocLink docId='platform/biostar_x/settings-device-manage-device-users' />.

:::
