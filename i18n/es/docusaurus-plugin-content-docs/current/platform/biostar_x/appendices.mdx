### ffmpeg

**BioStar X** includes ffmpeg ([https://ffmpeg.org](https://ffmpeg.org)) for video file conversion and probing. It ships two ffmpeg command-line binaries, *ffmpeg.exe* and *ffprobe.exe*; both are built from the single ffmpeg source tarball below (ffprobe is part of the ffmpeg project, not a separate component).

* Component: ffmpeg (ffmpeg.exe, ffprobe.exe)

* Version: 8.1

* License: GNU Lesser General Public License v2.1

   Full text: see [COPYING.LGPLv2.1](./opensource/opensourcelicenses.txt)

* Source code: ffmpeg-8.1.tar.xz

* Upstream URL: [ffmpeg-8.1.tar.xz](https://supremadocs.blob.core.windows.net/opensource/ffmpeg-8.1.tar.xz)

* SHA-256: b072aed6871998cce9b36e7774033105ca29e33632be5b6347f3206898e0756a

```txt title="Build configuration:"
./configure \
    --arch=x86_64 \
    --target-os=mingw64 \
    --disable-gpl \
    --disable-nonfree \
    --disable-libx264 \
    --disable-libx265 \
    --disable-libxvid \
    --enable-mediafoundation \
    --enable-libmp3lame \
    --disable-doc \
    --disable-debug \
    --enable-small \
    --pkg-config-flags=--static \
    --extra-ldflags="-static" 
```

Modifications: None. Binary built from vanilla upstream source tarball.

Encoders used by **BioStar X**:

* h264_mf (H.264 via Windows Media Foundation)

* libmp3lame (MP3 audio, LGPL)

* License: GNU Lesser General Public License v2.1

* Source code: lame-3.100.tar.gz

* Upstream URL: [lame-3.100.tar.gz](https://supremadocs.blob.core.windows.net/opensource/lame-3.100.tar.gz)
