### ffmpeg

**BioStar X** incluye ffmpeg ([https://ffmpeg.org](https://ffmpeg.org)) para convertir y sondear archivos de video. Incluye dos binarios de línea de comandos de ffmpeg: *ffmpeg.exe* y *ffprobe.exe*. Ambos se compilan a partir del tarball único de código fuente upstream de ffmpeg que se indica abajo (ffprobe forma parte del proyecto ffmpeg, no es un componente aparte).

* Component: ffmpeg (ffmpeg.exe, ffprobe.exe)

* Version: 8.1

* License: GNU Lesser General Public License v2.1

   Texto completo: consulte [COPYING.LGPLv2.1](/opensource/opensourcelicenses.txt)

* Source code: ffmpeg-8.1.tar.xz

* Upstream URL: [ffmpeg-8.1.tar.xz](https://supremadocs.blob.core.windows.net/opensource/ffmpeg-8.1.tar.xz)

* SHA-256: b072aed6871998cce9b36e7774033105ca29e33632be5b6347f3206898e0756a

```txt title="Build configuration:"
./configure \
    --arch=x86_64 \
    --target-os=mingw64 \
    --disable-gpl \
    --disable-nonfree \
    --disable-libx264 \
    --disable-libx265 \
    --disable-libxvid \
    --enable-mediafoundation \
    --enable-libmp3lame \
    --disable-doc \
    --disable-debug \
    --enable-small \
    --pkg-config-flags=--static \
    --extra-ldflags="-static" 
```

Modificaciones: ninguna. Binario compilado a partir del tarball de código fuente upstream sin modificaciones.

Codificadores que usa **BioStar X**:

* h264_mf (H.264 via Windows Media Foundation)

* libmp3lame (MP3 audio, LGPL)
