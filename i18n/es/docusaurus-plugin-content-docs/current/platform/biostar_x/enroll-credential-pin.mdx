Aprenda a registrar un PIN para que los usuarios puedan acceder ingresando un PIN en el dispositivo. Puede registrar un PIN para un usuario individual o registrar PIN en lote para varios usuarios mediante la importación de un archivo CSV.

## Registrar un PIN

1. En la sección <Cmd sid='common.credential' product='2' />, haga clic en <Cmd sid='user.pin' product='2' />.

   <Image src='/img/biostarx-new-user-credential-pin.png' />

2. Cuando el campo de entrada se active, ingrese el PIN.

3. En <Cmd sid='user.confirmPin' product='2' />, ingrese el mismo PIN.

4. Haz clic en <Cmd sid='button.enroll' product='2' />.

:::info

* El PIN debe tener entre 4 y 16 dígitos y contener solo números.

* Puede registrar como máximo una credencial de PIN por usuario.

:::

## Registrar un PIN mediante importación de CSV

Use la función de importación de CSV para registrar a varios usuarios a la vez.

1. Agregue una columna `pin` al archivo CSV que se importará.

2. Ingrese el PIN del usuario en la columna `pin` y guarde el archivo CSV.

3. Vaya a la página <Cmd sid='shell.header.user' />.

4. Haga clic en <IcMoreW /> en la esquina superior derecha de la pantalla y seleccione <Cmd sid='team.menu.import.title' /> → <Cmd sid='team.menu.import.csv' />.

5. Siga las instrucciones en pantalla para seleccionar el archivo CSV y configurar las opciones de importación.

:::info

* Puede registrar como máximo una credencial de PIN por usuario.

* Para obtener más información sobre la función de importación de CSV, consulte <DocLink docId='platform/biostar_x/export-import-user-info#csvimport' />.

:::
