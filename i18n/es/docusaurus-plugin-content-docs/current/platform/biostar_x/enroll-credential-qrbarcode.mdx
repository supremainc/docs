Aprenda a registrar un código QR o un código de barras como credencial de usuario. Puede registrar códigos QR generados en **BioStar X** y códigos QR o códigos de barras emitidos externamente.

:::info

* Para los dispositivos que admiten la autenticación con QR/código de barras mediante un escáner, consulte la siguiente lista.

  * X-Station 2 (XS2-QDPB, XS2-QAPB)

* Para los dispositivos que admiten la autenticación con QR/código de barras mediante una cámara, consulte la siguiente lista.

  * Firmware BioStation 3 Max v1.0.0 o posterior

  * Firmware XPass Q2 v1.0.0 o posterior

  * Firmware BioStation 3 v1.1.0 o posterior

  * Firmware X-Station 2 (XS2-ODPB, XS2-OAPB, XS2-DPB, XS2-APB) v1.2.0 o posterior

  * Firmware X-Station 2 (XS2-QDPB, XS2-QAPB) v1.4.1 o posterior

* Se requiere una licencia de dispositivo independiente para utilizar la autenticación mediante QR/código de barras con una cámara. Para obtener más información, consulte <DocLink docId='platform/biostar_x/settings-license-device-license' />.

:::

## BioStar X QR {/* #biostarxqr */}

Puede emitir a un usuario un código QR que incluya un PIN cifrado para otorgarle acceso.

:::note

**Antes de comenzar**

* Configure la información de correo electrónico, incluida la configuración SMTP, antes de usar **BioStar QR**. Para obtener más información, consulta <DocLink docId='platform/biostar_x/settings-email-setting' />.

* Para emitir **BioStar QR**, debe ingresar una dirección de correo electrónico en la información del usuario. Para obtener más información, consulte <DocLink docId='platform/biostar_x/add-user-basic-info' />.

:::

1. Haga clic en <Cmd sid='button.addQr' product='2' /> en la sección <Cmd sid='common.credential' product='2' />.

2. Cuando aparezca la ventana <Cmd sid='user.header.qr' product='2' />, seleccione <Cmd sid='team.user.biostarQr' /> en las opciones de <Cmd sid='user.qrType' product='2' />.

   <Image src='/img/biostarx-new-user-credential-biostarqr.png' />

3. Seleccione la opción <Cmd sid='zone.intrusion.inputType' product='2' />.

   * <Cmd sid='user.random.cardid' product='2' />: Genera automáticamente un ID de tarjeta.

   * <Cmd sid='user.manual.input' product='2' />: Ingrese el ID de la tarjeta manualmente.

4. Haz clic en <Cmd sid='button.enroll' product='2' />.

Luego, cuando el usuario se autentica para acceder, el sistema emite un código QR y lo envía a la dirección de correo electrónico registrada en la información del usuario. El usuario puede escanear el código QR incluido en el correo electrónico en el dispositivo para obtener acceso.

:::info

Para evitar IDs de tarjeta duplicados, configure <Cmd sid='zone.intrusion.inputType' product='2' /> en <Cmd sid='user.random.cardid' product='2' />.

:::

## QR/código de barras {/* #qrbarcode */}

Puede registrar para el usuario códigos QR o códigos de barras emitidos por otros proveedores externos.

1. Haga clic en <Cmd sid='button.addQr' product='2' /> en la sección <Cmd sid='common.credential' product='2' />.

2. Cuando aparezca la ventana <Cmd sid='user.header.qr' product='2' />, seleccione <Cmd sid='team.user.credential.qrBarcode.title' /> en las opciones de <Cmd sid='user.qrType' product='2' />.

   <Image src='/img/biostarx-new-user-credential-qrbarcode.png' />

3. Seleccione <Cmd sid='common.enterManually' product='2' /> en las opciones de <Cmd sid='common.registrationOption' product='2' />.

4. En el campo <Cmd sid='user.cardId' product='2' />, ingrese el ID del código QR/código de barras emitido previamente.

5. Haz clic en <Cmd sid='button.enroll' product='2' />.

:::info

El campo <Cmd sid='user.cardId' product='2' /> acepta hasta 32 caracteres, incluidas letras, números y caracteres especiales.

:::
