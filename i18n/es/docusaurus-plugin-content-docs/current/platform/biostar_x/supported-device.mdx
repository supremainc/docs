---

La plataforma **BioStar X** admite los siguientes dispositivos y la versión mínima de firmware de cada dispositivo. Si el firmware del dispositivo es anterior a la versión indicada a continuación, actualice el firmware y luego use el dispositivo.

:::info

Un dispositivo puede no ser compatible con ciertas características de **BioStar X**, según especificaciones o la versión de firmware. Consulte la documentación de cada característica para conocer los dispositivos compatibles y las versiones de firmware.

:::
