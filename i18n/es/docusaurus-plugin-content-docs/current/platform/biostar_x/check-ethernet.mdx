Aprenda a verificar y configurar la prioridad de red del servidor antes de instalar **BioStar X**.

## ¿Cuándo se necesita?

Debe verificar y configurar la prioridad de red en las siguientes situaciones.

* Cuando el servidor tiene instalados dos o más adaptadores de red (tarjetas LAN)

* Cuando un adaptador de red específico debe utilizarse para el servicio de **BioStar X**

* Cuando necesite evitar problemas de conexión de red después de instalar **BioStar X**

:::info

Si ninguna de las situaciones anteriores aplica, no es necesario cambiar la prioridad de red. Omita este paso y continúe con la instalación de **BioStar X**. Para obtener más información sobre cómo instalar **BioStar X**, consulte <DocLink docId='platform/biostar_x/express-install' />.

:::

:::warning

Durante la instalación de **BioStar X**, se selecciona automáticamente el adaptador de red con un valor de métrica de red más bajo (mayor prioridad). Como puede ser difícil cambiar esta configuración después de la instalación, **asegúrese de verificar y ajustar la prioridad de red antes de la instalación**.

:::

## Verificar la Prioridad de Red

### Verificar en el símbolo del sistema

1. Para abrir el **Command Prompt**, busque `cmd` en el menú **Start**.

2. Ingrese el siguiente comando.

   ```cmd
   route print
   ```

3. En la salida, busque entradas en la sección **IPv4 Route Table** donde **Network Destination** sea `0.0.0.0`.

4. Verifique el valor en la columna **Metric**. **Cuanto menor sea el valor, mayor será la prioridad**.

<PageBreak />

**Ejemplo de salida:**

<Image src='/img/common/biostarx-install-check-network-cmd.png' alone />

En el ejemplo anterior, la interfaz `192.168.40.123` tiene un valor de métrica de **20**, por lo que tiene una prioridad más alta.

### Verificar la información del adaptador de red

Verifique a qué adaptador de red corresponde cada interfaz.

1. En la ventana del **Command Prompt**, ingrese el siguiente comando.

   ```cmd
   ipconfig /all
   ```

2. Haga coincidir la **IPv4 address** de cada adaptador de red con la dirección de **Gateway** que verificó anteriormente para identificar el adaptador.

<PageBreak />

## Cambiar la prioridad de red

Para aumentar la prioridad del adaptador de red seleccionado, siga estos pasos.

:::info

Estos pasos se basan en Windows 11. La ubicación de los menús puede variar según su versión de Windows.

:::

<Steps>
<Step>

### Abrir la configuración de red

1. En el menú **Start**, escriba **View Network Connections**.

   <Image src='/img/biostarx-install-check-start-network-search.png' />

2. Haga clic en **View Network Connections** en los resultados de la búsqueda.

3. Haga doble clic en el adaptador conectado a Internet en la lista.

   <Image src='/img/biostarx-install-check-control-network-connections.png' />

</Step>
<Step>

### Abrir las opciones del adaptador

1. Cuando aparezca la ventana **Ethernet Status**, haga clic en **Properties**.

   <Image src='/img/biostarx-install-check-ethernet-status.png' />

2. Cuando aparezca la ventana Propiedades de Ethernet, seleccione <b>Internet Protocol Version 4 (TCP/IPv4)</b> en la lista.

   <Image src='/img/biostarx-install-check-ethernet-properties.png' />

3. Haga clic en **Properties**.

4. Cuando aparezca la ventana **Internet Protocol Version 4 (TCP/IPv4) Properties**, haga clic en **Advanced**.

   <Image src='/img/biostarx-install-check-protocol-properties.png' />

</Step>
<Step>

### Configuración de métrica

1. Desmarque la casilla **Automatic Metric**.

   <Image src='/img/biostarx-install-check-set-metrics.png' />

2. Ingrese el valor que desea usar en el campo **Interface Metric**.

   * Para obtener la prioridad más alta, ingrese `1`.

   * Para obtener una prioridad más alta que la de otros adaptadores, ingrese un número menor que los valores de métrica de los demás adaptadores.

3. Para guardar la configuración y cerrar todas las ventanas, haga clic en **OK**.

:::info

El campo **Interface Metric** acepta valores de `1` a `9999`. Los valores más bajos tienen mayor prioridad.

:::

</Step>
<Step>

### Verificar la configuración

1. Vuelva a abrir el **Command Prompt** y ejecute el comando `route print`.

2. Verifique si el valor de la métrica ha cambiado.

</Step>
</Steps>

## Solución de Problemas

* Si la configuración no se aplica, reinicie el equipo o deshabilite y luego vuelva a habilitar el adaptador de red.

* Si se pierde la conexión de red, vuelva a la configuración original y seleccione de nuevo la casilla **Automatic Metric**. Comuníquese con el administrador de red para verificar la configuración correcta.

:::info

Si necesita cambiar la configuración de red después de instalar **BioStar X**, debe desinstalar por completo el programa y luego volver a instalarlo.

:::
