Aprenda a instalar **BioStar X** paso a paso con el método <Cmd code='biostar2.install.customInstall' className='bold'/>. <Cmd code='biostar2.install.customInstall' className='bold'/> se conecta a una base de datos existente (MariaDB o MS SQL Server) en un servidor local o remoto y genera el esquema de la base de datos. Antes de iniciar la instalación, prepare la base de datos y la cuenta de usuario a la que se conectará.

## Antes de empezar {/* #start-before */}

* Se admiten las siguientes bases de datos para usarlas con **BioStar X**.

  * MariaDB 11.4.4

  * MS SQL Server 2012 SP3

  * MS SQL Server 2014 SP2

  * MS SQL Server 2016 SP1

  * MS SQL Server 2017

  * MS SQL Server 2019

  * MS SQL Server 2022

* MS SQL Server admite TLS 1.2 para la comunicación segura.

* Si falla la creación de tablas de la base de datos después de configurar MS SQL Server como base de datos, ejecute los scripts en *C:\Program Files\BioStar X\dbscript\mssql* para crear las tablas.

* Cuando selecciona <Cmd code='biostar2.install.customInstall' className='bold'/> como opción de instalación, no puede establecer **AC DB name**, **TA DB name** y **VE DB name** en el mismo valor.

* Para usar la autenticación de Windows, se requiere [Microsoft ODBC Driver 17 for SQL Server](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver16#version-17).
  Instale primero el controlador.
