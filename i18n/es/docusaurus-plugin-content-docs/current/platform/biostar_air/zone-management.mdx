Las zonas son agrupaciones lógicas de puertas y dispositivos. Se usan para anti-passback, estado en sitio, conteo de personas y otras aplicaciones futuras.

## Comprender las zonas y el anti-passback (APB)

Al usar zonas para el anti-passback, el administrador debe definir puntos de entrada y puntos de salida para la zona. Estos puntos determinan cuándo un usuario con credencial está dentro o fuera de la zona. Un usuario con credencial no puede reingresar a la zona sin salir primero, aunque use una credencial diferente. El anti-passback también se usa para definir puntos claros de entrada y salida, y evita que los usuarios regresen y salgan por una entrada.

## Zona perimetral

Al igual que el anti-passback, BioStar Air define una **zona perimetral** que determina el estado en sitio de un usuario con credencial. Esto es importante para las funciones **En sitio ahora** y **Pase de lista**. De forma opcional, se puede configurar la zona perimetral para anti-passback.
