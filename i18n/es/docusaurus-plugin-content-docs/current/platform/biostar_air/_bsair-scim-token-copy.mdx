### BioStar Air: Copiar el token SCIM {/* #copyToken */}

1. Haga clic en <Cmd sid='settings_menu' product='air' /> → <Cmd sid='site_submenu' product='air' /> en la barra lateral izquierda de BioStar Air.

2. Haga clic en la pestaña <Cmd>SSO & SCIM</Cmd>.

3. En la sección <Cmd sid='sso_scim.additional_features.scim.title' product='air' />, copie el valor de <Cmd sid='sso_scim.additional_features.scim.endpoint_url' product='air' />.

   <Image src='/img/air/bsair-settings-site-idp-okta-copy-endpoint-url.png' />

4. Haga clic en <Cmd sid='sso_scim.additional_features.scim.generate_token' product='air' />.

5. En el cuadro de diálogo Generación de token completada, copie el token.

:::info

* Copie el token generado de inmediato. Copie el token solo al generarlo. Después de cerrar el cuadro de diálogo, el sistema no permite copiar el token de nuevo.

* Si pierde el token, haga clic en <Cmd sid='sso_scim.additional_features.scim.rotate_token' product='air' /> para generar un nuevo token. Ingrese el nuevo token nuevamente en el proveedor de identidad.

* En el siguiente paso, ingrese la URL del extremo de SCIM y el token copiado en este paso.

:::
