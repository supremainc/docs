# BS2_SetIPConfigViaUDPEx

<Badge only>+ v2.6.3</Badge> Host ip를 지정하여, 장치의 IP 설정 정보를 udp broadcasting을 통해 저장합니다.

다수의 Ethernet card가 설치되어 있는 시스템에서 유용합니다.

## 함수

```cpp
#include "BS_API.h"

int BS2_SetIPConfigViaUDPEx(void* context, uint32_t deviceId, const BS2IpConfig* config, const char* hostipAddr);
```

:::info

[BS2IpConfig 구조체 보기](configuration_api#bs2ipconfig) 

:::

## 파라미터

- [In] `context` : Context

- [In] `deviceId` : 장치 식별자

- [In] `config` : IP 설정 정보 포인터

- [In] `hostipAddr` : 호스트 IP 주소

## 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생할 경우 상응하는 에러 코드를 반환합니다.
