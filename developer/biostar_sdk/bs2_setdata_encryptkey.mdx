<Badge only>+ v2.7.1</Badge> 사용자의 PIN 코드 암호화 키 값을 변경합니다.

장치의 PIN 암호화 키가 설정하려는 키와 같으면 설정은 무시됩니다.

또한 장치의 PIN 암호화 키가 설정하려는 키와 다르면 해당 키로 설정되고 장치의 모든 사용자 정보가 삭제됩니다.

:::caution

* PIN 암호화 키를 변경하면 변경한 사용자 정의 키를 사용하기 위해 장치의 모든 사용자가 삭제됩니다.

* [BS2_EnrolUser](bs2_enroluser)와 같은 함수를 통해 사용자를 장치에 다시 추가해야 합니다.

* [BS2_MakePinCode](bs2_makepincode) 함수는 기본 키 값으로 사용자 PIN 코드를 암호화합니다.

* PIN 암호화 키를 사용자 정의 값으로 변경했다면 [BS2_MakePinCodeWithKey](bs2_makepincodewithkey)를 호출하여 사용자에게 다시 할당해야 합니다.

:::

### 함수

```cpp
#include "BS_API.h"

int BS2_SetDataEncryptKey(void* context, uint32_t deviceId, const BS2EncryptKey* keyInfo);
```

:::info

[BS2EncryptKey 구조체 보기](sdk_api#bs2encryptkey) 

:::

### 파라미터

- [In] `context` : Context

- [In] `deviceId` : 장치 식별자

- [In] `keyInfo` : 설정할 키 정보 구조체의 주소

### 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생할 경우 상응하는 에러 코드를 반환합니다.
