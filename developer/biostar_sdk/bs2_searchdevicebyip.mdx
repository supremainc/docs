# BS2_SearchDeviceByIP

<Badge only>+ v2.9.13</Badge> 특정 IPv4 주소의 장치를 검색하고 현재 Context에 가용한 장치 목록을 갱신합니다. 장치 목록은 [BS2_GetDevices](bs2_getdevices) 함수를 통해 가져올 수 있습니다.

브로드캐스트를 사용하지 않고 지정한 주소로 직접 유니캐스트 요청을 보내므로, 브로드캐스트가 차단된 구간이거나 장치가 다른 서브넷에 있어도 장치를 찾을 수 있습니다.

:::info

이전의 장치 목록을 덮어씁니다. 

:::

:::caution

응답 시간 초과가 `BS_SDK_SUCCESS`로 보고됩니다. 장치가 없는 주소로 호출해도 성공이 반환됩니다.

반환값으로 판단하지 마시고, [BS2_GetDevices](bs2_getdevices)가 반환하는 장치 수로 확인해야 합니다.

:::

## 함수

```cpp
#include "BS_API.h"

int BS2_SearchDeviceByIP(void* context, const char* deviceIpAddr);
```

## 파라미터

- [In] `context` : Context

- [In] `deviceIpAddr` : 검색할 장치의 IPv4 주소

## 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생할 경우 상응하는 에러 코드를 반환합니다.

IPv6 주소를 전달하면 `BS_SDK_ERROR_INVALID_ADDRESS`를 반환합니다.
