# BS2_GetRS485Config

RS485 네트워크 설정 정보를 가져옵니다.

## 함수

```cpp
#include "BS_API.h"

int BS2_GetRS485Config(void* context, uint32_t deviceId, BS2Rs485Config* config);
```

:::info

[BS2Rs485Config 구조체 보기](configuration_api#bs2rs485config) 

:::

## 파라미터

- [In] `context` : Context

- [In] `deviceId` : 장치 식별자

- [Out] `config` : RS485 네트워크 설정 정보를 저장할 포인터

## 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생할 경우 상응하는 에러 코드를 반환합니다.
