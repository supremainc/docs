# BS2_GetCardConfigEx

장치의 iClass SEOS 카드 설정 정보를 가져옵니다.

:::info

보안강화를 위해 키 값은 취득할 수 없습니다.

:::

## 함수

```cpp
#include "BS_API.h"

int BS2_GetCardConfigEx(void* context, uint32_t deviceId, BS2CardConfigEx* config);
```

:::info

[BS2CardConfigEx 구조체 보기](configuration_api#bs2cardconfigex) 

:::

## 파라미터

- [In] `context` : Context

- [In] `deviceId` : 장치 식별자

- [Out] `config` : 스마트 카드 설정 정보를 저장할 포인터

## 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생힐 경우 상응하는 에러 코드를 반환합니다.
