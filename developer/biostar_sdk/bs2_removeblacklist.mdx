# BS2_RemoveBlackList

주어진 블랙리스트를 제거합니다.

## 함수

```cpp
#include "BS_API.h"

int BS2_RemoveBlackList(void* context, uint32_t deviceId, BS2BlackList* blacklists, uint32_t blacklistCount);
```

:::info

[BS2BlackList 구조체 보기](blacklist_api#bs2blacklist) 

:::

## 파라미터

- [In] `context` : Context

- [In] `deviceId` : 장치 식별자

- [In] `blacklists` : 제거할 blacklist 리스트

- [In] `blacklistCount` : blacklist 리스트의 개수

## 반환값

성공적으로 수행될 경우 `BS_SDK_SUCCESS`를 반환하고, 에러가 발생할 경우 상응하는 에러 코드를 반환합니다.
