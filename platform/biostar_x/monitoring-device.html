장치 모니터링하기

장치 및 카메라 모니터링 기능을 사용하는 방법을 안내합니다. 장치와 카메라의 상태를 점검하고, 상세 정보를 확인하며, 카메라 영상을 실시간으로 재생하는 등 다양한 기능을 활용할 수 있습니다. 또한, 최근 발생한 이벤트를 확인하여 장치와 카메라의 상태를 효율적으로 관리하는 방법을 확인하세요.

모니터링 페이지는 런처 페이지에서 모니터링을 클릭하거나 화면 왼쪽 상단의 바로 가기 목록에서 모니터링을 선택하여 진입할 수 있습니다.

장치 및 카메라 상태 점검​

화면 왼쪽 사이드바에서 장치 탭을 클릭하세요. 모든 장치와 카메라의 상태를 점검할 수 있습니다. 장치와 카메라의 상태는 아래를 참고하세요.

상태 아이콘설명
장치가 정상 연결된 상태입니다.
장치가 꺼져 있거나 연결이 해제된 상태입니다.
카메라가 연결된 상태입니다.
카메라가 꺼져 있거나 연결이 해제된 상태입니다.

주의가 필요한 장치 모아보기​

관리자는 조치가 필요한 장치만 한 번에 모아 볼 수 있습니다. 화면 왼쪽 사이드바의 주의가 필요한 항목을 클릭하세요. 장치의 상태를 확인하고, 문제가 발생한 대상에 조치를 취할 수 있습니다.

장치 트리에서 정상이 아닌 장치를 조치 대상으로 판정합니다.

이상 상태 종류상태 표시설명

  • 장치 잠금 조건은 작업 조건 및 동작 설정하기에서 설정한 작업 조건 및 동작에 따라 결정됩니다. 이 상태를 확인하고 해제하는 방법은 #deviceLockRelease를 참고하세요.

  • 인증 실패 잠금 조건은 장치 설정에서 구성할 수 있습니다. 자세한 내용은 인증 설정하기를 참고하세요. 이 상태를 확인하고 해제하는 방법은 #authFailLockout를 참고하세요.

장치 제어​

화면 왼쪽 사이드바의 장치 목록에서 원하는 장치를 선택하고 마우스 오른쪽 버튼을 클릭하세요. 팝업 메뉴에서 원하는 기능을 선택할 수 있습니다.

장치 유형에 따라 표시되는 제어 기능은 다를 수 있습니다.

장치 유형제어 기능
마스터 장치, 슬레이브 없이 서버에 직접 연결되는 기본 장치작업 중지, 재시작, 장치 잠금 해제, 인증 실패 잠금 해제, 재연결(서버에서 장치로 연결하는 방식일 때만)

장치 재연결​

장치의 연결 상태와 관계없이 팝업 메뉴에서 재연결을 클릭하세요. 연결이 끊긴 장치는 다시 연결을 시도하고, 정상 연결된 장치는 설정을 다시 전송하거나 이상 상태를 해소하는 용도로 사용할 수 있습니다. 장치가 다시 연결되면 상태 아이콘이 정상 상태()로 변경됩니다.

알아두기

재연결 기능은 장치에서 서버 연결 옵션으로 설정된 장치는 지원하지 않습니다. 장치 등록에 대한 자세한 내용은 장치 등록하기를 참고하세요.

장치 재시작​

장치를 재시작하려면, 팝업 메뉴에서 재시작을 클릭하세요. 경고 메시지 창이 나타나면 확인 버튼을 클릭하세요.

장치 잠금 해제​

관리자가 설정한 작업 조건 및 동작에 의해 장치가 잠기면, 화면 왼쪽 사이드바의 장치 이름 아래에 장치 잠금 상태가 표시됩니다. 장치를 선택하면 화면 오른쪽 미리보기 패널 상단에도 같은 배너가 나타납니다.

  • 장치가 잠금 상태일 때만 팝업 메뉴에 장치 잠금 해제가 표시됩니다. 잠금 상태를 해제하려면 잠긴 장치를 선택하고 팝업 메뉴에서 장치 잠금 해제를 클릭하세요.

  • 잠긴 장치를 선택하면 화면 오른쪽 미리보기 패널 상단에 나타나는 배너에서 장치 잠금 해제 버튼을 클릭하세요.

알아두기

장치 잠금 해제 기능은 전체 관리자 또는 모니터링 관리자 권한이 있는 사용자에게만 표시됩니다.

인증 실패 잠금 해제​

인증 실패 잠금 옵션에서 설정한 횟수 이상 인증에 실패하면 장치가 잠금 상태로 전환됩니다. 장치가 잠금 상태이면 화면 왼쪽 사이드바의 장치 이름 아래에 인증 실패 잠금 상태가 표시되고, 장치를 선택하면 화면 오른쪽 미리보기 패널 상단에도 같은 배너가 나타나며 이벤트 발생 시각과 장치 정보를 확인할 수 있습니다.

장치가 인증 실패 잠금 상태일 때만 팝업 메뉴에 인증 실패 잠금 해제가 표시됩니다. 잠긴 장치를 선택하고 팝업 메뉴에서 인증 실패 잠금 해제를 클릭하세요.

알아두기

  • 인증 실패 잠금 해제 메뉴는 전체 관리자 또는 모니터링 관리자 권한이 있는 사용자에게만 표시됩니다.

  • 설정한 잠금 시간(1차 잠금 시간/2차 잠금 시간)이 지나면 장치가 자동으로 잠금을 해제합니다. 이때는 별도 조치 없이도 잠금 상태가 해소됩니다. 잠금 조건 및 잠금 시간 설정에 대한 자세한 내용은 인증 설정하기를 참고하세요.

작업 중지​

장치에서 실행 중인 알람 기반, 트리거 기반 동작을 모두 중지하려면 팝업 메뉴에서 작업 중지를 클릭하세요. 화면 상단에 작업 중지 성공 메시지가 나타납니다.

장치 상세 보기​

장치의 상세 정보를 확인하려면, 팝업 메뉴에서 상세 보기를 클릭하세요. 또는 장치를 더블 클릭하세요. 화면 오른쪽에 장치의 상세 정보가 나타납니다.

  • 장치 제어: 장치 작업 중지 또는 재시작, 재연결 등의 제어 기능을 실행할 수 있습니다.

  • 장치 상세 정보: 장치의 ID 및 그룹, 모델명, 기동 시간, IP 주소 등의 정보를 확인할 수 있습니다.

  • 최근 이벤트: 선택한 장치에서 발생한 최근 이벤트 목록을 확인할 수 있습니다.

여러 장치 한 번에 제어하기​

여러 장치를 한 번에 선택해서 재연결, 재시작, 잠금 해제 등의 명령을 한 번에 실행하는 방법을 안내합니다. 화면 왼쪽 사이드바의 장치 탭에서 장치를 두 개 이상 선택하면 화면 오른쪽에 일괄 제어 패널이 나타납니다.

알아두기

카메라는 일괄 제어 대상이 아닙니다. 카메라 제어 방법은 #controlCamera를 참고하세요.

여러 장치 선택하기​

화면 왼쪽 사이드바의 장치 탭에서 장치를 선택하는 방법은 다음과 같습니다.

  • Ctrl + 클릭: 클릭한 장치를 선택 목록에 추가하거나 제외합니다. 나머지 선택은 그대로 유지됩니다.

  • Shift + 클릭: 마지막으로 클릭한 장치부터 지금 클릭한 장치까지 범위를 선택합니다. 장치 그룹은 범위 선택 대상이 아닙니다.

  • 그룹() 클릭: 그룹 이름을 클릭하면 그 아래에 있는 모든 장치가 선택 목록에 추가됩니다. 이미 선택한 장치는 그대로 유지됩니다.

알아두기

  • 하위에 장치가 없는 빈 그룹만 선택하면 화면 오른쪽 패널이 닫힙니다.

  • 장치를 한 개만 선택하면 장치 상세 정보 패널이 나타나고, 두 개 이상 선택하면 일괄 제어 패널로 전환됩니다.

일괄 제어 패널 구성​

  • 장치 잠금 해제, 인증 실패 잠금 해제: 선택한 장치 중 각각 잠금·인증 실패 잠금 상태인 장치가 있을 때 활성화되며, 버튼 옆에 대상 장치 수가 함께 표시됩니다.

  • 작업 중지, 재연결, 재시작: 대상 장치 수를 표시하지 않고, 선택한 장치 중 해당 제어를 지원하는 장치가 있으면 활성화됩니다.

  • 장치 제어: 장치 잠금 해제, 인증 실패 잠금 해제, 작업 중지, 재연결, 재시작 기능 실행 버튼을 사용할 수 있습니다.

  • 구분 경계선: 장치 제어 영역과 선택된 항목 사이의 경계선을 위아래로 드래그하면 두 영역의 높이 배분을 조절할 수 있습니다.

  • 선택된 항목: 선택한 장치의 연결 상태 및 이름, 이상 상태를 확인할 수 있습니다. 이상 상태 종류는 #attention-criteria을 참고하세요.

각 버튼을 클릭하면 확인 창이 나타납니다. 확인 창에서 취소를 클릭하면 선택한 기능을 실행하지 않고, 선택한 기능이 표시된 버튼을 클릭하면 선택한 장치 전체로 해당 기능을 실행합니다.

알아두기

선택한 장치 유형이 섞여 있으면 각 장치가 지원하는 제어를 합쳐서 표시합니다. 선택한 장치 중 어느 장치도 지원하지 않는 제어는 버튼이 나타나지 않으며, 지원하는 제어가 하나도 없으면 안내 문구와 선택 장치 목록 표만 표시됩니다.

실행 결과 확인하기​

  • 선택한 모든 장치가 성공하면 성공 메시지만 표시됩니다.

  • 한 개의 장치라도 실패하면 실패 메시지와 함께 상세 보기 버튼이 표시됩니다.

    상세 보기를 클릭하면 성공, 실패, 대상 아님 세 그룹으로 구분된 결과를 확인할 수 있습니다. 실패한 항목의 이름과 사유를 클립보드에 복사하려면 실패 내역 복사 버튼을 클릭하세요.

알아두기

  • 재연결 버튼은 예외입니다. 요청이 접수되면 항상 성공 메시지만 표시되며, 실패 여부나 상세 결과 창은 제공되지 않습니다. 실제 연결 성공 여부는 상태 트리에서 확인하세요.

  • 장치 잠금 해제와 인증 실패 잠금 해제는 각각 별도로 처리되어 결과 창도 따로 표시됩니다.

카메라 제어​

화면 왼쪽 사이드바의 카메라 목록에서 원하는 카메라를 선택하고 마우스 오른쪽 버튼을 클릭하세요. 팝업 메뉴에서 원하는 기능을 선택할 수 있습니다.

카메라 영상 재생​

비디오 타일에 카메라 영상을 배치하고 실시간으로 모니터링하려면, 팝업 메뉴에서 비디오 열기를 클릭하세요.

비디오 타일에 카메라 영상을 추가하는 방법은 아래와 같은 방식도 지원합니다.

  • 화면 왼쪽 사이드바의 카메라 목록에서 영상을 재생할 카메라를 더블 클릭하세요.

  • 카메라를 비디오 타일 영역으로 드래그 앤 드롭 방식으로 영상을 추가할 수도 있습니다.

알아두기

  • 비디오 타일에는 화면 왼쪽 상단부터 차례로 추가되며, 현재 화면에 추가할 공간이 없으면 에러 메시지가 표시됩니다.

  • 영상 제어 방법 및 영상에 표시되는 도구에 대한 자세한 내용은 비디오 모니터링하기를 참고하세요.

  • 모든 카메라 그룹 목록에서 카메라가 보이지 않는다면 카메라 그룹 권한을 확인하세요. 커스텀 권한의 관리자가 카메라 그룹 권한을 설정하지 않았다면 카메라가 보이지 않을 수 있습니다. 카메라 그룹 권한 설정에 대한 자세한 내용은 카메라 설정하기를 참고하세요.

카메라 상세 보기​

카메라의 상세 정보를 확인하려면, 팝업 메뉴에서 상세 보기를 클릭하세요. 카메라의 그룹, 설명, 아이디와 IP 주소를 확인할 수 있습니다.
