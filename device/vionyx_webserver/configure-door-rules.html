출입문 규칙 설정하기

출입문 규칙을 사용하면 출입문에서 발생한 출입 판단 결과에 따라 오디오 재생, 웹훅 전송, 릴레이 동작을 자동 실행할 수 있습니다. 출입이 허용되면 출입문은 출입문 설정에 따라 자동으로 열리므로, 출입문 규칙에서는 문을 여는 것 외에 필요한 추가 동작을 설정합니다.

아래와 같은 상황에서 출입문 규칙을 설정하세요.

  • 출입이 허용되면 환영 음성을, 거부되면 안내 음성을 재생하고 싶을 때

  • 미인가자가 뒤따라 들어오면 비상등이나 경고음을 동작시키고 싶을 때

  • 출입 기록을 외부 출입 통제 시스템이나 관제 서버로 전송하고 싶을 때

시작하기 전에​

출입문 규칙을 설정하기 전에 아래 사항을 확인하세요.

  • 규칙을 적용할 출입문을 먼저 등록하세요. 자세한 내용은 출입문 관리하기를 참고하세요.

  • 오디오를 사용하려면 재생할 오디오 클립을 미리 업로드하세요. 자세한 내용은 오디오 클립 업로드하기를 참고하세요.

  • 웹훅을 사용하려면 수신할 서버의 URL을 미리 준비하세요.

  • 릴레이를 사용하려면 비상등, 경고음 등 동작시킬 장치가 릴레이 포트에 연결되어 있는지 확인하세요. 외부 장치 연결에 대한 자세한 내용은 ViOnyx 설치 가이드를 참고하세요.

출입 판단 결과​

출입문 규칙에서는 다음 출입 판단 결과마다 실행할 동작을 각각 설정할 수 있습니다.

출입 판단 결과발생 조건
출입 허용출입 레벨이 있는 사용자가 출입 시간 안에 식별되어 출입이 허용되었습니다.
미식별로 출입 거부출입 통제 영역에 들어온 사람의 얼굴을 인식하지 못했거나, 등록되지 않은 사람입니다.
액세스 레벨로 출입 거부등록된 사용자로 식별되었지만, 해당 출입문의 출입 레벨이 없거나 출입 시간이 아닙니다.
출입문 모드로 출입 거부 (수동/스케줄 잠금)출입문이 수동 잠금 상태이거나 잠금 일정 시간대여서 출입이 거부되었습니다.
안티 테일게이팅으로 출입 거부검증 영역의 인원이 출입 통제 이벤트의 테일게이팅 옵션 조건을 충족하지 않아 출입이 거부되었습니다.
인증자 통과 (출입문 라인)출입이 허용된 사용자가 이벤트 진입 라인을 지나 실제로 출입했습니다.
거부 후 통과 (보안 이벤트)출입이 거부된 사람이 이벤트 진입 라인을 지나 출입했습니다. 강제 출입이 의심되는 보안 이벤트입니다.

출입문 규칙 추가​

규칙 추가 시작​

  1. 화면 왼쪽 상단의 출입 메뉴를 클릭하세요.

  2. 화면 왼쪽 사이드바에서 출입문 규칙 설정을 클릭하세요.

  3. 화면 오른쪽 상단의 + 추가 버튼을 클릭하세요.

  4. 출입문 규칙 추가 화면이 나타나면 규칙 이름을 입력하고, 조건과 동작을 설정하세요.

규칙 이름 입력​

이름 입력 필드에 규칙 이름을 입력하세요. 필수 항목입니다.

조건 설정​

조건 섹션에서 규칙을 적용할 출입문을 선택하세요.

  • 채널: 채널은 CH 1로 고정되어 있습니다. 피쉬아이 뷰만 지원합니다.

  • 출입문: 규칙을 적용할 출입문을 선택하세요. 필수 항목입니다.

동작 설정​

동작 섹션에는 출입 판단 결과별로 오디오, 웹훅, 릴레이 동작이 표시됩니다. 동작을 실행할 출입 판단 결과에서 원하는 동작의 토글 버튼을 클릭해 활성화한 후 버튼을 클릭하세요. 동작별 설정 팝업이 나타납니다.

최소 1개의 동작을 활성화해야 규칙을 저장할 수 있습니다. 동작별 설정 방법은 아래를 참고하세요.

알아두기

동작별 일정의 시간대가 아니면 출입 판단 결과가 발생해도 해당 동작은 실행되지 않습니다. 일정은 AI&규칙 → 일정에서 관리할 수 있습니다. 자세한 내용은 일정 관리하기를 참고하세요.

오디오 동작 설정​

출입 판단 결과가 발생하면 카메라에서 오디오 클립을 재생합니다.

  • 오디오 클립: 재생할 오디오 클립을 선택하세요. 필수 항목입니다.

  • 반복: 오디오 클립을 반복 재생할 횟수를 선택하세요.

  • 일정: 오디오를 재생할 일정을 선택하세요. 필수 항목이며, 기본값은 항상입니다.

오디오 동작 설정을 저장하려면 적용 버튼을 클릭하세요.

알아두기

오디오 동작을 설정하기 전에 오디오 클립을 미리 준비해야 합니다. 오디오 클립은 시스템 → 오디오 메뉴에서 업로드할 수 있습니다. 자세한 내용은 오디오 클립 업로드하기를 참고하세요.

웹훅 동작 설정​

출입 판단 결과가 발생하면 외부 서버로 웹훅을 전송합니다.

  • 메소드: 웹훅 전송 방식입니다. POST 방식만 지원합니다.

  • URL: 웹훅을 수신할 URL을 입력하세요. 필수 항목입니다.

  • 헤더: 웹훅에 포함할 HTTP 헤더를 설정하세요. 기본으로 Content-Type: application/json 헤더가 추가되어 있습니다. + 추가 버튼을 클릭해 헤더를 추가할 수 있습니다. 같은 헤더 이름은 중복해서 사용할 수 없으며, 시스템에서 예약한 헤더 이름은 사용할 수 없습니다.

  • 바디: 웹훅 본문에 포함할 항목을 설정하세요. 필수 항목입니다. 각 줄의 왼쪽 목록에서 전송할 정보를 선택하고, 가운데 필드에 JSON 키 이름을 입력하세요. 오른쪽 필드에는 이벤트가 발생할 때 실제 값으로 바뀌는 변수가 표시됩니다. + 추가 버튼을 클릭해 사용자 정의 항목을 추가하거나 버튼을 클릭해 삭제할 수 있습니다. 본문 크기는 최대 64KB입니다.

  • 일정: 웹훅을 전송할 일정을 선택하세요. 필수 항목이며, 기본값은 항상입니다.

설정을 저장하려면 적용 버튼을 클릭하세요.

알아두기

  • 헤더와 본문에 입력한 값은 보안을 위해 저장 후 화면에 다시 표시되지 않습니다. 규칙을 수정할 때 저장된 값은 그대로 유지되며, 새로 입력하면 기존 값을 대체합니다.

  • 웹훅 전송 결과는 시스템 로그에서 확인할 수 있습니다. 자세한 내용은 시스템 로그 확인하기를 참고하세요.

릴레이 동작 설정​

출입 판단 결과가 발생하면 선택한 릴레이를 동작시킵니다. 비상등, 경고음, 보조 잠금 장치 등을 연동할 때 사용하세요.

  • 포트: 동작시킬 릴레이 포트를 선택하세요. 필수 항목입니다. 출입문 잠금 장치로 사용 중인 릴레이 포트는 선택할 수 없습니다.

  • 개방 시간: 릴레이를 동작 상태로 유지할 시간을 설정하세요. 슬라이더를 움직이거나 입력 필드에 값을 직접 입력할 수 있습니다. 1초부터 120초까지 설정할 수 있으며, 기본값은 3초입니다.

    • 이벤트 종료까지 유지: 이 옵션을 선택하면 개방 시간과 관계없이 출입 통제 이벤트가 종료될 때까지 릴레이를 동작 상태로 유지합니다.

  • 접점 타입: 릴레이의 접점 타입을 선택하세요. 필수 항목이며, 포트를 선택하면 설정할 수 있습니다.

    • Normal Open (N/O): 평상시 열려 있다가 릴레이가 동작하면 닫히는 접점입니다.

    • Normal Close (N/C): 평상시 닫혀 있다가 릴레이가 동작하면 열리는 접점입니다.

  • 일정: 릴레이를 동작시킬 일정을 선택하세요. 필수 항목이며, 기본값은 항상입니다.

설정을 저장하려면 적용 버튼을 클릭하세요.

주의

접점 타입은 규칙이 아니라 릴레이 포트에 적용되는 설정입니다. 접점 타입을 변경하면 확인 메시지가 나타나며, 확인 버튼을 클릭하면 해당 포트를 사용하는 모든 규칙과 출입문에 즉시 적용됩니다. 포트가 수동 잠금 또는 수동 잠금 해제 상태일 때 변경하면 출력이 반전되어 잠긴 문이 열릴 수 있으니 주의하세요.

규칙 저장​

모든 설정을 완료한 후 화면 오른쪽 상단의 저장 버튼을 클릭하세요. 저장한 규칙은 출입문 규칙 목록에 추가되고 바로 적용됩니다.

알아두기

출입문 규칙은 최대 20개까지 만들 수 있습니다.

출입문 규칙 목록 확인​

출입문 규칙 목록에서 등록된 규칙과 각 규칙의 적용 대상을 확인할 수 있습니다.

  • 특정 출입문 규칙을 찾으려면 검색 필드()에 출입문 규칙 이름을 입력하세요.

  • 한 페이지에 표시할 출입문 규칙 개수를 변경하려면 화면 오른쪽 상단의 행 수 목록()에서 원하는 값을 선택하세요.

  • 정렬 기준을 변경하려면 ID순 정렬()에서 원하는 기준을 선택하세요.

출입문 규칙 목록에 표시되는 항목은 다음과 같습니다.

항목설명
번호규칙 번호입니다.
이름규칙 이름입니다.
출입문규칙을 적용하는 출입문입니다.
이벤트활성화된 동작이 하나 이상 있는 출입 판단 결과입니다. 결과가 여러 개이면 일부만 표시됩니다.
일정규칙에 적용된 일정입니다.
켜짐/꺼짐규칙을 켜거나 끌 수 있습니다.
작업규칙을 수정()하거나 삭제()할 수 있는 기능을 제공합니다.

출입문 규칙 활성화/비활성화​

출입문 규칙 목록에서 켜짐/꺼짐 열의 토글 버튼을 클릭하면 해당 규칙을 활성화하거나 비활성화할 수 있습니다. 비활성화한 규칙은 출입 판단 결과가 발생해도 동작을 실행하지 않습니다. 규칙을 삭제하지 않고 잠시 중단할 때 사용하세요.

출입문 규칙 수정​

  1. 출입문 규칙 목록에서 수정하려는 규칙의 오른쪽에 있는 버튼을 클릭하세요.

  2. 출입문 규칙 편집 화면이 나타나면 조건과 동작을 수정하세요.

  3. 수정한 내용을 저장하려면 화면 오른쪽 상단의 저장 버튼을 클릭하세요.

출입문 규칙 삭제​

출입문 규칙 목록에서 삭제하려는 규칙의 오른쪽에 있는 버튼을 클릭하세요. 확인 메시지가 나타나면 확인 버튼을 클릭하세요. 삭제한 규칙은 복구할 수 없습니다.
