## 공장 초기화 {/* #factory-reset */}

장치에 저장된 모든 정보와 루트 인증서를 삭제하고 설정을 초기화합니다.

### 장치에서 초기화하기

1. 전원을 연결하세요.

1. **INIT** 버튼을 빠르게 세 번 누르세요.

   <Include product='corestation_40'><Image src='/img/device/factory-reset-cs40.png' className='none' alone /></Include>

   <Include product='corestation_20'><Image src='/img/device/factory-reset-cs20.png' className='none' alone /></Include>

1. 장치의 **STATUS LED**가 노란색으로 깜박이면 **INIT** 버튼을 길게 누르세요.

<PageBreak />

### CoreStation Setup Manager에서 초기화하기

1. 이더넷 케이블을 이용해 제품을 PC에 연결하세요.

1. 웹 브라우저의 주소 입력 필드에 `https://169.254.0.1:3001`을 입력하여 CoreStation Setup Manager에 접속하세요.

   :::info

   크롬 75 버전 이상인 웹 브라우저를 사용하세요.

   :::

1. **CONFIGURE**를 클릭하세요.

1. **Information** 항목에서 **Factory Default**를 클릭하세요.

:::info

* 장치에 저장된 루트 인증서가 존재하지 않을 경우 공장 초기화를 진행할 수 없습니다.

* CoreStation Setup Manager에 접속해 제품의 네트워크 설정을 관리하거나 슬레이브 장치, 입력 및 출력 포트, Wiegand 포트의 연결 상태를 확인할 수 있습니다.

<Include product='corestation_20'>

* CoreStation Setup Manager는 제품의 펌웨어 1.0.0 버전 이상에서 지원됩니다.

</Include>

<Include product='corestation_40'>

* CoreStation Setup Manager는 제품의 펌웨어 1.3.1 버전 이상에서 지원됩니다. 1.3.1보다 낮은 버전의 펌웨어를 사용할 경우 BioStar X에 접속하여 펌웨어를 최신 버전으로 업그레이드하세요.

</Include>

* CoreStation Setup Manager에 대한 자세한 내용은 <Linkto to='device/corestation_setup_manager'>CoreStation Setup Manager</Linkto>를 참고하세요.

* BioStar X 최신 버전은 제품이 네트워크에 연결되어 재설정이 가능할 때 확인할 수 있습니다.

* 더 자세한 내용은 슈프리마 기술 지원팀(CS@suprema.co.kr)에 문의하세요.
