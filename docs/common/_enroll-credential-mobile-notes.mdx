* <Cmd sid='common.info' product='2' /> 섹션의 <Cmd sid='common.photo' product='2' />, <Cmd sid='common.department' product='2' />, <Cmd sid='team.user.detail.title' product='2' /> 옵션을 활성화했다면, 해당 정보를 사용자의 모바일 출입 카드에 표시할 수 있습니다. 이때 표시하는 항목은 사용자 정보에 입력된 내용을 기준으로 합니다. 사용자 기본 정보 입력에 대한 자세한 내용은 <DocLink docId='platform/biostar_x/add-user-basic-info' />를 참고하세요.

* 사용자 이름에 모바일 액세스 카드와 호환되지 않는 특수 문자가 포함된 경우 발급이 제한됩니다. `@` `-` `_` `+` `[` `]` `,` `.` 만 사용할 수 있습니다.

* 사용자 이름에 홑따옴표(`'`)가 포함되어 있다면, 사용자 저장 시 홑따옴표가 제거된 값이 모바일 출입 카드 발급 시스템으로 전송된다는 안내가 표시됩니다. 이 안내가 표시되는 시점에는 카드 레코드가 이미 생성된 상태이므로, 안내를 취소하면 에어팝 포털로의 전송만 중단되어 해당 카드는 사용할 수 없는 상태로 남습니다. 이 경우 시스템은 사용할 수 없는 카드를 사용자와 연결하지 않고, 나머지 사용자 정보만 저장합니다.
