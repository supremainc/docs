:::note

**사용자 ID 및 이름 입력 규칙**

* <Cmd sid='team.user.table.id' />의 값으로 띄어쓰기를 포함할 수 없습니다.

* <Cmd sid='team.user.table.id' />에는 마침표(`.`)를 포함할 수 있으나, 마침표 하나(`.`) 또는 마침표 두 개(`..`)만으로는 입력할 수 없습니다.

* 사용자 이름은 특수 기호를 포함하여 최대 48자까지 입력할 수 있습니다.

  > 특수 기호: `~` `!` `@` `#` `$` `%` `^` `&` `(` `)` `-` `_` `=` `+` `[` `]` `{` `}` `;` `.` `'`

* 사용자 이름에는 다음 문자를 사용할 수 없습니다: `₩` `/` `:` `*` `?` `"` `<` `>` `|` `` ` ``

* `&`, `@`, `~` 문자로 시작하는 사용자 이름은 입력할 수 없습니다.

:::
