## 네트워크 설정 초기화 {/* #reset-network-settings */}

장치의 네트워크 설정을 초기화합니다.

1. 전원을 연결하세요.

1. **INIT** 버튼을 3초 이상 길게 누르세요.

   <Include product='corestation_40'><Image src='/img/device/reset-network-settings-cs40.png' className='none' alone /></Include>

   <Include product='corestation_20'><Image src='/img/device/reset-network-settings-cs20.png' className='none' alone /></Include>

1. 네트워크 설정이 아래와 같이 초기화됩니다. 초기화된 네트워크 정보를 이용해 BioStar X에서 장치를 연결하세요.

   * **TCP/IP 주소**: 장치가 DHCP를 사용하도록 설정되어 IP 주소가 자동으로 할당됩니다.
   
      :::info
      
      DHCP 주소 할당에 실패하면 169.254.x.x로 설정됩니다.

      :::

   * **서버 모드**: 장치가 서버로 직접 연결을 요청하지 않도록 설정됩니다.

   * **RS-485**: 기본값으로 설정되며, 전송 속도는 115200 bps로 설정됩니다.

1. 기존 네트워크 설정을 사용하려면 TCP/IP나 RS-485 정보를 변경하세요.
