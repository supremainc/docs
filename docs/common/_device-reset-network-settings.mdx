## 네트워크 설정 초기화 {/* #reset-network-settings */}

장치의 네트워크 설정을 초기화합니다.

1. 장치 전원을 켜세요.

1. 초기화 버튼을 장치가 자동으로 재부팅될 때까지 길게 누르세요.

1. 네트워크 설정이 다음과 같이 초기화됩니다. 초기화된 네트워크 정보를 참고하여 BioStar X에서 장치를 연결하세요.

   * **TCP/IP 주소**: DHCP를 사용하도록 설정되어 IP 주소가 자동으로 할당됩니다.
   
      :::info
      
      DHCP 주소 할당에 실패하면 169.254.x.x로 설정됩니다.

      :::

   * **서버 모드**: 장치가 서버에 직접 연결을 요청하지 않도록 설정됩니다.

   * **RS-485**: 기본값으로 설정되며, 통신 속도는 115200 bps로 설정됩니다.

1. 장치 전원을 껐다가 다시 켜고, 네트워크 정보가 올바르게 설정되었는지 확인하세요.
