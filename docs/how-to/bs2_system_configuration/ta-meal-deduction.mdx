# How to configure meal deduction option

You can set meal deduction time from the shift.

<Image src='/img/how-to/mealdeduction_01.png' width='1000' alone />

:::info

You can deduct two meal times from the shift if you check Meal deduction 2. 

:::

If you click the button in Meal deduction, you can choose among the 3 different options for this.

<Image src='/img/how-to/mealdeduction_02.png' width='900' alone />

1. By Punch

   You can track how employees use their entire meal time each day. Employees have to register meal start / meal end event with a T&A device for their meal time and the administrator can see this record through the Time Card or Report in a single glance.

   You can configure this option referring to article [How to Configure a T&A Device](ta-device-settings) - configuring the T&A mode.

1. Auto

   You can set the meal deduction by setting Deduction time and Minimal hours before deduction.

1. Fixed

   You can set the fixed meal deduction by setting Start time and End time.

   :::caution

   Fixed meal deduction is available from BioStar 2.7.0 or higher. 

   :::
