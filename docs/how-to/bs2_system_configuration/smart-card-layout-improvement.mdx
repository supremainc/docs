# Improved Smart Card Layout Settings

* **Affected Version**: BioStar 2.9.4 and above

With the new feature **Custom Smart Card** layout added in BioStar 2 Version 2.9.4, there are a few changes and improvements made throughout the **Smart Card** layout as well.

Smart Card Layout Settings for BioStar 2 Version 2.9.3 and below did not separately show (mark) the required field for Smart Card Layout.

With BioStar 2 Version 2.9.4, the smart card settings layout displays the required (mandatory) field value.

## \[Current\] BioStar 2 Version 2.9.4

<Image src='/img/how-to/improved_smart_card_layout_settings_3.png' width='1000' alone />

Display the mandatory (required) field with red markings in the front, as shown in the image above for the Smart Card layout with MIFARE and iCLASS type of card needed: Name of the smart card, Start Block Index, Template Count, and Template size.

<Image src='/img/how-to/improved_smart_card_layout_settings_4.png' width='1000' alone />

When the DESFire Advanced card is Enabled, File Read Access Key, File Read Access Key Index, App ID, File ID, Encryption Type, Template Count, and Template Size are the mandatory (required) fields.

:::info

When the File Read Access Key Index value and File Write Access Key Index are the same, the File Write Access Key data field will be greyed out and display a message stating, **Same as the file read access key**.

<Image src='/img/how-to/improved_smart_card_layout_settings_5.png' width='1000' alone />

:::

<Image src='/img/how-to/improved_smart_card_layout_settings_6.png' width='1000' alone />

For iCLASS Seos smart card layout, ADF Address Value, Template Count, and Template Size are mandatory (required) values.
