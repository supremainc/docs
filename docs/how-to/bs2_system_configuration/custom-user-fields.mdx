# How to Create Custom User Fields

Custom user fields can be used when you need additional fields for user information other than the basic user information provided.

:::warning

* This feature is available in BioStar 2 versions 2.2.1 and above.

* You *cannot* search users via custom user field values on the search bar.

   <Image src='/img/how-to/2xtraining_custom_user_field_001.png' width='500' alone />

* You *can* import users with custom fields with a `.csv` file.

   <Image src='/img/how-to/2xtraining_custom_user_field_002.png' width='500' alone />

:::

1. Click on **Setting** → **SERVER**.

   <Image src='/img/how-to/2xtraining_custom_user_field_003.png' width='1000' alone />

1. In the **User/Device Management** tab, click **+ Add** on the **Custom User Field**.

   <Image src='/img/how-to/2xtraining_custom_user_field_004.png' width='1000' alone />

   :::info

   There are 3 types of custom user fields you can create:

   * **Text Input Box**: This field allows up to 32 characters.

   * **Number Input Box**: This field allows up to 10 digits.

   * **Combo Box**: You can create up to 20 options for this dropdown box. Separate the combo box items with a semicolon(;).

   <Image src='/img/how-to/2xtraining_custom_user_field_005.png' width='1000' alone />

   :::

1. When you're done adding the custom fields, click **Apply** on the bottom of the page.

1. If you go back to the **USER** menu, you will see the additional fields in all existing users and also when you add a new user.

   <Image src='/img/how-to/2xtraining_custom_user_field_005.png' width='1000' alone />
