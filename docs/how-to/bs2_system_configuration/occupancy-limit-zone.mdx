# How To Configure an Occupancy Limit Zone

**Affect Products & Versions**

* **Device**:

   * FaceStation 2 v1.5.0 or later

   * FaceStaiton F2 v1.1.0 or later

* **BioStar 2**: BioStar v2.8.11 or later

The Occupancy Limit Zone enables an administrator to manage and control the population density of a place to prevent overcrowding and monitor the zone status. You can use this feature to manage the indoor space to avoid overcrowding for COVID-19 policies. Suprema's Occupancy Limit Zone allows only a limited number of people to enter based on the authentication record from the entry/exit device and restricts entry beyond that, enabling monitoring of the occupants in the zone. 

:::caution

* BioStar 2 AC license is required to use the Occupancy Limit Zone feature.

* For further license information, please visit [\[BioStar 2\] Server License Specification](https://support.supremainc.com/en/support/solutions/articles/24000017584).

:::

## How to Configure Occupancy Limit Zone

You can set the Occupancy Limit Zone following the steps below.

1. Go **Zone** and click **Add Zone**.

1. Choose **Occupancy Limit** to create a new zone.

   <Image src='/img/how-to/olzone_1.png' width='1000' alone />

1. Enter a name for the Zone and select devices to configure the Zone.

   Please note that Occupancy Limit Zone only supports FaceStation 2 and FaceStation F2.

   <Image src='/img/how-to/olzone_2.png' width='1000' alone />

   :::info

   Occupancy Limit Zone only supports Global mode.

   :::

   <Image src='/img/how-to/olzone_3.png' width='1000' alone />

1. Enter the number of people that can enter this zone at one time in Limit.

   You can enter numbers from 0 to 10,000.

   * **Limit 0**: people can enter the zone without a limit.

      <Image src='/img/how-to/olzone_4.png' width='1000' alone />

   * **Count Alert**: Set an alert to an administrator or set to save event logs before Count reaches the occupancy limit.

      * You can set up two alerts and should enter numbers smaller than the Limit value. The values of the alerts must be different.
   
      <Image src='/img/how-to/olzone_5.png' width='1000' alone />

   * **Auto Count Reset**: Set the time to automatically initialize Count. The Count will be initialized at the time you set every day.

      <Image src='/img/how-to/olzone_6.png' width='1000' alone />

   * **Network Failure Action**: Set whether to allow users to enter or leave when a network error occurs in the device set in the zone. If you set it to Allow Entry and Exit, it stops entry restrictions when the device loses network connection, so people can enter the zone even if Count in the zone exceeds the occupancy limit.

      <Image src='/img/how-to/olzone_7.png' width='1000' alone />

1. If there are users who should be able to access this zone regardless of the rules, set Bypass Group.

   <Image src='/img/how-to/olzone_8.png' width='1000' alone />
