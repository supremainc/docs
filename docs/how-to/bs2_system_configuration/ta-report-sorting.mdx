# Supports the Sorting for Entire Data in the T&A Report

In the BioStar 2.7.10, it becomes easier to sort the entire T&A report data from T&A report page. Before this feature supported, you could sort the T&A data with some limits. However, from BioStar 2.7.10, when you sort the data, then all data in the T&A report get an effect as well as csv and pdf exported files.

For example, once you click the 'Name' column head and sort all T&A data by user name, then this sorting rule will affect for the second page in the T&A report.
