# How to enroll a new user via Mobile App

1. Go to **USER** and check the current user status and tap **+** on the top.

   <div className='grid-container'>

   <Image src='/img/how-to/enroll_new_user_1.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_2.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_3.jpg' width='700' alone />

   </div>

1. Tap → in the **User ID** row and enter four digit numbers or higher. Only the user ID is a mandatory input data for new user creation. And tap **Name** and enter names, and choose BioStar Operator level according to his or her role. Once you save new user, you can then see the information message to add credentials.

   <div className='grid-container'>

   <Image src='/img/how-to/enroll_new_user_4.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_5.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_6.jpg' width='700' alone />

   </div>

   <div className='grid-container'>
   
   <Image src='/img/how-to/enroll_new_user_7.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_8.jpg' width='700' alone />

   </div>

1. Go to Credential and choose Fingerprint and tap + on the top. You can see the devices connected by TCP/IP. Select a device and enroll fingerprints following to the guide message. You enroll up to 10 fingerprints for one user.

   <div className='grid-container'>
   
   <Image src='/img/how-to/enroll_new_user_9.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_10.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_11.jpg' width='700' alone />

   </div>

1. As the same way, you can enroll a card by reading it on the connected device or assigning cards from the unassigned card list.

   <div className='grid-container'>
   
   <Image src='/img/how-to/enroll_new_user_12.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_13.jpg' width='700' alone />
   
   <Image src='/img/how-to/enroll_new_user_14.jpg' width='700' alone />

   </div>

1. After entering all the data, tap <IcDown/> on the top and check the updated user list.

   <Image src='/img/how-to/enroll_new_user_15.jpg' width='700' alone />

1. If you want to edit the user data, select a user and tap the pencil icon on the top.

   <Image src='/img/how-to/107.png' width='300' alone />

1. If the server is set to use **Automatic User Synchronization**, the updated user data are automatically reflected to all the devices, and the users can use the devices immediately.

   <Image src='/img/how-to/108.png' width='300' alone />
