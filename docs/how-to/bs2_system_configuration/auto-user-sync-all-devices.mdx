# Overview of "All Devices (Including User Update from Device)" - An Automatic User Synchronization Option

BioStar 2 supports Automatic User Synchronization, which ensures that existing and updated user data (added, modified, or deleted) on the BioStar 2 server is synchronized to all connected devices. Four synchronization options are available.

* Not Used

* All Devices

* All Devices (Including user update from device)

* Specific Devices (Only devices belonging to the access group)

This article focuses on the All Devices (Including user update from device) option and provides case studies to illustrate its behavior.

## What is This Function?

When using All Devices (Including User Update from Device), user information (added, modified, or deleted) on the BioStar 2 server is automatically synchronized with all connected Suprema devices. This behavior is identical to the All Devices option.The key difference is that this option also allows new users added directly on a device to be synchronized back to the server.

:::info

**Including User Update from Device** does not synchronize modifications or deletions made on a device to the server. Only newly added users are synchronized from the device to the BioStar 2 server. 

:::
