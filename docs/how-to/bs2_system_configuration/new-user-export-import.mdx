# Support New Export/Import User Information

From BioStar 2.8.10, a new user information export and import functions are supported.

:::warning

* If you upgrade BioStar 2 to 2.8.10 or later versions, the old user information data file export and import method supported by the previous version will NO longer be available.

* You MUST match the device firmware version to use the new user information export/import function.

* Visual face credentials registered via upload image or mobile CANNOT be transferred through user information export/import.

:::
