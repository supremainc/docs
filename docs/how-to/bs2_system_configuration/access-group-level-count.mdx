# The number of access group and access level

Before BioStar 2.7.0, BioStar 2 was limited to 128 Access groups and Access levels.

From BioStar 2.7.0, BioStar 2 can create access groups and access levels infinitely without any restriction.

<Image src='/img/how-to/the_number_of_access_group_and_access_level.png' width='1000' alone />

BioStar 2 allows you to create infinite number of Access group, but this number is limited by the device FW's and the number is different for each FW.

**FW list which can accommodate up to 2048:**

<Image src='/img/how-to/agal.png' width='700' alone />

:::info

Others including Entry devices with firmware version V2.x can accommodate up to 128 access groups 

:::

:::caution

Sync error occurs when the number of Access Groups for the FW exceeds its limit. 

:::
