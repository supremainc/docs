# How to use custom input event name

**From BioStar 2 V2.7.1**, the custom input event name change is supported for easier searching and detecting input events by given names.

It is often used for marking break-glass events and receiving alerts and searching the event by the designated event name.

<Image src='/img/how-to/break_glass_event.jpg' width='800' alone />

## How to set?

1. Go to the Advanced device setting page, and set **Trigger & Action**.

1. Choose **Input(Event Name Change)** and enter trigger settings and choose **Input(Event Name Change)**.

   <Image src='/img/how-to/event_name1.jpg' width='1000' alone />

1. Choose **None** for action when it does not need to output relay signals.

   <Image src='/img/how-to/none_action.jpg' width='1000' alone />

1. Check the monitoring tab to see events and alerts with the custom event names.
