# How to Activate Biostar 2 License

## Before Activating Biostar 2 License

1. What is supported with BioStar 2's licenses?

   Refer to the [FAQ article](https://support.supremainc.com/en/support/solutions/articles/24000017584--biostar-2-server-license-specification) for details.

1. What are global zone and local zone?

   * Global Zone: TCP/IP based zone configuration (BioStar 2 server is a master of the zone)

   * Local Zone: RS485 based zone configuration (Master device is a master of the zone)

   * The zone master makes logical decisions and controls functionality

   <Image src='/img/how-to/58.png' width='1000' alone />

## How to Activate License for Biostar 2 Version 2.9.0 and Above

1. Open BioStar 2 → Log in to BioStar 2 → Go to **Settings** Menu.

   <Image src='/img/how-to/license_ui_change_menu.png' width='900' alone />

1. Check if the server is connected to the Internet. If connected, you can activate via online.

1. Enter the customer site name and activation key and click **Activate**. You can receive activation key from Suprema or your local distributor.

   <Image src='/img/how-to/60.png' width='800' alone />

1. If the server is not connected to the Internet, click **Request offline Key** and download offline key request file.

   <Image src='/img/how-to/61.png' width='500' alone />

1. Send the offline key request file to Suprema and receive the offline license key in return.

1. Activate the license and check the information about compatible FW versions to use the updated new features.

   <Image src='/img/how-to/62.png' width='600' alone />

1. Activated license status can be checked from the Server setting and **About**.

   <Image src='/img/how-to/check_if_license_has_been_applied_properly_about.png' width='1000' alone />
