# How To Set Up Self-Registration Page

From BioStar v2.7.7, BioStar2 supports Visitor Management.

* Required License: Visitor License of BioStar2

* [\[BioStar 2\] BioStar 2.7.7 New Features and Configuration Guide](https://support.supremainc.com/en/support/solutions/articles/24000044461--biostar-2-biostar-2-7-7-new-features-and-configuration-guide)

Once you register a self-registration PC referring to the article [How To Configure Self-Registration Page of Visitor Management](https://support.supremainc.com/en/support/solutions/articles/24000047141--biostar-2-how-to-configure-self-registration-page-of-visitor-management) you can have the below page.

Page Path: `https://ServerPC_IPaddress:ServerPort/#/register_welcome`
