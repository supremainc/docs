# How to calculate exact worktime/breaktime for devices without T&A key?

:::note

**This guide is for devices WITHOUT function keys only**

This configuration method applies to devices like **XPass 2**, **BioEntry W2**, **BioEntry W3** that do NOT have touchscreen or keypad for T&A key selection.

For devices WITH function keys (BioStation 3, BioStation 2a, X-Station 2, FaceStation F2, BioLite N2, FaceStation 2), please refer to: [How to Configure a T&A Device](ta-device-settings)

:::

## Overview

For devices **WITH function keys** (touchscreen/keypad such as BioStation 3, BioStation 2a, X-Station 2, FaceStation F2, BioLite N2, FaceStation 2), you can configure multiple T&A codes (Code 1 and Code 2) in a single device as shown in [How to Configure a T&A Device](ta-device-settings). Users select Check In/Out at the device during authentication, and BioStar calculates worktime and breaktime based on their selection.

However, for devices **WITHOUT function keys** (e.g., XPass 2, BioEntry W2, BioEntry W3), this method does not work. These devices cannot display T&A options for users to select, so you cannot assign multiple codes to one device. Instead, each T&A function (Check In, Check Out, Break Start, Break End) must be assigned to a separate physical device or door location.

:::info

**Common Mistake**: Assigning both **Check In** (Code 1) and **Check Out** (Code 2) to a single XPass 2 or BioEntry W2 device will cause incorrect T&A results and missing punch logs. 

:::

Following guideline shows how to configure check in and check out functions for devices without T&A function keys.

## Configuration Steps

:::info

**Key Principle**: Each T&A function (Check In, Check Out, Break Start, Break End) must be assigned to a **SEPARATE physical device** or **separate door location** when using devices without function keys.

:::

1. Prepare two devices. One device for IN and another device for OUT.

1. Go to **Time Attendance** → **Setting** and register two devices as T&A device.

1. Choose **IN** device and set it mode to **Fixed** option with **Break End**.

   <Image src='/img/how-to/fixed_1.png' width='900' alone />
   
1. Choose **OUT** device and set it mode to **Fixed** option with **Break Start**.

   <Image src='/img/how-to/fixed_2.png' width='900' alone /> 

## T&A Calculation Results

BioStar will calculate worktime and breaktime based on the punch without pressing any T&A key. However, the result is always **Missing Break Start, Missing Break End** in BioStar versions before 2.4.

<Image src='/img/how-to/fixed_3.png' width='700' alone />

Starting version 2.4, if you are using **First check-in & Last check-out** with **Break by Punch**, check **Handle Exception of Fixed Break/Meal T&A Key**. This should make your report result to be normal.

## Device Type Quick Reference

| Device Type | Examples | T&A Configuration Method | Notes |
| --- | --- | --- | --- |
| **WITH Function Keys** (Touchscreen/Keypad) | BioStation 3, BioStation 2a, X-Station 2, FaceStation F2, BioLite N2, FaceStation 2 | **Multiple codes in ONE device** (up to 16 codes)<br/>Users select T&A type at device | Can assign multiple T&A punch types (Check In, Check Out, Break Start, Break End, Meal Time Start, Meal Time End) |
| **WITHOUT Function Keys** | XPass 2, BioEntry W2, BioEntry W3 | **One T&A type per device**<br/>Use Fixed mode or By Schedule mode | Cannot assign multiple codes<br/>Each device performs only one T&A function |

:::info

BioStar 2 supports up to 16 T&A codes per device. However, there are 6 different T&A punch log types: Check In, Check Out, Break Start, Break End, Meal Time Start, and Meal Time End.

:::

For devices **WITH function keys**, you can configure multiple codes and assign them to different T&A types. Users will select the appropriate type at the device during authentication.

For devices **WITHOUT function keys**, you can only assign one T&A type per device using Fixed mode (e.g., this device is always **Check In**) or By Schedule mode (e.g., automatically changes between **Check In** during morning hours and **Check Out** during evening hours).

## Frequently Asked Questions

<details className='faqs'>
<summary>**Can I assign both Check In and Check Out to one XPass 2 device?**</summary>

**No**. XPass 2 does not have function keys, so users cannot select between Check In/Out. You must use **separate physical devices** or configure each device with **Fixed mode** for a single T&A function.

</details>

<details className='faqs'>
<summary>**What happens if I configure Code 1 and Code 2 on the same XPass 2 device like the example in "How to Configure a T&A Device"?**</summary>

T&A logs will be recorded incorrectly, causing:

* Wrong worktime calculations

* Missing punch events

* Duplicated entries

* Time spent investigating and correcting T&A results

</details>

<details className='faqs'>
<summary>**I only have one XPass 2 or BioEntry W2 device. What should I do?**</summary>

You have two options:

* Use **By Schedule** mode: The device automatically changes T&A type based on time (suitable for fixed shift workers).

* Install a second device at exit location for Check Out.

</details>

## Troubleshooting

| Problem | Cause | Solution |
| --- | --- | --- |
| T&A results show incorrect Check In/Out times | Both Code 1 and Code 2 assigned to one device without function keys | Reconfigure: Use separate devices with Fixed mode |
| **Missing Break Start/End** messages | Break devices not configured | Configure additional devices for Break Start/End if needed |
| Users cannot select T&A type at device | Device has no function keys (expected behavior) | Use Fixed mode or By Schedule mode |
