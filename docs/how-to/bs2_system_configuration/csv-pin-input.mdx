# Enter and Modify PIN When Using User CSV Import

**Affect Products & Versions**

* **BioStar 2**: 	BioStar v2.8.14 or above

In BioStar 2.8.14, we improved the CSV Import feature to support entering and modifying PIN credentials.

:::warning

Enrolled PIN data CANNOT be exported to a CSV file.

:::

1. Add the 'pin' column to the CSV file to be imported.

   You can use 'PIN', 'pin', or any other column names for this.

   <Image src='/img/how-to/2.8.14-1.png' width='700' alone />

1. Enter the user's PIN on the 'pin' column and save the file.

   <Image src='/img/how-to/2.8.14-2.png' width='900' alone />

1. Import CSV file that added PINs into BioStar 2.

   'pin' column will be on the bottom of the CSV Import column list.
   
   <Image src='/img/how-to/2.8.14-3.png' width='400' alone />
