# Page navigation and search condition

The page navigation and search condition are improved in BioStar 2.5.0.

## Page Navigation

In BioStar 2.5.0, you can only move to the front and back pages of the current page unlike previous versions. In other word, you cannot go to the first and the last pages directly.

<Image src='/img/how-to/2x_sc_monitoring_1.png' width='1000' alone />

## Search Condition

In BioStar 2.5.0, new function that you can filter the event logs about certain period is introduced to improve the speed of search. Basically, you can set the 1 Day, 3 Days, 1 Week, 1 Month, 3 Months or 6 Months. Furthermore, if you want to search for the event logs regarding a customized period, you should set the Custom Period.
