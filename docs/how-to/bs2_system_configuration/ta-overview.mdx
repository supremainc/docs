# How BioStar 2 T&A works

BioStar 2 T&A helps you manage employee working hours more efficiently using its easy-to-configure and intuitive time-card features. BioStar 2 Overtime Rules feature makes it easier for administrators to calculate and configure overtime as well as other time rules.

:::info

The term **Pay Code** has been changed to **Time Code**. 

:::
