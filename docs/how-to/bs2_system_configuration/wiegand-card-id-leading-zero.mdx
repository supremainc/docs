# Fixed Constraint That Wiegand Card ID Cannot Start with 0

**Affect Products & Versions**

* **BioStar 2**: 	BioStar v2.8.16 or above

In BioStar 1, customers could register Wiegand cards with Facility Code 0. However, these Wiegand cards could not be registered in the previous versions of BioStar 2. Suprema has improved the function to register Wiegand cards with Facility Code 0 starting from BioStar 2.8.16 for the convenience of customers.
