# BioStar 2 T&A Case Study

:::note

**Practice Time Attendance Case Study Shift Example: Company A**

* Day Start time: 06:00

* Fixed Worktime: 08:00 to 17:00

* Breaktime: Employees are to punch IN/OUT to record their break time

* Max Break Time: 60 minutes

* First Check In & Last Check-Out: Disabled

* Grace 5mins for Both in and out

* Meal Deduction 1: By Punch

* Break Time By Punch

* Schedule Type: Weekly

* Weekend Days: Sun, Mon
