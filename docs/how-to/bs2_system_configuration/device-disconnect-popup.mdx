# How to configure an alert pop-up message when a device is disconnected

From BioStar 2 Version 2.5.0, user can configure an alert message for the device disconnection detected. When a device is disconnected, the alert message will be shown as a pop-up message on the screen of BioStar 2.

Go to **Setting** → **ALERT**.

<Image src='/img/how-to/2x_sc_alert_1.png' width='900' alone />

Check the box named **Device Disconnection Detected** and then click **Apply** button.

<Image src='/img/how-to/device_disconnection_detected_alert_setting.jpg' width='1000' alone />

At this stage, you can edit/ customize the alert message by clicking note/ document shaped icon and enter **Name** and **Message**.

<Image src='/img/how-to/2x_sc_alert_3.png' width='1000' alone />

When the device gets disconnected, the alert message will be displayed below.

<Image src='/img/how-to/2x_sc_alert_4.png' width='1000' alone />
