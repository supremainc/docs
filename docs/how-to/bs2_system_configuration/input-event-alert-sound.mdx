# Input (Event Name Change) triggers Alert Sound action

The custom-named input has been added but, this triggers only **Output** and **None** until BioStar 2.7.10.

From BioStar 2.7.11, you may choose the **Alert Sound** action in addition.

Please find the added action **Alert Sound** in **Device** → **Advanced** → **Trigger & Action**.
