# Available to login with ID or Login ID

From BioStar 2.5.0, you can login to BioStar 2 via one of the options below.

* ID

* Login ID

For example, a user named Sharon can log in to BioStar 2 via one of the two options marked by red boxes.

:::info

User can't login with his/her email information.

:::
