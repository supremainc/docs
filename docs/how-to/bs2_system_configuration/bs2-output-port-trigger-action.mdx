# Improved Trigger & Actions to Be Able to Use the Output Port of the BioStation 2

As you know, BioStation 2 is the only Suprema device that has a separate TTL Output port. In order to support various installation environments of customers, Suprema improved its function to configure Trigger & Action through the TTL Output port of BioStation 2.

Before using this feature, you should **match both BioStar 2 software and BioStation 2 firmware version** as follows.

:::note

* **BioStar 2 SW**: v2.8.3 or above

* **BioStation 2 Firmware**: v1.9.0 or above

:::

1. Configure at Device Trigger & Action.

   **BioStar 2** → **Device** → BioStation 2 → **Advanced** → **Trigger & Action**

   <Image src='/img/how-to/2.8.3_2_1_.png' width='1000' alone />

1. Configure at BioStar 2 Global Trigger & Action.

   **BioStar 2** → **Settings** → **Trigger & Action**

   <Image src='/img/how-to/2.8.3_2_2_.png' width='1000' alone />

1. Configure at BioStar 2 Door Alarm.

   **BioStar 2** → **Door** → **Alarm**

   <Image src='/img/how-to/2.8.3_2_3_.png' width='1000' alone />

1. Configure at BioStar 2 Zone Alarm.

   **BioStar 2** → **Zone** → **Alarm**

   <Image src='/img/how-to/2.8.3_2_4_.png' width='1000' alone />
