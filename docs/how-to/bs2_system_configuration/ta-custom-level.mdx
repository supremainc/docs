# Improved the Custom Level for T&A Management

Before the BioStar 2.7.10, there were some limitation for the T&A custom admin user. For example, T&A custom admin user could not see the T&A rules and schedules which the admin user created. So T&A custom admin user could not check all T&A rules and schedules and could not understand the current operation correctly. Additionally, the T&A custom operator could not see and edit the rules and schedules which the higher authorized users, such as administrator and T&A operator, created.

From BioStar 2.7.10, the T&A custom admin user can check **Time Code**, **Shift**, **Schedule Template**, **Rule** and **Schedule** no matter which authority the user has. Also, depends on the user's authority, the user can edit or read the items.

## Change of the T&A custom admin user who has T&A read right

* The custom admin user can check **Time Code**, **Shift**, **Schedule Template**, **Rule** and **Schedule** no matter which authority the user has.

   <Image src='/img/how-to/v9_8.png' width='800' alone />

   :::caution

   * If the custom admin user has only a specific User Group (or Device Group and etc), the user can check about the dedicated group data.

   * As the below images, the custom admin user can check the users in the 'User Group A' in the Schedule.

   :::

   <Image src='/img/how-to/v9_9.png' width='1000' alone />

   <Image src='/img/how-to/v9_10.png' width='1000' alone />

   <Image src='/img/how-to/v9_11.png' width='1000' alone />

* The custom admin user can manage **Report Type**, **User Group**, and **Users** in the main Report Search Condition.

   <Image src='/img/how-to/v9_12.png' width='1000' alone />

* The custom admin user cannot save the filter or modify the columns.

   <Image src='/img/how-to/v9_13.png' width='1000' alone />

* The custom admin user can update T&A report with configured period by the same user.

* The custom admin user can see T&A device lists which the user has the authority to check.

* When the custom admin user clicks the T&A device from the registered list, the user can check T&A configuration on the device.

   <Image src='/img/how-to/v9_14.png' width='1000' alone />

* The custom admin user can check the **Sender Information** from the T&A setting page but cannot edit.

   <Image src='/img/how-to/v9_15.png' width='1000' alone />
