# BioStar 2 user ID can be mapped to several different fields in Active Directory

When user name of AD is set as a fixed value for the User ID it causes difficulties for users to integrate with another third-party system. Up to BioStar 2.7.8, the User ID could not be changed to another field.

**From BioStar 2.7.10, User ID field can be changed/set to map to other values.**
