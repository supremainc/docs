# Fingerprint Enrollment on the Slave device

From BioStar 2.5.0, you can enroll fingerprints via slave devices. This means you can choose to use a slave device for scanning fingerprints.

## Example:

* BioStation A2 (id: 541531003): Master Device

* BioStation L2 (id: 540084005): Slave Device

Master device is connected with Slave device via RS-485.

<Image src='/img/how-to/2x_sc_slave_device_1.png' width='1000' alone />

You can successfully scan fingerprints via slave devices just by selecting a slave device on the window below.

<Image src='/img/how-to/2x_sc_slave_device_2.png' width='500' alone />

:::info

This feature is not supported in BioLite Net.

:::
