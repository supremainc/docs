# 14 Subjects of CoreStation FAQ

## 1. CoreStation Network Reset and Factory Default

<details className='faqs'>
<summary>**How to reset CoreStation network?**</summary>

Push init button on CoreStation more than 3 seconds.

:::info

For more details, please refer to the link below.

[Network and Factory Default W2, P2, CoreStation](https://support.supremainc.com/en/support/solutions/articles/24000014900)

:::

</details>

<details className='faqs'>
<summary>**How to do factory default setting of CoreStation?**</summary>

1. Factory default setting by BioStar2

   * Connect CoreStation with BioStar2

   * Go to **Server** and set **Secure Communication with Device** as **USE** and click **Apply**

   * Wait until CoreStation connects to Server

   * Push init button on CoreStation 4 times straight

1. Factory default setting by CoreStation SETUP Manager

   * Connect CoreStation with PC

   * Access web browser at `https://169.254.0.1:3001`

   * Log in CoreStation SETUP Manager

   * Click 'Factory Default' button on configuration page 

:::info

For more details, please refer to the link below.

[How to configure CoreStation IP configuration via SETUP Manager](https://support.supremainc.com/en/support/solutions/articles/24000051368--corestation-how-to-configure-corestation-ip-configuration-via-setup-manager) 

:::

</details>

## 3. The number of door controlled by CoreStation

<details className='faqs'>
<summary>**How many doors does a CoreStation support? **</summary>

CoreStation has built-in 4 relays which are to control 4 doors. By adding slave device via RS485, it can control up to 52 doors and via Wiegand, control up to 132 doors.

</details>

<details className='faqs'>
<summary>**How many RS485 (OSDP) devices can be connected to CoreStation?**</summary>

64ch. Each port supports up to 31 slave devices with daisy chain.

</details>

<details className='faqs'>
<summary>**How many Wiegand devices can be connected to CoreStation?**</summary>

132ch. CoreStation has 4 Wiegand ports and 64ea DM-20 which has 2 Wiegand ports can connect to CoreStation by RS485.

</details>

<details className='faqs'>
<summary>**How many doors can DM-20 support?**</summary>

DM-20 has 4 relays which support 4 doors with RS485 devices.

:::info

For more details, please refer to the link below.

[Maximum Slave Devices with CoreStation](https://support.supremainc.com/en/support/solutions/articles/24000024806)

[CoreStation 2 Sample Door Configuration](https://support.supremainc.com/en/support/solutions/articles/24000020224--biostar-2-corestation-2-sample-door-configuration) 

:::

</details>

## 4. How to use 3rd party reader with CoreStation

<details className='faqs'>
<summary>**Can we use 3rd party card reader with CoreStation?**</summary>

Yes, All standard card readers that support Wiegand output can work with CoreStation.

</details>

<details className='faqs'>
<summary>**Can we use 3rd party keypad reader with CoreStation?**</summary>

No, CoreStation doesn't support the single key output from Wiegand signal so it cannot use with 3rd party keypad reader.

</details>

<details className='faqs'>
<summary>**Can we use 3rd party fingerprint reader with CoreStation?**</summary>

Yes, 3rd party fingerprint reader can connect with CoreStation by Wiegand. CoreStation has a matcher that supports Suprema template. You can either use Suprema fingerprint slave reader BER2 or Suprema intelligent fingerprint reader by RS485 (OSDP) connection.

:::info

For more details, please refer to the link below.

[OSDP Protocol Support](https://support.supremainc.com/en/support/solutions/articles/24000016700--biostar-2-osdp-protocol-support) 

:::

</details>

## 5. How to use XPD2 or BER2 with 3rd party controller

## 6. How to replace a 3rd party controller and Wiegand reader with CoreStation, XPD2 and/or BER2

<details className='faqs'>
<summary>**Can we connect Wiegand cable with RS485 cable of XPD2 and BER2?**</summary>

Yes, Check Wiegand cable at the site is shielded twisted 2 pair cable. If it is, you can connect Wiegand 3 core cable with RS485 cable (TRX+,TRX-,GND) of XPD2 and/or BER2.

</details>

<details className='faqs'>

## 10. Power

<details className='faqs'>
<summary>**What is the specification of Power AUX IN of CoreStation?**</summary>

12V DC, 3A

</details>

<details className='faqs'>
<summary>**What is the power output of CoreStation?**</summary>

12V, up to 1.5A. Slave device or Wiegand device or lock etc. can be powered within 1.5A. In case of exceeding 1.5A, you need separate power supply.

</details>

## 11. Installation

<details className='faqs'>
<summary>**How to connect slave device with CoreStation by RS485?**</summary>

Use an AWG24 twisted pair with a maximum length of 1.2km for RS485 cable which has 120 ohm impedance. It is mandatory to wire in parallel format.

:::info

For more details, please refer to the link below.

[Daisy Chain and RS485 Connection](https://support.supremainc.com/en/support/solutions/articles/24000017277--both-biostar-daisy-chain-and-rs485-connection) 

:::

</details>

## 13. Offline function

<details className='faqs'>
<summary>**When the host computer to go offline, can CoreStation work?**</summary>

Yes, It works in local zone mode. CoreStation has capacity of storing 5,000,000 logs. When the network is back, it will upload all the logs to the host. However, it is not supported in global zone mode.

</details>

<details className='faqs'>
<summary>**When slave device is cut from CoreStation, can the slave work?**</summary>

No, it's not supported.

</details>

<details className='faqs'>
<summary>**Can we connect CoreStation to another CoreStation by RS485 for back-up?**</summary>

No, it's not supported.

</details>
