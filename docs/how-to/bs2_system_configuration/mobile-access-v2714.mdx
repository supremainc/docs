# Enhancement in Suprema Mobile Access Usage in 2.7.14

## Overview

In the former BioStar 2, there were various limitations when registering device through Mobile Credential application and use.

For example, if the user currently had devices in the running BioStar 2 server and wanted to use Suprema Mobile Access, then user had to reset the device, remove it from BioStar 2 server, and re-configure all settings back after they setup Mobile Credential settings. So Suprema improved the Mobile Credential feature for user convenience in BioStar 2.7.14 and renamed it Mobile Access.

:::info

The name of Suprema Mobile Credential has been changed to Suprema Mobile Access. Both, Suprema Mobile Credential and Suprema Mobile Access are the name of the service. Since 27-April-2020, SUPREMA has updated the name of the mobile app to **Airfob Pass** and updated the name of the portal from Mobile Credential Portal to **Airfob Portal**.

:::

This article indicates the updated feature of Suprema Mobile Credential in BioStar v2.7.14.

To get a concept and operation of Suprema Mobile Access (Credential), please go to the article below and review it. [Overview of Suprema Mobile Access's Features](https://support.supremainc.com/en/support/solutions/articles/24000055757-overview-of-suprema-mobile-access-s-features)

New features for Suprema Mobile Access (Credential) updated in BioStar v2.7.14 are:

## Merged Mobile Credential's Advanced part into General items , and renamed the menu to Mobile Access

Updated Part: **BioStar 2** → **Settings** → **Mobile Access**

In BioStar 2.7.14, we merged Domain, Port, and Site ID into **General** items.

## Change of Mobile Access Usage

1. When you enable 'Use' the Mobile Credential Access, 'Site ID', 'Password', and 'Email' are required values.

   <Image src='/img/how-to/mobile_access_main_page.jpg' width='1000' alone />

   * Email, Password: the data of the user who signed in the portal. `https://mc.suprema.io`

      <Image src='/img/how-to/mobile_access_site_id_info.jpg' width='1000' alone />

   * Site ID: the site ID which user created through the portal. `https://mc.suprema.io`

      <Image src='/img/how-to/how_to_find_site_id_in_portal.airfob.png' width='1000' alone />

1. After typing in all values, **Connect** button gets activated.

   <Image src='/img/how-to/mobile_access_site_id_info.jpg' width='1000' alone />

1. When you click the **Connect** button, then BioStar2 will synchronize the information to the **Airfob Portal** and check if the information is valid.

   Airfob Portal is a new name of Suprema Mobile Credential Portal.

   If the information is correct with **Airfob Portal**, then the below popup will show up.

   * Connected. Please register devices before using mobile access.

      <Image src='/img/how-to/mobile_access_connect_succeed_alert.png' width='1000' alone />

   * If the information is mismatched with the **Airfob Portal**, then an error pop-up will appear and decline setting up the connection.

   :::info

   If ONLY **Site ID** is wrong, the connection will be set up but will show up error pop-up window to correct **Site ID**.

   :::

1. You can add new devices in the **Site** through **+ Add** button on the right side.

   <Image src='/img/how-to/add_device_to_mobile_access.png' width='1000' alone />

   Once you click **+ Add** in Device Registration, devices in Device Menu of BioStar2 will be shown. From BioStar v2.7.14, the upgraded hardware of XPass D2 is available to use for Suprema Mobile Access. Follow this article for → [Supported Devices List of Mobile Access](https://support.supremainc.com/en/support/solutions/articles/24000058364--suprema-mobile-access-supported-devices-list-of-mobile-access)

1. If you have registered devices already to the Airfob portal, it will be deployed as blue box at the bottom.

   <Image src='/img/how-to/device_registration_for_mobile_access_done.jpg' width='1000' alone />

   If you click **Sync** button on the right side of the device, the key for connection setup will be overwritten on the device.

   If you click **Delete** button on the most right side of the device, device will be automatically removed from Airfob Portal and key will be deleted from the device at the same time.

1. You can sort devices by **Device ID** and **Device Name**.

1. When you try to set Mobile Credential Set, **Not Use** with registered devices in the list, the pop-up message will come up. 

   * ONLY IF all devices' synchronization keys are deleted properly, then Mobile Access Set will turn to **Not Use**.

   * Otherwise, the **Use** status will be kept and failed devices are left in the list.

   <Image src='/img/how-to/2.7.14-mobile_7.png' width='300' alone />

1. You can check the Mobile Access configuration change from Audit Trail.

   <Image src='/img/how-to/2.7.14-mobile_9.png' width='1000' alone />
