# How To Use Third party QR

**Affect Products & Versions**

* **Device**: X-Station 2 v1.0.1_20210329 or above

* **BioStar 2**: 	BioStar v2.8.11 or above

X-Station 2 QR device can store the data in third-party QR as a user credential if the third-party QR data is based on printable ASCII characters. Maximum up to 32 Characters can be used as the QR/Barcode data in BioStar 2.

In this case, the system administrator of BioStar 2 needs to manually add QR/Barcode data.

In addition, importing the CSV file is available to enroll multiple user QR/Barcode data at once.

## How To Add third party QR/Barcode

1. Manual update

   Please check if the existing QR system generates QR code as printable ASCII. Add a new User → Credential → Select **QR/Barcode** in the QR/Barcode Type list. Click **Apply**.

   <Image src='/img/how-to/3rdpartyqr_1.png' width='1000' alone />

1. User CSV Import

   CSV Import in User menu is available for users to update the existing QR/Barcode data.
