This course is to check and learn each configuration steps to use BioStar 2 system proficiently.

## Objectives

After completing this course, trainees should be able to:

* Know the proper way to configure the system.

* Know the feature specification and their coverage.

* Deploy the system and avoid configuration mistakes and errors.

## Target Audience

First time BioStar 2 users and installers.
