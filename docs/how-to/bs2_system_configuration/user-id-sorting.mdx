# User ID sorting depending on the user ID type setting in the server

## Known Issue

User ID sorting was not working properly based on User ID Setting, particularly in Muster Zone and Access Group Menu, in BioStar 2 Version 2.7.10.

## Resolved

From BioStar 2 Version 2.7.11, User ID got sorted correctly according to server user ID setting, both in the Muster zone and Access group menu.
