# How to synchronize devices with the server

You may have seen your device with a yellow symbol on the device menu once you connected the device to the server.

<Image src='/img/how-to/2x_sysconfig_device_synchronization_001.png' width='600' alone />

This means that the device has different access groups, doors, zone, and user information than the server.

In BioStar 2.5, device synchronization is automatic on device reconnection if you turned automatic user synchronization on.

This means that when a device disconnected from the server, you had to click sync again in previous devices to synchronize the devices with the server but now it is automatically taken care of.

From BioStar 2.7.1, a new device synchronization has been supported.

If you choose 'All Devices (including user update from the device)', you can update some user information when you modify from the device directly.

From BioStar 2.7.11, 'Specific Devices (Only devices belonging to the access group)' has been included.

This is a partial auto user synchronization mode that depends on the access group configuration.

To get more detailed information, please check the linked document. ['Specific Devices (Only Devices Belonging to the Access Group)' Option](specific-devices-option)

## Configuring Automatic User Synchronization

1. Log in to BioStar 2 with an administrator account.

1. Click **Setting**.

1. Click **SERVER**.

   <Image src='/img/how-to/2x_sysconfig_device_synchronization_002.png' width='1000' alone />

1. On **User/Device Management** → **Automatic User Synchronization**.

   <Image src='/img/how-to/usersync_2.7.12.png' width='800' alone />

1. Choose the synchronization mode which you want and click **Apply**.
