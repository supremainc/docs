## 1. Entra ID SSO 연결

**BioStar Air에서**

1. **Admin Portal** → **Settings** → **Site** → **SSO & SCIM**으로 이동하세요.
2. ID 공급자로 **Microsoft Entra ID**를 선택하세요.
3. 자동으로 표시되는 **리다이렉트 URI**를 복사해 두세요.

**Microsoft Entra 관리 센터에서**

1. **Entra ID** → **App registrations** → **New registration**으로 이동하세요.
2. 앱 이름을 "BioStar Air"로 지정하세요.
3. **Accounts in this organizational directory only (Single tenant)**를 선택하세요.
4. Redirect URI 항목에서 **Web**을 선택하고, 복사해 둔 BioStar Air의 Redirect URI를 붙여넣으세요.
5. **Register**를 클릭하세요.
6. 등록된 "BioStar Air" 앱의 Overview 화면에서 다음 값을 복사하세요.
   - Application (client) ID
   - Directory (tenant) ID
7. **Certificates & secrets** → **Client secrets** → **New client secret**으로 이동하세요.
8. 설명을 입력하고 만료 기간을 선택하세요.
9. **Add**를 클릭하세요.
10. 생성된 보안 비밀의 **Value**를 즉시 복사하세요.

:::caution

Secret ID가 아니라 **Value**를 사용해야 합니다. Value는 이 시점 이후에는 다시 표시되지 않으므로 반드시 지금 복사해 두세요.

:::

**BioStar Air에서**

1. 복사해 둔 값을 각각 **클라이언트 ID**, **클라이언트 시크릿**, **테넌트 ID** 필드에 입력하고, **이메일 도메인** 필드에 조직의 이메일 도메인을 입력하세요.
2. **저장 및 검증**을 클릭하세요.

**Microsoft Entra 관리 센터에서**

1. **Enterprise applications** → **BioStar Air** → **Users and groups**로 이동하세요.
2. BioStar Air 관리자로 로그인할 Entra 사용자 또는 그룹을 할당하세요.

## 2. Entra ID SCIM 프로비저닝 연결

**BioStar Air에서**

**SSO & SCIM** → **SCIM 프로비저닝**으로 이동하세요. SCIM 프로비저닝은 위 SSO 설정을 저장하고 검증해야 활성화됩니다.

1. **SCIM 엔드포인트 URL**을 복사해 두세요.
2. 토큰 생성 버튼을 클릭해 SCIM 토큰을 생성하세요.
3. 생성된 토큰을 즉시 복사하세요. 토큰은 이 시점에만 확인할 수 있으므로 반드시 직접 복사해 두세요.

**Microsoft Entra 관리 센터에서**

1. **Entra ID** → **Enterprise applications** → **New application**으로 이동하세요.
2. **Create your own application**을 선택하세요.
3. 이름을 "BioStar Air SCIM"으로 입력하세요.
4. **Integrate any other application you don't find in the gallery (Non-gallery)**를 선택하세요.
5. **Create**를 클릭하세요.
6. 생성된 BioStar Air SCIM 앱에서 **Manage** → **Provisioning**으로 이동하세요.
7. Provisioning Mode를 **Automatic**으로 설정하세요.
8. **Admin Credentials**의 **Tenant URL**에 복사해 둔 SCIM 엔드포인트 URL을, **Secret Token**에 복사해 둔 토큰을 입력하세요.
9. **Test Connection**을 클릭해 정상적으로 연결되는지 확인하세요.
10. **Save**를 클릭하세요.
11. **Users and groups** → **Add user/group**으로 이동해 프로비저닝할 사용자와 보안 그룹을 할당하세요.
12. **Mappings**로 이동해 사용자와 그룹 동기화가 모두 활성화되어 있는지 확인하세요.
13. 속성 매핑을 변경하기 전에 먼저 매핑 내용을 검토하세요.
14. Provisioning 개요 화면에서 **Start provisioning**을 클릭하세요.

:::tip

소규모 테스트 그룹으로 먼저 시작하는 것을 권장합니다. 그룹 멤버십 변경 사항이 BioStar Air에 반영되기까지 최대 약 40분이 걸릴 수 있습니다.

:::
