장치 및 카메라 모니터링 기능을 사용하는 방법을 안내합니다. 장치와 카메라의 상태를 점검하고, 상세 정보를 확인하며, 카메라 영상을 실시간으로 재생하는 등 다양한 기능을 활용할 수 있습니다. 또한, 최근 발생한 이벤트를 확인하여 장치와 카메라의 상태를 효율적으로 관리하는 방법을 확인하세요.

<Cmd sid='arena.title' /> 페이지는 <Cmd sid='shell.header.launcher' /> 페이지에서 <Cmd sid='arena.title' />을 클릭하거나 화면 왼쪽 상단의 바로 가기 목록에서 <Cmd sid='arena.title' />을 선택하여 진입할 수 있습니다.

## 장치 및 카메라 상태 점검

화면 왼쪽 사이드바에서 <Cmd sid='arena.tree.device.title' /> 탭을 클릭하세요. 모든 장치와 카메라의 상태를 점검할 수 있습니다. 장치와 카메라의 상태는 아래를 참고하세요.

<div className='col2--20-80 overflow-x'>

| 상태 아이콘 | 설명 |
| :--: | -- |
| <IcDeviceOn width='35px' height='35px'/> | 장치가 정상 연결된 상태입니다. |
| <IcDeviceOff width='35px' height='35px' /> | 장치가 꺼져 있거나 연결이 해제된 상태입니다. |
| <IcCamOk width='auto' height='35px'/> | 카메라가 연결된 상태입니다. |
| <IcCamFail width='auto' height='35px'/> | 카메라가 꺼져 있거나 연결이 해제된 상태입니다. |

</div>

### 주의가 필요한 장치 모아보기 {/* #checkAttentionFilter */}

관리자는 조치가 필요한 장치만 한 번에 모아 볼 수 있습니다. 화면 왼쪽 사이드바의 <Cmd sid='arena.tree.door.entitiesNeedAttention' />을 클릭하세요. 장치의 상태를 확인하고, 문제가 발생한 대상에 조치를 취할 수 있습니다.

<Image src='/img/biostarx-monitoring-device-attention-filter.png' />

### 조치 대상 판정 기준

장치 트리에서 정상이 아닌 장치를 조치 대상으로 판정합니다.

| 이상 상태 종류 | 상태 표시 | 설명 |
| -- | -- | -- |
| 연결 끊김 | <Cmd sid='arena.tree.disconnected' /> | 장치와의 네트워크 연결이 끊긴 상태 |
| 동기화 오류 | <Cmd sid='arena.tree.syncError' /> | 연결은 되어 있으니 데이터 동기화가 어긋난 상태 |
| 커뮤니케이션 서버 오류 | <Cmd sid='arena.tree.communicationError' /> | 장치가 속한 커뮤니케이션 서버에서 오류가 발생한 상태 |
| 장치 잠금 | <Cmd sid='arena.tree.deviceLocked' /> | 작업 조건 및 동작에 의해 장치가 잠긴 상태 |
| 인증 실패 잠금 | <Cmd sid='arena.preview.device.authFailLockout.title' /> | 지정한 횟수 이상 인증에 실패하여 장치가 잠긴 상태 |

:::info

* <Cmd sid='arena.tree.deviceLocked' /> 조건은 <DocLink docId='platform/biostar_x/settings-triger-and-action' />에서 설정한 작업 조건 및 동작에 따라 결정됩니다. 이 상태를 확인하고 해제하는 방법은 <DocLink inner='#deviceLockRelease' />를 참고하세요.

* <Cmd sid='arena.preview.device.authFailLockout.title' /> 조건은 장치 설정에서 구성할 수 있습니다. 자세한 내용은 <DocLink docId='platform/biostar_x/settings-device-details-auth#howToAuth' />를 참고하세요. 이 상태를 확인하고 해제하는 방법은 <DocLink inner='#authFailLockout' />를 참고하세요.

:::


## 장치 제어

화면 왼쪽 사이드바의 장치 목록에서 원하는 장치를 선택하고 마우스 오른쪽 버튼을 클릭하세요. 팝업 메뉴에서 원하는 기능을 선택할 수 있습니다.

<Image src='/img/biostarx-monitoring-device-popup.png' />

### 장치 재연결

장치가 꺼져 있거나 연결이 해제된 상태인 경우, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.reconnect' />을 클릭하세요. 장치가 다시 연결되면 상태 아이콘이 <StatusOK/>로 변경됩니다.

:::info

<Cmd sid='arena.tree.contextMenu.reconnect' /> 기능은 <Cmd sid='device.info.deviceToServerConnection' product='2' /> 옵션으로 연결된 장치는 지원하지 않습니다. 장치 등록에 대한 자세한 내용은 <DocLink docId='platform/biostar_x/settings-adding-devices#setipaddress' />를 참고하세요.

:::


### 장치 재시작

장치를 재시작하려면, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.reboot' />을 클릭하세요. 


### 장치 잠금 해제 {/* #deviceLockRelease */}

관리자가 설정한 작업 조건 및 동작에 의해 장치가 잠기면, 화면 왼쪽 사이드바의 장치 이름 아래에 <Cmd sid='arena.tree.deviceLocked' /> 상태가 표시됩니다. 장치를 선택하면 화면 오른쪽 프리뷰 패널 상단에도 같은 배너가 나타납니다.

<Image src='/img/biostarx-monitoring-device-lock.png' />

* 장치가 잠금 상태일 때만 팝업 메뉴에 <Cmd sid='arena.tree.contextMenu.deviceUnlock' />가 표시됩니다. 잠금 상태를 해제하려면 잠긴 장치를 선택하고 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.deviceUnlock' />를 클릭하세요.

* 잠긴 장치를 선택하면 화면 오른쪽 프리뷰 패널 상단에 나타나는 배너에서 <Cmd sid='arena.preview.banner.unlock' /> 버튼을 클릭하세요.

:::info

<Cmd sid='arena.tree.contextMenu.deviceUnlock' /> 기능은 <Cmd sid='setting.account.administrator' /> 또는 <Cmd sid='setting.account.monitoringOperator' /> 권한이 있는 사용자에게만 표시됩니다.

:::


### 인증 실패 잠금 해제 {/* #authFailLockout */}

<Cmd sid='device.info.authFailLockout.label' product='2' /> 옵션에서 설정한 횟수 이상 인증에 실패하면 장치가 자동으로 잠깁니다.

장치가 잠기면 화면 왼쪽 사이드바의 장치 이름 아래에 <Cmd sid='arena.preview.device.authFailLockout.title' /> 상태가 표시되고, 장치를 선택하면 화면 오른쪽 프리뷰 패널 상단에도 같은 배너가 나타나며 이벤트 발생 시각과 장치 정보를 확인할 수 있습니다.

<Image src='/img/biostarx-monitoring-device-auth-fail-lock.png' />

* 장치가 인증 실패 잠금 상태일 때만 팝업 메뉴에 <Cmd sid='arena.batchResult.action.clearLockout' />가 표시됩니다. 잠긴 장치를 선택하고 팝업 메뉴에서 <Cmd sid='arena.batchResult.action.clearLockout' />를 클릭하세요.

:::info

* <Cmd sid='arena.batchResult.action.clearLockout' /> 메뉴는 <Cmd sid='setting.account.administrator' /> 또는 <Cmd sid='setting.account.monitoringOperator' /> 권한이 있는 사용자에게만 표시됩니다.

* 설정한 잠금 시간(<Cmd sid='device.info.authFailLockout.firstLockout' product='2' />/<Cmd sid='device.info.authFailLockout.secondLockout' product='2' />)이 지나면 장치가 자동으로 잠금을 해제합니다. 이때는 별도 조치 없이도 잠금 상태가 해소됩니다. 잠금 조건 및 잠금 시간 설정에 대한 자세한 내용은 <DocLink docId='platform/biostar_x/settings-device-details-auth#howToAuth' />를 참고하세요.

:::


### 작업 중지

진행 중인 작업을 중지하려면, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.stopAction' />를 클릭하세요. 화면 상단에 작업 중지 성공 메시지가 나타납니다. 작업 중지가 완료되면 메시지가 사라집니다.


### 장치 상세 보기

장치의 상세 정보를 확인하려면, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.viewDetail' />를 클릭하세요. 또는 장치를 더블 클릭하세요. 화면 오른쪽에 장치의 상세 정보가 나타납니다.

<Image src='/img/biostarx-monitoring-device-details.png' />

* **장치 제어**: 장치 작업 중지 또는 재시작, 재연결 등의 제어 기능을 실행할 수 있습니다.

* **장치 상세 정보**: 장치의 ID 및 그룹, 모델명, 기동 시간, IP 주소 등의 정보를 확인할 수 있습니다.

* <Cmd sid='arena.recentEvent' />: 선택한 장치에서 발생한 최근 이벤트 목록을 확인할 수 있습니다.


## 카메라 제어

화면 왼쪽 사이드바의 카메라 목록에서 원하는 카메라를 선택하고 마우스 오른쪽 버튼을 클릭하세요. 팝업 메뉴에서 원하는 기능을 선택할 수 있습니다.

<Image src='/img/biostarx-monitoring-camera-popup.png' />

### 카메라 영상 재생

비디오 타일에 카메라 영상을 배치하고 실시간으로 모니터링하려면, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.openVideo' />를 클릭하세요.

:::note

비디오 타일에 카메라 영상을 추가하는 방법은 아래와 같은 방식도 지원합니다.

* 화면 왼쪽 사이드바의 카메라 목록에서 영상을 재생할 카메라를 더블 클릭하세요. 

* 카메라를 비디오 타일 영역으로 드래그 앤 드롭 방식으로 영상을 추가할 수도 있습니다.

:::

:::info

* 비디오 타일에는 화면 왼쪽 상단부터 차례로 추가되며, 현재 화면에 추가할 공간이 없으면 에러 메시지가 표시됩니다.

* 영상 제어 방법 및 영상에 표시되는 도구에 대한 자세한 내용은 <DocLink docId='platform/biostar_x/monitoring-video' />를 참고하세요.

* <Cmd sid='arena.tree.device.allCameraGroups' /> 목록에서 카메라가 보이지 않는다면 카메라 그룹 권한을 확인하세요. 커스텀 권한의 관리자가 카메라 그룹 권한을 설정하지 않았다면 카메라가 보이지 않을 수 있습니다. 카메라 그룹 권한 설정에 대한 자세한 내용은 <DocLink docId='platform/biostar_x/settings-videos-camera#addCameraPermission' />를 참고하세요.

:::


### 카메라 상세 보기

카메라의 상세 정보를 확인하려면, 팝업 메뉴에서 <Cmd sid='arena.tree.contextMenu.viewDetail' />를 클릭하세요. 카메라의 그룹, 설명, 아이디와 IP 주소를 확인할 수 있습니다.

<Image src='/img/biostarx-monitoring-camera-details.png' />
