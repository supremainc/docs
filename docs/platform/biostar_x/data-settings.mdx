description: 자동 생성 스케줄을 설정했다면 리포트를 저장할 경로를 설정하세요.
keywords: [리포트 저장, 자동 생성]
---

<Cmd sid='reportApp.mainMenu.schedule' product='2' />을 설정했다면 리포트를 저장할 경로를 설정하세요.

1. <Cmd sid='reportApp.mainMenu.settings' product='2' />을 클릭하세요.

1. 리포트를 저장할 경로를 입력하세요.

    <Image src='/img/biostarx-data-settings.png' className='none' />

    * <Cmd sid='reportApp.exportReportPath' product='2' />: 지정한 경로로 리포트가 저장되며, 경로를 입력하지 않으면 사용자 PC의 *Documents\BioStarX* 폴더에 자동 저장됩니다.

    :::info

    자동 생성 리포트는 클라이언트 PC가 아닌 서버에 저장됩니다. 저장 경로를 설정할 때 입력하는 위치는 서버를 기준으로 하므로, 파일은 서버의 해당 경로에서 확인할 수 있습니다.

    :::

1. 설정을 저장하려면 <Cmd sid="reportApp.apply" product='2' />을 클릭하세요.
