:::info

장치가 최소 펌웨어 버전을 충족해도 장치 사양이나 펌웨어 버전에 따라 **BioStar X**의 일부 기능을 사용하지 못할 수 있습니다. 기능별 지원 장치와 펌웨어 버전은 각 기능 문서를 확인하세요.

:::
