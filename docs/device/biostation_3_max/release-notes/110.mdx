# 펌웨어 버전 1.1.0 (빌드 번호 1.1.0_260728)

릴리즈<Separator/>2026-07-31

## 신규 기능 및 개선

---

1. 대기화면 영상 재생 기능 지원

   :::note

   이 기능은 BioStar X에서 설정할 수 있습니다. 자세한 설정 방법은 BioStar X 가이드의 <Linkto to='platform/biostar_x/???'>대기화면에서 영상 재생 설정하기</Linkto>를 참고하세요.

   :::

1. DESFire EV2/EV3 카드에 대한 EV2 Secure Messaging 인증 및 발급 지원

1. OSDP 리더 모드에서 타사 컨트롤 패널의 출입 거부 시 'Access Denied'로 표시되도록 개선

1. BLE 동작 안정성 개선

1. 사용자 ID 및 사용자 이름의 허용 문자 확장

   * 사용자 ID에 마침표(.) 입력 지원

   * 사용자 이름에 마침표(.)와 아포스트로피(') 입력 지원

1. 근태 메시지가 두 줄로 표시되도록 개선

1. 화재 알람 발생 후 전원 재기동 시 화재 경보 구역 상태 표시 및 알람 해제 동작 개선
