# 펌웨어 버전 1.1.0 (빌드 번호 1.1.0_260728)

릴리즈<Separator/>2026-07-29

## 신규 기능 및 개선

---

<Jira num='BS3MFW-451' /> 대기화면 동영상 플레이
1. 대기화면 영상 재생 기능 지원
1. Added support for video playback on the standby screen.

  :::note

  이 기능은 BioStar X에서 설정할 수 있습니다. 자세한 설정 방법은 BioStar X 가이드의 *대기화면에서 영상 재생 설정하기*를 참고하세요.

  :::

  :::note

  This feature can be configured in BioStar X. For detailed instructions, refer to **Setting Up Video Playback on the Standby Screen** in the BioStar X guide.

  :::

<Jira num='BS3MFW-412' /> BDP-1343 Desfire EV2 and EV3 features supported by Readers and Software
1. DESFire EV2/EV3 카드에 대한 EV2 Secure Messaging 인증 및 발급 지원
1. Supported EV2 Secure Messaging authentication and issuance for DESFire EV2 and EV3 cards.

<Jira num='BS3MFW-463' />	BSF-2925BDP-1634 OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기
1. OSDP 리더 모드에서 타사 컨트롤 패널의 출입 거부 시 'Access Denied'로 표시되도록 개선
1. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

<Jira num='BS3MFW-541' />	[FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System)
1. BLE 동작 안정성 개선
1. Improved BLE stability.

(BS3MFW-562) [UI 지원 장치] 사용자 이름 및 사용자 ID에 Dot(.) 지원
1. 사용자 ID 및 사용자 이름의 허용 문자 확장
  * 사용자 ID에 마침표(.) 입력 지원
  * 사용자 이름에 마침표(.)와 아포스트로피(') 입력 지원

1. Expanded allowed characters for User ID and User Name
  * Added support for periods (.) in User ID
  * Added support for periods (.) and apostrophes (') in User Name

(BS3MFW-95)	Server / Device Private MSG관련하여 근태 표시 시 아래 이미지 처럼 표시가 되는 현상 - 1.0.0
1. 근태 메시지가 두 줄로 표시되도록 개선
1. Improved T&A message display to show on two lines.
