# 펌웨어 버전 1.5.0 (빌드 번호 1.5.0_260813)

릴리즈<Separator/>2026-08-13

:::caution

- 펌웨어가 v1.4.0인 제품을 사용하는 경우, 반드시 v1.4.1로 업그레이드한 후 사용하세요.<br/>중요한 보안 및 안정성 개선이 포함되어 있으므로, 반드시 최신 버전으로 업그레이드한 후 사용해야 합니다.

- 펌웨어를 v1.4.0 이상으로 업그레이드한 뒤 하위 버전으로 다운그레이드할 수 없습니다.

- 장치의 펌웨어 다운그레이드 가능 여부 및 신규 BLE 칩 적용 여부는 장치의 시리얼 번호를 확인한 뒤 [슈프리마 홈페이지](https://supremainc.com)에 문의하세요.

:::

## 신규 기능 및 개선

---

(BS3FW-2302) XPQ2 지원
1. 신규 장치 연결 지원
   * XPass Q2
1. Supports new device.
   * XPass Q2

(BS3FW-2257) [BDP-1480] Auth Fail Lockout(EN-60839)
1. PIN 인증 반복 실패 시 장치를 잠그는 **Auth Fail Lockout** 기능 추가
1. Added **Auth Fail Lockout** feature, which locks the device after repeated PIN authentication failures.

(BS3FW-2262) [BDP-1479] Rapid Face Authentication
1. 얼굴 인증 관련 기능 추가 및 개선
   * 얼굴 인증 성능 개선
   * 다중 얼굴 순차 인증 지원(장치 라이선스 필요)
   * 무단 동행 출입 방지(Anti-Tailgating) 지원

1. Added and improved face authentication features
   * Improved face authentication performance
   * Added support for sequential multi-face authentication (device license required)
   * Added support for Anti-Tailgating

(BS3FW-1568) [BDP-853] Slave 장치의 Baudrate 설정 기능
1. 슬레이브 장치의 전송 속도를 설정할 수 있는 기능 지원
1. Supports feature to set the baud rate of slave devices.

(BS3FW-2158) Master Admin의 크리덴셜이 2개 미만이 되었을 때 Master Admin 크리덴셜 등록 강제되도록 개선
1. **마스터 관리자**의 크리덴셜이 2개 미만일 때 재등록이 강제되도록 개선
1. Improved **Master Admin** to enforce re-enrollment when fewer than two credentials remain.

(BS3FW-2187) USB Export시 생성되는 파일명이 BioStarX_ 로 표시되도록 변경 요청
1. USB 내보내기/가져오기 파일명 처리 개선
   * USB 내보내기 시 생성되는 파일명이 BioStarX_로 시작하도록 변경
   * BioStar X에서 내보낸 파일이 가져오기 목록에 표시되지 않는 문제 개선

1. Improved USB export/import file name handling
   * Changed the file name generated during USB export to start with BioStarX_
   * Fixed Files exported from BioStar X not appearing in the import list

(BS3FW-2268) 장치에서 지원하지 않는 이벤트에 대해 "Undefined Event"로 로그가 남도록 개선
1. 장치에서 지원하지 않는 이벤트 및 에러에 대한 로그 표시 개선
1. Improved log display for unsupported events and errors on the device.

(BS3FW-2320) [UI지원모델] 인증성공 아이콘 Blue -> Green으로 변경 요청 건
1. 인증 성공 시 표시되는 아이콘 색상을 초록색으로 변경
1. Changed the authentication success icon color to green.

(BS3FW-2342) [BSF-2925][BDP-1634] OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기
1. OSDP 리더 모드에서 타사 컨트롤 패널의 출입 거부 시 'Access Denied'로 표시되도록 개선
1. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

(BS3FW-2343) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경 - 발생버전 :  V1.0.0
1. 화재 알람 발생 후 전원 재기동 시 화재 경보 구역 상태 표시 및 알람 해제 동작 개선
1. Improved zone status display and alarm clearing behavior after power restart following a fire alarm.

(BS3FW-2403) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System) - 발생버전 : V1.0.0
1. BLE 동작 안정성 개선
1. Improved BLE stability.

(BS3FW-2424) [UI 지원 장치]  사용자 이름 및 사용자 ID에 Dot(.) 지원
1. 사용자 ID 및 사용자 이름의 허용 문자 확장
   * 사용자 ID에 마침표(.) 입력 지원
   * 사용자 이름에 마침표(.)와 아포스트로피(') 입력 지원

1. Expanded allowed characters for User ID and User Name
   * Added support for periods (.) in User ID
   * Added support for periods (.) and apostrophes (') in User Name
