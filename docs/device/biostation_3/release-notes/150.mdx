# 펌웨어 버전 1.5.0 (빌드 번호 1.5.0_26XXXX)

릴리즈<Separator/>2026-08-XX

:::caution

- 펌웨어가 v1.4.0인 제품을 사용하는 경우, 반드시 v1.4.1로 업그레이드한 후 사용하세요.<br/>중요한 보안 및 안정성 개선이 포함되어 있으므로, 반드시 최신 버전으로 업그레이드한 후 사용해야 합니다.

- 펌웨어를 v1.4.0 이상으로 업그레이드한 뒤 하위 버전으로 다운그레이드할 수 없습니다.

- 장치의 펌웨어 다운그레이드 가능 여부 및 신규 BLE 칩 적용 여부는 장치의 시리얼 번호를 확인한 뒤 [슈프리마 홈페이지](https://supremainc.com)에 문의하세요.

:::

## 신규 기능 및 개선

---

BS3FW-1568 : Slave 장치 Baudrate 설정 기능 지원
1. 슬레이브 장치의 전송 속도를 설정할 수 있는 기능 지원
1. Supports feature to set the baud rate of slave devices.

BS3FW-2158 : Master Admin Credential이 2개 미만일 경우 Credential 등록 강제하도록 개선
1. **마스터 관리자**의 크리덴셜이 2개 미만일 때 재등록이 강제되도록 개선
1. Improved **Master Admin** to enforce re-enrollment when fewer than two credentials remain.

BS3FW-2320 : 인증 성공 아이콘 색상 Blue → Green 변경
1. 인증 성공 시 표시되는 아이콘 색상을 초록색으로 변경
1. Changed the authentication success icon color to green.

BS3FW-2295 : EV2 Secure Messaging 지원 Master를 미지원 버전으로 다운그레이드 시 Slave 카드 인증 불가 문제 수정

BS3FW-2301 : EV2 SM 활성 + Wiegand Bypass 환경에서 EV1 카드 CSN 전달 문제 수정

BS3FW-2332 : iPhone iOS 26 업그레이드 후 Airfob Pass 출입 불가 문제 수정

BS3FW-2341 : Wiegand Reader에서 카드 전용 사용자 인증 시 Authentication Fail (Invalid Credential) 발생 문제 수정
