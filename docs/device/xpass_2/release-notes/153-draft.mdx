# 펌웨어 버전 1.5.3 (빌드 번호 1.5.3_260802)

릴리즈<Separator/>2026-08-07

:::caution

- 펌웨어 v1.5.1 이상이 설치된 장치는 v1.5.1 미만 버전으로 다운그레이드할 수 없습니다.

- XP2-MAPB-H 모델은 v1.4.3 미만 버전으로 다운그레이드할 수 없습니다.

- 하드웨어 v1.2.0 이상의 XP2-GKDPB 모델은 v1.4.3 미만 버전으로 다운그레이드할 수 없습니다. 하드웨어 버전은 BioStar 2의 **장치** 메뉴에서 확인할 수 있습니다.

- 신규 BLE 칩이 적용된 장치는 v1.3.1 미만 버전으로 다운그레이드할 수 없습니다. 기존 BLE 칩이 적용된 장치에는 이 제한이 적용되지 않습니다.

장치의 펌웨어 다운그레이드 가능 여부 및 신규 BLE 칩 적용 여부는 장치의 시리얼 번호를 확인한 뒤 [슈프리마 홈페이지](https://supremainc.com)에 문의하세요.

:::


## 신규 기능 및 개선

---

(XPASSII-707) [BDP-1593] 출입문 Toggle
1. 사용자 인증을 통해 출입문을 수동 개방하거나 해제 상태로 전환하는 기능 추가
1. Added support for unlocking or normalizing a door through user authentication.

(XPASSII-562) [BDP-1561] Extended Door Open Time
1. 특정 사용자에게 기본 출입문 열림 시간보다 더 긴 시간 동안 출입문이 열리도록 하는 **연장된 출입문 열림 시간** 기능 지원
1. Supports the **Extended Door Open Time** feature, which allows certain users to have the door remain open longer than the default door open time.

(XPASSII-708) [BDP-1592] Door Unlock/Lock Improvement
1. 모니터링에서 출입문 제어 상태와 변경 정보를 정확하게 확인하도록 개선
1. Improved door control status to accurately display control results and change details in monitoring.

(XPASSII-561) [BDP-962] Realtime Status of all devices connected to BSX
1. BioStar X에서 장치의 여러 상태를 실시간으로 확인할 수 있도록 지원
1. Supports real-time monitoring of the device's multiple statuses in BioStar X.

(XPASSII-705) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경
1. 화재 알람 발생 후 전원 재기동 시 화재 경보 구역 상태 표시 및 알람 해제 동작 개선
1. Improved zone status display and alarm clearing behavior after power restart following a fire alarm.

(XPASSII-711) [FIMA-212] XPASS D2 BLE 이슈 (Up2 Code System)
1. BLE 동작 안정성 개선
1. Improved BLE stability.

(XPASSII-558) [BDP-990] Relay가 Lock되었을 때 인증 실패 처리하기
1. **수동 잠김**으로 설정된 출입문에 인증 시 인증 실패 이벤트가 발생하고 상태 메시지가 표시되도록 개선
1. Improved so that when authentication is attempted on a door set to **Manual Lock**, an authentication failure event occurs and a locked message appears.
