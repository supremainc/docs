# 펌웨어 버전 2.3.0 (빌드 번호 2.3.0_260731)

릴리즈<Separator/>2026-08-04

:::caution

신규 SE 프로세서가 적용된 장치의 경우 펌웨어를 v2.1.0 이상으로 업그레이드한 뒤 하위 버전으로 다운그레이드할 수 없으며, 하위 버전에서 커스터마이징한 펌웨어도 다운그레이드할 수 없습니다.

기존 SE 프로세서가 적용된 장치는 하위 버전으로 다운그레이드할 수 있습니다.

장치의 신규 SE 프로세서 적용 여부 및 펌웨어 다운그레이드 가능 여부는 장치의 시리얼 번호를 확인한 뒤 [슈프리마 홈페이지](https://supremainc.com)에 문의하세요.

:::

## 신규 기능 및 개선

---

(DFW-1216) [BDP-1239] Lock Override(=Fireman's Card) 지원
1. 비상 시 특정 카드를 사용하여 출입문을 개방할 수 있는 **비상 개방 카드** 기능 지원
1. Supports the **Lock Override** feature, which allows you to enroll a card that can open a door to be opened using a specific card.

(DFW-1218) [BDP-962] Real Time Status of all devices connected to BioStar X
1. BioStar X에서 장치의 여러 상태를 실시간으로 확인할 수 있도록 지원
1. Supports real-time monitoring of the device's multiple statuses in BioStar X.

(DFW-1219) [BDP-953] Alternate Access Timer
1. 특정 사용자에게 기본 출입문 열림 시간보다 더 긴 시간 동안 출입문이 열리도록 하는 **연장된 출입문 열림 시간** 기능 지원
1. Supports the **Extended Door Open Time** feature, which allows certain users to have the door remain open longer than the default door open time.

(DFW-1221) [BDP-956] 서버 관리자가 출입문을 일정 시간 동안만 Locked/Unlocked로 제어할 수 있는 기능 (Door Mode Override)
1. 관리자가 출입문의 상태를 변경한 뒤 일정 시간이 지나면 출입문을 보통 상태로 복구하는 **출입문 모드 우회** 기능 지원
1. Supports the **Door Mode Override** feature, which restores the door to its normal state after the administrator changes the door status and a certain period of time has elapsed.

(DFW-1222) [BDP-954] Door control on device
1. 장치의 메뉴에서 연결된 출입문의 릴레이를 제어할 수 있도록 지원
1. Supports controlling the relay of a connected door from the device menu.

(DFW-1283) [BDP-1593] 출입문 Toggle
1. 사용자 인증을 통해 출입문을 수동 개방하거나 해제 상태로 전환하는 기능 추가
1. Added support for unlocking or normalizing a door through user authentication.

(DFW-1209) [BDP-990] Relay 가 Locked 되어 있을 때, 인증 시 인증 실패 처리하기
1. **수동 잠김**으로 설정된 출입문에 인증 시 인증 실패 이벤트가 발생하고 상태 메시지가 표시되도록 개선
1. Improved so that when authentication is attempted on a door set to **Manual Lock**, an authentication failure event occurs and a locked message appears.

(DFW-1279) [BSF-2925][BDP-1634] OSDP 연동 시 CP 로부터 인증 실패 LED CMD 를 전송받으면 Access Denied 로 표시하기
1. OSDP 리더 모드에서 타사 컨트롤 패널의 출입 거부 시 'Access Denied'로 표시되도록 개선
1. Improved OSDP reader mode to display "Access Denied" when access is denied by a third-party control panel.

(DFW-1295) [BDP-1592] Door Lock/Unlock Control Improvement
1. 모니터링에서 출입문 제어 상태와 변경 정보를 정확하게 확인하도록 개선
1. Improved door control status to accurately display control results and change details in monitoring.

(DFW-1310) [FIMA-212] XPASS D2 BLE 이슈
1. BLE 동작 안정성 개선
1. Improved BLE stability.

(DFW-1339) [UI 지원 장치] 사용자 이름 및 사용자 ID에 Dot(.) 지원
1. 사용자 ID 및 사용자 이름의 허용 문자 확장
   * 사용자 ID에 마침표(.) 입력 지원
   * 사용자 이름에 마침표(.)와 아포스트로피(') 입력 지원

1. Expanded allowed characters for User ID and User Name
   * Added support for periods (.) in User ID
   * Added support for periods (.) and apostrophes (') in User Name

(DFW-1280) Fire Alarm Zone 상태를 메모리에 바로 쓰도록 변경
1. 화재 알람 발생 후 전원 재기동 시 화재 경보 구역 상태 표시 및 알람 해제 동작 개선
1. Improved Fire alarm zone status display and alarm clearing behavior after power restart following a fire alarm.
